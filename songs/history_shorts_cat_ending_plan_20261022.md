# 고양이 1분 컷 엔딩 기획 — 10곡 모두 다른 "인간계로 가자냥!" (2026-10-22)

고양이 간략본 10곡의 끝에 **8초짜리 엔딩**을 붙입니다. 엔딩은 **곡마다 모두 다릅니다.**
목표는 한 가지입니다. **1분 컷을 다 본 아이가 3~4분짜리 전곡(인간계 버전)을 이어서 누르게 하는 것.**

---

## 1. 공통 약속 (10곡 모두 같은 것)

> 고양이들은 **냥계**에 삽니다. 냥계에서는 역사를 1분 만에 "맛보기"로만 배워요.
> 연도를 **전부** 외우려면 **인간계**에 있는 **전곡**을 들어야 합니다.

| 약속 | 내용 |
|---|---|
| 길이 | 노래 끝 + **8초** |
| 냥력 마스터 게이지 | 화면 위쪽, 발바닥 칸이 차오르다 **30%**에서 "띵!" 멈춤 (제가 영상 프로그램으로 그림) |
| 인간계로 가는 길 | 곡마다 모양이 다름 (동굴 구멍, 벌집, 돌다리, 우체통…). 그 너머로 **전곡 영상의 대표 그림**이 보임 |
| 마지막 2초 | 화면 **오른쪽 절반은 비움** → 유튜브 최종 화면의 전곡 카드 자리 |
| 마지막 자막 | "○ ○○ 연도 암기송 3:52 → 들으러 가자냥!" |

**곡마다 다른 것**: 그림 2장(E1·E2), 엔딩 대사, 엔딩 소리(Suno), 게이지가 멈추는 방식.

| 시간 | 내용 |
|---|---|
| 0~2초 | **E1 그림** + 곡마다 다른 "1분이 끝났다!" 개그 |
| 2~4초 | 게이지 0% → 30% (곡마다 다른 방식으로 멈춤) |
| 4~6초 | **E2 그림** — 곡마다 다른 "인간계로 가는 길"이 열림 |
| 6~8초 | 인간계 길 너머에 전곡 그림 + 마지막 자막 + 최종 화면 카드 |

## 3. 제가 할 일 (그림과 소리를 받으면)

1. **냥력 마스터 게이지**를 곡마다 다른 방식(도끼질, 꿀, 돌다리, 박수, 별, 율동, 커튼, 말발굽)으로 움직이게 영상 프로그램에 넣습니다.
2. 각 E2 그림의 빛나는 문 안쪽에 **그 시대 전곡 영상의 대표 그림**을 합성합니다.
3. 엔딩 소리 8초를 노래 끝에 0.3초 겹쳐 이어 붙입니다.
4. 업로드 정보 문서에 **최종 화면 설정 방법**을 넣습니다. 전곡 영상 카드는 오른쪽 문 자리에, 구독 버튼은 아래쪽에 둡니다.
5. 설명란 맨 위에 **"🐾 전곡(인간계 버전) 보러 가기 → [링크]"**를 넣습니다.

> 엔딩 소리가 마음에 안 들면, 효과음과 마지막 화음만으로 제가 소리를 만들어 붙일 수도 있습니다.
