# 고려 전기 연도 암기송! 918~1145 — Suno 제작 문서 (2026-10-05)

고려 전기(고려 건국부터 삼국사기 편찬까지)의 **연도와 사건을 짝지어** 랩으로 외우는 곡입니다.
조선 전기·조선 후기·근현대사 암기송과 같은 형식입니다. 영상도 같은 방법(장면 그림 3장씩, 싱크 프로그램)으로 만들 수 있습니다.

| 항목 | 내용 |
|---|---|
| 곡 제목 | 고려 전기 연도 암기송! 918~1145 |
| 대상 | 초등 고학년 (5~6학년 사회), 중학생 역사 |
| 목표 | 연도 10개와 사건 10개를 짝지어 암기 (+ 연도 없이 외우는 왕 업적 2개) |
| 스타일 | **레게 + 랩** (레게 힙합, 원드롭 리듬, 90 BPM). 절은 랩, 훅은 레게 가락으로 따라 부르기 쉽게 |

**노비안검법**
956년

958년

1107년

**이자겸의 난**
1126년

1135년

## 2. 암기 설계

### 2-1. 장치

| 장치 | 어디에 | 왜 효과가 있나 |
|---|---|---|
| **연도만 이어 부르는 레게 훅** | "구일팔! 구삼육! / 오육 오팔 구구삼! …" | 900년대와 1100년대를 끊어서 외웁니다. 레게의 느긋한 뒷박에 연도가 하나씩 또렷하게 얹힙니다 |
| **"연도 + 사건" 한 줄 공식** | 모든 절 "구일팔 고려 건국, …" | 연도와 사건이 한 덩어리로 붙습니다 |
| **4덩어리** | 1절 태조 / 2절 광종·성종 / 3절 거란·여진 / 4절 문벌 귀족 | 왕 이름·나라 이름이 사건을 묶는 상자가 됩니다 |
| **양방향 퀴즈** | 브리지 "구구삼?" → "서희 외교 담판!" / "귀주 대첩은?" → "일공일구!" | 연도 → 사건, 사건 → 연도 둘 다 연습합니다 |
