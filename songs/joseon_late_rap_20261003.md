## 1. 외울 연표

**대동법 실시**
1608년
광해군 때 경기도에서 처음 실시하여, 집집마다 특산물로 내던 공납을 토지의 넓이에 따라 쌀 등으로 내게 했습니다. 숙종 때 전국으로 확대되었습니다.

**정묘호란**
1627년
후금이 조선에 쳐들어온 전쟁입니다.

**병자호란**
1636년
나라 이름을 바꾼 청이 다시 쳐들어오자 인조는 남한산성으로 피란하여 맞섰으나, 결국 청에 항복했습니다.

**상평통보 유통**
1678년
숙종 때 상평통보를 공식 화폐로 정하여 전국에 유통시켰습니다. 상업이 발달하는 바탕이 되었습니다.

**백두산정계비 건립**
1712년
숙종 때 청과 국경을 정하고 백두산에 비석을 세웠습니다.

**탕평책**
영조·정조 때
영조와 정조는 붕당 사이의 다툼을 줄이기 위해 여러 붕당의 인재를 고르게 등용하는 탕평책을 펼쳤습니다.

**균역법 실시**
1750년
영조는 백성이 내던 군포를 2필에서 1필로 줄여 주었습니다.

**규장각 설치**
1776년
정조는 즉위한 해에 규장각을 설치하여 학문을 연구하고 인재를 길렀습니다.

**실학**
조선 후기
현실 문제를 해결하려는 학문으로, 유형원·이익·정약용·박지원·박제가 등이 농업과 상공업의 개혁을 주장했습니다.

**수원 화성 완성**
1796년
정조가 수원에 화성을 쌓았습니다. 정약용이 설계하고 거중기를 사용해 공사 기간을 줄였습니다.

**홍경래의 난**
1811년
정조가 죽은 뒤 세도 정치로 정치가 어지러워진 가운데, 평안도 지역에 대한 차별과 수탈에 맞서 홍경래가 일으킨 봉기입니다.

**동학 창시**
1860년
최제우가 서학(천주교)에 맞서 동학을 만들었습니다. 모든 사람이 평등하다고 가르쳤습니다.

**임술 농민 봉기**
1862년
삼정(전정·군정·환곡)의 문란에 맞서 진주에서 시작되어 전국으로 퍼진 농민 봉기입니다.

**흥선대원군 집권**
1863년
고종이 어린 나이에 왕위에 오르자 아버지 흥선대원군이 나라의 실권을 잡았습니다.

## 2. 암기 설계

### 2-1. 다섯 가지 장치

| 장치 | 어디에 | 왜 효과가 있나 |
|---|---|---|
| **세기별 4개씩 훅** | "일육! 공팔 이칠 삼육 칠팔! / 일칠! 일이 오공 칠육 구육! / 일팔! 일일 육공 육이 육삼!" | 1600년대·1700년대·1800년대가 **딱 4개씩**. 세 줄만 외우면 12개 연도가 끝납니다 |
| **"연도 + 사건" 한 줄 공식** | 모든 절 "일육공팔 대동법, …" | 연도를 읽으면 사건이 붙어 나옵니다 |
| **왕별 4덩어리** | 1절 광해군·인조(전쟁) / 2절 숙종·영조 / 3절 정조 / 4절 세도 정치~고종 | 왕 이름이 사건을 묶는 상자 역할을 합니다 |
| **연도 없는 개념은 왕에 붙이기** | 탕평책은 영조 절, 실학은 정조 절 | 연도는 없지만 시험에 자주 나오는 개념을 왕과 함께 외웁니다 |
| **양방향 퀴즈** | 브리지 "일육삼육?" → "병자호란!" / "균역법은?" → "일칠오공!" | 연도 → 사건, 사건 → 연도 둘 다 연습합니다 |

### 2-2. 훅에 숨겨 둔 연도 규칙

| 규칙 | 연도 | 외우는 말 |
|---|---|---|
| 호란 둘은 9년 차이 | 1627 → 1636 | "이칠 삼육." 정묘는 후금, 병자는 청 |
| 정조는 칠육에 시작, 구육에 화성 | 1776 → 1796 | 끝자리가 둘 다 "육". 20년 차이 |
| **1800년대 끝 셋이 연달아** | 1860 → 1862 → 1863 | "육공 육이 육삼." 동학, 봉기, 대원군 |
| **근현대사 랩으로 바로 연결** | 1863 → 1866 | 대원군 집권(육삼) 3년 뒤 병인양요(육육). 근현대사 랩 첫 연도입니다 |

### 2-3. 헷갈리는 짝 구분법

| 헷갈리는 것 | 구분법 |
|---|---|
| 정묘호란 vs 병자호란 | **정묘(1627)는 후금, 병자(1636)는 청.** 후금이 나라 이름을 청으로 바꿨습니다. 남한산성은 병자호란 |
| 대동법 vs 균역법 | **대동법은 공납(특산물) → 쌀**, 광해군 1608. **균역법은 군포 2필 → 1필**, 영조 1750 |
| 영조 vs 정조 | 둘 다 탕평책. **영조는 균역법, 정조는 규장각과 수원 화성** |
| 홍경래의 난 vs 임술 농민 봉기 | **홍경래(1811)는 평안도**, **임술(1862)은 진주에서 시작해 전국** |
| 동학 창시 vs 동학 농민 운동 | **창시는 1860 최제우**, 농민 운동은 1894 전봉준 (근현대사 랩) |

### 2-4. 보너스: 12지·다른 곡과 이어지는 연도 이름

| 사건 | 연도 | 그해 이름 | 그해의 띠 | 다른 곡과의 고리 |
|---|---|---|---|---|
| **정묘**호란 | 1627 | 정묘년 | 토끼 | — |
| **병자**호란 | 1636 | 병자년 | 쥐 | 240년 뒤 1876 강화도 조약도 **병자**년 (병자수호조약) |
| 홍경래의 난 | 1811 | **신미**년 | 양 | 60년 뒤 1871 **신미**양요 |
| **임술** 농민 봉기 | 1862 | 임술년 | 개 | — |

> 육십갑자는 60년마다 같은 이름이 돌아옵니다. 1811 신미 → 1871 신미, 1636 병자 → 1876 병자(240년 = 60×4).
> 본 가사에는 넣지 않았고 공부 보조용입니다.

## 6. 생성 체크리스트

### 6-1. 생성 전

- [ ] Custom 모드 켜기
- [ ] Title, Style, Exclude, Lyrics 네 칸 다 채우기
- [ ] 연도는 모두 한글로 ("1636" ✕ → "일육삼육" ○)
- [ ] "2필", "1필"은 "두 필", "한 필"로 (가사에 이미 반영)

### 6-2. 생성 후 고르는 기준

4~6개를 생성하고 아래 순서로 거릅니다. **1번에서 떨어지면 나머지는 볼 필요 없습니다.**

| 순위 | 확인할 것 | 탈락 기준 |
|---|---|---|
| 1 | **훅의 연도 12개가 순서대로 다 들리는가** | 하나라도 빠지거나 바뀌면 탈락 |
| 2 | **절마다 연도와 사건이 짝이 맞는가** | Suno가 단어를 바꿔 부르면 탈락 |
| 3 | 어려운 단어가 또렷한가 | "정묘호란", "상평통보", "백두산정계비", "균역법", "규장각", "임술"이 뭉개지면 탈락 |
| 4 | 4절이 끝까지 다 나오는가 | 줄을 건너뛰면 탈락 |
| 5 | 브리지 묻고 답하기가 구분되는가 | 섞이면 아쉬움 |
| 6 | 길이 3분 30초~4분 10초 | 길면 Outro 잘라내기 |

### 6-3. 문제가 생겼을 때

| 증상 | 고치는 법 |
|---|---|
| 연도가 뭉개짐 | BPM 85로 낮추거나 D 스타일. 연도 사이에 쉼표: `일육, 공팔` |
| 훅 한 줄에 연도 4개가 너무 빠름 | 훅을 6줄로 쪼개기: `일육! 공팔 이칠!` / `삼육 칠팔!` … |
| "백두산정계비"를 다르게 읽음 | `백두산 정계비`로 띄어 쓰기 |
| 4절 가사가 잘림 | 4절을 둘로 나누기: `[Verse 4]`(홍경래·동학) / `[Verse 4b]`(임술·대원군) |
| 노래로 불러 랩이 안 됨 | Style 맨 앞 `rap only, no singing` 확인 |
| 곡이 중간에 끝남 | Extend로 이어 붙이거나, 1~2절과 3~4절을 따로 생성 |
