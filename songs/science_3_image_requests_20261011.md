# 3학년 과학송 4곡 — ChatGPT 그림 의뢰 스크립트

곡마다 **새로 그릴 그림 12장**입니다(이미 받은 그림 12장은 그대로 씁니다). 4곡 모두 48장입니다.

**쓰는 법**
1. 곡마다 ChatGPT에서 **새 대화**를 엽니다.
2. **메시지 0**(공통 규칙)을 먼저 보내고, 메시지 4개를 차례로 하나씩 보냅니다. 메시지 하나에 그림 3장입니다.
3. 받은 그림을 메시지에 적힌 파일 이름(예: `03a.png`)으로 저장합니다.
4. 곡마다 압축해서 올려 주세요. 압축 파일 이름에 **과학3-1상 / 과학3-1하 / 과학3-2상 / 과학3-2하**를 넣어 주세요.

> ChatGPT가 한 번에 한 장만 그리면 "다음 장 그려 줘"라고 보내면 이어서 그립니다. 그림에 글자가 들어가면 "글자는 지우고 다시 그려 줘"라고 보내세요.

```
[과학3-2하 01] 고체와 액체 관찰
핵심: 고체는 손으로 잡을 수 있고 모양과 부피가 일정함(나무 막대, 플라스틱 막대, 돌). 액체는 흐르고 그릇에 따라 모양이 변함(물, 주스, 우유). 액체의 부피는 눈금 실린더로 잼.

아래 장면을 한 장씩 차례로 그려 줘. 공통 규칙(화풍, 정확성, 가로 1536×1024, 글자 없음)을 꼭 지키고,
그림을 줄 때마다 답장 글 첫 줄에 파일 이름을 적어 줘. 그림 안에는 글자를 넣지 마.

■ 01a.png (손으로 잡는 고체)
실험 책상 위에 나무 막대, 플라스틱 막대, 돌멩이, 쇠구슬이 놓여 있고 과학이가 나무 막대를 손으로 꼭 쥐어 들어 보인다.

■ 01b.png (흘러내리는 액체)
차차가 투명한 주전자로 물을, 과학이가 주스 병으로 오렌지 주스를 투명 그릇에 붓고 있다. 옆 컵에는 하얀 우유. 흘러내리는 물줄기가 잘 보이게.

■ 01c.png (눈금 실린더 읽기)
눈금 실린더 속 파란 물의 수면을 아주 가까이. 차차가 몸을 낮춰 수면과 눈높이를 맞춰 읽고 있다. 눈금은 가로줄만, 숫자 없이.

```

### 메시지 04 — 공기의 이동과 주변 물질 분류

```
[과학3-2하 04] 공기의 이동과 주변 물질 분류
핵심: 주사기를 밀면 공기가 관을 따라 이동함. 우리 주변 물질을 고체·액체·기체로 분류함.

아래 장면을 한 장씩 차례로 그려 줘. 공통 규칙(화풍, 정확성, 가로 1536×1024, 글자 없음)을 꼭 지키고,
그림을 줄 때마다 답장 글 첫 줄에 파일 이름을 적어 줘. 그림 안에는 글자를 넣지 마.

■ 04a.png (주사기로 공기 옮기기)
투명한 관으로 연결된 주사기 두 개. 과학이가 한쪽 주사기를 밀자 반대쪽 주사기의 손잡이가 밀려 나온다. 관 속 공기의 이동을 옅은 화살표로.

■ 04b.png (고체·액체·기체로 나누기)
교실 바닥에 바구니 세 개: 왼쪽 바구니에 책·지우개·연필(고체), 가운데 바구니에 물병·우유팩·주스병(액체), 오른쪽 바구니에는 공기로 빵빵한 풍선들(기체). 과학이와 차차가 물건을 나누어 담는다.

■ 04c.png (보이지 않는 공기)
바람 부는 운동장에서 차차가 비눗방울을 불고, 과학이가 손에 든 바람개비가 빙글빙글 돈다. 공기는 안 보이지만 움직임으로 느껴지는 장면.

```

### 메시지 05 — 소리가 나는 물체는 떨려요

```
[과학3-2하 05] 소리가 나는 물체는 떨려요
핵심: 소리가 나는 물체는 떨림. 목에 손을 대고 말하면 떨림이 느껴지고, 소리 나는 소리굽쇠를 물에 대면 물이 튐.

아래 장면을 한 장씩 차례로 그려 줘. 공통 규칙(화풍, 정확성, 가로 1536×1024, 글자 없음)을 꼭 지키고,
그림을 줄 때마다 답장 글 첫 줄에 파일 이름을 적어 줘. 그림 안에는 글자를 넣지 마.

■ 05a.png (목에 손을 대고)
차차가 목에 손을 살짝 대고 노래를 부르고 있다. 목 둘레에 떨림을 나타내는 작은 진동 선. 과학이가 따라 해 본다.

■ 05b.png (소리굽쇠와 물)
고무망치로 친 소리굽쇠를 물이 담긴 그릇에 대자 물방울이 사방으로 튀어 오르는 순간을 아주 가까이.

■ 05c.png (스피커 위 좁쌀)
작은 스피커 위에 얇은 비닐을 씌우고 좁쌀을 올렸다. 음악이 나오자 좁쌀이 통통 튀어 오른다. 스피커 둘레에 진동 선.

```

### 메시지 07 — 소리의 전달과 반사

```
[과학3-2하 07] 소리의 전달과 반사
핵심: 소리는 고체(책상), 액체(물), 기체(공기)를 통해 전해짐. 딱딱한 물체는 소리를 잘 반사하고 부드러운 스펀지는 잘 반사하지 않음.

아래 장면을 한 장씩 차례로 그려 줘. 공통 규칙(화풍, 정확성, 가로 1536×1024, 글자 없음)을 꼭 지키고,
그림을 줄 때마다 답장 글 첫 줄에 파일 이름을 적어 줘. 그림 안에는 글자를 넣지 마.

■ 07a.png (책상에 귀를 대고)
과학이가 교실 책상에 귀를 바짝 대고, 책상 반대쪽 끝에서 차차가 연필로 책상을 톡톡 두드린다. 책상을 따라 진동 선이 과학이 귀까지 이어진다.

■ 07b.png (물속에서 듣는 소리)
수영장 물속 단면. 물안경을 쓴 과학이가 물속에 잠겨 있고, 물 밖에서 차차가 물에 담근 종을 흔든다. 물속으로 동그란 물결선이 퍼져 과학이에게 닿는다.

■ 07c.png (딱딱한 판과 스펀지 비교)
화면을 반으로 나눈 비교. 왼쪽: 소리 물결선이 단단한 나무판에 부딪혀 진하게 되돌아온다. 오른쪽: 같은 물결선이 폭신한 스펀지에 부딪혀 대부분 사라지고 아주 옅게만 되돌아온다.

```
