## 1. 외울 내용

| 절 | 핵심 내용 |
|---|---|
| 물질의 상태 ① | 나무 막대, 돌멩이, 손으로 잡을 수 있는 고체 / 그릇이 바뀌어도 모양과 부피는 그대로 / 물, 주스, 우유는 흘러내리는 액체 / 그릇 따라 모양이 바뀌어도 부피는 그대로 / 눈금 실린더로 재 보면 처음과 똑같아 |
| 물질의 상태 ② | 눈에 보이지 않는 공기는 기체 / 컵을 거꾸로 물에 넣으면 공기가 공간을 차지해 / 주사기를 밀면 공기가 이동해서 풍선이 부풀어 / 기체는 그릇을 가득 채워 / 공기를 넣은 공이 더 무거워, 공기도 무게가 있어 / 우리 주변 물질은 고체, 액체, 기체 |
| 소리의 성질 ① | 소리가 나는 물체는 떨려 / 목에 손을 대고 말하면 떨림이 느껴져 / 소리굽쇠를 물에 대면 물이 튀어 올라 / 세게 치면 큰 소리, 약하게 치면 작은 소리, 소리의 세기 / 실로폰 짧은 음판은 높은 소리, 긴 음판은 낮은 소리, 소리의 높낮이 |
| 소리의 성질 ② | 소리는 고체, 액체, 기체를 타고 전해져 / 책상에 귀를 대도 들리고, 물속에서도 들려 / 실 전화기는 실이 팽팽해야 잘 들려 / 딱딱한 물체에 부딪히면 소리가 되돌아와, 소리의 반사 / 부드러운 스펀지는 소리를 잘 반사하지 않아 / 메아리도 반사, 방음벽과 이중창으로 소음을 줄여 |

후렴은 **단원 이름 + 한 줄 요약**입니다: 셋, 물질의 상태! / 고체, 액체, 기체! / 넷, 소리의 성질! / 떨림, 세기, 높낮이, 반사!
