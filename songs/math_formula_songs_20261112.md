# 초등 수학 공식송 — 4학년 · 5학년 지금 진도 (2026-11-12)

> 앞서 드린 `math_songs_plan_20261112.md`를 **지금 진도 + 공식 외우기 + 3분 이내**에 맞춰 다시 짠 판입니다. Suno에는 이 문서의 스크립트를 쓰세요.

## 1. 진도 확인

2026년 판 여러 교재 목차에서 확인한 2학기 단원 순서입니다 (2022 개정, 출판사 공통).

| 학년 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 4학년 2학기 | 분수의 덧셈과 뺄셈 | 삼각형 | 소수의 덧셈과 뺄셈 | **사각형** | **꺾은선그래프** | **다각형** |
| 5학년 2학기 | 수의 범위와 어림하기 | 분수의 곱셈 | 합동과 대칭 | **소수의 곱셈** | **직육면체** | **평균과 가능성** |

- 11월 중순~12월은 보통 **4단원 끝 ~ 6단원**을 배웁니다. 그래서 두 곡 모두 **4·5·6단원**만 담았습니다. (지금 배우는 것 + 곧 배울 것 + 기말 범위)
- ⚠️ 달별 진도표는 찾지 못했습니다. 위 시기는 "6단원을 한 학기에 고르게 나눈" 추정이고, 학교마다 1~2주 차이가 납니다. **아이가 지금 몇 단원을 배우는지** 알려 주시면 그 단원을 맨 앞·후렴으로 옮기겠습니다.

## 2. 만드는 원칙

1. **공식 한 줄 = 노래 한 줄.** 공식을 그대로 가사로 (예: "평균은, 모두 더해서 개수로 나누기!")
2. **공식마다 두 번씩.** 선창 → 아이들 따라 외치기. 후렴은 그 곡에서 **가장 중요한 공식 하나**.
3. **3분 이내** (목표 2분 30초). 인트로 대사 한 줄, 퀴즈 2문제만.
4. 화면에는 **공식 카드**가 뜹니다 (아래 표). 도형·그래프는 제가 프로그램으로 정확히 그립니다.

## 3. 4학년 2학기 — 「사각형 공식송」

### 화면에 뜨는 공식 카드

| 번호 | 공식 |
|---|---|
| ① | 수직 = 두 직선이 **직각**으로 만남 / 평행 = **만나지 않는** 두 직선 |
| ② | 사다리꼴 = 평행한 변이 **한 쌍이라도** 있는 사각형 |
| ③ | 평행사변형 = 마주 보는 **두 쌍**의 변이 평행 |
| ④ | 평행사변형: 마주 보는 변·각이 같다 / **이웃한 두 각의 합 = 180°** |
| ⑤ | 마름모 = **네 변의 길이가 모두 같은** 사각형 |
| ⑥ | 직사각형 = 네 각이 모두 직각 / 정사각형 = 네 변 같고 네 각 직각 |
| ⑦ | 꺾은선그래프 = **변화**를 볼 때 / 필요 없는 부분은 **물결선** |
| ⑧ | 정다각형 = 변의 길이와 각의 크기가 **모두 같은** 다각형 |
| ⑨ | 대각선 개수: 삼각형 0 · 사각형 2 · 오각형 5 · 육각형 9 |

**Title**
```
사각형 공식송 | 4학년 2학기 수학
```

**Style of Music**
```
upbeat Korean kids pop chant, 126 BPM, handclaps, bright synth, funky bass, short punchy lines, call-and-response with kids choir, every line very clear Korean diction, educational, 2 minutes 30 seconds, no long intro
```

**Exclude Styles**
```
slow, ballad, sad, dark, heavy metal, autotune, mumble, long intro, long outro
```

## 4. 5학년 2학기 — 「육·십이·팔 공식송」

### 화면에 뜨는 공식 카드

| 번호 | 공식 |
|---|---|
| ① | 소수의 곱셈 = 자연수처럼 곱하고, **소수점 아래 자리 수를 더한 만큼** 소수점 찍기 (0.3 × 0.4 = 0.12) |
| ② | 직육면체 = 직사각형 6개 / 정육면체 = 정사각형 6개 |
| ③ | **면 6 · 모서리 12 · 꼭짓점 8** |
| ④ | 밑면 = 서로 **평행**한 두 면 / 옆면 = 밑면과 **수직**인 면 4개 |
| ⑤ | 겨냥도: 보이는 모서리 **실선** 9개, 안 보이는 모서리 **점선** 3개 |
| ⑥ | **평균 = 자료의 값을 모두 더한 수 ÷ 자료의 수** |
| ⑦ | 가능성: 불가능하다 **0** · 반반이다 **1/2** · 확실하다 **1** |
