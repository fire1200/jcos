# 지리송 기획안 v3 — 「츄르 도둑을 잡아라!」 2곡판 (2026-10-31)

> v2(권역별 6편 + 총정리)를 **음원 2개**로 줄인 판입니다. 이야기·대답 타임·패러디·도장 모으기는 그대로 살리고, 2곡이 **한 이야기의 1부·2부**가 되게 묶었습니다.

| | 1곡 | 2곡 |
|---|---|---|
| 제목(가제) | **냥팡을 쫓아라! 전국 시·도 추격송** | **냥팡을 쫓아라! 옛 지도 고개 넘기송** |
| 배우는 것 | 시·도 이름·위치·종류 + 도청(행정 중심지) | 옛 지방 이름(경기·관동·관서·관북·해서·호서·호남·영남·기호) + 영동·영서 |
| 지도 | **지금 지도** (파란 계열) | **옛 지도** (한지 느낌 갈색 계열, 한반도 전체) |
| 멜로디 (저작권 끝난 곡) | 그리그 「산속 마왕의 궁전」 — 살금살금 시작해 **점점 빨라지는 추격** | 주페 「경기병 서곡」 — 말 타고 **다그닥 고개 넘기** |
| 길이 | 약 2분 40초 | 약 2분 30초 |
| 이야기 | 냥팡이 전국에 숨긴 황금 츄르 찾기 → 끝에 냥팡이 **옛 지도 속으로 도망** | 옛 지도 속 추격 → 문경새재에서 냥팡을 잡음 → 정체 공개, 친구가 됨 |

- **지금 지도와 옛 지도를 곡으로 나눈 까닭**: 옛 지방 이름은 지금 행정구역과 범위가 같지 않습니다. 한 곡에 섞으면 헷갈리므로, 지도 색까지 다르게 해서 "1곡 = 지금, 2곡 = 옛날"로 확실히 구분합니다.
- **1곡 끝 → 2곡 처음**이 이어지므로 재생목록 자동재생으로 2곡을 연달아 보게 됩니다 (아동용이라 종료 화면을 못 쓰는 대신).
- 각 곡에서 **1분 컷(냥계 버전)과 쇼츠**를 잘라 만듭니다 (6번).

---

## 1. 등장인물 (v2와 같음)

- **냥팡**: 검은 망토, 츄르 모양 가면의 괴도 고양이. 황금 츄르를 훔쳐 전국에 숨김. 말투는 조금 멋있게("~다냥, 후후") → 고학년도 유치하지 않게.
- **냥돌이**: 탐정단. 용감하지만 길치. 엉뚱한 곳으로 가서 웃음 담당.
- **냥순이**: 탐정단. 지도 박사, **팩트체크** 담당.
- **시청하는 아이 = 탐정단 대장**: 대답 타임에 정답을 외침.

## 2. 공통 장치 (두 곡 모두)

| 장치 | 방법 | 참고한 외국 사례 |
|---|---|---|
| **대답 타임** | "도청은? 3, 2, 1…" 2~3초 멈춤 → 아이 코러스 정답 | 블루스 클루스 |
| **단서로 추리** | 냥팡이 남긴 쪽지 → 지역 맞히기 | 카르멘 샌디에고 |
| **패러디 5~8초** | 1곡 「냥비게이션」, 2곡 「냥기예보」 | 호러블 히스토리즈 |
| **점점 빨라지기** | 1곡 끝의 종류 정리를 빠르게 → "따라 부르면 지도 천재!" | 야코스 월드 |
| **도장 꽝!** | 정답마다 탐정 수첩에 도장 + 지역 반짝 | 수집 놀이 |
| **같은 후렴** | 두 곡 모두 같은 후렴 → 2곡에서는 아이가 먼저 부름 | 일본 도도부현 노래 |

**공통 후렴**
> 콕콕 콕! 지도를 콕!
> 냥팡은 어디? 단서를 봐!
> 3, 2, 1… 대장이 말해!
> (아이들) ○○○! (도장 꽝!)

## 3. 1곡 — 「냥팡을 쫓아라! 전국 시·도 추격송」 (지금 지도)

**멜로디**: 「산속 마왕의 궁전」. 원곡처럼 **처음엔 살금살금 → 갈수록 빨라짐**. 냥팡을 쫓을수록 빨라지는 추격전.

| 시간 | 구간 | 화면 |
|---|---|---|
| 0~10초 | 대사 인트로 | 냥팡이 황금 츄르 자루를 메고 휙! 단서 쪽지가 지도 위로 흩날림 |
| 10~40초 | 1절 수도권 | 서울·인천·경기 반짝 → 경기도청 대답 타임 |
| 40~50초 | 후렴 | 도장 꽝 |
| 50~80초 | 2절 강원·충청 | 「냥비게이션」 패러디 (5초) |
| 80~110초 | 3절 전라·제주 | 냥돌이가 튜브로 제주 가기 (웃음) |
| 110~135초 | 4절 경상 | 대답 타임 2문제 |
| 135~155초 | **빨라지는 종류 정리** | 특별시·특별자치시·광역시·도·특별자치도 칸에 지역이 착착 들어감 |
| 155~165초 | 아웃트로 | 냥팡이 **옛 지도 그림 속으로 쏙** 도망 → "2부에서 계속!" |

## 4. 2곡 — 「냥팡을 쫓아라! 옛 지도 고개 넘기송」 (옛 지도)

**멜로디**: 「경기병 서곡」의 말 달리는 부분. 탐정단이 조선 시대 말을 타고 **고개를 하나씩 넘으며** 냥팡을 쫓습니다. 한국사 시리즈를 본 아이들에게 "냥계 시간 여행" 느낌.

**먼저 기준이 되는 고개·물을 보여 주고 → 그 방향의 지방 이름을 부릅니다.**

| 시간 | 구간 | 화면 |
|---|---|---|
| 0~10초 | 인트로 | 지도가 한지 색으로 바뀌며 탐정단이 옛 지도 속으로 쏙 |
| 10~35초 | 1절 경기 | 서울(한양) 둘레 = 왕의 땅 경기 |
| 35~70초 | 2절 철령관 셋 | 철령관 표시 → 북쪽 관북, 서쪽 관서, 동쪽 관동 (+ 해서) |
| 70~85초 | **냥기예보** | "대관령 동쪽 영동엔 함박눈, 서쪽 영서엔 맑음!" → 관동 안의 영동·영서 |
| 85~120초 | 3절 호서·호남 | 냥순이 **팩트체크 코너**: "이름 유래는 설이 여러 개냥!" |
| 120~140초 | 4절 영남 + 클라이맥스 | 조령(문경새재)에서 냥팡을 잡음 |
| 140~150초 | 정리 + 엔딩 | 경기 + 호서 = 기호. 냥팡 정체 공개 |

### 가사 초안

```
[인트로 — 대사]
냥돌: 여긴… 옛날 지도 속이다냥?!
냥순: 말 타고 고개를 넘자! 다그닥 출발!

[1절 — 경기]
한양 둘레 왕의 땅, 그 이름은 경기!
경기는 서울 둘레? 3, 2, 1… (아이들) 맞아!

[2절 — 철령관 셋 (+해서)]
철령관 고개 하나에 이름이 셋
북쪽은 관북, 서쪽은 관서, 동쪽은 관동!
황해 바다 쪽 해서도 잊지 마

[냥기예보 — 대사]
"냥기예보입니다. 관동 지방, 대관령 동쪽 영동엔 함박눈!

[후렴]
콕콕 콕! 지도를 콕! 냥팡은 어디? 단서를 봐!
3, 2, 1… 대장이 말해! (아이들) 관동! (도장 꽝!)

[3절 — 호서·호남]

(냥순: 팩트체크! 어느 호수·강 기준인지는 설이 여러 개냥!)
전라 땅 옛 이름은? 3, 2, 1… (아이들) 호남!

[4절 — 영남, 클라이맥스]

(냥돌: 잡았다냥!! 냥팡: 으앗!)

[정리]

관북 관서 관동, 해서 호서 호남 영남!

[엔딩 — 대사]
냥팡(가면을 벗으며): 사실… 지도가 너무 좋아서 전국을 다 돌아보고 싶었다냥…
냥순: 그럼 다음엔 우리랑 같이 가자!
```

> 2곡의 지방 이름 범위·유래는 교과서 표현에 맞춰 꼭 고칩니다(8번). 특히 **관동 ≠ 영동** (관동 안을 대관령으로 나눈 것이 영동·영서), 관북·관서는 지금의 북한 지역이라 **한반도 전체 지도**로 보여 줍니다.

## 7. 그림과 지도

- **고양이 그림** (ChatGPT): 1곡 약 22장, 2곡 약 20장. 요청문은 가사가 확정되면 드립니다.
- **지도는 AI로 그리지 않습니다.** 공개 행정경계 자료로 제가 직접 만들고, 부르는 지역만 반짝이게 합니다.
  - 1곡: 지금 시·도 지도 + 도청 핀 + 종류별 색
  - 2곡: 한반도 전체 옛 지도 + 고개(철령관·대관령·조령) 표시 + 지방 이름 범위
- 고양이 그림과 지도는 따로 만들어 합칩니다 (화면 가운데 지도, 아래 자막 칸 비움).

## 8. 녹음 전에 꼭 확인할 것

1. **교과서 출판사·단원** — 가사 표현(특히 2곡 지방 이름 유래)을 교과서와 똑같이 맞춥니다.
2. **행정구역 변화** — 2026년 7월 1일 광주광역시와 전라남도가 「전남광주통합특별시」로 합쳐졌다는 보도가 있습니다(행정안전부 공식 자료로 확인 필요). 교과서는 17개 기준일 가능성이 큽니다.
   - 1곡은 **교과서 기준**으로 녹음하고 화면에 "교과서 기준" 표시.
   - 후렴에는 숫자("17개!")를 넣지 않았습니다. 바뀌는 곳은 **3절·종류 정리 두 군데**뿐이라, 필요하면 그 부분만 다시 녹음합니다.
3. **도청 위치** — 충남(홍성, 내포신도시), 전남(무안), 경북(안동)처럼 옛 도시에서 옮긴 곳은 공식 누리집 주소로 다시 확인.
4. "서울은 경기도에 둘러싸여"처럼 경계가 틀릴 수 있는 말은 쓰지 않음 → "서울 둘레 넓게 경기도".
5. 지방 이름 유래에 설이 여러 개인 것은 가사에 하나로 단정하지 않고 냥순이 **팩트체크 코너**로.
