## 2. 암기 설계

### 2-1. 장치

| 장치 | 어디에 | 왜 효과가 있나 |
|---|---|---|
| **"기원전 / 기원후"로 나눈 후렴** | "기원전! 이삼삼삼! 일공팔! …" / "기원후! 사이! 삼칠일! …" | 기원전 5개, 기원후 7개를 두 묶음으로 외웁니다 |
| **랄랄라 꼬리말** | 후렴 끝 "한국사 연도송~ 랄랄라" | 원하신 곡처럼 귀에 맴도는 반복 구절. 아이들이 따라 부르는 신호 |
| **절 끝 숫자 외치기** | "오칠 신라! 삼칠 고구려! 일팔 백제!" | 노래로 부른 내용을 숫자 + 이름으로 한 번 더 박아 넣습니다 |
| **세기별 전성기** | 3절 4세기 백제 → 4절 5세기 고구려 → 6세기 신라 | 시험에 자주 나오는 "전성기 순서: 백제 → 고구려 → 신라" |
| **양방향 퀴즈** | 브리지 "기원전 오칠?" → "신라!" / "이차돈 순교는?" → "오이칠!" | 연도 → 사건, 사건 → 연도 둘 다 연습 |

### 2-2. 숨겨 둔 연도 규칙

| 규칙 | 연도 | 외우는 말 |
|---|---|---|
| **삼국 건국은 오칠 → 삼칠 → 일팔** | 기원전 57 → 37 → 18 | "신·고·백" 순서. 20년, 19년 간격 |
| **칠일 칠이, 1년 차이** | 371 → 372 | 백제가 평양성을 치고, 바로 다음 해 고구려가 불교·태학으로 나라를 다짐 |
| **이칠 이칠, 100년 차이** | 427 → 527 | 장수왕 평양 천도(427), 딱 100년 뒤 법흥왕 불교 공인(527) |
| **전성기는 4·5·6세기** | 371 / 427 / 553 | 백제 4세기, 고구려 5세기, 신라 6세기 |

### 2-3. 헷갈리는 짝 구분법

| 헷갈리는 것 | 구분법 |
|---|---|
| 불교 수용(고구려) vs 불교 공인(신라) | **고구려가 먼저 받아들이고(372), 신라는 가장 늦게 공인(527)** |
| 광개토 대왕 vs 장수왕 | **아버지 광개토 대왕은 넓히고(391), 아들 장수왕은 평양으로 옮기고 남쪽으로(427)** |
| 근초고왕 vs 소수림왕 | **근초고왕은 백제, 소수림왕은 고구려.** 근초고왕의 공격으로 위기를 맞은 고구려를 소수림왕이 다시 정비 |
| 고구려·백제·신라 건국 순서 | 노래 순서대로 **신라 → 고구려 → 백제** ("삼국사기" 기록) |
