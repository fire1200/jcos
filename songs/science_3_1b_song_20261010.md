# 3학년 1학기 과학송 (하)! 자석의 이용 · 지구의 모습 — Suno 제작 문서 (2026-10-10)

3학년 과학송을 **학기마다 상·하 두 곡**으로 나눈 시리즈의 곡입니다. 한 곡에 **단원 2개**만 담고, 단원마다 **절 2개**로 교과서 내용을 자세히 노래합니다.

## 1. 외울 내용

| 절 | 핵심 내용 |
|---|---|
| 자석의 이용 ① | 자석은 철로 된 물체를 끌어당겨 / 클립, 철못, 철 숟가락은 착, 나무, 플라스틱, 유리는 그대로 / 클립이 많이 붙는 자석의 양 끝은 극 / 한쪽은 엔극, 한쪽은 에스극 / 종이나 유리가 사이에 있어도 자석은 철을 끌어당겨 |
| 자석의 이용 ② | 물에 띄운 자석은 빙글 돌아 북쪽과 남쪽 / 엔극은 북쪽, 에스극은 남쪽 / 나침반 바늘도 자석, 엔극은 언제나 북쪽 / 같은 극은 밀어 내고, 다른 극은 끌어당겨 / 냉장고 문, 자석 필통, 클립 통, 생활 속 자석 |
| 지구의 모습 ① | 지구는 둥근 공 모양 / 산과 들, 강과 호수, 바다와 사막, 화산과 폭포 / 지구 표면은 육지와 바다, 바다가 훨씬 넓어 / 바닷물은 짜고, 강물과 호숫물은 짜지 않아 |
| 지구의 모습 ② | 공기는 눈에 안 보여도 지구를 둘러싸 / 숨을 쉬고, 바람이 불고, 연이 날아 / 달도 둥근 공 모양, 크고 작은 충돌 구덩이 / 어둡게 보이는 달의 바다엔 물이 없어 / 달에는 공기도 물도 없어, 생물이 살 수 없어 / 물과 공기가 있는 지구, 생물이 살기에 알맞아 |

후렴은 **단원 이름 + 한 줄 요약**입니다: 셋, 자석의 이용! / 같은 극은 밀고, 다른 극은 착! / 넷, 지구의 모습! / 둥근 지구, 넓은 바다, 공기!
