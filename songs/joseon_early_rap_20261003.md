## 1. 외울 연표

근현대사 때 주신 형식(사건 / 연도 / 설명)에 맞췄습니다.

**위화도 회군**
1388년
고려 말 요동 정벌에 나선 이성계가 위화도에서 군대를 돌려 정권을 잡았습니다.

**조선 건국**
1392년
이성계가 정도전 등 신진 사대부와 함께 고려를 무너뜨리고 조선을 세웠습니다.

**한양 천도**
1394년
도읍을 한양으로 옮기고 경복궁, 종묘, 사직 등을 세웠습니다.

**호패법 실시**
1413년
태종은 16세 이상 남자에게 호패를 차게 하여 인구를 파악하고 세금과 군역을 거두었습니다.

**집현전 확대**
1420년
세종은 집현전을 확대하여 학자들이 학문과 정책을 연구하게 했습니다.

**과학 기구 발명**
1434년 ~ 1441년
장영실 등이 자동 물시계 자격루와 해시계 앙부일구(1434), 비의 양을 재는 측우기(1441)를 만들었습니다.

**훈민정음 창제와 반포**
1443년 ~ 1446년
세종은 백성이 쉽게 배워 쓸 수 있도록 1443년 훈민정음을 만들고 1446년 반포했습니다.

**4군 6진 개척**
세종 때
최윤덕은 압록강 쪽에 4군을, 김종서는 두만강 쪽에 6진을 개척하여 오늘날과 비슷한 국경선을 확보했습니다.

**경국대전 완성**
1485년
세조 때 편찬을 시작하여 성종 때 완성한 조선의 기본 법전으로, 유교 정치의 바탕이 되었습니다.

**사화**
1498년 ~ 1545년
훈구 세력과 사림 사이의 갈등으로 사림이 큰 화를 입은 사건으로, 무오사화(1498)부터 을사사화(1545)까지 네 차례 일어났습니다.

**임진왜란**
1592년 ~ 1598년
일본이 조선을 침략한 전쟁으로, 이순신의 수군과 전국의 의병이 활약하여 일본군을 물리쳤습니다.

## 2. 암기 설계

### 2-1. 다섯 가지 장치

| 장치 | 어디에 | 왜 효과가 있나 |
|---|---|---|
| **연도만 이어 부르는 훅** | "일삼! 팔팔 구이 구사! / 일사! 일삼 이공 삼사 …" | 12개 연도를 세기(1300년대·1400년대·1500년대)별로 끊어 외웁니다 |
| **"연도 + 사건" 한 줄 공식** | 모든 절 "일삼구이 조선 건국, …" | 연도를 읽으면 사건이, 사건을 들으면 연도가 붙어 나옵니다 |
| **왕별 4덩어리** | 1절 이성계(건국) / 2절 태종·세종 / 3절 세종의 업적 / 4절 성종 이후 | 왕 이름이 사건을 묶는 상자 역할을 합니다 |
| **세종 절 따로** | 3절 전체가 세종 | 시험에 가장 많이 나오는 왕. 업적 5개(집현전, 과학 기구, 훈민정음, 4군 6진)를 한 절에 모읍니다 |
| **양방향 퀴즈** | 브리지 "일사사삼?" → "훈민정음 창제!" / "임진왜란은?" → "일오구이!" | 연도 → 사건, 사건 → 연도 둘 다 연습합니다 |

### 2-2. 훅에 숨겨 둔 연도 규칙

| 규칙 | 연도 | 외우는 말 |
|---|---|---|
| 회군 → 건국 → 천도, 2년씩 | 1388 → 1392 → 1394 | "팔팔 구이 구사." 4년 뒤 건국, 2년 뒤 천도 |
| **훈민정음은 사삼 만들고 사육 반포** | 1443 → 1446 | 3년 차이. "사삼 창제, 사육 반포" |
| 세종의 1440년대 | 1441 → 1443 → 1446 | "사일 사삼 사육." 측우기, 창제, 반포 |
| **건국 200년 뒤 임진왜란** | 1392 → 1592 | 끝 두 자리가 똑같이 "구이" |

### 2-3. 헷갈리는 짝 구분법

| 헷갈리는 것 | 구분법 |
|---|---|
| 창제 vs 반포 | **창제는 만든 것(1443), 반포는 널리 알린 것(1446).** 만들고 3년 뒤 알렸습니다 |
| 자격루 vs 앙부일구 | **자격루는 물시계**(스스로 치는 "자격"), **앙부일구는 해시계**(솥 모양, 해 그림자) |
| 4군 vs 6진 | **4군은 압록강, 최윤덕. 6진은 두만강, 김종서.** "사압최, 육두김" |
| 경국대전 시작 vs 완성 | **세조가 시작, 성종이 완성** |
| 훈구 vs 사림 | 사화에서 **화를 입은 쪽이 사림** |

### 6-2. 생성 후 고르는 기준

4~6개를 생성하고 아래 순서로 거릅니다. **1번에서 떨어지면 나머지는 볼 필요 없습니다.**

| 순위 | 확인할 것 | 탈락 기준 |
|---|---|---|
| 1 | **훅의 연도 12개가 순서대로 다 들리는가** | 하나라도 빠지거나 바뀌면 탈락 |
| 2 | **절마다 연도와 사건이 짝이 맞는가** | Suno가 단어를 바꿔 부르면 탈락 |
| 3 | 어려운 단어가 또렷한가 | "위화도 회군", "앙부일구", "훈민정음", "경국대전", "무오사화"가 뭉개지면 탈락 |
| 4 | 3절(세종)이 끝까지 다 나오는가 | 줄을 건너뛰면 탈락 |
| 5 | 브리지 묻고 답하기가 구분되는가 | 섞이면 아쉬움 |
| 6 | 길이 3분 30초~4분 10초 | 길면 Outro 잘라내기 |

### 6-3. 문제가 생겼을 때

| 증상 | 고치는 법 |
|---|---|
| 연도가 뭉개짐 | BPM 85로 낮추거나 D 스타일. 연도 사이에 쉼표: `일삼, 팔팔` |
| 3절 가사가 잘림 | 3절을 둘로 나누기: `[Verse 3]`(과학 기구·훈민정음) / `[Verse 3b]`(4군 6진) |
| "앙부일구"를 다르게 읽음 | `앙-부-일-구`로 띄어 쓰기 |
| 국악기 소리 때문에 랩이 묻힘 | B 스타일로 바꾸기 |
| 노래로 불러 랩이 안 됨 | Style 맨 앞 `rap only, no singing` 확인 |
| 곡이 중간에 끝남 | Extend로 이어 붙이거나, 1~2절과 3~4절을 따로 생성 |
