## 1. 수학송이 과학송과 다른 점 (재미 + 정확)

1. **외울 문장 = 후렴.** 정의("네 변의 길이가 모두 같은 사각형, 마름모!")를 후렴으로 반복해 시험 문장 그대로 머리에 남게.
2. **숫자는 박자에 딱.** "면 6! 모서리 12! 꼭짓점 8!"처럼 숫자를 박자 맨 앞에 두고 아이들이 외치게.
3. **3, 2, 1 퀴즈**(지리송·퀴즈 쇼츠와 같은 방식) — 멈추고 아이가 답하기.
4. **도형·그래프는 AI 그림 대신 제가 프로그램으로 정확히 그립니다.** (지리송 지도처럼) 변 길이·직각 표시·평행 표시·대각선이 틀리면 안 되기 때문. 고양이 그림은 ChatGPT로, 도형은 제가 그려 화면 왼쪽에 합칩니다.
5. 냥돌이·냥순이가 "수학 탐정단"으로 등장 → 지리송 「지도 탐정단」과 이어지는 세계관.

## 2. 4-2 (하) — 「사각형 가족 대소동!」

**배우는 내용 (외울 문장)**
- **수직**: 두 직선이 만나서 이루는 각이 직각일 때. 한 직선을 다른 직선의 **수선**이라고 함
- **평행**: 서로 만나지 않는 두 직선. **평행선 사이의 거리**는 수선의 길이
- **사다리꼴**: 평행한 변이 **한 쌍이라도** 있는 사각형
- **평행사변형**: 마주 보는 **두 쌍**의 변이 서로 평행 / 마주 보는 변의 길이·마주 보는 각의 크기가 같음 / 이웃한 두 각의 합 180°
- **마름모**: **네 변의 길이가 모두 같은** 사각형 / 마주 보는 두 쌍의 변 평행 / 두 대각선이 서로 수직으로 만나 이등분
- **직사각형**: 네 각이 모두 직각 / **정사각형**: 네 변 같고 네 각 직각
- **포함 관계**: 정사각형은 직사각형이면서 마름모, 모두 평행사변형, 모두 사다리꼴
- **꺾은선그래프**: 시간에 따라 **변하는 모양**을 보기 좋음 / 필요 없는 부분은 **물결선(≈)**으로 줄임
- **다각형**: 선분으로만 둘러싸인 도형 / **정다각형**: 변의 길이와 각의 크기가 모두 같음 / **대각선**: 이웃하지 않는 두 꼭짓점을 이은 선분 (삼각형 0개, 사각형 2개, 오각형 5개, 육각형 9개)

## 4. 4-2 (상) · 5-2 (상) 내용 정리 (가사는 출판사 확인 뒤)

**4-2 (상) 「분수·소수 더하기 빼기 & 삼각형 삼총사」**
- 분모가 같은 분수의 덧셈·뺄셈: 분모는 그대로, 분자끼리 / 대분수는 자연수끼리·분수끼리, 모자라면 1을 가분수로 바꿔 빼기
- 소수의 덧셈·뺄셈: **소수점 자리를 맞춰** 세로로
- 이등변삼각형: 두 변의 길이가 같음, 두 각의 크기가 같음 / 정삼각형: 세 변 같음, 세 각 모두 60°
- 예각삼각형: 세 각이 모두 예각 / 직각삼각형: 한 각이 직각 / 둔각삼각형: 한 각이 둔각

**5-2 (상) 「이상·이하·초과·미만 & 합동 쌍둥이」**
- 이상·이하: 그 수를 **포함** / 초과·미만: **포함하지 않음** (수직선에서 ● 와 ○)
- 올림·버림·반올림: 반올림은 구하려는 자리 바로 아래 숫자가 **0~4면 버리고, 5~9면 올림**
- 분수의 곱셈: 분자끼리, 분모끼리 곱하기 / 자연수 × 분수
- 합동: 모양과 크기가 같아 **완전히 겹치는** 두 도형 / 대응점·대응변·대응각
- 선대칭도형(대칭축), 점대칭도형(대칭의 중심, 180° 돌리면 겹침)
