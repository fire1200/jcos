## 0. 모든 곡 공통

### 0-1. 원곡과 비슷하게 만드는 법 (Suno)

**방법 A (가장 비슷함, 추천) — 원곡 소리를 올려 Cover**

1. 원곡 녹음을 준비합니다.
   - **클래식 곡**(⓪①③④⑦): 위키미디어 공용(commons.wikimedia.org)이나 Musopen에서 곡 이름을 검색하고, **Public domain** 표시가 있는 녹음만 받으세요. 시중 음반은 쓰면 안 됩니다.
   - **동요·민요**(②⑤⑥⑦): 피아노, 리코더, 휴대폰 피아노 앱으로 **선율을 직접 한 번 쳐서 녹음**하면 됩니다. 직접 녹음한 소리는 권리 걱정이 없습니다.
2. 1분 20초 안쪽으로 잘라 Suno → **Create → Audio(업로드)** 로 올립니다.
3. **Cover** → 곡마다 적힌 Style과 Lyrics를 넣습니다.
4. 3~4번 만들어 **선율이 원곡과 가장 비슷하고 가사가 또렷한 것**을 고릅니다.

**방법 B — 글만으로**: 곡마다 적힌 Style에 원곡 이름과 특징을 넣어 두었습니다. 동요·민요는 Suno가 선율을 꽤 비슷하게 따라 하지만, 클래식 곡은 "비슷한 느낌"에 그칠 때가 많습니다.

**공통 Exclude Styles**

```
slow, ballad, sad, dark, rap, trap, autotune, heavy metal, distortion, long instrumental intro, explicit lyrics
```

### 0-2. 영상

- 가로 1080p, 1분 20초 이내, 일반 영상.
- 지금 한국사 영상과 같은 배치: 큰 연도와 사건 이름, 가사 자막(연도는 숫자로), 연표 막대.
- 끝 화면: "전체 노래는 ○ ○○ 연도 암기송에서!" + 끝 화면 카드로 원래 곡 연결.

### 0-3. 그림 공통 규칙 — 메시지 0 (곡마다 새 대화에서 맨 처음 한 번)

곡마다 그림은 **12장**(`00.png`~`11.png`)입니다. 압축 파일 이름은 곡마다 적어 둔 이름(예: **폴카선사**)으로 해 주세요.

```

[크기] 가로 1536×1024. 중요한 것은 화면 가운데에 두고, 맨 아래 1/5은 자막이 들어가니 단순한 배경으로 비워 줘.

[주인공] 모든 그림에 같은 두 아기 고양이가 나와. "냥돌이": 치즈색 줄무늬 아기 고양이, 파란 목도리. "냥순이": 하양·검정·주황 삼색 아기 고양이, 빨간 리본. 둘은 구경하고 놀라고 박수 치는 역할이고, 시대에 맞는 옷을 입어.

[지킬 것]
- 그림 안에 글자, 숫자, 간판 글씨 절대 넣지 마.
- 전쟁 장면도 귀엽게: 피, 다침, 죽음, 무서운 표정 없이. 칼과 창은 장난감처럼 둥글게.
- 나라를 잃거나 슬픈 장면은 놀리지 말고 "울먹이지만 힘내는" 분위기로.
- 실제 회사 로고, 만화 캐릭터는 그리지 마.
그림을 줄 때마다 답장 첫 줄에 파일 이름을 적어 줘.
```
