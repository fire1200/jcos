# 열두 띠 레이스! — 12지 암기송 Suno 제작 문서 (2026-10-03)

12지(띠 동물) 순서를 초등학생이 **노래 한 곡으로 외우게** 만드는 곡입니다.
요즘 초등학생이 좋아하는 일본 애니메이션 주제가풍 J-pop 스타일로, Suno에 그대로 붙여 넣을 수 있게 정리했습니다.

| 항목 | 내용 |
|---|---|
| 곡 제목 | 열두 띠 레이스! |
| 대상 | 초등학생 (저학년~고학년) |
| 목표 | 12지 순서 암기 (쥐 → 돼지) |
| 스타일 | 애니 오프닝풍 J-pop, 175 BPM, 밝은 신스팝 + 어린이 합창 |
| 길이 | 약 2분 40초~3분 |
| 가사 언어 | 한국어 (구호 일부 영어) |

## 1. 먼저 알아 둘 12지

| 순서 | 동물 | 한자 | 띠 이름 | 가사 속 울음소리 | 이야기 속 장면 |
|---|---|---|---|---|---|
| 1 | 쥐 | 子 (자) | 쥐띠 | 찍찍찍 | 소 등에 몰래 타고 가다 결승선 앞에서 뛰어내려 1등 |
| 2 | 소 | 丑 (축) | 소띠 | 음메 | 제일 먼저 출발해 뚜벅뚜벅 끝까지 |
| 3 | 호랑이 | 寅 (인) | 범띠 | 어흥 | 거센 물살을 힘으로 헤치고 |
| 4 | 토끼 | 卯 (묘) | 토끼띠 | 깡총깡총 | 돌과 통나무를 징검다리 삼아 폴짝 |
| 5 | 용 | 辰 (진) | 용띠 | (구름 타고) | 하늘을 날 수 있지만 도움을 주느라 5등 |
| 6 | 뱀 | 巳 (사) | 뱀띠 | 스르르륵 | 말 발굽에 몰래 감겨 있다가 |
| 7 | 말 | 午 (오) | 말띠 | 히히힝 | 뱀이 튀어나와 깜짝 놀라 7등 |
| 8 | 양 | 未 (미) | 양띠 | 메에메에 | 원숭이·닭과 뗏목을 같이 만들어 건넘 |
| 9 | 원숭이 | 申 (신) | 원숭이띠 | 끼끼끼 | 뗏목 팀 |
| 10 | 닭 | 酉 (유) | 닭띠 | 꼬끼오 | 뗏목 팀 |
| 11 | 개 | 戌 (술) | 개띠 | 멍멍멍 | 물장난을 하느라 늦음 |
| 12 | 돼지 | 亥 (해) | 돼지띠 | 꿀꿀꿀 | 먹고 낮잠 자다 꼴찌 |

> 이야기는 "옥황상제(또는 부처님)가 강을 건너 먼저 도착한 순서대로 띠를 정했다"는 민간 설화를 바탕으로 했습니다.
> 지역과 책마다 세부가 조금씩 다릅니다. 노래에서는 **앞뒤 동물이 서로 연결되는 장면**만 골랐습니다 (쥐→소, 뱀→말, 양·원숭이·닭 뗏목).

## 2. 암기 설계

이 곡의 목적은 "좋은 노래"보다 **"듣고 나면 순서가 입에서 나오는 노래"**입니다. 그래서 아래 다섯 장치를 넣었습니다.

| 장치 | 어디에 | 왜 효과가 있나 |
|---|---|---|
| **3마리씩 4묶음** | 후렴 "쥐 소 호랑이! / 토끼 용 뱀! / 말 양 원숭이! / 닭 개 돼지!" | 12개를 한 줄로 외우기는 어렵지만 3개짜리 4덩어리는 쉽습니다. 묶음마다 박자가 같아서 리듬으로 기억됩니다 |
| **등수 + 울음소리** | 절 가사 "찍찍찍 쥐가 일 등!" | 숫자(순서), 소리(동물), 장면(이야기)이 한 줄에 같이 들어가 세 갈래로 기억됩니다 |
| **이야기 연결** | 쥐가 소 등에 탐 / 뱀이 말 발굽에 숨음 / 뗏목 팀 | "뱀 다음이 뭐였지?" → "뱀이 말한테 숨었지" → 말. 앞 동물이 다음 동물을 불러옵니다 |
| **반복 6회** | 후렴 3번 × 후렴 안에서 2번 | 한 곡을 한 번 들어도 12마리 전체 순서를 처음부터 끝까지 6번 듣습니다 |
| **묻고 답하기** | 브리지 "다섯 번째는? 용!" | 듣기만 하는 것보다 떠올려서 답할 때 기억이 훨씬 오래갑니다. 노래 안에서 작은 시험을 봅니다 |

### 곡 구조와 암기 흐름

| 구간 | 들어가는 동물 | 역할 | 대략 시간 |
|---|---|---|---|
| Intro | — | 구호로 시작, 집중시키기 | 0:00~0:08 |
| Verse 1 | 1~3 (쥐 소 호랑이) | 첫 묶음 소개 | 0:08~0:25 |
| Verse 2 | 4~6 (토끼 용 뱀) | 둘째 묶음 소개 | 0:25~0:42 |
| Chorus 1 | 12마리 전부 ×2 | 전체 순서 처음 듣기 | 0:42~1:05 |
| Verse 3 | 7~9 (말 양 원숭이) | 셋째 묶음 소개 | 1:05~1:22 |
| Verse 4 | 10~12 (닭 개 돼지) | 넷째 묶음 소개 | 1:22~1:39 |
| Chorus 2 | 12마리 전부 ×2 | 전체 순서 다시 | 1:39~2:02 |
| Bridge | 6마리 퀴즈 | 떠올려서 답하기 | 2:02~2:20 |
| Final Chorus | 12마리 전부 ×2 | 키 올려 마무리 | 2:20~2:45 |
| Outro | — | "너는 무슨 띠야?" 대화 유도 | 2:45~2:50 |

시간은 175 BPM 기준 예상치입니다. Suno가 생성할 때마다 조금씩 달라집니다.

## 5. 생성 체크리스트

### 5-1. 생성 전

- [ ] Custom 모드 켜기
- [ ] Title, Style, Exclude, Lyrics 네 칸 다 채우기
- [ ] 가사의 숫자가 한글인지 확인 ("1등" ✕ → "일 등" ○)
- [ ] Style에 실제 가수·그룹 이름이 없는지 확인 (아래 6장)

### 5-2. 생성 후 고르는 기준

4~6개를 생성하고 아래 순서로 거릅니다. **1번에서 떨어지면 나머지는 볼 필요 없습니다.**

| 순위 | 확인할 것 | 탈락 기준 |
|---|---|---|
| 1 | **후렴 12마리가 순서대로 다 들리는가** | 한 마리라도 빠지거나 순서가 바뀌면 탈락. 암기송에서 틀린 순서는 치명적입니다 |
| 2 | 동물 이름 발음이 또렷한가 | "호랑이", "원숭이"가 뭉개지면 탈락 |
| 3 | 등수 숫자가 맞게 불리는가 | "십일 등", "십이 등"이 정확한지 |
| 4 | 묶음 구호가 여럿이 외치는 느낌인가 | 혼자 부르면 아쉽지만 탈락까지는 아님 |
| 5 | 브리지 묻고 답하기가 구분되는가 | 질문과 답이 섞이면 아쉬움 |
| 6 | 전체 길이 2분 30초~3분 30초 | 너무 길면 Outro 잘라내기 |

### 5-3. 문제가 생겼을 때

| 증상 | 고치는 법 |
|---|---|
| 동물 이름 발음이 뭉개짐 | 해당 줄을 띄어 쓰기: `호 랑 이` 또는 `호-랑-이`. 그래도 안 되면 BPM을 160으로 낮추기 |
| 후렴에서 동물이 빠짐 | 후렴 한 줄을 두 줄로 나누기: `쥐 소 호랑이!` / `토끼 용 뱀!` |
| 숫자를 영어나 아라비아 숫자식으로 읽음 | 숫자를 모두 한글로 썼는지 다시 확인 |
| 묶음 구호를 노래로 늘려 부름 | `[Gang vocals]`를 `[Shouted chant]`로 바꾸기 |
| 곡이 중간에 끝남 | 가사가 길면 Suno가 자를 수 있습니다. Extend로 이어 붙이거나 Verse 하나씩 나눠 생성 |
| 일본어로 부름 | Style에 `Korean lyrics, Korean vocal`을 앞쪽으로 옮기기 |
| 너무 어른스럽거나 섹시한 톤 | Style에 `children's song, wholesome` 추가, Exclude에 `sexy, mature` 추가 |

## 6. 주의할 점

| 항목 | 내용 |
|---|---|
| **실제 아티스트 이름 금지** | YOASOBI, Ado, 요네즈 켄시 같은 이름을 Style에 쓰면 Suno가 거부하거나 무시합니다. 대신 "anime opening, bright synth pop"처럼 장르와 소리로 묘사합니다 |
| **애니 주제가 멜로디 흉내 금지** | 특정 애니 주제가와 비슷하게 들리면 저작권 분쟁 소지가 있습니다. 생성 결과가 아는 곡과 비슷하면 버리고 다시 생성하세요 |
| **사용 권리** | Suno 무료 플랜 결과물은 상업적 사용이 제한됩니다. 유튜브 수익화 채널에 올릴 거라면 유료 플랜에서 생성하세요. 조건은 바뀔 수 있으니 올리기 전에 Suno 이용약관을 다시 확인하세요 |
| **아동용 콘텐츠 설정** | 유튜브에 올릴 때 초등학생 대상이면 "아동용으로 제작됨"으로 설정해야 합니다. 이 경우 댓글·개인 맞춤 광고가 꺼집니다 |
| **설화 내용** | 설화는 판본마다 다릅니다. "정답"이 아니라 "외우기 위한 이야기"로 소개하세요 |

## 7. 보너스: 한자 12지 랩

조금 큰 아이들이 **자축인묘진사오미신유술해**까지 외우게 하고 싶을 때 씁니다.
기본 가사의 `[Bridge]` 바로 다음, `[Final Chorus]` 앞에 넣습니다.

```
[Rap]
자 축 인 묘! 쥐 소 호랑이 토끼!
진 사 오 미! 용 뱀 말 양!
신 유 술 해! 원숭이 닭 개 돼지!
자축인묘 진사오미 신유술해! 예!
```

> Suno가 한 글자짜리 한자음을 뭉개는 경우가 많습니다. 기본 가사에서 뺀 이유입니다.
> 넣는다면 5-2의 1번 기준을 이 부분에도 똑같이 적용해서, 12글자가 다 들리는 버전만 고르세요.

## 8. 쇼츠·짧은 버전

### 8-1. 30초 쇼츠용

완성곡에서 **Chorus 1 한 번(약 20~25초)**만 잘라 씁니다. 쇼츠 화면 구성 예시는 이렇습니다.

| 가사 | 화면 |
|---|---|
| 쥐 소 호랑이! | 동물 3마리가 왼쪽부터 차례로 등장, 위에 1·2·3 숫자 |
| 토끼 용 뱀! | 4·5·6 |
| 말 양 원숭이! | 7·8·9 |
| 닭 개 돼지! | 10·11·12 |
| 열두 띠 레이스, 한 번 더! | 12마리가 한 줄로 정렬 |
| (반복) | 동물은 가리고 숫자만 보여 주기. 따라 부르며 맞히게 |
| 이제 다 외웠지? 예! | "너는 무슨 띠야? 댓글로!" 문구 |

두 번째 반복에서 동물을 가리는 것이 핵심입니다. 보는 아이가 스스로 떠올리게 되어 기억에 남습니다.


## 9. 활용 아이디어

### 9-1. 따라 부르기 3단계

| 단계 | 방법 |
|---|---|
| 1일차 | 느린 버전(4장 D)으로 가사 보며 듣기 |
| 2~3일차 | 기본 버전으로 후렴만 따라 부르기 |
| 4일차~ | 브리지 퀴즈에서 답을 먼저 외치기. 노래 없이 "다섯 번째는?" 물어보기 |

### 9-2. Outro "너는 무슨 띠야?"와 이어지는 표

초등학생 출생 연도별 띠입니다. 대화나 활동지에 쓰기 좋습니다.

| 출생 연도 | 띠 | 지금 학년 (2026년 기준, 빠른 생일 제외) |
|---|---|---|
| 2014 | 말 | 6학년 |
| 2015 | 양 | 5학년 |
| 2016 | 원숭이 | 4학년 |
| 2017 | 닭 | 3학년 |
| 2018 | 개 | 2학년 |
| 2019 | 돼지 | 1학년 |

> 띠는 전통적으로 설날(또는 입춘) 기준으로 바뀝니다. **1월~2월 초에 태어난 아이는 앞 해의 띠**일 수 있으니 확인해 주세요.
> 참고로 2026년은 말의 해(병오년), 2027년은 양의 해(정미년)입니다.

### 9-3. 같이 쓰면 좋은 것

- 12마리 그림 카드를 순서대로 섞어 놓고 노래에 맞춰 줄 세우기
- 브리지 퀴즈를 늘려서 "여덟 번째는?", "토끼 다음은?" 같은 질문 추가
- 자기 띠 동물이 나올 때 일어서기 게임
