# 제목·설명 템플릿 세트 (아기 수면음악 채널)

대상 채널: https://www.youtube.com/@PPAIEO
관련 문서: `plans/youtube_baby_sleep_exposure_v2_20260916.md` 3-3절

## 1. 제목 공식

```
[핵심 키워드] | [문제·상황 훅] [길이] [연속재생] [부가 키워드]
```

규칙
- 핵심 키워드는 앞 30자 안에. 모바일 검색 결과는 약 40자 이후가 잘린다.
- 훅은 부모의 상황을 말한다. "잠 안 자는", "새벽에 깨는", "낮잠 짧은", "울음 그치는".
- 길이(1시간 / 3시간 / 10시간)와 "연속재생"은 클릭 전 안심 요소.
- **"광고없음"·"무광고"는 쓰지 않는다.** 유튜브는 수익 창출을 하지 않는 채널의 영상에도 광고를 표시할 수 있어(한국 2021-06-01 적용) 운영자가 보장할 수 없다. 부모가 실제로 원하는 것은 "밤중에 끊기지 않는다"이므로 "연속재생"이 같은 약속을 거짓 없이 전달한다. 근거는 `plans/benchmark_merged_20260925.md` 5절
- 이모지는 1개 이하. 대문자·느낌표 남발 금지.
- 아기 얼굴·캐릭터·유아 표현을 앞세우지 않는다(아동용 자동 분류 회피).
