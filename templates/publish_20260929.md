## 0. 붙여넣기 전 확인 2가지

### 0-1. 핑크노이즈 베드를 넣어야 제목이 사실이 됩니다

제목에 `소프트 핑크노이즈`가 들어갑니다. 10-1 원래 사양은 **허밍 8곡만**이었으므로, 그대로 렌더링하면 제목이 약속을 어깁니다.

**핑크노이즈 베드를 넣으시길 권합니다.** 이유가 두 개입니다.

| 이유 | 내용 |
|---|---|
| 반복이 덜 들립니다 | 64분 소재를 2.8회 반복합니다. 연속 노이즈가 이음매를 덮어 줍니다 |
| 실제로 유용합니다 | 방 안 소음(문소리·발소리)을 가려 아기가 덜 깹니다 |

| 항목 | 값 |
|---|---|
| 종류 | 핑크노이즈 (화이트노이즈보다 고역이 부드러움) |
| 레벨 | 허밍 대비 **-28 dB**. 허밍이 멈춘 구간에서만 겨우 들리는 정도 |
| 구간 | 0:00부터 끝까지 연속. 페이드 없음 |
| 필터 | 10kHz 이상 저역통과. 고역이 남으면 거칠게 들립니다 |
| 추가 작업 | 약 20분 |

**넣지 않으실 경우** 제목을 아래 B안으로 바꾸세요.

```
아기 수면음악 | 밤잠용 엄마 허밍 자장가 3시간 연속재생
```

### 0-2. "직접 녹음"이라고 쓰지 마세요

허밍 곡이 AI 생성분이면 **설명·댓글·커뮤니티 어디에도 "직접 불렀다", "직접 녹음했다"를 쓰면 안 됩니다.** 아래 문안은 전부 소리를 묘사할 뿐 누가 불렀는지 말하지 않게 써 두었습니다. 그대로 쓰시면 문제없습니다.

사람이 직접 부른 곡이면 그때는 "직접 부른"을 넣어도 됩니다. 그 편이 강력한 차별점이니, 해당하면 알려 주세요. 문안을 고쳐 드립니다.
