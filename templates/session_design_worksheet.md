# 세션 설계 워크시트 (처방 3-2)

**왜 필요한가.** 2026년 추천 시스템은 시청 후 시청자가 계속 보게 만드는 영상에 노출을 더 준다. 수면음악은 시청자가 잠들면서 세션이 끝나는 장르라 구조적으로 불리하다. 재생목록과 최종화면으로 자동재생이 채널 안에서 이어지게 만들어 이 손해를 상쇄한다.

## 1. 재생목록 구조

재생목록은 5개로 고정한다. 많을수록 좋은 것이 아니라, 자동재생이 확실히 걸리는 게 중요하다.

| 재생목록 | 대상 상황 | 담을 영상 | 정렬 |
|---|---|---|---|
| 밤잠 10시간 | 저녁 재우기~새벽 | 8~12시간 롱폼 | 수동(대표작 먼저) |
| 낮잠 1~3시간 | 낮 재우기 | 1~3시간 | 수동 |
| 백색소음 | 울음·배앓이 진정 | 전 길이 | 수동 |
| 태교·임산부 | 임신 중 | 전 길이 | 수동 |
| 신생아 0~3개월 | 월령별 진입점 | 위 4개에서 교차 선택 | 수동 |

원칙
- 한 영상은 최대 2개 재생목록에만 넣는다. 그 이상은 어느 목록이 주력인지 신호가 흐려진다.
- 각 목록 1번 자리에는 그 목록에서 평균 시청 지속 시간이 가장 긴 영상을 둔다. 자동재생 첫 곡이 이탈률을 결정한다.
- 재생목록 설명 첫 줄도 줄글 문장으로 쓴다. 검색에 노출된다.

## 2. 최종화면 연결도

최종화면은 마지막 20초에 요소 2개만 둔다. 요소가 많으면 아무것도 클릭되지 않는다.

```
밤잠 10시간 #N
  ├─ 요소1(동영상): 밤잠 10시간 #N+1   ← 같은 시리즈 다음 편
  └─ 요소2(재생목록): 밤잠 10시간

낮잠 1~3시간
  ├─ 요소1(동영상): 같은 길이대 다른 소리
  └─ 요소2(동영상): 밤잠 10시간 대표작  ← 낮잠 시청자를 밤잠으로 넘김

백색소음
  ├─ 요소1(동영상): 같은 소리의 긴 버전
  └─ 요소2(재생목록): 백색소음

쇼츠
  └─ 관련 동영상 링크: 해당 롱폼 또는 24시간 라이브
```

핵심은 **낮잠 → 밤잠** 연결이다. 낮잠 영상은 1~3시간이라 끝까지 재생되는 일이 있고, 그 순간이 다음 영상으로 넘길 유일한 기회다.

## 3. 시리즈 번호 운영

- 제목 끝이 아니라 앞쪽 부가 위치에 `밤 시리즈 #12` 형태로 넣는다.
- 번호가 있으면 시청자가 "다음 편"을 찾는 행동을 한다. 이것이 세션 연장으로 이어진다.
- 시리즈당 최소 10편이 쌓여야 의미가 있다. 시리즈를 3개 넘게 벌이지 않는다.

## 4. 점검 워크시트

전 영상을 한 번 훑으며 아래를 채운다. `tools/check_metadata.py`가 재생목록·최종화면 누락을 자동으로 잡아 준다.

| 영상 제목 | 길이 | 재생목록 | 목록 내 순번 | 최종화면 요소1 | 최종화면 요소2 | 시리즈 번호 | 조치 |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

조치 열에 쓸 값: `배치`, `순번변경`, `최종화면추가`, `없음`

## 5. 완료 기준

- [ ] 모든 영상이 재생목록 1개 이상에 속한다
- [ ] 모든 영상에 최종화면 요소 2개가 있다
- [ ] 각 재생목록 1번 자리가 그 목록 최고 AVD 영상이다
- [ ] 낮잠 영상 최종화면에 밤잠 대표작이 걸려 있다
- [ ] 스튜디오 트래픽 소스에서 "재생목록"과 "추천 동영상" 비중이 2주 뒤 상승했다
