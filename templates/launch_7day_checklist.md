# 영상 공개 첫 7일 운영 체크리스트

근거: 2026년 추천 시스템은 공개 후 24~48시간 핵심 시청자 반응으로 확장 여부를 정하고, Hype는 공개 후 7일 안에만 가능하다.

## D-1 (공개 전날)

- [ ] 시청자층 "아동용 아님" 확인 (근거: 부모 대상 콘텐츠)
- [ ] 제목 공식 적용, 설명 첫 두 문장 영상 고유 문장으로 작성
- [ ] 다국어 제목·설명 (영어·일본어) 입력
- [ ] 썸네일 3종 "테스트 및 비교" 등록
- [ ] 재생목록 배치, 최종화면(마지막 20초) 다음 영상 지정
- [ ] 타임스탬프 챕터 5개 이상
- [ ] 제목에 `광고없음`·`무광고`가 없는지 확인 (유튜브가 비수익 채널 영상에도 광고를 붙일 수 있어 보장 불가. `연속재생`을 쓴다)
- [ ] 공개 예약: 저녁 8시 KST (해외 타깃은 미 동부 저녁 8시 = KST 오전 9시 별도)
- [ ] 커뮤니티 예고글 발행: "내일 저녁 8시, ○○ 자장가 10시간"

## D-0 (공개 당일)

- [ ] 공개 직후 고정댓글 등록 (아래 문안)
- [ ] 커뮤니티 게시글: 썸네일 + 한 줄 + 링크
- [ ] 인스타그램 릴스 / 스토리 15초 클립 + 링크
- [ ] 맘카페·네이버 블로그 임베드 (홍보 규정 준수, 후기 형태로)
- [ ] 라이브 스트림 설명에 신작 링크 추가
- [ ] 2시간 후 실시간 지표 확인: 조회수, 노출 클릭률, 평균 시청 지속 시간

## D+1 ~ D+2 (48시간)

- [ ] CTR 3% 미만 → 테스트 중이 아니면 썸네일 즉시 교체
- [ ] 평균 시청 지속 시간이 채널 평균의 70% 미만 → 초반 30초 점검, 필요 시 재업로드 검토
- [ ] 댓글 전부 답변 (질문형 답변으로 대화 유도)
- [ ] 트래픽 소스 확인: 추천 비중이 오르는지

## D+3 ~ D+7

- [ ] Hype 요청 (YPP + 구독자 500 이상일 때): 커뮤니티·고정댓글에 요청 문구
- [ ] 쇼츠 2편 발행, "관련 동영상" 링크로 본 영상 연결
- [ ] 커뮤니티 설문 1회 ("다음엔 어떤 소리?")
- [ ] D+7 지표 기록: KPI 시트에 노출수·CTR·AVD·구독 전환

## 문안

### 고정댓글

```
밤새 틀어 두셔도 끊김 없이 이어집니다 🌙
볼륨은 대화 소리보다 낮게, 아기에게서 1m 이상 떨어진 곳에 두세요.
오늘 아기가 몇 분 만에 잠들었는지 댓글로 알려 주시면 다음 영상 만들 때 참고합니다.
▶ 신생아 자장가 재생목록: (링크)
```

### Hype 요청

```
이 영상이 도움이 되셨다면 영상 아래 "하이프" 버튼을 눌러 주세요.
공개 후 7일 안에만 가능하고, 작은 채널일수록 큰 힘이 됩니다 🙏
```

### 커뮤니티 예고

```
내일 저녁 8시 공개 🌙
"새벽에 자꾸 깨는 아기를 위한 밤샘 자장가 10시간"
엄마 심장박동 리듬 위에 피아노를 얹었습니다. 알림 켜 두시면 재우기 시간에 맞춰 도착합니다.
```

```

전체 10시간 버전은 프로필 링크 → 유튜브 @PPAIEO
#아기수면음악 #신생아자장가 #백색소음 #육아 #신생아
```
