# 오디오 제작 사양 (처방 3-4)

**왜 필요한가.** 평균 시청 지속 시간이 낮으면 노출이 줄어든다. 수면음악에서 초반 이탈의 원인은 거의 항상 인트로, 볼륨, 첫 곡 선택 셋 중 하나다. 감이 아니라 수치로 고정한다.

## 1. 라우드니스

| 항목 | 값 | 이유 |
|---|---|---|
| 통합 라우드니스 | **-16 LUFS** (허용 -17 ~ -14) | 유튜브 정규화 기준(-14) 근처. 더 낮으면 시청자가 볼륨을 올리고, 다음 영상에서 놀란다 |
| 트루 피크 | **-1.5 dBTP 이하** | 인코딩 후 클리핑 방지 |
| 라우드니스 레인지(LRA) | **4 LU 이하** | 곡 간 음량 차가 크면 새벽에 아기가 깬다. 수면음악의 핵심 지표 |
| 저역 컷 | 30Hz 이하 하이패스 | 스마트폰 스피커에서 들리지 않으면서 헤드룸만 먹는다 |
| 고역 | 12kHz 이상 완만히 감쇠 | 밤에 거슬리는 대역 제거 |

측정은 ffmpeg으로 충분하다.

```bash
ffmpeg -i input.wav -af ebur128=peak=true -f null - 2>&1 | tail -20
```

출력의 `I:`(통합 LUFS), `LRA:`, `Peak:`를 확인한다.

## 2. 구조 타임라인

### 10시간 밤잠 롱폼

| 구간 | 내용 | 목적 |
|---|---|---|
| 0:00 | **즉시 음악 시작.** 무음·로고·나레이션 금지 | 첫 5초 이탈 방지 |
| 0:00~10:00 | 가장 선율이 분명한 곡. 곡 전환 1회 | 평균 시청 지속 시간 구간. 여기서 버텨야 12분 목표 달성 |
| 10:00~20:00 | 레이어 추가(심장박동 또는 빗소리 페이드 인) | 중반 이탈 지점. 변화로 붙잡는다 |
| 20:00~60:00 | 선율 단순화, 반복 주기 확대 | 아기 수면 진입 |
| 1:00:00 이후 | 거의 정적인 패드·소음. 30분 주기 아주 느린 변화 | 새벽 각성 방지 |
| 마지막 20초 | 페이드 아웃하지 않고 볼륨 유지 | 최종화면 클릭 기회 확보 |

### 1~3시간 낮잠

- 0:00 즉시 시작, 15분 주기로 곡 전환.
- 끝에서 60초에 걸쳐 페이드 아웃. 낮잠은 깨어나는 것이 정상이다.

## 3. 시각 요소

비진정성 콘텐츠 정책 대응을 위해 영상마다 시각 요소를 다르게 한다. 같은 정지 이미지를 반복 사용하면 템플릿형 대량생산으로 판정될 수 있다.

- 최소한: 배경 색조, 별·구름 위치, 미세 모션(밝기 호흡)을 영상마다 바꾼다.
- 권장: 8~12시간 중 30분 주기로 아주 느린 그라디언트 변화를 넣는다. 파일 크기 영향이 작고 "정지 이미지 + 오디오" 판정을 피한다.
- 해상도 1920×1080, 30fps, 비트레이트는 정적 화면이므로 2~4Mbps로 충분하다.

## 5. 출고 전 체크리스트

- [ ] 0초에 음악이 나온다 (무음 구간 없음)
- [ ] 통합 라우드니스 -17 ~ -14 LUFS
- [ ] LRA 4 LU 이하
- [ ] 트루 피크 -1.5 dBTP 이하
- [ ] 첫 10분 안에 곡 전환 1회 이상
- [ ] 시각 요소가 직전 영상과 다르다
- [ ] 마지막 20초 볼륨이 유지된다
