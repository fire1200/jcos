# YouTube Music 유통·팟캐스트 RSS 실행 체크리스트 (처방 3-9)

**왜 필요한가.** 유튜브 본편 추천·검색 외에 수면음악이 많이 소비되는 표면이 두 곳 더 있다. YouTube Music 앱(오디오 전용 청취)과 팟캐스트 섹션(홈 캐러셀·TV 앱·YouTube Music 팟캐스트)이다. 둘 다 이미 만든 음원을 재활용하므로 제작 비용이 거의 없다.

## 0. 시작 전 판단

| 질문 | 예 | 아니오 |
|---|---|---|
| 음원이 자체 제작 또는 독점 라이선스인가 | 진행 | 유통 불가. 로열티 프리·AI 원본 음원은 유통사 심사에서 거절되거나 Content ID 충돌이 생긴다 |

**→ 2026-09-17 확인: 전량 자체 제작곡. 첫 행은 "예"로 확정, 바로 1절부터 진행한다.**
| 아티스트명을 정했는가 | 진행 (포근한 밤 자장가 / Cozy Night Lullaby) | 채널명과 동일하게 정한다. 발매마다 철자·띄어쓰기가 같아야 Topic 채널이 하나로 묶인다 |
| 앨범 커버(3000×3000 이상)가 있는가 | 진행 | 썸네일 가이드의 밤잠 시리즈 레이아웃을 정사각형으로 변형해 만든다 |

`templates/audio_production_spec.md` 4절의 음원 출처표는 모든 행이 "자체 제작"이므로 전 곡이 유통 대상이다. 첫 앨범에는 스튜디오 기준 평균 시청 지속 시간이 긴 순서로 10곡을 고른다.

## 1. YouTube Music 유통

### 1-1. 유통사 선택

| 구분 | 예 | 특징 |
|---|---|---|
| 국내 | 뮤즈플랫폼, 사운드리퍼블리카 | 한국어 지원, 국내 스트리밍(멜론·지니) 동시 등록 |
| 해외 | DistroKid, TuneCore, CD Baby | 연회비형, 무제한 발매, YouTube Music·Spotify·Apple 동시 |

수면음악은 해외 청취 비중이 크므로 해외 유통사 하나로 시작해도 충분하다.

### 1-2. 첫 앨범 구성

- 곡 수: 10곡. 각 30~60분이면 앨범 총 길이 5~10시간.
- 곡 제목은 롱폼 제목 공식의 앞부분을 쓴다. 예) `신생아 자장가 - 엄마 심장박동과 피아노`, 영어 병기 `Newborn Lullaby - Heartbeat & Piano`.
- 장르: New Age 또는 Ambient. "Children's Music"은 고르지 않는다(아동용 분류 위험).
- 앨범명: `아기 수면음악 Vol.1` 형태로 시리즈화.

### 1-3. 메타데이터 시트

발매 전에 아래를 채워 둔다. 발매 후 수정은 유통사마다 제한이 있다.

| 트랙 | 곡 제목(한) | 곡 제목(영) | 길이 | ISRC | 작곡자 | 원본 롱폼 영상 |
|---|---|---|---|---|---|---|
| 1 | | | | (유통사 자동 발급) | | |
| 2 | | | | | | |
| … | | | | | | |

- ISRC는 유통사가 무료로 발급한다. 직접 만들지 않는다.
- 작곡자 실명은 저작권 등록에 쓰이므로 정확히 기입한다.

### 1-4. 공식 아티스트 채널(OAC) 신청

1. 첫 앨범이 YouTube Music에 반영되면(보통 1~2주) Topic 채널이 자동 생성된다.
2. 유통사 대시보드에서 "YouTube Official Artist Channel" 신청 메뉴를 찾아 기존 채널 URL을 제출한다.
3. 승인되면 기존 채널에 음표 아이콘이 붙고, Topic 채널의 아트 트랙 조회수가 채널 통계에 합산된다.
4. 승인 조건: 채널에 자체 음원 영상 3개 이상, 유통사 발매 1건 이상.

### 1-4b. 저작권 등록 (선택, 수익 관련)

자체 제작곡이므로 한국음악저작권협회(KOMCA) 등록이 가능하다. 유튜브·YouTube Music·해외 스트리밍의 공연·전송 사용료가 별도로 정산된다. 노출과는 무관하지만 같은 음원에서 나오는 추가 수익이므로 유통사 발매와 함께 진행하면 효율적이다. 협회 가입에는 발표곡 실적이 필요하므로 유통사 발매 뒤에 신청한다.

### 1-5. 확인

- [ ] YouTube Music 앱에서 아티스트명 검색 시 Topic 채널이 뜬다
- [ ] 스튜디오 트래픽 소스에 "YouTube Music" 행이 생겼다
- [ ] 채널명 옆에 공식 아티스트 아이콘이 표시된다

## 2. 팟캐스트 RSS 연동

### 2-1. 호스팅

무료 티어가 있는 호스팅(Spotify for Creators, RSS.com 등)에 계정을 만들고 프로그램을 개설한다.

| 항목 | 값 |
|---|---|
| 프로그램명 | `포근한 밤 자장가 \| 아기 수면음악` |
| 카테고리 | Health & Fitness > Alternative Health, 또는 Music |
| 설명 첫 두 문장 | 롱폼 설명문 규칙과 동일. 줄글, 키워드 포함 |
| 커버 | 앨범 커버와 동일 (3000×3000) |
| 명시적 콘텐츠 | 아니오 |

### 2-2. 에피소드

- 10시간 롱폼의 오디오를 그대로 올린다. 대부분의 호스팅이 파일당 용량 제한이 있으므로 128kbps MP3로 인코딩하면 10시간에 약 550MB다. 제한을 넘기면 5시간으로 나눈다.
- 에피소드 제목 = 롱폼 제목. 설명 = 롱폼 설명 첫 세 줄 + 유튜브 영상 링크.
- 첫 등록은 3편. 이후 새 롱폼마다 1편씩 추가.

### 2-3. YouTube 연결

1. YouTube 스튜디오 > 만들기 > 새 팟캐스트 > **RSS 피드로 팟캐스트 제출**.
2. RSS URL 입력 후 이메일 인증.
3. 반영되면 채널에 "팟캐스트" 탭이 생기고, 각 에피소드가 정적 이미지 영상으로 자동 생성된다.
4. 자동 생성된 영상도 시청자층은 "아동용 아님"으로 설정한다.

### 2-4. 외부 배포

같은 RSS를 Spotify, Apple Podcasts에도 등록한다. 등록 화면에서 RSS URL만 붙여 넣으면 된다. 유튜브 밖 청취자를 채널로 데려오는 경로가 된다.

### 2-5. 확인

- [ ] 채널 페이지에 팟캐스트 탭이 보인다
- [ ] YouTube Music 앱 팟캐스트 검색에서 프로그램이 뜬다
- [ ] 스튜디오 트래픽 소스에 "팟캐스트" 관련 행이 생겼다
- [ ] Spotify·Apple Podcasts에 프로그램이 등록됐다

## 3. 일정과 측정

| 주차 | 작업 |
|---|---|
| 1주 | 음원 출처 정리, 유통사·호스팅 계정 개설, 커버 제작 |
| 2주 | 첫 앨범 10곡 제출, 팟캐스트 3편 등록, 스튜디오 RSS 연결 |

## 4. 주의

- 유통사 발매 음원을 유튜브 본편에도 올려 두면 Content ID가 자기 영상에 클레임을 걸 수 있다. 유통사 대시보드에서 자기 채널을 화이트리스트에 등록한다.
- 팟캐스트 자동 생성 영상은 본편 롱폼과 오디오가 같으므로, 본편 영상 설명에 "팟캐스트 버전" 링크를 넣어 중복 콘텐츠가 아닌 형식 차이임을 명시한다.
- 아티스트명·앨범명에 "키즈", "어린이"를 넣지 않는다.
