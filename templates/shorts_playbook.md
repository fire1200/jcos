# 쇼츠 플레이북 (처방 3-5)

**왜 필요한가.** 롱폼만 있으면 신규 시청자 유입이 검색으로 한정된다. 2026년 쇼츠는 채널을 한 번도 본 적 없는 시청자에게 닿는 주요 경로이고, "관련 동영상" 링크로 롱폼·라이브에 직접 연결할 수 있다.

## 1. 발행 규격

| 항목 | 값 |
|---|---|
| 길이 | 15~30초. 45초를 넘기지 않는다 |
| 비율 | 9:16 세로. 롱폼 화면을 잘라 쓰지 말고 세로용으로 따로 만든다 |
| 빈도 | 주 3~5회 |
| 관련 동영상 링크 | **반드시 설정.** 해당 롱폼 또는 24시간 라이브 |
| 자막 | 항상 켠다. 무음으로 보는 시청자가 많다 |
| 시청자층 | 롱폼과 동일하게 "아동용 아님" |

## 2. 훅 유형 5종과 대본

각 대본은 0초부터 텍스트가 화면에 있어야 한다. 쇼츠는 첫 1초에 스크롤 여부가 갈린다.

### 유형 A. 결과 선언형
```
[0초 텍스트] 이 소리 틀고 3분 만에 잠든 아기
[0~3초] 잠든 아기 영상 또는 조용한 아기방, 음악 즉시 시작
[3~20초] 음악 유지, 텍스트 전환: "엄마 심장박동 + 피아노"
[20~28초] "전체 10시간 버전은 아래 링크"
[관련 동영상] 해당 롱폼
```

### 유형 B. 문제 제시형
```
[0초 텍스트] 새벽 3시에 꼭 깨는 아기라면
[3~8초] "원인은 수면 주기 전환입니다"
[8~20초] "이 구간에 소리가 끊기면 깹니다" + 음악
[20~28초] "끊김 없는 10시간 버전"
[관련 동영상] 10시간 롱폼
```

### 유형 C. 비교형
```
[0초 텍스트] 백색소음 3가지, 아기 반응 차이
[0~8초] 빗소리 / [8~16초] 드라이기 / [16~24초] 심장박동
각 구간에 소리 이름 텍스트
[24~30초] "우리 아기에게 맞는 소리 찾기"
[관련 동영상] 백색소음 재생목록 대표 영상
```

### 유형 D. 팁형
```
[0초 텍스트] 수면음악 볼륨, 이게 기준입니다
[3~12초] "대화 소리보다 작게, 50dB 이하"
[12~22초] "아기에게서 1m 이상 떨어뜨리기"
[22~28초] "잠든 뒤 30분 타이머 권장"
[관련 동영상] 24시간 라이브
```

### 유형 E. 루틴형
```
[0초 텍스트] 재우기 루틴 3단계
[0~8초] 목욕 / [8~16초] 수유 / [16~24초] 음악
[24~30초] "매일 같은 시간, 같은 곡이 핵심"
[관련 동영상] 밤잠 재생목록 대표 영상
```

## 3. 제목·해시태그

- 제목은 40자 이내, 훅 문장 그대로. 키워드를 억지로 넣지 않는다. 쇼츠는 검색보다 피드가 주력이다.
- 해시태그 3개: `#아기수면음악 #신생아 #육아`
- 영어 쇼츠는 `#babysleepmusic #newborn #parenting`

## 4. 롱폼 전환 설계

쇼츠 조회수 자체는 목표가 아니다. 목표는 롱폼·라이브 유입이다.

- 마지막 3초에 시각적 CTA를 넣는다. 화살표와 "아래 링크" 텍스트.
- 관련 동영상 링크가 없는 쇼츠는 발행하지 않는다.
- 스튜디오 쇼츠 분석에서 "관련 동영상 클릭"을 주간 기록한다. `tools/kpi_tracker.xlsx`에 항목이 있다.

## 5. 하지 말 것

- 롱폼을 그대로 30초 잘라 붙이기. 훅이 없어 스크롤된다.
- 자막 없이 음악만. 무음 시청자에게 아무것도 전달되지 않는다.
- 아기 얼굴 클로즈업 썸네일. 아동용 자동 분류 위험.
- 같은 훅 문장 반복. 3회 이상 같은 대본은 피로도를 만든다.
