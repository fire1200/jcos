# 썸네일 가이드 (아기 수면음악 채널)

목적: 추천 피드에서 "같은 채널"로 즉시 인식되고, 부모가 밤에 어두운 화면에서도 읽을 수 있는 썸네일.

## 1. 고정 규칙

| 항목 | 규칙 |
|---|---|
| 크기 | 1280×720, 16:9, 2MB 이하, JPG 또는 PNG |
| 배경 | 남색 계열 단색 또는 부드러운 그라디언트. 채널 기본색 `#1B2A49` |
| 강조색 | 따뜻한 노란색 `#F5C86B` (달·별·텍스트 강조 1곳에만) |
| 보조색 | 연한 라벤더 `#C9B8E8` (구름·글로우) |
| 아이콘 | 달, 별, 구름, 조명, 오르골, 피아노 중 **1개**. 아기 얼굴 사진·만화 캐릭터·장난감 금지 |
| 텍스트 | 한글 1줄, 최대 6자. 예: "통잠 자장가", "10시간", "울음 멈춤" |
| 폰트 | 굵은 고딕(Pretendard Black, 노토산스 KR Black). 최소 120pt 상당 |
| 텍스트 위치 | 좌측 또는 우측 하단 고정. 우측 하단 모서리는 재생시간 표시와 겹치니 피한다 |
| 여백 | 상하좌우 60px 안쪽에 요소 배치 |
| 로고 | 좌측 상단 작은 워터마크 1개, 투명도 70% |

## 2. 시리즈별 변형

같은 레이아웃을 유지하고 아이콘과 강조색 톤만 바꾼다.

| 시리즈 | 아이콘 | 강조색 | 텍스트 예 |
|---|---|---|---|
| 밤잠 10시간 | 초승달 | 노란색 | "통잠 10시간" |
| 낮잠 | 구름 + 햇살 | 연주황 `#F7B58C` | "낮잠 2시간" |
| 백색소음 | 파형 곡선 | 민트 `#9FE1CB` | "울음 멈춤" |
| 태교 | 하트 안 별 | 연핑크 `#F2B8C6` | "태교 피아노" |
| 라이브 | 초승달 + LIVE 배지 | 빨간 배지 | "24시간 라이브" |

## 3. 제작 체크리스트

- [ ] 모바일 폭(약 160px)으로 축소해도 텍스트가 읽히는가
- [ ] 어두운 방에서 밝기 30%로 봐도 아이콘 형태가 보이는가
- [ ] 아기 얼굴, 캐릭터, 장난감, "키즈" 표현이 없는가
- [ ] 텍스트가 제목과 중복되지 않고 보완하는가 (제목: 키워드, 썸네일: 결과)
- [ ] 채널 페이지에서 최근 9개 썸네일이 한 세트처럼 보이는가
- [ ] 우측 하단에 재생시간 표시와 겹치는 요소가 없는가

## 4. A/B 테스트 운영

- 매 영상 3종 제작: A 텍스트 강조형, B 아이콘 강조형, C 텍스트 없음.
- 스튜디오 "테스트 및 비교"로 등록, 최소 2주 또는 노출 1만 회 이상 후 판정.
- 승자 패턴을 아래 로그에 기록해 3회 이상 이긴 패턴을 기본형으로 승격.

| 날짜 | 영상 | A | B | C | 승자 | 시청시간 점유율 | 메모 |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

## 5. 금지 사항

- 클릭베이트 문구 ("충격", "절대") → 불만족 신호.
- 빨간 화살표·원 표시 → 수면 콘텐츠 톤과 충돌.
- 텍스트 2줄 이상 → 모바일에서 판독 불가.
- 매 영상 다른 레이아웃 → 채널 인식 실패.
