## 0. 태그를 지우면서 같이 고쳐야 할 것

`[웃]`·`[옷]`을 지우는 김에 **더 큰 문제**를 함께 고칩니다.

| 문제 | 현재 | 영향 |
|---|---:|---|
| **제목 길이** | 평균 **84자**, 최대 98자, **61편 전부 60자 초과** | 모바일에서 뒷부분이 잘림 |
| **길이 표기 위치** | `\| 2 Hours` 가 맨 뒤 | 잘려서 안 보임. 이 장르 최대 클릭 요소인데 |
| BPM 중복 | `180 BPM ... 180spm` | 같은 숫자를 두 번. 글자만 먹음 |
| `Cadence` 접두 불일치 | 붙은 것과 안 붙은 것이 섞임 | 시리즈로 안 보임 |

`[웃]`·`[옷]` 4글자는 **네 번째로 큰 문제**입니다. 제목 전체를 손대는 김에 다 정리하세요.

### 모바일에서 실제로 보이는 것 (약 45자)

```
현재  「[옷] 180 BPM K-Pop Running Music 🔥 Girl-Crush 」
제안  「K-Pop Running Music 180 BPM | 2 Hours 🔥 Seoul」
```

같은 45자에 현재는 **장르와 BPM**만, 제안은 **장르·BPM·길이·장소**가 다 들어갑니다.

---

## 1. 제목 공식

### 1-1. 2시간 믹스 (28편)

```
[장르] Running Music [BPM] BPM | [길이] [이모지 1개] [장소·분위기]
```

| 자리 | 내용 | 왜 여기 |
|---|---|---|
| 1 | 장르 | 이 영상만의 차별점. `Rock`, `K-Pop`, `Piano`, `Techno`, `Jazz`, `Hip-Hop` |
| 2 | `Running Music` | 최대 검색어. 고정 |
| 3 | `[BPM] BPM` | 러너가 케이던스로 고릅니다 |
| 4 | `\| 2 Hours` | **앞으로 옮겼습니다.** 클릭 전 안심 요소 |
| 5 | 이모지 1개 | 구분자. 목록에서 눈에 걸림 |
| 6 | 장소·분위기 | 28편을 서로 구분. 잘려도 됨 |

**예시 (전부 60자 이하)**

```
K-Pop Running Music 180 BPM | 2 Hours 🔥 Seoul Han River        (55자)
Rock Running Music 210 BPM | 2 Hours 🎸 Budapest Sprint         (54자)
Rock Running Music 174 BPM | 2 Hours 🎸 Toronto Waterfront      (57자)
Techno Running Music 210 BPM | 2 Hours ⚡ London Sprint         (54자)
Piano Running Music 174 BPM | 2 Hours 🎹 Paris Morning Run      (57자)
Jazz Running Music 190 BPM | 2 Hours 🎷 Midnight River Run      (57자)
```

### 1-2. 단곡 (33편)

```
[장르] Running Track [BPM] BPM [이모지] "[곡명]" | [장소]
```

`Running Music` 이 아니라 **`Running Track`** 입니다. 이 한 단어가 믹스와 단곡을 가릅니다.

```
Romantic Piano Running Track 180 BPM 🎹 "Duiker" | Seoul        (55자)
Euro Techno Running Track 210 BPM ⚡ "Chacoan Mara" | London    (59자)
Cinematic Hip-Hop Running Track 174 BPM 🎬 "Steenbok"           (53자)
```

60자를 넘으면 **장소를 먼저 버리세요.** 곡명은 남깁니다 — 33편을 구분하는 유일한 요소입니다.

---

## 2. 지켜야 할 규칙

| 규칙 | 이유 |
|---|---|
| **60자 이하** | 넘으면 검색 결과에서 잘립니다 |
| **앞 45자 안에 장르·`Running Music`·BPM·길이** | 모바일 잘림 지점 |
| BPM은 **한 번만** | `180 BPM`과 `180spm`을 같이 쓰지 않습니다. SPM은 태그와 설명에 |
| 이모지 **1개** | 구분자 역할. 2개 이상은 글자만 먹습니다 |
| `Cadence` 접두 **쓰지 않음** | 재생목록 이름으로 옮깁니다 |
| 장소·분위기는 **맨 뒤** | 잘려도 손해가 가장 작습니다 |
| **같은 제목 금지** | 같은 장르·같은 BPM이면 장소로 반드시 구분 |

### SPM은 어디로 가나

러너 커뮤니티는 SPM(분당 걸음 수)을 씁니다. 제목에서 빼는 대신 **태그와 설명 첫 줄**에 넣습니다.

```
태그:  180 spm, running cadence 180, 180 bpm running music, rock running music, ...
설명:  Steady 180 BPM (180 SPM cadence) rock mix for a two-hour tempo run.
```

제목에서 8자를 아끼고 검색은 그대로 잡습니다.

## 3. 분류는 재생목록으로

`[웃]`·`[옷]`이 하던 일을 재생목록이 대신합니다. **더 잘합니다** — 빠이요 재생목록 CTR은 11.83%로 채널 평균의 **7배**입니다.

러너는 **케이던스로 고릅니다.** 그래서 BPM 구간으로 나눕니다.

| 재생목록 | 담을 것 | 러너의 용도 |
|---|---|---|
| `Easy Run — 160–174 BPM` | 믹스 중 160·174 | 회복주, 조깅 |
| `Tempo Run — 180 BPM` | 믹스 중 180 | 표준 케이던스 |
| `Speed Work — 190–210 BPM` | 믹스 중 190·210 | 인터벌, 스프린트 |
| `Original Running Tracks` | 단곡 33편 전부 | 곡 단위로 듣기 |

☐ 네 개를 먼저 만들고 영상을 배치한 뒤에 제목에서 태그를 지우세요. **분류를 옮겨 놓고 지워야 잃는 것이 없습니다.**

## 6. 같이 생각해 볼 것 — 단곡 33편

단곡 33편은 **토담토담에서 정리하기로 한 2분짜리 33편과 같은 구조**입니다. 편당 조회가 한 자릿수이고, 믹스에 이미 들어 있는 곡입니다.

지금 지우자는 것은 아닙니다. 다만 **앞으로는 단곡을 개별 영상으로 올리지 마세요.**

| 단곡의 쓸모 | 어떻게 |
|---|---|
| 쇼츠 소재 | 3~10분 곡에서 15초를 잘라 쇼츠로 |
| 유통 | 스트리밍 발매는 곡 단위 |
| 믹스 재료 | 2시간 믹스의 구성 |

**세 가지 다 개별 롱폼 영상으로 올릴 필요가 없습니다.** 재생목록에 묶어 두고, 새 곡은 믹스로 냅니다.
