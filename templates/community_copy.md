# 커뮤니티·고정댓글·설문 문안 모음

목적: 최근 30일 재방문 시청자를 늘린다. 재방문율이 낮으면 구독자 수와 무관하게 추천에서 밀린다.

## 1. 주간 루틴

| 요일 | 유형 | 내용 |
|---|---|---|
| 월 | 설문 | 이번 주 소리 투표 |
| 화 | 업로드 | 롱폼 + 고정댓글 |
| 수 | 팁 카드 | 재우기 루틴 한 줄 팁 |
| 목 | 쇼츠 | 롱폼 30초 클립 |
| 금 | 업로드 | 롱폼 + 고정댓글 |
| 토 | 감사·후기 | 댓글 후기 캡처 공유 (허락 받은 것만) |
| 일 | 예고 | 다음 주 라인업 |

## 2. 설문 문안

```
이번 주 밤잠 자장가, 어떤 소리로 만들까요? 🌙
○ 엄마 심장박동 + 피아노
○ 빗소리 + 오르골
○ 자궁소리 단독
○ 파도소리 + 허밍
```

```
아기가 밤에 깨는 시간은 주로 언제인가요?
○ 자정 전  ○ 새벽 1~3시  ○ 새벽 4~6시  ○ 거의 안 깸
→ 결과에 맞춰 곡 전환 시점을 배치합니다.
```

```
지금 아기 월령을 알려 주세요 (콘텐츠 기획용)
○ 0~3개월  ○ 4~6개월  ○ 7~12개월  ○ 13개월 이상
```

## 3. 팁 카드 문안 (수요일)

- 재우기 음악은 매일 같은 시간, 같은 곡으로 시작해야 "잠 신호"가 됩니다.
- 볼륨 기준: 부모가 속삭이는 소리보다 작게. 50dB 이하.
- 백색소음은 밤새 켜 두는 것보다 잠든 뒤 30분 후 자동 종료가 청력에 안전합니다. 타이머 활용.
- 낮잠은 커튼을 완전히 닫지 말고, 밤잠 음악과 낮잠 음악을 다르게 두면 아기가 구분합니다.
- 4개월 전후 수면 퇴행 시기에는 새 음악보다 익숙한 음악을 유지하세요.

## 4. 고정댓글 변형

### 기본
```
밤새 끊김 없이 이어집니다 🌙 볼륨은 속삭임보다 작게, 1m 이상 떨어진 곳에.
오늘 몇 분 만에 잠들었는지 댓글로 남겨 주세요.
```

### 백색소음 영상
```
이 소리는 자궁 안 소음 레벨(약 50dB)을 기준으로 만들었습니다.
30분 타이머와 함께 쓰시길 권합니다. 도움이 됐다면 다음 영상 소리를 설문에서 골라 주세요.
```

### 태교 영상
```
임신 주수를 댓글에 남겨 주시면, 주수별로 추천 시간대를 답변드립니다 💛
```

## 5. 댓글 답변 원칙

- 24시간 안에 전부 답변. 질문으로 끝내 대화를 이어간다.
- "몇 분 만에 잠들었다" 후기는 다음 영상 설명에 인용(허락 후).
- 요청 사운드는 반드시 다음 영상으로 만들고, 공개 시 요청자 언급.
- 부정 댓글(볼륨, 광고)은 사실 확인 후 수정 내용을 답변.
