## 1. 제 10/14 조언을 수정합니다

10/14에 이렇게 썼습니다.

> 직접 작곡·연주 → 해외 + **국내 + KOMCA 등록** (헬스장 공연료까지)

**국내와 KOMCA는 보류하시길 권합니다.** 조건을 확인한 결과입니다.

### 수정 이유 ① — "헬스장 공연료"는 제 과장이었습니다

KOMCA 공연 사용료는 **실제로 그 곡이 매장·방송에서 재생되어야** 발생합니다.

| | 현실 |
|---|---|
| 헬스장 BGM | 대부분 **상업용 음원 서비스**(샵캐스트 등)를 씁니다. 개별 신인 곡이 들어갈 자리가 아닙니다 |
| 방송 | 신인 러닝 음원이 지상파·케이블에 쓰일 가능성 ≈ 0 |

**발매 직후 신인 곡의 공연 사용료는 사실상 0원입니다.** 제가 이걸 국내 유통의 이유로 든 것은 근거가 약했습니다.

### 수정 이유 ② — KOMCA 신탁은 되돌리기 어렵습니다

| 항목 | 내용 |
|---|---|
| **신탁 범위** | 가입 시 **저작재산권 전부**를 협회에 신탁하는 구조입니다. 이 점은 업계에서 비판받아 온 부분입니다 |
| 탈퇴 | 탈퇴 후 **만 3년**이 지나야 재입회 가능 |
| 입회비 | **반환하지 않습니다** |
| 신청금 | 블로그 자료 기준 18~20만원 수준 (**공식 확인 필요**) |

**한 번 맡기면 3년간 되돌릴 수 없습니다.**

### 수정 이유 ③ — 기존 153편과 충돌 위험

빠이요 유튜브에 **같은 곡이 이미 올라가 있습니다.**

KOMCA 신탁 음원과 유통사 Content ID가 겹치면 **같은 곡에 두 곳이 권리를 주장**하는 상태가 됩니다. 본인 채널 영상이라도 꼬일 수 있습니다.

**이 상호작용을 제가 확신을 갖고 조언하기 어렵습니다.** 잘못 건드리면 기존 153편이 모두 영향을 받습니다.

### 수정 이유 ④ — 국내 스트리밍 수익이 거의 없습니다

| | |
|---|---|
| 곡명 | 영어 (Duiker, Steenbok, Chacoan Mara…) |
| 타깃 | 영어권 러너 |
| 국내 유통사 수수료 | **수익의 15~20%를 계속** |

**멜론·지니 이용자가 영어 제목 러닝 음악을 찾을 이유가 거의 없습니다.** 수익이 0에 가까운데 수수료 구조만 떠안습니다.

> ⚠️ 요금은 출처마다 달랐습니다. **결제 전 공식 요금 페이지에서 확인하세요.** Content ID 같은 애드온은 별도 요금입니다.

## 3. 실행 일정

| 날짜 | 할 일 | 소요 |
|---|---|---|
| 10/21 (수) | DistroKid 가입. **아티스트명 확정** | 40분 |
| 10/22~10/25 | 28곡 라우드니스 정리 (-10~-9 LUFS), WAV 추출 | 3시간 |
| 10/26 (월) | 커버 5장 제작 (3000×3000) | 2시간 |
| **10/27 (화)** | **EP3 (180 BPM) 업로드. 발매일 11/17 지정** | 1시간 |
| **11/3 (화)** | **Spotify 피칭 — 대표곡 1곡** (발매 14일 전) | 30분 |
| **11/17 (화)** | **EP3 발매** | — |
| 11/17 | EP2 (174 BPM) 업로드. 발매일 12/1 | 40분 |
| 11/24 | EP2 피칭 | 20분 |
| **12/1** | EP2 발매 | — |
| 이후 2주 간격 | EP1 (160) → EP4 (190) → EP5 (210) | |
| **1/26 (화)** | 5장 발매 완료 | — |

**총 약 9시간**이고 대부분 첫 주에 몰립니다. 이후는 2주마다 1시간입니다.

### 발매 순서

| 순서 | EP | 왜 |
|---|---|---|
| 1 | **180 BPM** | 러닝 케이던스 **표준**. 수요가 가장 큼. 첫 피칭을 여기 씁니다 |
| 2 | 174 BPM | 두 번째로 큼 |
| 3 | 160 BPM | 회복주·조깅 |
| 4 | 190 BPM | 스피드 |
| 5 | 210 BPM | 가장 좁음 (4곡) |

**Spotify는 한 번에 한 곡만 피칭됩니다.** 5장을 순차 발매하면 기회가 5번, 한꺼번에 내면 1번입니다.

## 4. 반드시 지킬 것 두 가지

### ① 아티스트명을 모든 발매에서 똑같이

철자·띄어쓰기가 하나라도 다르면 Spotify에서 **다른 아티스트로 갈라집니다.** 5장이 한 페이지에 모이지 않습니다.

☐ 아티스트명을 정하고 메모해 두세요. 5번 입력할 때마다 복사해서 붙이세요

### ② Content ID 화이트리스트

☐ **유통사 대시보드에서 빠이요 채널을 화이트리스트에 등록**

빠뜨리면 유통한 음원이 **기존 153편 전부에 클레임**을 겁니다. 영상이 수익 정지되고 푸는 데 시간이 걸립니다.

## 6. 국내와 KOMCA는 1년 뒤에 다시 봅니다

지금 안 하는 것이지 영영 안 하는 것이 아닙니다.

| 2027년 10월에 확인할 것 | 그러면 |
|---|---|
| Spotify에서 **월 1만 스트림을 넘는 곡**이 생겼는가 | 국내 유통 검토 |
| **플레이리스트에 등재**됐는가 | KOMCA 검토 |
| 국내 러너 유입이 보이는가 | 국내 유통 검토 |

**실적이 생긴 뒤에 들어가는 편이 모든 면에서 낫습니다.** 신탁 조건도 협상 여지가 생기고, 무엇보다 되돌릴 수 없는 결정을 데이터 없이 내리지 않게 됩니다.
