# A. 일반 신곡 (15 · 16 · 17)

## 넣는 방법 (일반 신곡)

1. **Custom** 켜기 → **Lyrics**에 `가사` 상자 통째로 → **Style of Music**에 `스타일 1안` → **Title**에 제목
2. 마음에 들지 않으면 같은 가사에 `스타일 2안`으로 한 번 더 만듭니다.

**공통 제외어 (Exclude Styles)**
```
rap, trap, heavy drums, distorted guitar, EDM drop, autotune, adult pop vocal, vibrato-heavy, scream, horror, sad minor ballad
```

**청음 체크**
- [ ] 가사가 또렷하다 (특히 받침: 뒤뚱, 칙칙폭폭, 첨벙, 꽥, 펑펑, 뽀드득)
- [ ] **가사 순서가 대본과 같다.** 다른 곡 가사가 섞이지 않았다(1차 7번 곡 때 있었던 문제)
- [ ] 후렴을 한 번 듣고 따라 부를 수 있다
- [ ] 이미 아는 동요와 선율이 비슷하게 들리지 않는다. 비슷하면 다시 만듭니다
- [ ] 2분 안팎에서 끝나고, 끝이 뚝 끊기지 않는다
- [ ] 외치는 소리가 무섭거나 거칠지 않다

### 15. 뒤뚱뒤뚱 펭귄 가족

# B. 첫말 노래 (⑪ · ⑫)

## 넣는 방법 (첫말)

1. **Custom 모드** → 아래 **Style**과 **Lyrics**를 그대로 붙여 넣고, **Title**에 곡 제목을 씁니다.
2. **Exclude styles**: `reverb, choir, male vocals, rap, autotune, fast tempo, long intro`
3. 한 곡에 4개 이상 뽑아 고릅니다. **첫 소리가 3초 안에 나오는지**, 단어가 반주보다 또렷한지 꼭 확인해 주세요.
