## 1. 진단: 도달은 되는데 자산이 안 쌓인다

### 1-1. 시청시간이 사실상 0이다

| 채널·경로 | 조회 1,000회당 시청시간 |
|---|---|
| **@jkos_kr 현재** | **1.1시간** |
| @PPAIEO 쇼츠 피드 | 1.1시간 |
| @PPAIEO 추천 동영상 | 69.3시간 |
| @dodamam 검색 유입 | **209.2시간** |

@jkos_kr은 조회 2,715회로 시청시간 3.07시간을 만들었습니다. @dodamam은 조회 **6회**로 1.06시간을 만들었습니다.
조회수는 452배 차이인데 시청시간은 3배 차이입니다.

구독은 시청시간에서 나옵니다. 11초를 본 사람은 채널 이름조차 기억하지 못합니다.

### 1-2. 조회가 업로드일에만 발생한다

조회 발생 14일 중 **상위 3일이 전체의 82%**입니다. 9/5에 1,512회, 9/18에 440회, 9/17에 221회. 나머지 날은 4~83회입니다.
올린 날만 조회가 나오고 다음 날 사라집니다. 누적되는 자산이 없습니다.

### 1-3. 타깃은 정확하다

한국에서만 시청됩니다. 서울 351, 부산 88, 인천 59, 대구 41. 해외 유입이 없습니다.
**광고로서는 이미 잘 작동하고 있습니다.** 고칠 것은 도달이 아니라 "본 사람이 남을 이유"입니다.

## 2. 앱 설치가 목표이면 평가 기준이 바뀐다

### 2-1. 앞선 판의 "쇼츠는 저효율"은 이 채널에 그대로 적용되지 않는다

이 저장소의 다른 분석에서 쇼츠를 저효율로 평가했습니다. 그 기준은 **시청시간과 구독자**였습니다.
앱 설치가 목표라면 기준이 다릅니다.

| 목표 | 좋은 트래픽 | 쇼츠 평가 |
|---|---|---|
| 시청시간·구독 (수면음악, 러닝) | 검색·추천 롱폼 | 나쁨 (조회 1,000당 1.1시간) |
| **앱 설치 (@jkos_kr)** | **모바일에서 손가락이 이미 화면에 있는 상태** | **좋음** |

쇼츠는 시청자의 100%가 모바일이고, 스크롤 중이라 탭 장벽이 낮습니다. 앱스토어까지 가는 경로가 짧습니다.
반면 롱폼은 PC·TV 시청이 섞여 있어 그 자리에서 설치하기 어렵습니다.

**따라서 쇼츠를 줄이면 안 됩니다.** 지금 조회 2,715회는 앱 설치 관점에서는 버리는 숫자가 아닙니다.

### 2-2. 그런데도 롱폼이 필요한 이유

구독자를 쌓고 싶다고 하셨고, 그것 말고도 실질적인 이유가 있습니다.

| 롱폼이 주는 것 | 앱 설치에 어떻게 기여하나 |
|---|---|
| 검색 유입 | 9월에 "중앙대 등급컷"을 검색한 수험생이 1년 내내 들어옴. 쇼츠는 하루면 끝 |
| 신뢰 | 10분을 본 사람은 앱을 깔 이유가 생김. 11초 본 사람은 앱 이름도 기억 못 함 |
| 재방문 | 구독자가 쌓이면 새 영상마다 설치 기회가 반복됨 |
| 앱 기능 설명 시간 | 쇼츠 20초로는 앱이 뭘 하는지 못 보여줌 |

### 2-3. 두 축을 나눠서 굴린다

| 축 | 포맷 | 목표 | 측정 |
|---|---|---|---|
| **설치 축** | 쇼츠 주 3~5편 | 즉시 설치 | 링크 클릭, 설치 수 |
| **자산 축** | 검색용 롱폼 주 1~2편 | 검색 유입·구독·신뢰 | 시청시간, 구독, 검색 비율 |

두 축은 서로 먹지 않습니다. 쇼츠로 들어온 사람이 롱폼을 보고, 롱폼으로 신뢰가 생긴 사람이 쇼츠에서 설치합니다.

### 3-2-1. 수험생 타깃에서 주의할 점

| 항목 | 이유 |
|---|---|
| 말투는 존댓말 + 또래 눈높이 | 반말은 거부감, 과한 격식은 이탈 |
| 영상 8~12분 | 수험생은 공부 사이에 봅니다. 20분은 길어요 |
| 자막 필수 | 독서실·이동 중 무음 시청이 많음 |

| 불안 조장 금지 | "이거 모르면 떨어진다" 식은 단기 클릭은 되지만 구독으로 안 감 |

### 3-3. 제목 공식

```
[대학·전형 키워드] + [구체적 질문·숫자] + [연도]
```

- 좋은 예: `중앙대 경영 등급컷 3년치 | 2027 수시 지원 가능선 정리`
- 나쁜 예: `입시 성공 비법 대공개!!` (검색어가 없고 클릭베이트)
- 나쁜 예: `이거 모르면 수시 망합니다` (불안 조장, 구독으로 안 이어짐)

앞 30자 안에 대학명 또는 전형명이 들어가야 검색에 잡힙니다. `tools/check_metadata.py`의 키워드 목록을 입시용으로 바꿔 쓰면 점검할 수 있습니다.

### 3-4. 앱 설치 전환 설계

#### 핵심 패턴: 문제 → 앱이 푸는 장면 → 링크

앱 마케팅에서 가장 잘 먹히는 구조는 **말로 설명하지 않고 화면으로 보여주는 것**입니다.

```
[0~3초]  수험생이 실제로 겪는 문제를 한 문장으로
         예) "환산점수 학교마다 달라서 계산 못 하겠지"
[3~15초] 앱 화면 녹화. 성적 입력 → 결과가 바로 나오는 장면
[15~25초] "링크에서 받을 수 있어" + 화면에 앱 아이콘
```

손으로 계산하는 장면과 앱으로 3초 만에 끝나는 장면을 **나란히 보여주면** 설치 이유가 설명 없이 전달됩니다.

#### 쇼츠 CTA 배치

| 위치 | 내용 |
|---|---|
| 화면 | 마지막 3초에 앱 아이콘 + "설명란 링크" 텍스트 |
| 고정댓글 | 설치 링크 (첫 줄) |
| 설명란 첫 줄 | 설치 링크 |
| 관련 동영상 링크 | 앱 사용법 롱폼 |

**설명란 링크는 반드시 첫 줄에 두세요.** 쇼츠 설명은 두 줄만 보이고 나머지는 접힙니다.

#### 링크는 하나로 통일한다

iOS와 Android를 따로 안내하면 이탈합니다. 기기를 감지해 자동으로 보내는 링크를 하나만 씁니다.

| 방법 | 비용 | 비고 |
|---|---|---|
| 직접 만든 랜딩 페이지 | 무료 | User-Agent로 iOS/Android 판별 후 각 스토어로 리다이렉트. 가장 단순하고 통제 가능 |
| AppsFlyer OneLink, Branch, Adjust | 무료 티어 있음 | 설치 귀속(어떤 영상에서 왔는지) 추적까지 됨 |

Firebase Dynamic Links는 2025년 8월에 종료되었으므로 쓰지 마세요.

랜딩 페이지를 만든다면 이렇게 둡니다.

```
jkos.example.com/app?v=shorts01
  → iOS면 App Store, Android면 Play Store로 리다이렉트
  → v 파라미터로 어느 영상에서 왔는지 기록
```

#### 설치 추적 설정

유튜브 스튜디오는 앱 설치를 알려주지 않습니다. 따로 붙여야 합니다.

- [ ] 랜딩 페이지에 GA4 설치 (링크 클릭 수 파악)
- [ ] 영상마다 링크 파라미터를 다르게 (`?v=shorts01`, `?v=long03`)
- [ ] Google Play Console > 통계 > **획득 보고서**에서 유입 경로 확인
- [ ] App Store Connect > 앱 분석 > **소스 유형**에서 웹 참조 확인
- [ ] 주간으로 "영상 조회 → 링크 클릭 → 설치" 세 단계를 기록

이 세 단계를 알아야 어디서 새는지 보입니다. 조회는 많은데 클릭이 없으면 CTA 문제, 클릭은 많은데 설치가 없으면 스토어 페이지 문제입니다.

#### 스토어 페이지도 퍼널의 일부다

영상을 아무리 잘 만들어도 스토어 페이지에서 떨어집니다.

- [ ] 앱 이름에 검색어 포함 (예: "등급컷", "입시" 등 실제 검색하는 말)
- [ ] 스크린샷 첫 장에 핵심 기능 한 장면
- [ ] 설명 첫 세 줄이 접히기 전 영역. 여기서 "뭐 하는 앱인지" 끝내기
- [ ] 초기 리뷰 확보. 리뷰 0개면 설치율이 크게 떨어집니다

### 3-5. 광고 표시와 지켜야 할 것

- **유료 광고 포함 표시**: 본인이 만든 앱을 본인 채널에서 홍보하는 것이므로 제3자 유료 광고에 해당하지 않습니다. 다만 앱이 유료이거나 인앱 결제가 있으면 영상에서 명시하세요.
- **앱 성능 과장 금지**: "이 앱 쓰면 합격", "정확도 100%" 같은 표현은 표시광고의 공정화에 관한 법률상 문제가 될 수 있습니다. "3년치 입결 데이터로 계산합니다" 같은 사실 표현을 쓰세요.
- **앱이 다루는 데이터의 출처와 한계 명시**: 등급컷·입결을 쓴다면 출처와 기준 연도를 앱 안과 영상 모두에 표기하세요. 추정치라면 추정치라고 쓰세요.
- **합격 사례 사용**: 실명·학교·성적을 쓰려면 본인 동의를 받아 두세요. 미성년자면 보호자 동의가 필요합니다.
- **등급컷·입결 데이터**: 출처를 화면과 설명란에 표기하세요. 수험생은 출처 없는 숫자를 신뢰하지 않고, 틀린 데이터는 채널 신뢰를 한 번에 무너뜨립니다.

### 4-1. 채널 세팅 (1주차)

- [ ] 채널 설명 첫 두 문장을 줄글로: 누구를 위한 채널인지, 무엇을 올리는지, 업로드 주기
- [ ] 키워드 설정: 중경외시, 중앙대, 경희대, 한국외대, 서울시립대, 수시, 정시, 등급컷, 학생부종합
- [ ] 시청자층 "아동용 아님" 확인 (수험생 대상이지만 13세 미만 타깃이 아님)

- [ ] 채널 예고편 설정 (구독하지 않은 방문자용 60초)
