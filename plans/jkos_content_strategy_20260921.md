결정: 광고 도달에 더해 **구독자를 쌓는 콘텐츠 채널로 키운다** (2026-09-21).
데이터: 2026-08-22~09-19 스튜디오 지역 내보내기. 분석 원본은 `plans/analysis_3channels_20260920.md` 4장.

> 이 문서는 "중경외시 진학을 목표로 하는 수험생·학부모에게 무언가를 광고하는 채널"을 전제로 썼습니다.
> 무엇을 광고하는지(학원·컨설팅·교재·과외 등), 타깃이 수험생인지 학부모인지, 전환 목표가 무엇인지(상담 신청·등록·사이트 유입)에 따라
> 3장 이하의 구체안이 달라집니다. 알려 주시면 그에 맞춰 고치겠습니다.

## 1. 진단: 지금 구조로는 구독자가 쌓이지 않는다

### 1-1. 시청시간이 사실상 0이다

| 채널·경로 | 조회 1,000회당 시청시간 |
|---|---|
| **@jkos_kr 현재** | **1.1시간** |
| @PPAIEO 쇼츠 피드 | 1.1시간 |
| @PPAIEO 추천 동영상 | 69.3시간 |
| @dodamam 검색 유입 | **209.2시간** |

@jkos_kr은 조회 2,715회로 시청시간 3.07시간을 만들었습니다. @dodamam은 조회 **6회**로 1.06시간을 만들었습니다.
조회수는 452배 차이인데 시청시간은 3배 차이입니다.

구독은 시청시간에서 나옵니다. 11초를 본 사람은 채널 이름조차 기억하지 못합니다.

### 1-2. 조회가 업로드일에만 발생한다

조회 발생 14일 중 **상위 3일이 전체의 82%**입니다. 9/5에 1,512회, 9/18에 440회, 9/17에 221회. 나머지 날은 4~83회입니다.
올린 날만 조회가 나오고 다음 날 사라집니다. 누적되는 자산이 없습니다.

### 1-3. 타깃은 정확하다

한국에서만 시청됩니다. 서울 351, 부산 88, 인천 59, 대구 41. 해외 유입이 없습니다.
**광고로서는 이미 잘 작동하고 있습니다.** 고칠 것은 도달이 아니라 "본 사람이 남을 이유"입니다.

## 2. 전환의 핵심: 광고를 콘텐츠 안에 넣는다

광고는 시청자에게 주는 것이 없어서 구독 이유가 없습니다. 구독을 받으려면 **시청자가 필요해서 찾아오는 정보**를 만들고, 광고는 그 안에 얹어야 합니다.

| 지금 | 바꿀 방향 |
|---|---|
| 광고 메시지가 영상의 전부 | 정보가 영상의 90%, 광고는 마지막 10% |
| 시청자가 얻는 것 없음 | 시청자가 검색해서 찾던 답을 얻음 |
| 11초 보고 이탈 | 필요한 정보라 끝까지 봄 |
| 올린 날만 조회 | 검색으로 계속 조회 |

입시 분야는 이 전환에 특히 유리합니다. 이유가 셋입니다.

1. **검색 수요가 크고 반복됩니다.** "중앙대 경영 등급컷", "경희대 수시 면접 후기" 같은 검색은 매년 같은 시기에 다시 발생합니다.
2. **시청 의도가 높습니다.** 입시 정보를 찾는 사람은 10분짜리 영상도 끝까지 봅니다. 수면음악 채널에서 검색 유입이 평균 12.5분을 본 것과 같은 원리입니다.
3. **광고와 정보의 거리가 가깝습니다.** 입시 정보를 주는 사람이 입시 서비스를 권하는 것은 시청자에게 자연스럽습니다.

## 3. 콘텐츠 설계

### 3-1. 포맷 세 층으로 나눈다

| 층 | 길이 | 역할 | 빈도 |
|---|---|---|---|
| **검색용 롱폼** | 8~15분 | 채널의 자산. 검색으로 1년 내내 조회 | 주 1~2편 |
| **쇼츠** | 20~40초 | 신규 유입. 관련 동영상 링크로 롱폼 연결 | 주 3편 |
| **시즌 라이브·속보** | 20~60분 | 등급컷 발표, 경쟁률 마감 같은 실시간 이벤트 | 시즌당 3~5회 |

지금은 쇼츠만 있습니다. **검색용 롱폼이 없어서 자산이 쌓이지 않는 것**이 핵심 문제입니다.

### 3-2. 검색용 롱폼 주제 (예시 20개)

검색량이 있고 매년 반복되는 주제로 고릅니다. 실제 검색량은 4-2의 방법으로 확인하세요.

**대학·학과 정보**
1. 중앙대 경영학부 3년치 등급컷과 경쟁률 분석
2. 경희대 국제캠 vs 서울캠, 뭐가 다른가
3. 한국외대 LD학부·LT학부 완전 정리
4. 서울시립대가 등록금이 싼 이유와 실제 학비
5. 중경외시 네 학교 취업률·만족도 비교

**전형 이해**
6. 수시 6장 어떻게 쓰나: 중경외시 지원 조합
7. 학생부종합전형 서류 평가 항목 뜯어보기
8. 논술전형, 중경외시 네 학교 출제 경향 차이
9. 정시 환산점수 계산법: 학교마다 다른 반영비
10. 수능 최저학력기준 충족 전략

**시기별**
11. 9월 모의고사 후 수시 지원 전략 바꾸는 법
12. 면접 2주 전 준비 순서
13. 정시 원서 접수 마지막 3일 판단법
14. 추가합격(추합) 어디까지 돌까

**경험·사례**
15. 중앙대 합격생이 말하는 자소서 쓰는 순서
16. 6등급에서 경희대 간 케이스 분석
17. 재수 결정 전에 따져볼 것 5가지

**학부모용**
18. 학부모가 수시 원서 접수 때 도와줄 수 있는 것
19. 입시 비용 실제 얼마나 드나
20. 아이와 입시 얘기할 때 하지 말아야 할 말

### 3-3. 제목 공식

```
[대학·전형 키워드] + [구체적 질문·숫자] + [연도]
```

- 좋은 예: `중앙대 경영 등급컷 3년치 분석 | 2027 수시 지원 가능선`
- 나쁜 예: `입시 성공 비법 대공개!!` (검색어가 없고 클릭베이트)

앞 30자 안에 대학명 또는 전형명이 들어가야 검색에 잡힙니다. `tools/check_metadata.py`의 키워드 목록을 입시용으로 바꿔 쓰면 점검할 수 있습니다.

### 3-4. 광고를 넣는 위치

| 위치 | 방식 | 비중 |
|---|---|---|
| 영상 도입 (0~10초) | 광고 금지. 바로 본론 | 0% |
| 본문 | 정보만 | 90% |
| 마지막 1~2분 | "더 자세한 상담은" 형태의 안내 | 10% |
| 고정댓글 | 링크와 연락처 | — |
| 설명란 3~5번째 줄 | 링크 (첫 두 줄은 영상 내용 요약) | — |

**유료 광고 포함 표시**: 제3자의 제품·서비스를 대가를 받고 홍보하면 업로드 시 "유료 광고 포함" 체크가 필요합니다. 본인 사업 홍보는 해당하지 않지만, 판단이 애매하면 표시하는 쪽이 안전합니다.

## 4. 실행

### 4-1. 채널 세팅 (1주차)

- [ ] 채널 설명 첫 두 문장을 줄글로: 누구를 위한 채널인지, 무엇을 올리는지, 업로드 주기
- [ ] 키워드 설정: 중경외시, 중앙대, 경희대, 한국외대, 서울시립대, 수시, 정시, 등급컷, 학생부종합
- [ ] 시청자층 "아동용 아님" 확인 (수험생 대상이지만 13세 미만 타깃이 아님)
- [ ] 재생목록 5개: `대학별 정보`, `수시 전형`, `정시 전략`, `합격 사례`, `학부모 가이드`
- [ ] 채널 예고편 설정 (구독하지 않은 방문자용 60초)
- [ ] 기존 광고 쇼츠 중 조회 하위는 일부공개 검토 (채널 페이지 클릭률 방어)

### 4-2. 검색어 확인 방법

1. YouTube 검색창에 "중앙대 경영" 입력 → 자동완성 목록이 실제 검색 수요입니다. 화면 캡처해 두세요.
2. 스튜디오 > 분석 > 도달범위 > **YouTube 검색어** 에서 현재 어떤 말로 들어오는지 확인
3. 구글 트렌드에서 "수시 원서", "등급컷" 검색량의 월별 패턴 확인 (시즌 캘린더 근거)

### 4-3. 시즌 캘린더 (한국 입시 일정 기준)

| 시기 | 검색 수요 | 올릴 것 |
|---|---|---|
| 9월 | 수시 원서 접수 | 지원 전략, 경쟁률 실시간 |
| 10~11월 | 논술·면접 | 전형별 준비법 |
| 11월 | 수능 | 가채점 후 판단 |
| 12월 | 수시 발표, 정시 원서 | 환산점수, 지원 조합 |
| 1~2월 | 정시 발표, 추합 | 추합 예측, 등록 판단 |
| 3~6월 | 비수기 | 대학·학과 정보 롱폼 축적 |
| 7~8월 | 수시 준비 | 자소서, 서류 |

**비수기(3~6월)에 대학·학과 정보 롱폼을 쌓아 두는 것이 중요합니다.** 9월 성수기에 검색이 몰릴 때 이미 올라가 있는 영상이 조회를 받습니다.

### 4-4. 첫 8주 일정

| 주차 | 할 것 |
|---|---|
| 1주 | 채널 세팅(4-1), 검색어 조사(4-2), 롱폼 1편 제작 |
| 2주 | 롱폼 #1 공개, 쇼츠 3편(롱폼 클립 + 관련 동영상 링크) |
| 3주 | 롱폼 #2, 쇼츠 3편, 첫 지표 확인 |
| 4주 | 롱폼 #3, 재생목록 정리, 4주 리뷰 |
| 5~8주 | 주 1~2 롱폼 + 주 3 쇼츠 유지, 시즌 이벤트 대응 |

## 5. KPI

콘텐츠 채널로 키우는 것이므로 광고 도달과 별도로 봅니다.

| 지표 | 현재 | 8주 목표 | 확인 |
|---|---|---|---|
| 조회 1,000회당 시청시간 | 1.1h | **10h 이상** | 롱폼 비중이 올라가면 자동으로 오름 |
| 검색 유입 비율 | 미확인 | 30% 이상 | 트래픽 소스 탭 |
| 롱폼 평균 시청 지속 시간 | 롱폼 없음 | 4분 이상 (8분 영상 기준 50%) | 참여도 탭 |
| 구독자 | 미확인 | +100 | 시청자층 탭 |
| 노출 클릭률 | 미확인 | 4% 이상 | 도달범위 탭 |
| 광고 도달 (기존 목적) | 조회 2,715/29일 | 유지 이상 | 총계 |

**광고 도달이 줄면 안 됩니다.** 쇼츠를 유지하면서 롱폼을 더하는 것이지, 쇼츠를 대체하는 것이 아닙니다.
