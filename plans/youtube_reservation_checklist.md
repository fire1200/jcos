## 1. 예약하는 방법 (YouTube 스튜디오)

### 이미 올려 둔 비공개 영상
```
스튜디오 → 콘텐츠 → 영상 제목 클릭(세부정보)
→ 오른쪽 "공개 상태" → 예약 → 날짜·시간 입력 → 저장
```

### 새로 올리는 영상
```
만들기 → 동영상 업로드 → 세부정보·요소 입력
→ 공개 상태 단계에서 "예약" → 날짜·시간 입력 → 예약
```

### 처음 한 번만 확인
- [ ] 스튜디오 **설정 → 일반 → 시간대가 (GMT+09:00) 서울**인지
- [ ] 시청자층 **아동용 아님**, 카테고리·언어는 기존 마라톤 영상과 같게
