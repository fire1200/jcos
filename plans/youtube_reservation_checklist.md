## 1. 예약하는 방법 (YouTube 스튜디오)

### 이미 올려 둔 비공개 영상
```
스튜디오 → 콘텐츠 → 영상 제목 클릭(세부정보)
→ 오른쪽 "공개 상태" → 예약 → 날짜·시간 입력 → 저장
```

### 새로 올리는 영상
```
만들기 → 동영상 업로드 → 세부정보·요소 입력
→ 공개 상태 단계에서 "예약" → 날짜·시간 입력 → 예약
```

### 처음 한 번만 확인
- [ ] 스튜디오 **설정 → 일반 → 시간대가 (GMT+09:00) 서울**인지
- [ ] 시청자층 **아동용 아님**, 카테고리·언어는 기존 마라톤 영상과 같게

## 2. 공통 문구

### A. 새 영상 (대회 2주 전 공개분) — 설명란 첫 줄
```
{연도} {대회명} {종목} 코스를 3D로 미리 보세요. 대회일 {M월 D일(요일)}.
```

### B. 2026년 끝난 대회 영상 — 설명란 첫 줄 + 고정 댓글
```
2026년 대회 기준 코스입니다. 2027 대회 코스는 대회 2주 전에 새 영상으로 올립니다.
```

### C. 2027 새 영상이 나온 날 — 옛 영상 설명란 첫 줄 + 고정 댓글 교체
```
▶ 2027 대회 코스 영상: {새 영상 링크}
```

### 재생목록 이름
```
{대회명} 코스 (연도별)
```
예) `대구마라톤 코스 (연도별)` — 같은 대회의 2026·2027 영상을 한 목록에 묶습니다.
