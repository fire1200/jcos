# 토담토담 실행 일정표 (2026-09-23 ~ 12-23)

전략 근거: `plans/todam_growth_plan_20260923.md` (외부 자문 + 내부 분석 통합안)
채널: 토담토담 [@dodamam](https://www.youtube.com/@dodamam)

**원칙 세 가지**
1. 9/26까지 기존 6편의 제목·썸네일·설명을 건드리지 않는다 (측정 보호)
2. 한 번에 한 변수만 바꾼다
3. 공개는 화·금 저녁 8시, 주 1~2편. 동시 공개 금지

> **기대치를 먼저 맞춥니다.**
> 업계 통계상 새 채널이 자리 잡는 시점은 **주 수가 아니라 영상 편수**로 세는 것이 정확합니다.
> 알고리즘은 각 영상을 누가 끝까지 보는지로 시청자를 학습하므로, 한 주제로 **10~20편**이 쌓여야 방향이 잡힙니다.
> 주 1회 업로드로 좁은 주제를 파면 **첫 10주 정도는 평평하다가** 한 편이 검색에 걸리면서 나머지를 끌어올리는 패턴이 흔합니다.
> 이 일정표가 4주·8주 리뷰를 두는 이유는 그때 성과가 나야 해서가 아니라, **방향이 맞는지 점검**하기 위해서입니다.
> 토담토담은 현재 6편이므로, 이 일정표 4주차(14편)와 8주차(22편)가 바로 그 학습 구간에 해당합니다.

## 9-2. 음원 준비: 먼저 해야 할 일

> **2026-09-23 추가.** 일정을 짜면서 놓쳤던 부분입니다. 영상 제작보다 이 작업이 먼저입니다.

### 9-2-1. 문제: 소재가 30분뿐이다

기존 15곡은 곡당 약 2분입니다. 허밍판 전체를 이어 붙여도 30분, 무가사판도 30분입니다.

| 만들려는 영상 | 길이 | 같은 소재 반복 횟수 |
|---|---|---|
| 10시간 엄마 허밍 | 600분 | **20회** |
| 3시간 빗소리 | 180분 | 18회 |
| 3시간 백색소음 | 180분 | 22회 |
| 기존 3시간 (이미 공개) | 180분 | 6회 |

같은 30분을 20번 반복하면 두 가지 문제가 생깁니다.

1. **부모가 단조로움을 느낍니다.** 새벽에 같은 멜로디가 20번째 돌아오면 거슬립니다.
2. **비진정성 콘텐츠 판정 위험.** 2025-07 개정 정책은 템플릿형·대량생산 콘텐츠를 수익화에서 제외합니다. 빠이요에서 같은 곡의 허밍·무가사 두 버전을 33편으로 쪼개 올린 것이 이미 실패한 전례입니다.

### 9-2-2. 해결: 곡당 길이를 늘린다

**새로 작곡하는 것이 아니라 기존 곡의 전개를 늘리는 작업입니다.**

| 곡당 길이 | 허밍 15곡 총 소재 | 10시간 채우는 반복 |
|---|---|---|
| 2분 (현재) | 30분 | 20회 |
| 5분 | 75분 | 8회 |
| **8분 (권장)** | **120분** | **5회** |
| 10분 | 150분 | 4회 |

**곡당 8분을 권합니다.** 5회 반복이면 수면음악에서 자연스러운 수준이고, 작업량도 감당할 수 있습니다.

**확장하는 방법** (작곡이 아니라 편곡)

| 방법 | 설명 |
|---|---|
| 변주 반복 | 같은 멜로디를 조옮김하거나 리듬을 미세하게 바꿔 2~3회 전개 |
| 레이어 증감 | 1절 피아노만 → 2절 패드 추가 → 3절 피아노만. 악기 조합으로 반복 인지를 낮춤 |
| 앰비언스 변화 | 리버브 길이와 스테레오 폭을 아주 느리게 변화 |
| 자연음 겹치기 | 빗소리·심장박동을 아주 낮게 깔면 같은 멜로디도 다르게 들림 |

### 10-9. 모든 영상 공통: 안전 안내 문구

수면음악 채널의 신뢰는 "아기에게 안전한가"에서 갈립니다. 근거 있는 수치를 쓰면 부모가 채널을 믿습니다.

**고정댓글 (모든 영상)**

```
밤새 광고 없이 이어집니다 🌙

🔉 안전한 사용법
- 볼륨은 50dB 이하로. 조용한 사무실이나 냉장고 소리 정도입니다.
- 기기는 아기에게서 2m 이상 떨어뜨려 주세요.
- 밤새 켜두기보다 잠든 뒤 30분 타이머를 권합니다.
(미국소아과학회 권고 기준)

오늘 아기가 몇 분 만에 잠들었는지 댓글로 알려 주시면 다음 영상에 참고합니다.
```

**설명란 하단 (모든 영상)**

```
🎧 볼륨 기준
미국소아과학회는 아기 수면 중 소음을 50dB 이하로 유지하고,
소리 기기를 아기에게서 약 2m 이상 떨어뜨릴 것을 권고합니다.
50dB은 속삭임(30dB)보다 크고 대화 소리(60dB)보다 작은 수준입니다.
```

**하지 말 것**

| 금지 | 이유 |
|---|---|
| "이 음악 들으면 무조건 잠듭니다" | 효과 보장 표현. 표시광고법 문제 소지 |
| "의학적으로 검증된" | 근거 없는 의학적 주장 |
| 볼륨 안내 없이 백색소음 영상 공개 | 청력 관련 민감 주제. 안내가 없으면 댓글에서 지적받음 |

이 안내는 **쇼츠 D형(팁) 대본의 소재로도 씁니다.** "수면음악 볼륨, 이게 기준입니다"는 정보 가치가 있어 저장·공유가 일어납니다.
