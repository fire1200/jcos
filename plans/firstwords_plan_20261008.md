# 첫말 노래 기획서 (다시 쓴 판)

작성 2026-10-08 · ChatGPT 기획서(`토담토담 아기 첫말 노래·모음영상 기획서`)를 참고했습니다.
받은 음원 9곡(11~13, 21~26)은 직접 열어서 길이·음량을 재고, 음성 인식으로 실제로 들리는 단어를 확인했습니다.

---

## 0. 먼저 정할 것: 어느 채널에 올리나 → **몽글구름 동요를 권합니다**

ChatGPT 기획서는 **토담토담**에 올리면서 "아동용 예"로 설정하고 `#아기동요` 태그를 붙이게 되어 있습니다.
이렇게 하면 우리가 지켜 온 토담토담 규칙과 부딪힙니다.

| | 토담토담 | 몽글구름 동요 |
|---|---|---|
| 채널 설정 | **아동용 아님** (보호자가 아기를 재울 때 트는 음악) | **아동용** 채널 |
| 제목·태그 | 동요·키즈·어린이를 쓰지 않음 | 동요를 써도 됨 |
| 첫말 노래와 맞는가 | 아기가 **깨어 있을 때** 화면을 보며 듣는 영상이라 재우는 음악과 쓰임이 다름 | 아이가 보는 노래 영상이라 그대로 맞음 |
| 아동용 영상이 섞이면 | 댓글·알림·맞춤 광고가 꺼진 영상이 섞여, 추천 흐름이 갈라질 수 있음 | 이미 같은 설정이라 문제없음 |

- **권장:** 몽글구름 동요에 새 시리즈 **「몽글이 첫말 노래」**로 올립니다. 재생목록도 새로 만듭니다.
- 아이를 향한 영상은 어느 채널에 올리든 **아동용 예**로 설정해야 합니다(YouTube 규정).
- 그래도 토담토담에 올리고 싶으면 영상마다 아동용 예로 설정하고, 제목과 태그에서 "동요"를 빼야 합니다. 그러면 검색 노출이 약해집니다.
- 빠이요 채널에는 어느 경우에도 올리지 않습니다.

## 1. 받은 음원을 실제로 확인한 결과

음성 인식(whisper-small)으로 3초 단위로 들리는 말을 찾았습니다.
- **목소리 비율:** 목소리가 들리는 구간이 전체 3초 칸 중 몇 칸인지 센 값입니다.
- **음량:** 9곡 모두 -13.2 ~ -14.2 LUFS로 고릅니다. 모음 영상을 만들 때 -14 LUFS로 맞추면 곡 사이 음량 차이가 생기지 않습니다.

| 번호 | 길이 | 실제로 들리는 단어 | 목소리 비율 | 판단 |
|---|---|---|---|---|
| 21 | 2:03 | 엄마·아빠·할아버지·할머니 (세 묶음, 순서 같음) | 13/41칸 | 단어가 가장 또렷함 → **가족편 본편 후보 1순위** |
| 22 | 1:43 | 엄마 엄마·아빠 아빠·할아버지·할머니 (단어를 두 번씩) | 13/34칸 | 또렷함. 두 번씩 불러 따라 하기 좋음 |
| 23 | 2:03 | 엄마 엄마·아빠 아빠·할아버지·할머니 할머니 (세 묶음) | 17/41칸 | "할아버지"가 "하라보디·바라보지"로 들림 → 발음이 조금 흐림 |
| 24 | 1:35 | 손·발·눈·코·입 (거의 인식 안 됨) | 6/32칸 | **직접 들어 보고 판단 필요** |
| 25 | 1:52 | 0초대 "손발 눈 코 입", 33초 "눈 코" 정도만 들림 | 7/37칸 | 간주가 아주 김. 직접 들어 보고 판단 필요 |
| 26 | 2:10 | 15~27초 "손 발 … 입" | 9/43칸 | 직접 들어 보고 판단 필요 |
| 11 | 2:20 | 가족(12~24초) → 몸(60~66초) → "먹자"(99초) | 10/47칸 | 세 주제가 섞인 **종합곡** |
| 12 | 2:15 | 몸(15초) → 우유·먹자(63~75초) → 가족(90~102초) | 9/45칸 | 세 주제가 섞인 **종합곡** |
| 13 | 2:30 | 맘마·우유·먹자·자자(30~45초) → 가족(75~84초) | 10/50칸 | 생활 단어가 가장 또렷 → **생활편 본편 후보** |

**확인해서 알게 된 것**
1. **간주가 깁니다.** 어느 곡이든 목소리는 전체의 20~40%뿐이고 나머지는 반주입니다. 그래서 단어 사이의 빈 시간을 그림으로 채우는 연출이 꼭 필요합니다(아래 3장 "어디 있을까?" 구조).
2. **11·12·13은 셋 다 종합곡입니다.** ChatGPT 표에는 11·13이 "생활 단어"로 적혀 있지만, 실제로는 세 곡 모두 가족·몸·생활 단어가 함께 들어 있습니다.
3. **몸 단어 곡(24·25·26)은 단어가 또렷한지 확인이 필요합니다.** 손·발·눈·코·입은 한 글자 단어라 음성 인식이 원래 약합니다. 그래서 인식이 안 됐다고 곧 발음이 나쁘다는 뜻은 아닙니다. 그래도 세 곡 모두 거의 안 잡혔으니 직접 들어 봐 주세요. 셋 다 흐리면 6장의 Suno 대본으로 새로 만듭니다.
4. **부르는 순서는 "할아버지 → 할머니"입니다.** ChatGPT가 제안한 제목은 "할머니 할아버지" 순서라서, 제목과 썸네일도 노래 순서대로 맞춥니다.

## 2. 무엇을 몇 편 올리나 → 9편을 다 본편으로 올리지 않습니다

ChatGPT 안은 본편 9편과 모음 4편입니다. 그런데 9곡은 사실상 **같은 단어를 부른 3주제 × 3버전**입니다.
- 비슷한 영상을 9편 올리고, 같은 음원으로 모음을 4편 더 만들면 총 13편이 됩니다.
- 이것은 YouTube가 2025년 7월부터 수익 창출에서 거르고 있는 **"대량 생산·반복 콘텐츠"**로 보일 수 있습니다.
- 시청자에게도 같은 노래가 계속 추천되어 채널이 지루해 보입니다.

**권장 구성: 영상 4편 + 쇼츠 6편**

| 영상 | 쓰는 음원 | 길이 | 비고 |
|---|---|---|---|
| ① 가족편 본편 | 21 | 2:03 | 세 묶음이 모두 또렷함 |
| ② 몸편 본편 | 24·25·26 중 가장 또렷한 1곡 (없으면 새로 만듦) | 약 2분 | 직접 들어 보고 선택 |
| ③ 생활편 본편 | 13 | 2:30 | 맘마·우유·먹자·자자가 또렷함 |
| ④ 첫말 노래 모음 | **9곡 전부** (가족 3 → 몸 3 → 종합 3) | 약 19분 | 본편에 안 쓴 6곡은 여기서만 나옴. 같은 곡을 두 번 넣지 않음 |
| 쇼츠 6편 | 본편에서 단어 2~3개 구간 | 각 20~30초 | 엄마·아빠 / 할아버지·할머니 / 손·발 / 눈·코·입 / 맘마·우유 / 먹자·자자 |

- **모음은 1편만:** ChatGPT 안의 주제별 모음 3편(가족·몸·종합)은 만들지 않습니다. 각각 6~7분짜리라 본편과 겹칩니다.
- **나머지 6곡:** 버리지 않고 ④ 모음 안에서 "두 번째 노래, 세 번째 노래"로 씁니다. 같은 단어라도 다른 곡이므로 반복 재생이 아닙니다.
- **나중에 늘리기:** 반응이 좋으면 같은 방식으로 동물·탈것 같은 새 단어 묶음을 추가합니다. 같은 단어를 다시 올리는 대신 새 단어로 늘립니다.

## 3. 영상 연출

### 캐릭터: 몽글이네 구름 가족 (사람 아기 그림 대신)

| 단어 | 캐릭터 | 알아보는 표시 |
|---|---|---|
| 아기 (시청자 대신) | 아기 구름 **몽이** | 작고 동그람, 볼 빨강 |
| 엄마 | 엄마 구름 | 분홍, 리본 |
| 아빠 | 아빠 구름 | 하늘색, 넥타이 |
| 할아버지 | 할아버지 구름 | 흰 수염, 지팡이 |
| 할머니 | 할머니 구름 | 동그란 안경, 뜨개 목도리 |

- **구름 가족으로 하는 이유:**
  - 실사처럼 보이는 AI 아기·사람 그림을 쓰지 않아도 됩니다. ChatGPT 기획서에도 있는 원칙입니다.
  - 몽글구름 채널의 몽글이와 같은 세계로 이어집니다.
  - 지금 쓰는 그림 프로그램(`kids/engine.py`)으로 바로 그릴 수 있고, 모든 영상에서 똑같은 모습을 유지합니다.
- **몸편 캐릭터:** 손과 발이 있어야 하므로 구름 대신 단순한 2D **아기 몽이(사람 모양)**를 하나 새로 그립니다. 머리가 크고 선이 굵은 그림체입니다.
- **생활편 그림:** 맘마(밥그릇), 우유(젖병), 물(컵), 먹자(숟가락), 자자(베개·달)

### 장면 구조: "어디 있을까?" → "여기 있네!" (간주를 쓰는 방법)

단어 하나마다 아래 세 단계로 보여 줍니다. 간주가 길어서 이 순서가 자연스럽게 들어맞습니다.

| 순서 | 소리 | 화면 |
|---|---|---|
| ① 기다림 (간주) | 반주만 | 구름 뒤나 이불 속에 무언가 숨어 있고, 살짝 흔들림. 작은 글자 "누구일까?" |
| ② 단어 | "엄마" | 엄마 구름이 천천히 나오며 손 흔들기. 바로 옆에 **"엄마"를 크게** 씀. 글자가 한 번 살짝 커졌다 돌아옴 |
| ③ 여백 | 반주 1~2초 | 그대로 멈춰서 보호자가 "엄마!" 하고 따라 말할 시간을 줌 |

- **한 화면에 단어 하나:** 큰 글자 하나를 그 대상 바로 옆에 놓습니다. 화면 아래 자막 줄은 쓰지 않습니다.
- **움직임은 느리게:** 빠른 화면 전환, 번쩍임, 흔들림은 쓰지 않습니다. 장면은 천천히 겹치며 바뀝니다(0.6초).
- **세 묶음의 변화:** 같은 단어라도 묶음마다 장면을 조금 바꿉니다.
  - 1묶음: 한 명씩 나와 인사
  - 2묶음: 아기 몽이를 안아 줌
  - 3묶음: 다 같이 손잡기
- **단어 시각 맞추기:** 지금 쓰고 있는 **자막 편집기**에 이 곡들을 추가합니다. 단어 하나를 한 줄로 두고, 들리는 순간에 Enter를 누르면 됩니다. 다 끝나면 지금처럼 "첫말 21 다 했어요"라고 알려주세요.

### 음향

- 모든 곡을 -14 LUFS로 맞춥니다. 지금 차이는 1dB 안쪽이라 거의 그대로입니다.
- 끝은 2.5초 동안 소리를 줄이고, 1.5초 조용한 화면으로 마무리합니다(지금 동요 영상과 같음).
- 모음 영상은 곡 사이에 몽글이 소개 카드를 4초 넣습니다(지금 모음과 같음). 효과음은 작은 차임 하나만 씁니다.
- 반주와 목소리를 따로 조절하는 것은 완성된 mp3로는 할 수 없습니다. 목소리가 묻힌 곡은 6장처럼 새로 만드는 것이 맞습니다.

## 4. 누구를 위한 영상인가 (문구 원칙)

- **보는 사람:** 보호자와 **함께 보는 12~36개월**로 잡습니다.
  - ChatGPT 안은 "10~24개월"입니다. 하지만 세계보건기구(WHO, 2019) 권고는 만 1세 미만에게 화면 시청을 권하지 않습니다.
  - 그래서 "돌 전 아기"를 겨냥하는 말은 제목과 설명에 쓰지 않습니다.
- **쓰지 않는 말:** "말이 빨라지는", "언어 발달", "말 트이는", "교육 효과" 같은 효과를 약속하는 말. ChatGPT 기획서와 같습니다.
- **쓰는 말:** "첫 단어를 노래로 만나요", "보호자와 함께 불러요"
- **AI 표기:** "가사는 직접 쓰고, 노래와 반주는 AI 음악 도구를 제작 과정에 활용해 만들었습니다." "직접 불렀다"는 말은 쓰지 않습니다.
