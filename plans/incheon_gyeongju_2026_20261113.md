## 2. 인천국제하프마라톤

### 2-1. 공식 코스도가 아주 좋습니다

공식 하프 코스도에 **1km부터 20km까지 모든 km 마커**가 지하철역·학교·관공서
이름과 함께 찍혀 있습니다. 지금까지 받아본 국내 대회 코스도 중 제일 정확합니다.

문학경기장 START → 1~3km(선학) → 4km(신연수역·적십자병원) → 5km(연수구청)
→ 6km(동막초교) → 8km(캠퍼스타운역) → 9km(지식정보단지역)
→ **반환점** → 13km(현대아울렛) → 15km(동막역) → 16km(동춘역)
→ 17km(원인재역) → 20km(문학경기장역) → FINISH 문학경기장

## 3. 경주벚꽃마라톤

### 3-1. 코스 구조

공식 코스 설명이 지명 단위로 전부 공개돼 있습니다.

**하프**: 보덕동 → 커피명가 → 보문삼거리 → 구황교(밑) → **경주여고뒤 반환**
→ 경주교(밑) → 경주소방서 앞 알천교(횡단 우회) → 구황교 → 보문교(밑)
→ 한화리조트 → 라한 → 코모도 → 힐튼사거리 → 천군네거리 → 골인

**10K**: 보덕동 → 경주월드방향 반환 → 천군네거리 → 커피명가 → 보문삼거리
→ 한화리조트 → 라한 → 코모도 → 힐튼사거리 → 천군네거리 → 골인

하프는 "보문호 한 바퀴 + 경주 시내 왕복", 10K는 "보문호 한 바퀴"입니다.

## 4. 어느 쪽을 먼저 만들까

| 기준 | 인천국제하프 | 경주벚꽃 |
|---|---|---|
| 하프 참가 규모 | 추정 7,000~8,000 (미공개) | **4,000 (확정)** |
| 코스 데이터 정확도 | **최상** (km 마커 전부) | 상 (지명 단위) |
| 고저 연출 | ✗ 평지 20m | **✓ V자 73m** |
| 검색 시즌 | 1~3월 | 12월 말~2월 |
| 경쟁 영상 | 수도권이라 많을 가능성 | 적을 가능성 |
| 접수 오픈 | 2027년 1월 초 예상 | **2026년 12월 말 예상** |

### 추천: **경주벚꽃을 먼저** 만드세요

이유 세 가지입니다.

1. **접수가 먼저 열립니다.** 올해 경주는 12/29~12/31에 종목별로 열렸고
   인천은 1월 초였습니다. 우리 데이터상 조회가 몰리는 구간은 접수 오픈
   직전·직후라, 경주를 먼저 올려야 두 대회 모두 타이밍을 잡습니다.

2. **3D로 보여줄 게 있습니다.** 인천은 20m 평지라 고저 연출이 안 나옵니다.
   경주는 전반 내리막 73m / 후반 오르막 71m라 영상 한 편의 서사가 나옵니다.

3. **벚꽃 시즌 검색어를 같이 먹습니다.** "경주 벚꽃"은 마라톤과 무관하게
   3~4월 검색량이 치솟는 키워드입니다.

인천은 **1월 중순**에 올리는 걸로 두 번째에 두시죠. 다만 인천은 하프 종목
정원이 공개돼 있지 않아 기대 조회 추정이 어렵습니다. 전체 15,000명에
WA 공인 하프라는 점을 보면 하프 비중이 꽤 클 것 같지만, 확정 숫자가 아닙니다.

## 5. 확인 못 한 것

- 인천국제하프 **종목별 정원** — 공식 사이트가 총원 15,000명만 표기
- 두 대회 **2027년 일정** — 두 사이트 모두 아직 2026년 내용 그대로
- 두 대회 **공식 하프 고저도** — 둘 다 제공 없음. GPX 값으로 대체
- 실제 완주자 수 — 기록 조회가 이름+배번 입력식이라 집계 불가
