## 3. 왜 작동하나

제가 "러닝 음악"만 보고 있는 동안, 사용자는 **러닝 콘텐츠**로 축을 옮기셨습니다.

| | 러닝 음악 (안 됐음) | 마라톤 코스 (됨) |
|---|---|---|
| 검색 의도 | 모호함 — "러닝 음악"은 누구나 찾지만 유튜브에서 안 찾음 | **명확함** — "서울마라톤 코스"를 치는 사람은 **참가자** |
| 언제 보나 | 달리면서 (화면 안 봄) | **대회 전 준비하면서** (화면 봄) |
| 언어 | 영어 | **한국어** |
| 대체재 | 수없이 많음 | **공식 코스도는 2D.** 3D 미리보기는 희소 |
| 시의성 | 없음 | **있음** — 대회 직전에 수요가 몰림 |

> **"야외 러너는 화면을 안 본다"는 제 분석은 맞았습니다. 그런데 러너는 달릴 때만 러너가 아닙니다.**
> 대회 2주 전에는 코스를 공부합니다. 그때는 화면을 봅니다.

### AI 영상이 문제가 안 됐습니다

제가 "AI 생성 영상이라 Virtual Run은 안 된다"고 했습니다. 그건 맞았습니다 — Virtual Run은 **"진짜 거기를 달리는 느낌"** 을 파는 장르라 생성 영상이 통하지 않습니다.

**그런데 3D 코스 미리보기는 느낌이 아니라 정보를 팝니다.** 어디서 오르막이고 어디서 꺾이는지만 알면 됩니다. **3D·AI 영상이 오히려 적합합니다.**

## 4. 제 분석의 메타 오류 — 같은 실수를 두 번

| | 제가 지목한 원인 | 실제 원인 | 결과 |
|---|---|---|---|
| **토담토담** | 빠이요 중복 때문에 노출 62 | **장르 수요** (수면음악 → 창작동요) | 노출 **2,172배** |
| **빠이요** | 채널이 학습돼 죽음, 무엇을 올려도 수십 회 | **콘텐츠-수요 적합성** (음악 → 마라톤 코스) | 노출 **685배** |

> **저는 구조적 원인(중복·채널 학습·플랫폼 부적합)을 과대평가하고, 콘텐츠와 수요의 적합성을 과소평가했습니다.**

두 번 다 사용자가 **직접 바꿔서 증명**하셨습니다. 제 분석이 아니라 사용자의 시도가 답을 찾았습니다.

**앞으로 "이 채널은 끝났다"류의 판정을 하지 않겠습니다.** 채널이 아니라 콘텐츠가 변수였습니다.
