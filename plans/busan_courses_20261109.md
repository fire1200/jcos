## 2. 부산국제마라톤 (11/15 · 다대포) — **GPX가 어디에도 없습니다**

| 확인한 곳 | 결과 |
|---|---|
| 공식 kjmarathon.com 코스안내 3개 페이지 | **코스맵 이미지만.** `gpx` 문자열 없음 |
| 와리가리 — 등록 코스 **224개 전수 확인** | **없음** |
| marathon-map.com — 코스 **204개 전수 확인** | **없음** (한국은 서울·대구 둘뿐) |

**공식 고저도도 없습니다.** 코스맵에 2.5km 간격 km 표지만 있습니다.

### 코스 (공식 코스맵 기준)

```
다대포해수욕장(START/FINISH) → 장림포구 → 을숙도대교 밑 → 낙동강하굿둑
  → 1차 반환점 (하굿둑 동편, 7.5km 직후)
  → 하굿둑 서진 → 2차 반환점 (을숙도 서편, 10~12.5km 사이)
  → 하굿둑 → 장림포구 → 다대포해수욕장
```

강변·해안 평지입니다. 고저 변화가 거의 없어 **3D 코스 영상의 핵심 가치(고저도)가 약합니다.**

> 이번 회차는 D-6이라 늦었습니다. **1만 명 대회니 다음 회차를 달력에 넣으세요.**
> 만들려면 직접 작도밖에 없고, 고저도는 보여줄 것이 없습니다.

> 공식 고저도 자체가 정교하고(km별 경사도까지 표기) 와리가리가 그걸 그대로 따랐습니다.

### 영상에 들어가야 할 것

| 구간 | 고도 |
|---|---|
| 0~6km 벡스코·요트경기장·동백섬 | 10m 안팎 평지 |
| **7~9km 광안대교** | **57m** |
| **12~17km 부산항대교** | **최고 82m (15.7km)** ← 코스 최고점 |
| 18~20km 남항대교 | 41~45m |
| 충무동 반환 → 같은 다리 되짚기 | |
| **30.2km 부산항대교 (복귀)** | **74m** |
| 38km 광안대교 (복귀) | 52m |

**다리 3개를 왕복으로 넘습니다. 봉우리가 6개입니다.** 이게 이 대회의 전부이고,
러너가 영상에서 확인하고 싶은 것도 이것뿐입니다.

> ☐ 제목에 **"광안대교·부산항대교·남항대교"** 를 넣으세요. 러너가 치는 검색어입니다
> ☐ 최고점 82m(부산항대교)와 30km 지점의 74m를 화면에 표시하세요 — 30km에 다시 올라가는 게 이 코스의 승부처입니다

## 4. 와리가리 — 제 판단을 정정합니다

`gpx_sources_20261109.md` 2절에 **"GPX 출처 명시 없음"** 이라고 썼습니다. **틀렸습니다.**
코스 상세 페이지 설명문에 이렇게 적혀 있습니다.

> 이 GPX는 대회 공식 코스도·구간 안내·고저도를 바탕으로 OpenStreetMap 도로 데이터
> (© OpenStreetMap contributors, ODbL) 위에 재구성한 경로입니다.
> 실제 계측 코스와 수십 m 단위로 다를 수 있습니다.

부산브릿지 10km에는 **"출발점 MP39는 좌표가 공개되지 않아 공식 거리 10.0km에 맞춰
광안대교 곡선부 위에 잡았습니다"** 라는 한계까지 적어 뒀습니다.

**제가 API 응답과 홈페이지·FAQ만 보고 코스 설명문을 안 읽었습니다.**

| | |
|---|---|
| 좌표 기반 | **OpenStreetMap (ODbL)** — 출처 표기가 조건 |
| 경로·고도 근거 | **대회 공식 코스도·구간 안내·고저도** |
| 검증된 정확도 | 2026 대구 공식 구간표 대비 **평균 0.08km** / 부산브릿지 공식 고저도 대비 **평균 1.2m** |

> 와리가리 **사이트 자체의 재사용 약관은 여전히 없습니다** (`All rights reserved`).
