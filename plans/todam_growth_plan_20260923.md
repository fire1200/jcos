## 2. 어긋나는 지점과 판단

### 2-1. "9/26까지 아무것도 바꾸지 말라" vs "지금 재생목록·10시간을 만들라"

**판단: 둘 다 맞습니다. 대상이 다릅니다.**

측정하려는 대상과 그렇지 않은 것을 나누면 충돌이 사라집니다.

| 구분 | 9/26까지 |
|---|---|
| **측정 대상 — 건드리지 않는다** | 기존 6편의 **제목, 썸네일, 설명, 공개 시각** |
| **측정 대상이 아님 — 지금 해도 된다** | 재생목록 생성, 채널 설정(배너·소개·키워드), **새 영상 제작**, 라이브 준비, 다국어 메타 준비 |

외부 자문의 원칙은 "변수를 하나씩"입니다. 기존 6편의 메타데이터를 건드리면 9/26 데이터가 오염됩니다. 반면 재생목록을 만들거나 새 영상을 올리는 것은 기존 6편의 변수를 바꾸지 않습니다.

> 단, 재생목록에 기존 영상을 넣는 것은 그 영상의 노출 경로를 약간 바꿉니다.
> 9/26 판단에 이 영향을 감안하려면 **재생목록 생성일을 기록**해 두세요. 그래도 효과가 워낙 커서 미룰 이유가 없습니다.

### 2-2. "주 1편" vs "검색 진입점을 늘려라"

**판단: 외부 자문이 더 맞습니다. 제 이전 제안을 수정합니다.**

제가 "영상 30편을 만들어 검색 공간을 덮자"고 했는데, 이는 두 가지 위험이 있습니다.

1. 길이만 바꾼 복제는 2025-07 개정 **비진정성 콘텐츠 정책**의 전형적 패턴입니다. 빠이요에서 2분짜리 33편이 노출 9,326회에 조회 216회였던 것이 같은 실패입니다.
2. 비슷한 영상이 많으면 서로 노출을 나눠 갖습니다. 빠이요 실측에서 하루 10편 이상 올린 날은 편당 노출이 3배였는데 조회는 더 낮았습니다.

**수정한 원칙: 편수가 아니라 "서로 다른 검색 의도의 수"를 늘립니다.**
같은 음원이라도 낮잠용과 밤잠용은 다른 검색어이고 다른 영상입니다. 하지만 "30분 무가사"와 "35분 무가사"는 같은 검색어입니다.

속도는 **주 1~2편**으로 합니다. 외부 자문의 주 1편에 가깝게 가되, 시즌이나 여력에 따라 2편까지 허용합니다.

### 2-3. "썸네일 문제인지 노출 문제인지 아직 모른다"

**판단: 부분적으로는 이미 답이 나와 있습니다.**

외부 자문은 공개 화면의 조회수만 보고 쓰셨습니다. 제가 받은 스튜디오 트래픽 소스 내보내기(8/22~9/19)에는 노출과 CTR이 들어 있습니다.

| 지표 | 값 | 판정 |
|---|---|---|
| 노출 | **62회** | 심각한 부족 |
| CTR (전체) | 6.45% | 목표 4%의 1.6배 |
| CTR (검색) | **8.0%** | 목표의 2배 |
| 평균 시청 (30분 영상) | 17분 54초 = 유지율 60% | 목표 50% 초과 |

**썸네일 문제가 아닙니다. 노출 자체가 없습니다.**
다만 이 데이터는 공개 1~2일차 기준이라 표본이 작습니다. 외부 자문이 말한 7일 데이터로 재확인할 가치는 있습니다.

따라서 외부 자문의 마지막 문장 **"노출 자체가 거의 없다면 썸네일보다 제목·설명의 검색 의도 개선을 먼저"** 가 현재 상황에 해당합니다. 9/26에 이 판단이 유지되는지만 확인하면 됩니다.

## 3. 통합 실행안

### 3-1. 지금부터 9/26까지 (측정 기간)

**손대지 않을 것**
- [ ] 기존 6편의 제목
- [ ] 기존 6편의 썸네일
- [ ] 기존 6편의 설명
- [ ] 공개 상태

**해도 되는 것 (기존 6편의 변수를 바꾸지 않음)**
- [ ] **재생목록 2개 생성** (생성일 기록)
  - `엄마 허밍 자장가`: 30분 · 1시간 · 3시간
  - `무가사 피아노 자장가`: 30분 · 1시간 · 3시간
  - 설정 > 재생목록 > 수정 > **공식 시리즈로 설정** 체크
- [ ] 채널 설정 점검: 시청자층 아동용 아님, 키워드, 채널 소개 첫 두 문장
- [ ] 배너·프로필·워터마크
- [ ] **다음 영상 2편 제작** (공개는 9/26 이후)
- [ ] 24시간 라이브 준비 (송출 환경만, 개시는 나중)
- [ ] 10시간 음원 제작 시작

### 3-2. 9월 26일: 데이터 수집

분석 > 고급 모드 > 기간 "지난 7일" 또는 각 영상 "게시 이후"

| 수집 항목 | 위치 |
|---|---|
| 영상별 노출수·노출 클릭률 | 콘텐츠 탭 내보내기 |
| 평균 시청 지속 시간·시청 시간 | 같은 파일 |
| 유입 경로 | 트래픽 소스 탭 내보내기 |
| **검색어** | 도달범위 > YouTube 검색어 |
| 시청자층 | 시청자층 탭 |

세 파일을 `tools/analytics_dashboard.html`에 올리면 진단이 자동으로 나옵니다.

### 3-3. 9월 26일 판단 분기

수집한 데이터로 아래 중 하나를 고릅니다. **동시에 두 가지를 하지 않습니다.**

| 상황 | 판정 | 그때 할 일 |
|---|---|---|
| **노출 < 500** | 노출 부족 (현재 유력) | **A안**: 제목·설명의 검색 의도 개선 + 신규 영상으로 검색어 확장. 썸네일은 건드리지 않음 |
| 노출 ≥ 500, CTR < 3% | 썸네일 문제 | **B안**: 노출이 가장 많고 CTR이 가장 낮은 **한 편만** 썸네일 교체, 7일 관찰 |
| 노출 ≥ 500, CTR ≥ 4%, 평균 시청 낮음 | 초반 이탈 | **C안**: 해당 영상 첫 3분 재편집 |
| 검색어에 예상 못 한 말이 나옴 | 기회 발견 | **D안**: 그 검색어로 신규 영상 1편 |

### 3-4. A안 상세 (노출 부족일 때 — 가장 유력)

**제목을 사용 상황으로 구분합니다.** 외부 자문의 안을 그대로 씁니다.

| 현재 | 개선안 |
|---|---|
| 아기 수면 음악 30분 \| 무가사 피아노 자장가 15곡 | `신생아 수면음악 30분 \| 낮잠용 무가사 피아노 자장가` |
| 아기 수면 음악 1시간 \| 엄마 허밍 자장가 14곡 | `아기 수면음악 1시간 \| 잠들기 전 엄마 허밍 자장가` |
| 아기 수면 음악 3시간 \| 무가사 자장가 14곡 | `아기 수면음악 3시간 \| 밤잠용 무가사 피아노 자장가` |

길이만으로는 검색 결과에서 서로 구분되지 않습니다. **낮잠 / 잠들기 전 / 밤잠**이 부모의 실제 검색 의도입니다.

**설명 첫 두 줄을 영상마다 다르게 씁니다.**

```
신생아와 영유아의 30분 낮잠 시간을 위한 무가사 피아노 자장가입니다.
갑작스러운 음량 변화 없이 편안하게 들을 수 있도록 구성했습니다.
```

`tools/check_metadata.py`가 설명 첫 줄 중복을 자동으로 잡습니다. 수정 후 한 번 돌려 보세요.

**신규 영상은 검색 의도 기준으로 확장합니다.**

| 우선순위 | 검색 의도 | 제목 예 |
|---|---|---|
| 1 | 밤새 트는 부모 | `아기 수면음악 10시간 \| 밤새 끊김 없는 엄마 허밍 자장가 광고없음` |
| 2 | 울음·배앓이 | `아기 울음 멈추는 소리 \| 배앓이 진정 백색소음 3시간` |
| 3 | 백색소음 결합 | `신생아 백색소음 \| 빗소리와 엄마 심장박동 8시간` |
| 4 | 야간 화면 | `아기 수면음악 3시간 \| 어두운 화면 밤잠용 (눈부심 없음)` |
| 5 | 태교 | `태교음악 \| 임신 중 마음이 편해지는 피아노 3시간` |

"어두운 화면 버전"은 외부 자문의 제안인데, 밤에 휴대폰을 옆에 두는 부모의 실제 불편을 푸는 좋은 각도입니다.

### 3-5. B안 상세 (썸네일 문제일 때)

외부 자문의 설계를 씁니다. 모바일에서 두 정보가 즉시 보여야 합니다.

| 요소 | 내용 |
|---|---|
| 큰 글자 | `30분 낮잠`, `1시간 잠자리`, `3시간 밤잠` |
| 구분 표시 | `엄마 허밍` 또는 `무가사` |
| 색 체계 | 엄마 허밍 = 따뜻한 조명 계열 / 무가사 = 달빛·피아노 계열 |

`templates/thumbnail_guide.md`의 레이아웃 규칙 위에 이 색 구분을 얹습니다.

**한 편만 바꿉니다.** 노출이 가장 많고 CTR이 가장 낮은 영상 하나를 골라 7일 관찰합니다.

## 4. 이후 순서 (9/26 조치가 자리 잡은 뒤)

한 번에 하나씩, 앞 단계 효과를 확인하고 다음으로 갑니다.

| 순서 | 조치 | 왜 이 순서인가 |
|---|---|---|
| 1 | 10시간 롱폼 | "10시간" 검색어를 통째로 놓치고 있음. 시청시간도 한 편이 만드는 양이 다름 |
| 2 | 다국어 제목·설명 (영어·일본어) | 음악은 언어 장벽 없음. 기존 영상에도 소급 적용 가능해 비용이 가장 낮음 |
| 3 | 24시간 라이브 | 검색 실시간 슬롯과 홈 라이브 섹션은 **별도 노출 풀** |
| 4 | 쇼츠 (관련 동영상 링크로 롱폼 연결) | 검색이 붙기 전 공백을 메움 |
| 5 | 외부 홍보 (블로그 글 1편 → 영상 1편) | 외부 자문의 원칙대로 한 번에 한 편 |
| 6 | YouTube Music 유통 · 팟캐스트 RSS | 별도 노출 표면. 음원 재활용 |
