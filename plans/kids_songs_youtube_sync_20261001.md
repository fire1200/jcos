# 동요 10곡 — 유튜브 자동 동기화로 자막 시각 받기

작성 2026-10-01

**목적:** 유튜브가 노래를 듣고 가사 줄마다 시작 시각을 맞춰 줍니다. 그 결과(.srt 파일)를 받아 Claude가 화면 자막을 정확한 시각에 다시 입혀 최종 영상을 만듭니다.

**이 키트에 든 것**

| 폴더 | 내용 |
|---|---|
| `영상\` | `kids01_sync.mp4` ~ `kids10_sync.mp4`: 노래 + 제목 화면만 있는 **동기화 전용 영상**. 공개하지 않습니다 |
| `가사\` | `kids01_가사.txt` ~ `kids10_가사.txt`: 붙여 넣을 가사. Suno에 넣은 가사 그대로이고, `[Verse]` 같은 표시와 `(쿵!)` 같은 괄호는 뺐습니다 |

**한 곡에 약 5분, 10곡에 약 50분** (자동 처리 대기 시간 제외)

---

## 1. 업로드 (10곡 한 번에 가능)

1. [studio.youtube.com](https://studio.youtube.com) 접속
2. 오른쪽 위 **만들기 → 동영상 업로드** → `영상` 폴더의 10개 파일을 **한꺼번에 선택**
3. 각 영상 설정 창에서:
   - 제목: 그대로 두기 (`kids01_sync` 등)
   - 시청자층: **예, 아동용입니다** (실제 내용대로)
   - **공개 상태: 비공개** ← 꼭 확인
   - **저장**
4. 업로드가 끝날 때까지 기다리기 (곡당 1~2분)

> **어느 채널에 올려도 됩니다.** 비공개라 아무도 보지 못하고, 다 끝나면 지웁니다. **빠이요(PPAIEO) 채널은 쓰지 않습니다.** 토담토담에 올려도 비공개 영상은 채널 성과에 영향을 주지 않습니다.

---

## 2. 자동 동기화 (곡마다)

1. 스튜디오 왼쪽 메뉴 **자막**
2. 목록에서 `kids01_sync` 클릭
3. 처음이면 **언어 설정** 창이 나옵니다 → **한국어** → 확인
4. 한국어 줄의 자막 칸에서 **추가**
5. 세 가지 방법 중 **자동 동기화** 선택
6. `가사\kids01_가사.txt`를 열어 **전체 복사(Ctrl+A → Ctrl+C)** → 입력 칸에 **붙여넣기(Ctrl+V)**
7. **시간 할당** 버튼
8. "처리 중"이 몇 분 걸립니다. 다른 곡을 먼저 진행해도 됩니다
9. 끝나면 자막이 줄마다 시각과 함께 보입니다 → 오른쪽 위 **게시**
   - 영상이 비공개라 자막을 게시해도 아무도 보지 못합니다

`kids02` ~ `kids10`도 같은 방법으로 진행합니다.

---

## 3. .srt 파일 받기 (곡마다)

1. **자막** 메뉴 → 영상 선택 → 한국어 줄의 자막 칸에 마우스를 올림
2. **⋮ (옵션)** → **다운로드** → **.srt**
3. 받은 파일 이름에 곡 번호가 보이게 바꿉니다: `kids01.srt`, `kids02.srt` …

**10개를 Claude 채팅창에 끌어다 놓아 주세요.** 그러면 Claude가:
- srt 시각대로 화면 자막을 다시 입히고
- 장면 전환(1절·후렴·다리)도 그 시각에 맞춰
- 최종 영상 10편을 만들어 보냅니다

---

## 4. 다 끝나면

- 동기화 전용 영상 10개는 **삭제**합니다 (스튜디오 → 콘텐츠 → 선택 → 옵션 → 영구 삭제)
- 최종 영상을 어느 채널에 올릴지는 따로 정합니다 (새 아동용 채널 권장)

---

## 5. 문제가 생기면

| 증상 | 해결 |
|---|---|
| "자동 동기화" 버튼이 안 보임 | 영상 처리가 끝나지 않았음. 5~10분 뒤 다시 |
| 시간 할당이 실패하거나 아주 오래 걸림 | 그 곡은 건너뛰고 나머지부터. 실패한 곡은 Claude의 자동 맞춤(검수표 방식)으로 처리 |
| 결과를 보니 일부 줄 시각이 엉뚱함 | 그대로 받아서 보내 주세요. Claude가 노래 인식 결과와 대조해 이상한 줄을 걸러 냅니다 |
| 자막이 두 줄씩 묶여 있음 | 그대로 보내 주세요. Claude가 가사 줄 단위로 다시 나눕니다 |
| .srt 대신 .sbv만 보임 | .sbv도 괜찮습니다 |
