## 3. 철회 2 — 유통 발매 1순위

### 왜 그렇게 썼나

케어멜로디가 유튜브·Topic·Spotify·Amazon 네 면에 걸려 있는 것을 보고, 토담토담의 노출 62회는 면이 하나여서라고 진단했습니다.

### 두 가지를 놓쳤습니다

**첫째, 인과가 반대입니다.** 케어멜로디 17.7만은 374편이 만들었고 건반DIARY 10.3만은 769편이 만들었습니다. 둘 다 공식 아티스트 채널이지만 유통이 원인이 아니라 결과입니다. 유통은 이미 큰 채널이 수익을 넓히는 수단이지 작은 채널이 커지는 수단이 아닙니다.

**둘째, 제가 쓴 경고를 제가 무시했습니다.** `templates/music_distribution_podcast_checklist.md` 9행에 이렇게 적혀 있습니다.

> 음원이 자체 제작 또는 독점 라이선스인가 — 로열티 프리·AI 원본 음원은 유통사 심사에서 거절되거나 Content ID 충돌이 생긴다

**지금 토담토담 음원에는 Suno 생성분 비중이 큽니다.** 이 상태로 유통하면 심사 거절이거나, 통과해도 내 음원이 내 본편에 Content ID 클레임을 겁니다. 제가 v1에서 "가장 큰 한 수"라고 부른 것이 실은 가장 위험한 한 수였습니다.

### 수정

**유통은 12월 이후로 미룹니다.** 조건 두 개를 먼저 채웁니다.

1. 자체 녹음·연주 비중이 앨범 10곡을 채울 만큼 올라갈 것
2. 3시간판 몇 편의 28일 지표가 확보될 것

외부 자료 12절도 같은 결론입니다 — "고유 음원 카탈로그가 충분하면 외부 음원 유통 가능성을 검토한다."

## 4. 철회 3 — 감성+이모지 제목

### 실제 최고 성과 제목 두 개

**달빛소리 5,828만:**
```
5분만에 꿈나라 직행 + 쉬 소리·빗소리·물소리 + 수면교육 백색소음
+ 10시간 연속재생 + 광고없음
```

**케어멜로디 579만:**
```
아가에게 들려주기 좋은 느린 수면음악 [7시간]
```

둘 다 **기능형**입니다. 상황·소리 구성·길이를 그대로 적습니다. 이모지도 감성 수식어도 없습니다.

제가 v1에서 "우리 템플릿과 정반대"라고 쓴 그 템플릿이, 실은 최고 성과 영상들과 같은 문법이었습니다.

### 수정

**`templates/title_description_templates.md`의 기능형 공식을 유지합니다.** 외부 자료 6-1절 공식도 사실상 동일합니다.

```
[구체적인 사용 상황] | [핵심 소리·음악] | [재생시간]
```

A/B 시험은 취소하지 않고 **방향을 바꿉니다** — 감성 대 기능이 아니라, 기능형 안에서 **소리 중심이냐 문제 중심이냐**를 봅니다. 8절에 설계했습니다.

## 5. 외부 자료를 받아들여 바꾸는 것 — "광고없음"

외부 자료 6-1절이 `광고없음`을 피할 표현으로 분류했습니다. 확인해 보니 맞습니다.

유튜브는 2020년 11월 미국, **2021년 6월 1일부터 한국을 포함한 그 외 지역**에서 서비스 약관을 바꿔, 수익 창출에 참여하지 않는 채널의 영상에도 광고를 표시할 수 있게 했습니다. 고객센터에 `YouTube 파트너가 아닌데 내 동영상에 광고가 표시되는 이유는 무엇인가요?` 라는 문서가 따로 있을 정도로 실제로 일어나는 일입니다.

즉 **운영자가 통제할 수 없는 것을 제목에서 약속하고 있었습니다.**

달빛소리 5,828만 영상이 이 표현을 쓰는 건 사실입니다. 그렇다고 안전해지지는 않습니다. 그 채널이 감수한 위험일 뿐이고, 새벽에 광고가 떠서 아기가 깨면 제목이 거짓말이 됩니다.

### 대체 표현

| 지금 | 바꿀 것 | 왜 |
|---|---|---|
| `... 3시간 광고없음` | `... 3시간 연속재생` | 음원이 끊기지 않는 것은 사실이고 검증 가능 |

부모가 실제로 원하는 것은 "광고가 없다"가 아니라 **"밤중에 끊기지 않는다"** 입니다. 연속재생이 그 약속을 거짓 없이 전달합니다.

## 6. 통합 결론 — 진짜 병목

v1에서 저는 "면적이 병목"이라고 했습니다. **방향은 맞았고 수단이 틀렸습니다.**

면적은 유통 플랫폼 수가 아니라 **채널 안의 사용 상황 수**입니다.

| 채널 | 영상 수 | 구독자 |
|---|---:|---:|
| 건반DIARY | 769 | 10.3만 |
| 케어멜로디 | 374 | 17.7만 |
| 달빛소리 | 7 | 8.14만 |
| **토담토담** | **6** | — |

달빛소리가 반례처럼 보이지만 아닙니다. **7편 중 6편은 1,800~4.2만이고, 1편이 전체 조회의 99.8%입니다.** 구독자 대비 716배는 계획이 아니라 복권입니다. 외부 자료도 같은 판정입니다.

그리고 제 기존 실측이 이를 뒷받침합니다. `plans/analysis_3channels_20260920.md` 2-1절에서 **추천 동영상이 조회 3.8%로 시청시간의 49.8%를 만들었습니다.** 토담토담의 추천 유입은 0이고 검색 5회가 전부입니다. 추천은 채널 안에 **이어서 볼 것**이 있어야 작동하는데, 6편으로는 이어질 것이 없습니다.

> **1순위는 서로 다른 사용 상황의 수를 늘리는 것입니다.**

### 상황 세분화 — 외부 자료의 가장 큰 기여

건반DIARY의 방식이 정확히 이것입니다. **음악 정체성은 좁게(잔잔한 피아노 찬양), 사용 상황은 넓게(수면·기도·독서·청소·공부·조깅·아침·카페).**

인기 10편이 전부 같은 피아노 찬양인데 상황만 다릅니다. 케어멜로디도 같습니다 — 놀이방·교실·병원·독서·공부·아침·계절.

토담토담에 옮기면 **엄마 허밍과 피아노는 그대로 두고, 상황을 쪼갭니다.**

## 7. 달빛소리 대표 영상 해부 — 즉시 적용할 것

5,828만 회를 만든 요소를 하나씩 봅니다.

| 요소 | 채택 | 이유 |
|---|---|---|
| **쉬 소리를 제목에 명시** | ✅ **즉시** | 쉬~ 소리 자체는 기존 계획 10-2에 이미 있습니다(35%). **빠진 것은 제목입니다** |
| 물소리 추가 | ✅ | 기존에 없는 유일한 소재. 직접 녹음 가능 |
| 구체적 소리 조합을 제목에 명시 | ✅ | "백색소음"이 아니라 "쉬 소리+빗소리+물소리" |
| 밤새 조작 불필요한 길이 | ✅ | 3시간 검증 후 10시간 |
| 어두운 비 오는 창문 화면 | ✅ | 야간 사용 목적과 화면이 일치 |
| 육아 커뮤니티 URL 공유 | ✅ | 외부 유입 경로. 원칙은 외부 자료 10절 준수 |
| `5분만에 꿈나라 직행` | ❌ | 결과를 보장할 수 없음 |
| `광고없음` | ❌ | 5절 |

**정정 (2026-09-25):** 처음에 "쉬 소리가 기존 계획에 없다"고 썼는데 틀렸습니다. `plans/todam_schedule_20260923.md` 10-2절에 **"쉬~ 소리 30%"** 로 이미 들어 있고, 9/25 Suno 생성 목록에도 있습니다. 제가 `쉬 소리`로만 검색해 `쉬~ 소리` 표기를 놓쳤습니다.

**그래서 진짜 빠진 것은 소재가 아니라 제목입니다.** 기존 #2 제목은 `아기 울음 멈추는 소리 | 배앓이 진정 백색소음 3시간` 입니다. 소리를 다 섞어 놓고 제목에는 "백색소음"이라고만 씁니다. 5,828만 영상은 **소리 이름을 그대로 제목에 씁니다** — 그게 차이입니다.

조치는 두 가지입니다.

1. **제목에 소리 이름을 쓴다.** 10/13에 `쉬 소리와 빗소리 물소리 | 아기 재우는 백색소음 | 3시간 연속재생` 을 신설했습니다(일정표 10-4b)
2. **물소리를 확보한다.** 세 소리 중 유일하게 기존 계획에 없습니다. 직접 녹음이 가능해 유통 심사 문제도 없습니다
