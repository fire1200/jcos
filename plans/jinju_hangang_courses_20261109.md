## 2. ⚠ 진주는 와리가리 고도를 쓰면 안 됩니다

부산브릿지와 **품질이 다릅니다.**

| | 부산브릿지 | **진주** |
|---|---|---|
| 와리가리 출처 설명문 | **있음** (공식 코스도·고저도 기반 + OSM) | **없음** |
| 공식 고저도와 차이 | **평균 1.2m** | **계통 편차 +5.7m, 잔차 2.8m** |
| 거리 표기 | 42.152km | **42.545km** (공인보다 350m 김) |
| 하프 거리 | — | **20.671km** (공인보다 426m 짧음) |

와리가리는 6km·16km·36km에 55m급 봉우리를 그리는데 **공식 고저도에는 없습니다.**
지형 모델 추정치가 섞인 것으로 보입니다.

### 그래서 좌표만 쓰고 고도는 전부 공식으로 교체했습니다

**좌표 자체는 정확합니다.**

| 검증 | |
|---|---|
| 풀코스 좌표 직접 합산 | **42.192km** (공인 42.195km와 **3m 차이**) |
| 풀 반환점 | 21.11km (공식 21.1km) |
| 하프 반환점 | 10.54km (공인 10.549km) |

> 와리가리가 **표시하는** 거리 42.5km 쪽이 오히려 틀렸습니다. 좌표를 직접 합산하면 맞습니다.

☐ 와리가리 2026 데이터는 2025와 거리·상승이 **완전히 같은 값**입니다. 2025판을 그대로 쓴 것으로 보입니다.
