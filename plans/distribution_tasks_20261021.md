## 1. 작업 목록 (A 기준, 약 7시간)

### 1-1. 음원 마스터링 — 40분

유튜브용(-16 LUFS)과 스트리밍용(-10 LUFS)은 사양이 다릅니다. **그대로 올리면 러닝 음악으로서 힘이 없습니다.**

스크립트를 만들어 뒀습니다. 28곡을 한 번에 처리합니다.

```bash
./scripts/master_for_streaming.sh 원본폴더 발매용폴더
```

하는 일:
- 앞뒤 무음 제거
- 2패스 loudnorm → **-10 LUFS / 트루 피크 -1.0 dBTP**
- **WAV 24bit / 44.1kHz** 추출
- 곡별 전후 비교표 출력 (`_마스터링_결과.txt`)

☐ 스크립트 실행 (28곡 약 20분)
☐ 결과표에서 ⚠ 표시된 곡 **귀로 확인**
☐ 곡 맨 앞이 뚝 끊기지 않는지, 끝 잔향이 안 잘렸는지 확인

> ⚠️ 이 스크립트는 제가 실행 검증을 못 했습니다. 이 컨테이너에 ffmpeg가 없습니다. 문법 검사와 필터 그래프 검토만 했습니다. **첫 1곡으로 먼저 시험해 보고** 전체를 돌리세요.

### 1-2. 메타데이터 — 40분

**28곡 표를 미리 채워 뒀습니다.** `templates/distribution_tracklist.csv`

| 이미 채워진 것 | 직접 채울 것 |
|---|---|
| 앨범명 (BPM별 5장) | **아티스트명** |
| 트랙 번호·순서 | **작곡자 실명** |
| 곡명 (`Duiker (180 BPM)` 형식) | 피칭할 곡 표시 |
| 세부 장르 / 유통사 장르 | |
| 발매 순서 (180 → 174 → 160 → 190 → 210) | |

☐ 아티스트명 확정 — **이것부터**
☐ 5장에 들어갈 **피칭 대표곡 1곡씩** 표시

🔒 **작곡자 실명은 유통사 화면에 직접 입력하세요.** 이 CSV와 저장소에는 적지 마세요. 공개 저장소입니다.

### 1-3. 커버 아트 5장 — 2시간

| 항목 | 값 |
|---|---|
| 규격 | **3000 × 3000 px**, JPEG 또는 PNG, RGB |
| 공통 | 같은 틀에 **BPM 숫자만 바꾸기** → 시리즈로 보입니다 |
| 넣을 것 | 앨범명, BPM 숫자 크게 |
| 넣지 말 것 | 다른 아티스트·브랜드 로고, 실존 인물 사진, "Spotify" 등 플랫폼명 |

☐ 1장 만들고 BPM만 바꿔 5장

### 1-4. 유통사 가입·업로드 — 1.5시간

☐ **DistroKid 가입** (연 $23~25, 결제 전 공식 요금 확인)
☐ 아티스트명 입력 — **CSV와 글자 하나까지 동일하게**
☐ **EP3 (180 BPM) 6곡 업로드**
☐ 발매일 **11/17** 지정
☐ **Content ID 화이트리스트에 빠이요 채널 등록** ⬅ 빠뜨리면 기존 153편 수익 정지
☐ 지역 설정: 전 세계
☐ 가사: 없음 (Instrumental)

### 1-5. Spotify 피칭 — 30분

☐ **Spotify for Artists 계정 연결** (유통사 업로드 후 가능)
☐ **11/3에 피칭** — 발매 14일 전
   `Music → Upcoming → 곡 선택 → 양식 작성`

**피칭 양식에 쓸 내용 (복사해서 쓰세요)**

```
Instrumental running music composed at a fixed 180 BPM cadence.
Written specifically for runners who train to a metronome-steady beat —
each track holds one tempo from start to finish with no drops or breakdowns.
Part of a five-EP series covering 160, 174, 180, 190 and 210 BPM.
```

☐ 장르·분위기 태그: Electronic / Workout / Energetic / Instrumental

> **한 번에 한 곡만 피칭됩니다.** 그래서 5장을 2주 간격으로 냅니다. 한꺼번에 내면 기회가 1번입니다.

### 1-6. 발매 후 — 회당 1시간

☐ 빠이요 쇼츠 설명 첫 줄에 **Spotify 링크** 추가
☐ 빠이요 채널 소개란에 링크 한 줄
☐ YouTube Music Topic 채널이 생기면 **Official Artist Channel 신청**

## 3. 실수하면 되돌리기 어려운 것 셋

| | 왜 |
|---|---|
| **아티스트명 불일치** | 한 글자만 달라도 Spotify에서 **다른 아티스트로 갈라집니다.** 5장이 한 페이지에 안 모입니다. 합치려면 유통사 통해 수정 요청해야 하고 시간이 걸립니다 |
| **Content ID 화이트리스트 누락** | 유통 음원이 **기존 153편 전부에 클레임**을 겁니다. 푸는 데 몇 주 걸립니다 |
| **압축 음원 업로드** | 발매 후 파일 교체가 어렵습니다. 음질이 영구히 남습니다 |
