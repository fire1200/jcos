### 3-1. 영상별 업로드 절차 (6편 반복)
1. [ ] studio(새 채널) > 오른쪽 위 **만들기** > **동영상 업로드** > 파일 선택
2. [ ] **세부정보**
   - 제목: 패키지의 "새 제목" 그대로 복사
   - 설명: 패키지의 설명 전체 복사 → 재생목록 링크, 라이브 링크 자리 채우기 → 타임스탬프를 **실제 곡 전환 시각**으로 수정
   - 썸네일: **테스트 및 비교** > 3장 업로드 (A/B/C)
   - 재생목록: 패키지 표대로 (예: #1은 밤잠 + 엄마 허밍)
   - 시청자층: **아니요, 아동용 아님** (기본값 확인)
   - 자세히 보기: 태그 붙여넣기, 언어 한국어, 카테고리 음악, 댓글 허용
3. [ ] **동영상 요소**
   - 최종화면 추가 > 템플릿 "동영상 1 + 재생목록 1" > 마지막 20초 > 패키지 표의 요소1·요소2 지정 (첫 영상은 요소1이 아직 없으므로 재생목록 2개로, 두 번째 영상 올린 뒤 돌아와서 수정)
4. [ ] **검사**: 저작권 경고 없음 확인 (자체 제작곡이므로 없어야 정상)
5. [ ] **공개 상태**: **예약** > 날짜는 패키지 일정, 시간 **20:00** > 예약
6. [ ] 공개 후 24시간 안에 **자막** > 제목·설명 번역 추가: 영어, 일본어 (패키지의 EN/JA 제목 + 공통 설명 틀)
