## 2. 춘천마라톤 — 공식 GPX는 없지만 코스도가 아주 좋습니다

| 확인한 곳 | 결과 |
|---|---|
| 공식 chuncheonmarathon.com — 코스 5개 페이지 + JS 번들 3개 전수 | **`gpx` 문자열 0회** |
| 와리가리 | 있음 (routeYearId 321) |
| marathon-map | 없음 |

**공식 코스도에 2.5km 간격 km 표지와 급수대·스펀지·초코파이·바나나·스포츠젤 위치가
전부 찍혀 있습니다.** 영상에 넣을 급수대 정보를 따로 찾을 필요가 없습니다.

### 코스 — 의암호 한 바퀴 순환

```
공지천교(출발) → 의암호 서안 남하 → 신연교·의암댐 → 서안 북상 → 서상대교
  → 춘천댐(약 28km) → 동안 남하 → 신매대교·위도(하프 지점 21.1km 표기)
  → 소양2교 → 춘천역 → 공지천 인조구장(도착)
```

**왕복이 아니라 순환입니다.** 되돌아오는 구간이 없어 영상이 지루해지지 않습니다.

| 지점 | 고도 |
|---|---|
| 0~3km | 75m 안팎 |
| **4~6km** | **102~106m** ← 초반 오르막 |
| 8~17km | 79~86m |
| 17.8km | 101m |
| **28.9km** | **114m** ← 코스 최고점 (춘천댐 부근) |
| 32km | 93m |
| 34~42km | 77~82m |

누적 상승 **공식 202m / 와리가리 220m**.

> ☐ **"30km 직전에 최고점"** 이 이 코스의 전부입니다. 풀코스에서 가장 힘든 구간에
> 오르막이 옵니다. 제목·썸네일에 쓸 수 있는 소재입니다

### 검증 결과

| | |
|---|---|
| 와리가리 좌표 합산 거리 | **42.171 km** (공인 42.195km와 **24m 차이**) |
| 공식 지도 지점 대조 | 신매대교 ±0.33km(이탈 1m), 춘천댐 ±1.09km(이탈 11m), 소양2교 이탈 16m |
| 고도 (공식 vs 와리가리) | 평균 **4.4m**, 최대 11.5m. 봉우리 위치 일치 (5.8/6.0km, 29.0/28.9km) |

그래도 **고도는 공식 고저도로 교체**해서 GPX를 만들었습니다.

> ⚠ 공식 고저도 원본이 **842×139px** 입니다. 수치화 정밀도가 약 **1.3m**입니다.
> 봉우리 위치와 높이는 믿을 만하지만 소수점은 의미 없습니다.
