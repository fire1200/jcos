# 「몽글이 첫말 노래」 Suno 제작 대본 — 6곡

작성 2026-10-08 · 채널: **몽글구름 동요** (아동용) · Suno Pro로 제작
한글 말소리를 처음 만나는 아기가 보호자와 함께 듣는 노래로 새로 썼습니다. 이전에 받은 음원 9곡(11~13, 21~26)을 대신합니다.

---

## 1. 곡을 이렇게 만든 이유 (모든 곡에 공통)

| 원칙 | 가사·편곡에 넣은 방법 |
|---|---|
| **아기가 먼저 내기 쉬운 소리부터** | 입술소리 ㅁ·ㅂ·ㅃ, 같은 소리를 되풀이하는 말(맘마, 빠이빠이, 냠냠, 멍멍)을 앞에 배치 |
| **단어는 문장 끝에, 혼자 들리게** | "엄마 어디 있나? → 여기! **엄마**" 처럼 물음 뒤에 단어만 따로 부름. 단어 앞뒤에 다른 말을 붙이지 않음 |
| **한 번 듣고 끝나지 않게** | 단어마다 3번: 물음 → 단어 두 번 → 짧은 문장 → 다시 단어 |
| **소리와 뜻을 묶기** | 단어마다 몸짓 소리를 짝지음 (손-짝짝, 물-꿀꺽, 멍멍이-멍멍). 영상에서 같은 동작을 보여 줌 |
| **느리고, 높고, 또렷하게** | 66~96 BPM. 맑고 따뜻한 여성 목소리, 또박또박. 울림(리버브)·합창·빠른 랩은 넣지 않음 |
| **한 곡에 새 단어는 4~6개만** | 6곡 × 5단어 안팎 = 약 30단어. 곡마다 주제를 하나로 묶음 |
| **곡마다 다른 소리** | 악기·빠르기를 모두 다르게 해서 6곡이 같은 노래처럼 들리지 않게 함 (반복 콘텐츠 방지) |
| **짧게** | 목표 1분 30초 ~ 2분. 전주는 2마디 이내 |
| **보호자가 따라 부르기 쉽게** | 음역이 좁고, 같은 가락을 되풀이함 |

> 이 원칙은 제작 기준입니다. 영상 제목과 설명에는 "말이 빨라진다", "언어 발달" 같은 효과를 약속하는 말을 쓰지 않습니다. 이 문서 5장에 넣을 문구가 있습니다.

## 3. 생성 방법 (Suno Pro)

1. **Custom 모드**를 켜고, 아래의 **Style**과 **Lyrics**를 그대로 붙여 넣습니다.
2. **Title**에는 곡 제목을 씁니다.
3. 가능하면 **Exclude styles**(빼고 싶은 스타일) 칸에 `reverb, choir, male vocals, rap, autotune, fast tempo`를 넣습니다.
4. 한 곡에 **4개 이상** 뽑은 뒤, 아래 점검표로 고릅니다.
5. 고른 파일은 `fw01_엄마아빠어디있나.mp3`처럼 **`fw` + 번호 + 제목**으로 저장해서 올려 주세요. 후보를 여러 개 보내실 때는 `_A`, `_B`를 붙여 주세요.

**고르는 점검표** (전부 "예"인 것)
- [ ] 단어(엄마, 손, 맘마 …)가 **반주보다 크고 또렷하게** 들린다
- [ ] 가사 순서가 대본과 같다 (줄이 빠지거나 다른 가사가 섞이지 않았다. 7번 곡 때 같은 문제가 있었습니다)
- [ ] 목소리에 울림이 적다 (목욕탕 소리 같지 않다)
- [ ] 전주가 짧다 (5초 이내)
- [ ] 끝이 뚝 끊기지 않는다
- [ ] 길이가 1분 20초 ~ 2분 20초

가사가 틀리게 불린 줄이 있으면 Suno의 **Replace Section**(구간 다시 만들기)으로 그 부분만 다시 만듭니다. 안 되면 새로 뽑습니다.

## 5. 영상과 업로드 (기획서 `firstwords_plan_20261008.md`와 같은 규칙)

- **영상 구조:** 물음("어디 있나?") → 단어가 들리는 순간 숨어 있던 것이 나타남 + 큰 글자 → 1~2초 여백.
- **그림:** 몽글이네 구름 가족과 아기 몽이(2D). 사람처럼 보이는 AI 그림은 쓰지 않습니다.
- **자막 시각:** 곡이 나오면 자막 편집기에 추가합니다. **단어 하나가 한 줄**입니다.
- **설명란 공통 문구**
```
가사는 직접 쓰고, 노래와 반주는 AI 음악 도구를 제작 과정에 활용해 만들었습니다.
이 영상은 노래를 즐기기 위한 것이며, 언어 발달이나 학습 효과를 약속하지 않습니다.
보호자와 함께, 노래에 나오는 것을 손가락으로 가리키며 천천히 불러 주세요.
```
- **업로드 설정:** 아동용 **예** · 변경되거나 합성된 콘텐츠 **예** · 재생목록 「몽글이 첫말 노래」
