# 동요 10곡 자막 시각 맞추기 — 작업 지시서

작성 2026-10-02 · 채널: 몽글구름 동요 (아동용 새 채널)

---

## 1. 왜 하나요

| 문제 | 설명 |
|---|---|
| 지금 영상의 가사 자막은 **자동으로 추정한 시각** | Claude가 노래 소리를 음성 인식해 가사 줄마다 시작 시각을 추정했습니다. 노래라 인식이 부정확해서, 특히 **반복되는 후렴·Suno가 가사를 바꿔 부른 곳에서 1~2초 어긋날 수 있습니다** |
| 아이들은 화면 가사를 보며 따라 부릅니다 | 가사가 늦거나 빠르면 따라 부르기 영상의 가치가 떨어지고, 유튜브 아동용 품질 기준에서 소리와 화면이 맞지 않는 영상은 낮게 평가됩니다 |
| 장면 전환도 같은 시각을 씁니다 | "뿡!" 큰 글자, 후렴에서 구름이 날아가는 장면 등도 가사 시각 기준이라, 시각이 정확해지면 장면도 노래에 딱 맞습니다 |

**해결:** 유튜브의 **자동 동기화** 기능은 가사 글자만 주면 노래를 듣고 줄마다 시각을 맞춰 줍니다. 그 결과(.srt 파일)를 받아 Claude가 **화면 자막·장면을 그 시각으로 다시 렌더링**합니다.

**덤:** 이 작업을 하면 영상에 정확한 **자막(CC)** 도 같이 붙습니다. 검색과 접근성에 도움이 됩니다.

## 2. 전체 흐름

| 단계 | 누가 | 할 일 | 시간 |
|---|---|---|---|
| ① | 운영자 | 예약된 본편 10편에 자동 동기화 → .srt 다운로드 | 곡당 5분 + 처리 대기 |
| ② | 운영자 | .srt 10개를 Claude 채팅창에 끌어다 놓기 | 1분 |
| ③ | Claude | srt 시각으로 본편 10편·쇼츠 10편·모음01 다시 렌더링 | 약 2시간 |
| ④ | 운영자 | 교체본을 같은 날짜·시각으로 새로 예약, 이전 예약은 삭제 | 곡당 5분 |

**지금 바로 10곡 모두 진행합니다.** 유튜브가 처리하는 동안 기다리는 시간이 대부분이라, 10곡을 한꺼번에 걸어 두고 끝난 순서대로 다운로드하면 됩니다.

## 3. ① 자동 동기화 (곡마다 반복)

1. [studio.youtube.com](https://studio.youtube.com) → 오른쪽 위 프로필에서 **몽글구름 동요** 채널인지 확인
2. 왼쪽 메뉴 **자막**
3. 목록에서 예약된 본편 클릭 (예: `구름 빵빵 방귀 풍선 🎈 | …`)
4. 처음이면 **언어 설정** → **한국어** → 확인
5. **한국어** 줄의 "자막" 칸에서 **추가**
6. **자동 동기화** 선택
7. 이 문서 **6장의 해당 곡 가사 상자**를 통째로 복사해 붙여 넣기
8. **시간 할당** 클릭 → "처리 중" (몇 분)
9. 다음 곡으로 넘어가 3~8 반복 (기다리지 않아도 됨)
10. 처리가 끝난 곡: 자막이 줄마다 시각과 함께 보이면 오른쪽 위 **게시**

**주의**
- 쇼츠와 모음 영상은 **동기화하지 않습니다.** 본편 srt로 Claude가 함께 다시 만듭니다
- 7번은 **C 버전(1분 48초)** 가사를 써야 합니다. 6장의 7번 가사가 C 버전입니다
- 따로 올린 **동기화용 비공개 영상**(`kidsNN_sync`)에서 해도 결과는 같습니다. 단 7번은 C 버전으로 다시 만든 `kids07_sync.mp4`여야 합니다

## 5. ③·④ Claude가 만드는 교체본과 다시 예약하기

**Claude가 보내는 파일 이름**

| 종류 | 파일 이름 규칙 | 예 |
|---|---|---|
| 본편 | `kidsNN_곡이름_v2.mp4` | `kids01_구름빵빵방귀풍선_v2.mp4` |
| 쇼츠 | `shortsNN_v2.mp4` | `shorts01_v2.mp4` |
| 모음 | `모음01_신나는창작동요모음_v2.mp4` | — |

`_v2`가 붙은 파일이 교체본입니다. 썸네일·제목·태그·설명은 **바뀌지 않습니다** (게시 계획 md 그대로).

**다시 예약하는 순서 (곡마다)**
1. 교체본 업로드 → 제목·태그·설명·썸네일·재생목록은 게시 계획 md 그대로
2. 아동용 **예**, 변경되거나 합성된 콘텐츠 **예**
3. **같은 날짜·시각**으로 예약
4. 스튜디오 → 콘텐츠에서 **이전 예약 영상(v1) 삭제**
5. 새 영상에도 자막(CC)을 붙이려면: 자막 → 추가 → **파일 업로드** → `kidsNN.srt`

유튜브는 이미 올린 영상의 파일만 바꿔 끼울 수 없어서 새로 올리는 방식입니다. **공개 전이라 조회수 손실은 없습니다.**
