## 1. 원칙

1. **유튜브는 영상을 채널 간 이동시키지 못한다.** 새 채널에는 원본 파일을 다시 올린다. 조회수·댓글·좋아요는 따라오지 않는다.
2. **전부 옮기지 않는다.** 원 채널에서 성과가 증명된 롱폼 6편만 재업로드한다. 2분짜리 33편은 영상이 아니라 앨범·쇼츠 소재로 쓴다.
3. **원 채널에서는 삭제하지 않고 일부공개로 돌린다.** 링크가 살아 있고, 나중에 되돌릴 수 있다.
4. **순서가 있다.** 원 채널 트래픽 소스 CSV를 먼저 내보내고, 그다음 일부공개, 그다음 새 채널 업로드 시작.
5. **러닝 음악은 한 편도 옮기지 않는다.** 러닝 관련 102편은 @PPAIEO에 그대로 둔다.

## 3. 절차

### 3-1. 사전 작업 (@PPAIEO, 순서 엄수)

1. [ ] **트래픽 소스 CSV 내보내기** — studio.youtube.com > 채널 전환 PPAIEO > 분석 > 고급 모드 > 트래픽 소스 탭 > 지난 28일 > 내보내기 > CSV. (일부공개 전 기준선)
2. [ ] **원본 파일 확보** — 로컬 제작 원본(무손실 또는 원 렌더링 파일)을 6편 찾는다. 원본이 없을 때만 스튜디오 다운로드를 쓴다: 콘텐츠 > 해당 영상 ⋮ > 다운로드. 스튜디오 다운로드는 720p 재인코딩본이라 오디오가 한 번 더 압축된다. 가능하면 프로젝트에서 다시 렌더링한다.
3. [ ] **오디오 점검** — 6편 각각 `ffmpeg -i 파일 -af ebur128=peak=true -f null -` 로 통합 라우드니스 -17~-14 LUFS, LRA 4 이하, 피크 -1.5 dBTP 이하 확인. 벗어나면 `templates/audio_production_spec.md` 1장 기준으로 마스터링.
4. [ ] **#6 (30분 무가사) 첫 10분 재편집** — 원 채널에서 평균 시청 2.5분에 이탈. 0초 음악 시작, 선율 분명한 곡을 첫 곡으로, 10분 안에 곡 전환 1회.
5. [ ] **썸네일 18장 제작** — 6편 × A/B/C. 규격 `templates/thumbnail_guide.md`. 아기 얼굴·캐릭터 금지.

### 3-2. @PPAIEO 일부공개 전환

1. [ ] 콘텐츠 > 동영상 탭 > 검색 `자장가` > 전체 선택 > 수정 > 공개 상태 > **일부공개** > 업데이트
2. [ ] 검색 `수면`, `신생아` 로 반복해 누락 확인 (총 39편)
3. [ ] 필터 > 시청자층 > 아동용 → 표시된 편수 기록
4. [ ] 롱폼 6편 설명 첫 줄에 추가: `이 영상은 새 채널 토담토담로 이전했습니다 → https://www.youtube.com/@dodamam`
5. [ ] 재생목록 탭 > 수면음악 재생목록 삭제
6. [ ] 설정 > 채널 > 기본 정보 > 키워드에서 수면·자장가 삭제 / 맞춤설정 > 채널 설명에서 수면음악 문구 삭제
7. [ ] 러닝 영상 최종화면·카드에 수면 영상이 걸려 있으면 러닝 영상으로 교체

### 3-3. @dodamam 사전 세팅 (업로드 전에 한 번)

1. [ ] 설정 > 채널 > 고급 설정 > 시청자층 **아동용 아님**
2. [ ] 설정 > 업로드 기본 설정 > 시청자층 아동용 아님, 카테고리 음악, 언어 한국어, 태그 `아기수면음악, 신생아자장가, 엄마허밍`
3. [ ] 맞춤설정 > 기본 정보 > 설명: `아기 재우는 부모를 위한 자체 제작 자장가·수면음악 채널입니다. 엄마 허밍과 무가사 피아노를 30분부터 10시간까지 광고 없이 올립니다. 매주 화·금 저녁 8시에 새 영상이 올라옵니다.`
4. [ ] 브랜딩: 프로필(초승달), 배너(밤하늘 + 토담토담 + 매주 화·금 저녁 8시), 워터마크(초승달, 전체 동영상)
5. [ ] 재생목록 5개 생성: `밤잠 자장가 3시간·10시간`, `낮잠 자장가 30분·1시간`, `엄마 허밍 자장가`, `무가사 피아노 자장가`, `신생아 0~3개월`

### 3-4. 재업로드 (편당 30~40분, 6회 반복)

1. [ ] studio > 채널 전환 **토담토담** > 만들기 > 동영상 업로드 > 원본 파일
2. [ ] 세부정보: 제목·설명·태그를 `plans/reupload_package_v1.md`에서 복사. 설명의 재생목록 링크 자리에 `https://www.youtube.com/@dodamam/playlists`, 타임스탬프는 실제 곡 전환 시각으로
3. [ ] 썸네일: 테스트 및 비교 > A/B/C 3장
4. [ ] 재생목록: 패키지 표대로 (예: #1 → 밤잠 + 엄마 허밍)
5. [ ] 시청자층 아동용 아님 확인
6. [ ] 동영상 요소 > 최종화면: 마지막 20초, 동영상 1 + 재생목록 1. #1은 #2가 아직 없으므로 재생목록 2개로 두고, #2 업로드 후 돌아와 수정
7. [ ] 검사: 저작권 경고 없음 확인
8. [ ] 공개 상태 > 예약 > 표의 날짜, 20:00
9. [ ] 공개 후 24시간 안: 자막 > 제목·설명 번역 추가 (영어·일본어, 패키지에 있음)
10. [ ] 공개 당일: 고정댓글 등록 (`templates/launch_7day_checklist.md`), 2시간 후 노출·클릭률 확인, 48시간 후 CTR 3% 미만이면 썸네일 교체

### 3-5. 검증 (각 편 공개 후)

- [ ] 새 채널 영상 페이지에서 시청자층 표시가 아동용이 아닌지 (댓글창이 열려 있으면 정상)
- [ ] 원 채널 같은 영상이 일부공개 상태인지
- [ ] Content ID 클레임이 없는지 (자체 제작곡이면 없어야 정상. 유통 발매 뒤에는 유통사 화이트리스트 등록 필요)
- [ ] 최종화면 클릭이 새 채널 안의 영상으로 가는지 (원 채널 영상으로 가면 안 됨)
