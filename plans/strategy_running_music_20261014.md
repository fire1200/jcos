# 러닝 음악 전략 (2026-10-14)

직전 결정: `plans/decision_ppaieo_20261012.md` (빠이요 신규 제작 중단)
**이 문서는 그 결정을 일부 조정합니다.**

---

## 1. 제가 놓치고 있던 근본 원인

지금까지 빠이요를 "제목이 나쁘다", "노출이 안 나온다", "수면이 섞였다"로 설명했습니다. 전부 표면입니다.

> **야외에서 달리는 사람은 화면을 보지 않습니다.**

| 장르 | 시청자가 화면을 보나 |
|---|---|
| 아기 수면음악 | **본다** — 부모가 폰을 아기 옆에 둠 |
| 창작동요 | **본다** — 아이가 화면을 봄 |
| 공부 음악 | **본다** — 노트북에 틀어 둠 |
| **러닝 음악 (야외)** | **안 본다** — 주머니에 넣고 달림 |

유튜브는 **화면 기반 플랫폼**입니다. 백그라운드 재생은 프리미엄 구독이 필요합니다.

러너는 Spotify, Apple Music, 또는 가민 워치에 음악을 **내려받아** 듣습니다. 폰조차 안 들고 나가는 경우가 많습니다.

**빠이요의 음악이 나쁜 게 아니라, 그 음악을 듣는 사람이 유튜브에 없습니다.**

---

## 2. 그러면 러닝 음악을 버려야 하나 — 아닙니다

**플랫폼이 틀렸을 뿐입니다.** 157편의 음원 자체는 자산입니다.

러닝 음악에는 두 개의 진짜 시장이 있고, 둘 다 유튜브 채널이 아닙니다.

| 시장 | 어디 |
|---|---|
| **① 야외 러너** | **스트리밍** (Spotify·Apple Music·가민 워치) |
| **② 실내 러너 (트레드밀)** | **유튜브** — 단, 음악이 아니라 **영상**을 봅니다 |

---

## 3. 시장 ① — 스트리밍 유통

러너가 실제로 음악을 듣는 곳입니다.

Spotify에는 `RUNNING 2026`, `Run Workout Music`, `Running Playlist 120-160 BPM Cardio` 같은 러닝 플레이리스트가 다수 운영됩니다. **BPM이 명시된 플레이리스트가 실제로 존재합니다.**

빠이요 음원의 강점이 여기서 살아납니다.

| 강점 | 왜 |
|---|---|
| **BPM이 곡마다 명확** | 160·174·180·190·210. 러닝 플레이리스트의 분류 기준 그 자체 |
| 장르가 다양 | 록·재즈·피아노·테크노·K-Pop·신스팝·클래식 |
| **157편의 카탈로그** | 신인에게 이 분량은 드뭅니다 |

### 다만 — 먼저 확인할 것

`templates/music_distribution_podcast_checklist.md` 9행의 경고가 여기에도 적용됩니다.

> 로열티 프리·AI 원본 음원은 유통사 심사에서 거절되거나 Content ID 충돌이 생긴다

☐ **빠이요 157편이 어떻게 만들어졌습니까?** 직접 작곡·연주인지, AI 생성인지에 따라 유통 가능 여부가 갈립니다

AI 생성분이 많다면 유통은 어렵고, 이 축은 접어야 합니다.

---

## 4. 시장 ② — Virtual Run (트레드밀용 영상)

**실내 러너는 화면을 봅니다.** 트레드밀 앞에 화면이 있고, 거기에 영상을 틀어 놓습니다.

유튜브에 이 장르가 실재합니다 — `Virtual Treadmill Run`, `Virtual Running - Scenery`, `1 Hour Virtual Run`. 파리·노르웨이·해안 트레일 등 여러 채널이 운영 중입니다.

### 사용자는 이미 이 방향을 찾으셨습니다

10/10에 올리신 영상입니다.

```
160 SPM Day City Run | 25-Minute World Run Film | No Talking
```

**정확히 이 장르입니다.** 노출 13회에 조회 5회였지만 올린 지 나흘이고 한 편뿐입니다. 판단할 데이터가 아닙니다.

### 왜 이게 빠이요에 맞나

| | |
|---|---|
| **음악이 이미 있습니다** | 157편. 영상만 얹으면 됩니다 |
| 길이가 깁니다 | 25분~1시간. 트레드밀 러너는 그만큼 달립니다 |
| **시청시간이 큽니다** | 2시간 믹스와 달리 **끝까지 보는 이유**가 있습니다 |
| BPM이 의미를 가집니다 | 영상 속도와 케이던스가 맞물립니다 |

**2시간 믹스는 "듣는 것"이라 유튜브에서 질 수밖에 없고, Virtual Run은 "보는 것"이라 유튜브가 맞는 자리입니다.**

### 결정적 조건 — 실사 촬영인가

이 장르의 시청자는 **"진짜 거기를 달리는 느낌"** 을 원합니다. 액션캠으로 찍은 1인칭 영상이 핵심입니다.

☐ **10/10 영상이 실제 촬영분입니까, AI 생성 영상입니까?**

| 실사 | AI 생성 |
|---|---|
| 이 장르가 작동합니다 | **작동하지 않습니다.** 시청자가 바로 알아챕니다 |

AI 생성이라면 이 축도 접어야 합니다. 그 경우 3절(유통)만 남습니다.

### 실사라면 — 차별점이 있습니다

기존 Virtual Run 영상은 대부분 유럽·북미입니다. **한국 도시는 희소합니다.**

| 후보 | |
|---|---|
| 한강 야간 러닝 | 야경. 국내외 모두 희소 |
| 경복궁·북촌 새벽 | 외국인 시청자에게 강함 |
| 부산 해안 | 바다 + 도시 |
| 제주 올레길 | 자연 |

## 7. 수정된 실행안

**전면 전환이 아니라 시험입니다.**

| 순서 | 할 일 | 비용 | 선행 조건 |
|---|---|---|---|
| **0** | **음원 제작 방식 확인** (직접 / AI) | 0 | — |
| **0** | **10/10 영상이 실사인지 확인** | 0 | — |
| 1 | Virtual Run **1편 시험** (한국 도시, 25~30분) | 촬영 2시간 + 편집 2시간 | 실사 촬영 가능 |
| 2 | 2주 관찰 | 0 | — |
| 3 | 유통사 계정 개설·발매 | 3시간 | 자체 제작 음원 |

**0번 두 가지 답에 따라 1·3번이 결정됩니다.** 답을 모르면 아무것도 시작하지 마세요.

| 답 | 그러면 |
|---|---|
| 음원 자체 제작 + 실사 촬영 가능 | **1·3번 모두 진행** |
| 음원 자체 제작 + 실사 불가 | **3번만** (유통) |
| 음원 AI 생성 + 실사 가능 | **1번만** (Virtual Run) |
| 둘 다 아님 | 직전 결정대로 **아무것도 하지 않음** |
