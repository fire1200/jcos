## 1. 왜 하는가 — 목적

### 1-1. 채널의 병목

토담토담은 음악은 이미 작동합니다. 문제는 **유튜브가 영상을 거의 보여 주지 않는다는 것** 하나입니다.

| 단계 | 현재 (8/22~9/19) | 목표 | 판정 |
|---|---|---|---|
| 노출 | 62회 | 수천 회 | **병목** |
| 클릭률 | 6.45% (검색 8.0%) | 4% | 목표 초과 |
| 유지율 | 60% | 50% | 목표 초과 |

노출이 없는 이유는 **채널 안에 서로 다른 사용 상황이 6개뿐**이라서입니다. 경쟁 채널은 같은 음악 정체성으로 상황만 수백 개로 쪼갰습니다(케어멜로디 374편, 건반DIARY 769편). 그래서 8주 계획의 1순위가 **상황 세분화**입니다.

### 1-2. 이 영상이 채우는 상황

**"부모가 아는 선율로 재우기."** 지금까지의 토담토담 곡은 전부 창작곡이라, 부모가 곡명으로 검색해 들어올 길이 없었습니다. 이 영상은 처음으로 **곡명 검색어**(브람스 자장가, 반짝반짝 작은별, 모차르트 자장가…)를 채널에 들여옵니다.

| 목적 | 구체적으로 |
|---|---|
| **새 검색 진입점** | 곡명 8개가 제목·설명·태그·챕터에 들어가 새 검색어가 생김 |
| **상황 하나 추가** | 8주 계획 6주차 신규 상황 칸. 영상 수 22편 목표에 기여 |
| **새 재생목록** | `익숙한 선율 자장가` 시리즈의 첫 편. 잘 되면 2편·크리스마스판으로 확장 |
| **채널 정체성 유지** | 편성의 절반을 엄마 허밍으로. "동요 채널"이 아니라 "토담토담이 부르는 익숙한 자장가" |

### 1-3. 하지 않는 것

| 하지 않음 | 이유 |
|---|---|
| 동요 채널로 전환 | 경쟁 3채널 모두 남의 곡이 아니라 **자기 소리**로 컸음. 창작 허밍 노선이 본류 |
| 아이가 따라 부르는 동요 영상 | 아동용 설정이 필요해 댓글·알림·최종화면이 막힘 |
| 저작권이 남은 인기 동요 | 섬집아기·반달·산토끼·에델바이스·과수원길 등은 보호 중 |

| 길이 | 3시간 |

### 2-1. 곡 구성과 순서

8곡 × 8분 = 64분 소재, 3시간에 2.8회 순환. 9/29 #1과 같은 구조입니다.

| 순서 | 구간 | 곡 | 선율 출처 (저작권) | 편성 | 조성 | 템포 |
|---:|---|---|---|---|---|---|
| 1 | 0:00~8:00 | **반짝반짝 작은별** | 프랑스 민요, 18세기 (만료) | 오르골 | F장조 | 56 |
| 2 | 8:00~16:00 | **브람스 자장가** | 브람스 Op.49-4, 1897 작고 (만료) | 엄마 허밍 | F장조 | 54 |
| 3 | 16:00~24:00 | 나비야 | 독일 민요 「Hänschen klein」 (만료) | 오르골, **원곡 절반 템포** | F장조 | 52 |
| 4 | 24:00~32:00 | 고향의 봄 | 홍난파, 1941 작고 (만료). **가사 금지** | 엄마 허밍 | B♭장조 | 52 |
| 5 | 32:00~40:00 | 모차르트 자장가 | B. 플리스, 18세기 (만료) | 피아노 | B♭장조 | 50 |
| 6 | 40:00~48:00 | 낮에 나온 반달 | 홍난파, 1941 작고 (만료). **가사 금지** | 엄마 허밍 | B♭장조 | 50 |
| 7 | 48:00~56:00 | 슈베르트 자장가 | 슈베르트 D.498, 1828 작고 (만료) | 피아노 | F장조 | 48 |
| 8 | 56:00~64:00 | 저녁 기도 | 훔퍼딩크 「헨젤과 그레텔」, 1921 작고 (만료) | 낮은 허밍 + 피아노 | F장조 | 46 |

**순서를 이렇게 둔 이유**

| 원칙 | 적용 |
|---|---|
| 0~10분은 선율이 가장 분명하고 가장 익숙한 곡 (`templates/audio_production_spec.md` 2장) | 1번 반짝반짝 작은별: 유튜브 최다 조회 자장가. 클릭한 부모가 바로 알아들음 |
| 제목에 넣은 두 곡을 앞에 | 1·2번. 제목의 약속이 첫 16분 안에 지켜짐 |
| 뒤로 갈수록 느리고 단순하게 | 템포 56 → 46. 마지막은 가장 느린 저녁 기도 |
| 조성은 F·B♭ 두 개만 | 곡 전환 때 음높이가 튀지 않음. 새벽 각성 방지 |
| 편성 교대 (오르골·허밍·피아노) | 한 음색이 16분 넘게 이어지지 않음. 반복 인지를 낮춤 |

**빼 둔 곡:** 새야 새야 파랑새야·전래 자장가(채보판 확인 전 🟡), 퐁당퐁당(원곡이 경쾌함). 첫 편은 전부 ✅ 곡으로만 갑니다.

## 3. 지켜야 할 원칙

### 3-1. 저작권

| 원칙 | 이유 |
|---|---|
| **선율만 쓰고 가사는 한 줄도 넣지 않음** | 선율이 만료돼도 가사는 보호 중일 수 있음. 고향의 봄(이원수), 낮에 나온 반달(윤석중) 가사는 보호 중 |
| **원본 악보에서 선율을 직접 MIDI로 입력** | 남이 편곡·출판한 악보, 유튜브·음원 녹음에는 편곡자·음반 권리가 따로 있음 |
| **Suno에는 직접 만든 선율 음원만 업로드** | 권리 없는 음원 업로드는 Suno 약관 위반이고 상업 라이선스 대상도 아님 |
| **Pro 구독 중에만 생성, 영수증·생성 기록 보관** | 무료 요금제 곡은 수익화 불가, 소급 안 됨. 지금까지 곡은 전부 Pro로 확인됨 |
| **설명란에 원곡과 만료 근거 명시** | Content ID 오인 클레임(클래식 명곡에 흔함)에 이의 제기할 근거 |
| **사람이 한 작업을 기록** | AI 산출물은 인간의 창작적 기여가 없으면 저작권 등록이 어려움. MIDI·편곡·레이어 파일이 기여의 증거 |

한국 보호기간: 작고 후 70년. 단 **1962년 이전 작고자는 이미 만료**. 작곡과 작사는 따로 셉니다.

### 3-2. 아동용 자동 분류 피하기

**채널 점검 도구(`tools/check_metadata.py`)가 제목의 "동요"를 아동용 자동 분류 위험 단어로 보고 FAIL 처리합니다.** 유튜브는 제목·태그 같은 신호로 영상을 아동용으로 자동 분류할 수 있고, 아동용이 되면 댓글·알림·최종화면이 막힙니다.

| 쓰는 곳 | 표기 |
|---|---|
| 내부 문서·시리즈 이름 | 동요 선율 자장가 |
| 제목·태그·설명·재생목록 이름 | **"동요" 대신 곡명과 "자장가"·"오르골"**. 예: `브람스 자장가`, `반짝반짝 작은별` |
| 재생목록 공개 이름 | `익숙한 선율 자장가` |

곡명(반짝반짝 작은별)은 부모가 검색하는 말이고 점검 도구의 위험 단어가 아닙니다. 영상은 가사·캐릭터 없이 부모가 틀어 두는 수면 도구이므로 기존 영상과 같이 **아동용 아님**으로 설정합니다.

### 3-3. 채널 원칙 (기존 그대로)

| 원칙 | 이 영상에서 |
|---|---|
| 한 번에 한 변수만 | 썸네일 하나로 공개. 시험은 7일 뒤 |
| 주 2편 상한, 하루 1편 | 11/3 화 1편. 같은 날 다른 영상 금지 |

## 4. 전체 작업 목록과 일정

주간 루틴(주 7시간, 화·금 공개)과 겹치므로 3주에 나눴습니다. 날짜 옆 괄호는 예상 시간입니다.

### 4-1. 1주차 — 준비 (10/20~10/25)

- [ ] **10/20~10/21 (1.5h)** 8곡 저작권 재확인
  - [ ] KOMCA(komca.or.kr) 저작물 검색에서 8곡 모두 관리곡으로 나오지 않는지
  - [ ] 원곡자 사망연도 확인 (5장 카드의 "선율 출처")
  - [ ] 원본 악보 확보: IMSLP(클래식 4곡), 공유마당 『조선동요백곡집』 원판(홍난파 2곡), 민요 2곡은 직접 채보
- [ ] **10/22~10/25 (2.7h)** 선율 MIDI 입력 8곡 (곡당 20분)
  - [ ] 선율 한 줄만, 반주 없음
  - [ ] 조성·템포는 2-1 표대로
  - [ ] 피아노 음색 30~60초 WAV 렌더 → `곡명_melody.wav`

### 4-2. 2주차 — Suno 생성 (10/26~10/29)

- [ ] **10/26~10/29 (3.3h)** 5장 곡별 카드 순서대로 생성 (곡당 25분)
  - [ ] Pro 구독 상태 확인
  - [ ] Upload → Cover, 4~6회 생성, 1개 선택
  - [ ] Extend로 8분
  - [ ] 5-10 생성 후 확인 6항목
  - [ ] 생성 기록 캡처 (곡명·일시·요금제 화면)

### 4-3. 3주차 — 후처리·조립·게시 (10/30~11/3)

- [ ] **10/30~11/1 (4.0h)** 곡별 트림·자체 레이어 (6장, 곡당 30분)
- [ ] **11/2 월 (3.5h)**
  - [ ] 조립·핑크노이즈·마스터링 (7장)
  - [ ] 비주얼 (8-1)
  - [ ] 썸네일 (8-2)
  - [ ] 재생목록 `익숙한 선율 자장가` 생성, 공식 시리즈 설정
  - [ ] 메타데이터 입력 (9장), 점검 도구 FAIL 0 확인
  - [ ] 출고 전 체크리스트 (10장)
  - [ ] 11/3 20:00 예약
- [ ] **11/3 화 20:00 (0.5h)** 공개, 고정댓글
- [ ] **11/4 수** Content ID 클레임 확인, 48시간 지표 기록 준비

### 4-4. 시간 합계와 줄이는 방법

| 작업 | 시간 |
|---|---:|
| 저작권 확인·악보 | 1.5 |
| MIDI 입력 | 2.7 |
| Suno 생성 | 3.3 |
| 곡별 후처리 | 4.0 |
| 조립·비주얼·썸네일·메타 | 3.5 |

**버거우면 8곡 → 6곡**(나비야·낮에 나온 반달 제외, 48분 소재 3.75회 순환, 약 12시간). 공개일을 미루는 것보다 곡 수를 줄이는 쪽을 권합니다.

## 5. 곡별 작업 카드와 Suno 프롬프트


### 5-1. Suno 공통 사용법

| 항목 | 값 |
|---|---|
| 요금제 | **Pro 구독 중에만** 생성 |
| 모드 | Custom |
| 입력 | 4-1(MIDI 입력)에서 직접 만든 선율 WAV (`곡명_melody.wav`, 30~60초)를 **Upload → Cover** |
| 고급 옵션 (있을 때) | Audio Influence **높게(70~80%)** — 선율 유지 / Weirdness **낮게(15~25%)** / Style Influence 중간(50~60%) |
| 생성 수 | 곡당 4~6회, 선율이 원곡과 가장 가까운 것 선택 |
| 확장 | 고른 결과를 **Extend**로 8분까지. 확장할 때 가사란은 각 곡의 "확장용" 블록으로 교체 |
| 곡명이 거부될 때 | 스타일 프롬프트에서 곡·작곡가 이름 줄만 지우고 다시 생성 (선율은 업로드 음원이 잡아 줌) |

**스타일 프롬프트는 곡별 블록을 통째로 복사합니다.** 공통 문구를 이미 합쳐 두었습니다.

**허밍 곡의 가사란 `Mmm` 개수는 원곡 한 소절의 음표 수에 맞췄습니다.** Suno가 소절 길이를 맞추는 데만 쓰는 것이고, 실제 선율은 업로드 음원을 따릅니다. 원곡 가사를 대신 넣으면 안 됩니다.

### 5-2. 1번 반짝반짝 작은별 — 오르골 (0:00~8:00)

| 항목 | 값 |

| 4 | **자체 레이어**: 기존 토담토담 허밍 곡의 패드나 잔향을 **-25 dB**로 깔기 | DAW | 13분 |

**4단계가 핵심입니다.** 귀로는 거의 안 들리지만, 이 곡이 "AI 생성물 그대로"가 아니라 "AI 소재를 포함한 자체 편곡"이라는 근거가 됩니다(비진정성 정책 대응). 어떤 곡의 무엇을 깔았는지 부록 A에 적습니다.

| 편성 | 깔 자체 레이어 예시 |
|---|---|
| 오르골 (1·3번) | 기존 무가사 피아노 곡의 잔향 꼬리 |
| 엄마 허밍 (2·4·6번) | 기존 허밍 곡(몽실몽실 꿈자리 등)의 패드 |
| 피아노 (5·7번) | 기존 허밍 곡의 아주 낮은 허밍 한 겹 |
