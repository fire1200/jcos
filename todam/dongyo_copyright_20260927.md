# 동요를 Suno로 만들어 올려도 되는가 — 저작권 검토 (2026-09-27)

> 쓸 수 있는 곡만 골라 둔 목록은 `todam/dongyo_pd_list_20260927.md`

질문: 잘 되는 채널들이 동요 영상을 같이 올린다. 동요를 Suno로 새로 만들면 저작권 문제가 없는가?

> 법률 자문이 아닙니다. 공개 자료를 기준으로 정리했고, 수익이 걸린 곡은 아래 7장의 방법으로 한 번 더 확인하세요.

---

## 1. 결론

**Suno로 "새로 만든다"고 해서 저작권이 사라지지 않습니다.** 판단 기준은 도구가 아니라 **어떤 곡의 멜로디와 가사를 쓰느냐**입니다.

| 경우 | 판정 |
|---|---|
| 보호기간이 남은 동요의 멜로디를 Suno로 다시 부르거나 연주하게 함 | ❌ **침해.** 편곡(2차적저작물)이라 저작권자 허락이 필요 |
| 보호기간이 남은 동요의 가사를 Suno 가사 칸에 넣음 | ❌ 침해 + Suno 약관 위반 |
| 다른 사람의 동요 녹음을 Suno에 업로드해 커버 | ❌ 녹음 자체의 권리(음반제작자)까지 침해. Suno가 자동 차단하기도 함 |
| **보호기간이 끝난 멜로디**를 직접 입력·연주한 음원으로 Suno 편곡 | ⭕ 가능 (가사는 따로 확인) |
| 동요 **느낌의** 완전히 새로운 곡 | ⭕ 가능. 지금 토담토담 곡들과 같은 방식 |

"다른 채널이 올리니까 괜찮다"는 근거가 안 됩니다. 그 채널은 한국음악저작권협회(KOMCA) 이용 허락을 받았거나, 만료곡만 골랐거나, 아직 신고를 안 당했을 뿐일 수 있습니다.

## 2. 보호기간 계산법 (한국)

| 저작자 사망 시점 | 보호기간 |
|---|---|
| **1962년 12월 31일 이전** 사망 | 끝남 (당시 법으로 사후 50년에 만료) |
| 1963년 1월 1일 이후 사망 | **사후 70년**, 사망 다음 해 1월 1일부터 셈 |

- 작곡가와 작사가는 **따로** 셉니다. 멜로디가 만료돼도 가사는 남아 있을 수 있습니다
- 작자 미상은 만료라는 뜻이 아닙니다. 공표 후 70년이 기준이고, 뒤늦게 작자가 밝혀지는 경우가 있습니다(산토끼가 그랬습니다)
- 외국 민요 선율에 한국어 가사를 붙인 번안 동요는 **번안 가사에 별도 저작권**이 있을 수 있습니다

## 4. Suno 쪽 조건

| 항목 | 내용 | 토담토담 영향 |
|---|---|---|
| **요금제** | 무료 요금제로 만든 곡은 비상업적 이용만 허용. 나중에 유료 가입해도 소급 적용 안 됨 | **확인 완료 (2026-09-27): 지금까지 전부 Pro로 생성.** 공개된 영상 포함 상업 이용 문제없음. 앞으로도 Pro 구독 중에만 생성하고, 결제 영수증을 보관할 것 |
| 소유권 | 유료 요금제는 출력물 권리를 사용자에게 넘기지만, "저작권이 성립한다고 보증하지 않는다"고 명시 | 아래 5장 |
| 업로드 | 권리가 있는 음원만 업로드 가능. 저작권 음원은 자동 차단되고, 통과해도 상업 라이선스 대상 아님 | 만료 선율은 **직접 입력한 MIDI나 직접 연주**로 업로드 |
| 가사 | 권리 없는 가사 입력 금지 | 3-1 곡 가사 입력 금지 |
| 약관 변경 | 2025년 워너뮤직 합의 이후 2026년 약관·다운로드 정책이 바뀜 | 곡 만들 때마다 당시 약관을 한 번 확인 |

**만료 선율을 Suno에 넣는 현실적인 방법:** 글 프롬프트로 "브람스 자장가"라고 쓰면 선율이 정확히 나오지 않고 엉뚱한 곡이 나옵니다. 악보를 보고 **직접 MIDI로 찍거나 직접 연주한 짧은 음원을 업로드**해 편곡을 맡기는 방식이 정확하고 약관에도 맞습니다. 이때 악보는 원본 악보(만료)를 쓰고, 다른 사람이 편곡해 출판한 악보는 쓰지 마세요 — 편곡 악보에는 편곡자 권리가 있습니다.

## 5. 반대 방향의 위험 — 내 곡도 보호받기 어렵다

한국저작권위원회 「생성형 AI 활용 저작물의 저작권 등록 안내서」는 **인간의 창작적 기여가 없는 AI 산출물은 저작물이 아니며 등록할 수 없다**고 봅니다.

| 결과 | 대응 |
|---|---|
| 누가 토담토담 음원을 베껴 올려도 막기 어려움 | 편곡·구간 설계·레이어 조합 등 **사람이 한 작업을 기록**해 둠 (프로젝트 파일, 작업 메모) |
| 유통(YouTube Music·Content ID 등록) 심사에서 불리 | 기존 결정대로 **유통은 12월 이후**, 자체 녹음 비중을 올린 뒤 |

## 6. 유튜브 쪽 조건

### 6-1. 아동용 설정 — 가장 큰 전략 문제

아이가 보고 따라 부르는 동요 영상(가사 자막, 캐릭터 애니메이션)은 **아동용으로 설정해야** 합니다(COPPA). 아동용이 되면 댓글·알림·최종화면·카드·개인 맞춤 광고가 막힙니다. 토담토담 원칙("아동용 설정을 조회수 목적으로 바꾸지 않는다, 콘텐츠의 실제 성격으로 판단")과 정면으로 부딪힙니다.

| 형태 | 성격 | 설정 |
|---|---|---|
| 가사 자막·캐릭터가 나오는 따라 부르기 동요 | 아이가 보는 영상 | 아동용 |
| **동요 선율을 허밍·오르골로 만든 3시간 수면음악, 어두운 화면** | 부모가 틀어 두는 수면 도구 | 기존 영상과 같은 기준 |

그래서 **"동요 채널"이 되지 말고 "동요 선율 자장가"를 상황 하나로 추가**하는 것이 맞습니다.

### 6-2. 그 밖의 위험

| 위험 | 대응 |
|---|---|
| **Content ID 오인 클레임** — 브람스 자장가처럼 만료곡이라도 남의 녹음이 등록돼 있으면 내 영상에 클레임이 걸릴 수 있음 | 이의 제기 가능. 설명란에 "원곡: 브람스 (저작권 만료), 편곡·제작: 토담토담"을 명시하고 제작 파일 보관 |
| **비진정성 콘텐츠 정책** — Suno로 동요를 대량 생산하는 채널이 전형적 대상 | 동요 선율판도 **주 2편 한도 안에서** 상황 하나로만 |

## 7. 곡을 쓰기 전 확인 절차

1. **KOMCA 저작물 검색** ([komca.or.kr](https://www.komca.or.kr/)) — 곡명으로 검색. 나오면 관리 중인 곡이라 허락 없이 쓰면 안 됨
2. 안 나오면 **작곡가·작사가 사망연도** 확인 → 2장 표로 계산
3. 애매하면 **한국저작권위원회 공유마당 만료저작물**([gongu.copyright.or.kr](https://gongu.copyright.or.kr/gongu/main/contents.do?menuNo=200091)) 확인, 또는 위원회 무료 상담
4. Suno 생성 당시 **요금제** 확인 (Pro/Premier인지)
5. 설명란에 원곡 출처와 만료 근거 한 줄

## 8. 토담토담에 적용하는 제안

| 항목 | 제안 |
|---|---|
| 형태 | **동요 선율 자장가.** 만료 선율 3~5곡을 엄마 허밍·오르골·피아노로, 가사 없이, 어두운 화면 3시간 |
| 첫 편 후보 | `아기 수면음악 \| 브람스 자장가와 반짝반짝 작은별 오르골 \| 3시간 연속재생` |
| 시점 | 8주 계획의 **6주차 신규 상황 칸(11/3 또는 11/6)**. 기존 일정은 바꾸지 않음 |
| 선행 작업 | 곡별 7장 절차 통과, 선율 MIDI 직접 입력, Pro/Premier로 생성 |
| 판단 | 기존 상황 영상과 같은 기준(노출 추세·CTR·평균 시청)으로 보고, 잘 되면 크리스마스판(11/20)의 캐롤 선율도 같은 절차로 |

**요금제 확인 완료 (2026-09-27):** 지금까지 만든 곡은 전부 Pro 요금제로 생성했으므로 이미 공개한 영상과 앞으로 만들 동요 선율 자장가 모두 요금제 조건은 충족합니다. 남은 조건은 곡별 7장 절차(보호기간 확인)입니다.
