## 7. 문제가 생기면

| 증상 | 해결 |
|---|---|
| `songs folder not found` | 배치 파일과 같은 폴더에 `songs` 폴더를 만들고 곡을 넣기 |
| `need at least 3 songs` | 곡 3개 이상 넣기 |
| 곡 순서가 이상함 | 파일 이름 앞 번호(`01_`) 확인 → `xxx_seq.wav`부터 지우고 다시 |
| 노이즈가 너무 큼 / 작음 | 배치 파일 윗부분 `set NOISE_DB=-20`의 숫자를 낮추면(-24) 작아지고 높이면(-18) 커짐 → `Xxx_Final.wav`부터 지우고 다시 |
| 시냇물이 너무 큼 (#9) | `set NATURE_I=-30`을 `-33`으로 → `rest09_prep_nature.wav`부터 지우기 |
| 배경이 너무 어두움 / 밝음 | `set "BGEQ=..."`의 `-0.03`을 `0`에 가깝게 / 더 작게 → `xxx_loop30.mp4`부터 지우기 |
| `gradients` 오류 | `bg.png`를 넣으면 이 단계를 쓰지 않음 |
| 썸네일 `drawtext` 오류 | ffmpeg full 빌드 |

배치 파일을 다시 만들어야 하면 저장소에서 `python scripts/win/make_songmix_bats.py`를 실행합니다(설정은 파일 맨 위 `VIDEOS`).
