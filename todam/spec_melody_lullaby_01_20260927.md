## 0. 먼저 — 메타데이터에 "동요"를 쓰지 않습니다

**채널 점검 도구(`tools/check_metadata.py`)가 제목의 "동요"를 아동용 자동 분류 위험 단어로 보고 FAIL 처리합니다.** 유튜브는 제목·태그 같은 신호로 영상을 아동용으로 자동 분류할 수 있고, 아동용이 되면 댓글·알림·최종화면이 막힙니다.

| 쓰는 곳 | 표기 |
|---|---|
| 내부 문서·시리즈 이름 | 동요 선율 자장가 |
| 제목·태그·설명·재생목록 이름 | **"동요" 대신 곡명과 "자장가"·"오르골"**. 예: `브람스 자장가`, `반짝반짝 작은별` |
| 재생목록 공개 이름 | `익숙한 선율 자장가` |

곡명(반짝반짝 작은별)은 부모가 검색하는 말이고 점검 도구의 위험 단어가 아닙니다. 영상은 가사·캐릭터 없이 부모가 틀어 두는 수면 도구이므로 기존 영상과 같이 **아동용 아님**으로 설정합니다.

## 2. 음원 제작 절차 (곡마다)

### 2-1. 악보 → MIDI (곡당 20분)

**Suno에 글로 "브람스 자장가"라고 쓰면 선율이 정확히 안 나옵니다.** 직접 만든 선율 음원을 올려야 정확하고 약관에도 맞습니다.

| 단계 | 할 일 | 주의 |
|---|---|---|
| 1 | 원본 악보 확보 | 클래식 4곡: IMSLP 원판 악보. 홍난파 2곡: 공유마당 『조선동요백곡집』 원판. 민요 2곡: 단선율을 직접 채보 |
| 2 | **선율 한 줄만** DAW에 MIDI로 입력 | 반주는 넣지 않음. 남의 편곡을 참고하지 않음 |
| 3 | 조성·템포를 1장 표대로 맞춤 | |
| 4 | 피아노 음색 하나로 30~60초 WAV 렌더 | 이 파일이 Suno 업로드 원본 |
| 5 | MIDI·WAV 파일을 `곡명_melody.mid/.wav`로 보관 | 저작권 이의 제기와 인간 창작 기여의 증거 |

**다른 사람이 편곡·출판한 악보, 유튜브·음원 사이트 녹음은 절대 쓰지 않습니다.** 편곡자·음반 권리가 따로 있습니다.

### 2-2. Suno 생성 (곡당 25분)

**곡별로 복사해 쓰는 완성 프롬프트는 `templates/suno_prompts.md` 11장에 있습니다.** 아래는 구성 원리입니다.

Suno **Audio Upload**에 2-1의 WAV를 올리고, 편성별 스타일 프롬프트를 적용합니다. 가사란은 허밍이면 `templates/suno_prompts.md` 2-2의 허밍 표기, 나머지는 `[Instrumental]`.

모든 편성 프롬프트 맨 앞에 이 줄을 붙입니다.

```
follow the uploaded melody faithfully, do not add a new melody,
```

| 편성 | 스타일 프롬프트 |
|---|---|
| 오르골 | `templates/suno_prompts.md` 4장 오르골 프롬프트 그대로 |
| 엄마 허밍 | 같은 문서 2-1 공통 스타일 그대로 |
| 피아노 | 같은 문서 3-1 공통 스타일 그대로 |
| 낮은 허밍 + 피아노 (8번) | 2-1 + `soft felt piano underneath, very low register humming` |

| 단계 | 할 일 |
|---|---|
| 1 | 곡당 4~6회 생성, 선율이 원곡과 가장 가까운 것 선택 |
| 2 | Extend로 8분까지 |
| 3 | **선율 검수**: 원곡과 비교해 부모가 알아들을 수 있는지. Suno가 다른 곡 선율을 섞지 않았는지 귀로 확인 |
| 4 | 생성 기록 캡처 (곡명·생성 일시·Pro 요금제 화면) |

### 2-3. 후처리 (곡당 30분)

`templates/suno_prompts.md` 8-1의 8단계 중 **곡마다 하는 것은 1~4단계**(선별·확장·트림·자체 레이어)입니다. EQ·컴프레션·마스터링(5~7단계)은 3장에서 전체 조립본에 한 번만 합니다.

4단계 자체 레이어: 기존 토담토담 허밍 곡의 패드나 잔향을 **-25 dB**로 깝니다. AI 출력이 아니라 자체 편곡이라는 근거가 됩니다.

## 3. 조립·마스터링 (1.5시간)

| 항목 | 값 |
|---|---|
| 곡 전환 | 크로스페이드 8초 |
| 구간 설계 | 0:00 즉시 시작 / 0~10분 선율 분명 / 10~20분 레이어 추가 / 20분~ 단순화 (#1과 동일) |
| 핑크노이즈 베드 | 선율 대비 **-28 dB**, 0:00부터 끝까지. `scripts/add_pinknoise_bed.sh` 그대로 사용 |
| EQ | 30 Hz 이하 컷, 10 kHz 이상 완만히 감쇠 (오르골 고역이 가장 거슬림) |
| 라우드니스 | **-16 LUFS**, LRA **4 LU 이하**, 트루 피크 **-1.5 dBTP** |
| 편성 간 음량 | 오르골이 허밍보다 들리는 음량이 큼. 곡별 단기 라우드니스 차 **2 LU 이내**로 맞춤 |
| 마지막 20초 | 페이드 아웃 없이 유지 (최종화면) |
| 검증 | `ffmpeg -i 최종.wav -af ebur128=peak=true -f null - 2>&1 \| tail -20` |
