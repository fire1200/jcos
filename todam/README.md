| **지킬 수 없는 약속 금지** | `광고없음`·`5분 만에`·`통잠 보장` 금지. `연속재생` 사용 |

| **"직접 불렀다/녹음했다" 금지** (AI 생성분이면) | 사실과 다른 표기 |
| **다른 두 채널과 교차 홍보 금지** | 시청자가 안 겹쳐 프로필만 흐려짐 |
| **외부 홍보는 한 번에 한 편** | 스팸 방지, 효과 판별 |
| **성과는 편수로 센다** | 새 채널은 10~20편이 학습 구간. 첫 10주 평평한 것이 정상 |
