```
움집 앞에서 가락바퀴로 실을 뽑는 사람. 모두 단순한 천옷 차림, 옆모습과 뒷모습. 평화로운 분위기.
```

**04b — 인물·행동**

```
움집 앞에서 신석기 사람이 납작한 돌판(갈판) 위에 둥근 돌(갈돌)을 밀어 곡식을 가는 옆모습,
옆에서 다른 사람이 젖은 흙으로 토기를 빚으며 겉에 빗살 같은 줄무늬를 긋는다. 밝은 햇살.
```

**04c — 상징 클로즈업**

```
모래에 꽂아 세운 빗살무늬 토기 클로즈업. 아래가 뾰족한 회갈색 토기에 빗금 무늬가 촘촘하다.
```

```
마을을 나무 울타리와 도랑이 둘러싸고 있다. 황금빛 벼가 익어 가는 가을, 맑은 하늘.

```

```
마을을 내려다보는 뒷모습. 사람들은 옆모습과 뒷모습, 따뜻한 오후 햇빛.
```

**05c — 상징 클로즈업**

**06a — 전경**
```

주위에 푸른 풀밭과 들꽃. 뒤로 바다와 맑은 하늘, 흰 구름.
```

**06b — 인물·행동**
```
청동기 마을 사람들이 통나무를 굴리고 밧줄을 당겨 거대한 덮개돌을 옮기는 장면.

```

**06c — 상징 클로즈업**
```
붉은 천 위에 놓인 비파형 동검(아래쪽이 비파 악기처럼 둥글게 불룩한 청동 검)과 청동 거울 클로즈업.
```

**07a — 전경**
```

나무 기둥 집들과 흙벽, 멀리 산 위의 작은 성곽. 맑은 하늘과 햇살.
```

**07b — 인물·행동**
```
대장간에서 장인이 붉게 달군 쇠를 망치로 두드려 괭이와 낫을 만드는 옆모습. 불꽃이 튀고,
밖에서는 농부들이 새 철 괭이로 밭을 간다. 밝고 힘찬 분위기.
```

**07c — 상징 클로즈업**
```
돌 거푸집(틀) 옆에 놓인 세형 동검(가늘고 날씬한 청동 검)과 철 낫, 철 괭이 클로즈업.
금속 위로 반짝이는 햇빛. 뒤로 흐릿한 대장간 불빛.
```

### 08 여러 나라의 등장

> **고증 핵심**: 철기 문화를 바탕으로 만주와 한반도에 여러 나라가 생김. 부여(만주 넓은 평야), 고구려(압록강 산골짜기), 옥저와 동예(동해안), 삼한(한반도 남부의 마한·진한·변한). 제천 행사: 부여 영고, 고구려 동맹, 동예 무천, 삼한 5월제·10월제.
