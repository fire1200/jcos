규장각 서가에 가지런히 꽂힌 옛 책들과 비단 책갑 클로즈업. 책 글자는 보이지 않게.
창문으로 들어온 빛줄기에 먼지가 반짝인다.
```

### 09 실학

> **고증 핵심**: 현실 문제를 해결하려는 학문. 유형원, 이익, 정약용, 박지원, 박제가 등. 정약용은 강진에서 유배 생활 중 다산초당에서 많은 책을 씀. 박지원은 청나라에 다녀와 『열하일기』를 씀. 북학파는 청의 수레·벽돌 같은 기술을 배우자고 함.

**09a — 전경**
```
19세기 초 전라도 강진, 동백나무와 대나무 숲속의 작은 초당(다산초당). 마당의 평평한 바위, 작은 연못,
멀리 보이는 바다. 이른 아침 안개, 고요한 분위기.
```

**09b — 인물·행동**
```
18세기 후반 청나라 베이징 거리. 갓과 도포 차림의 조선 선비 일행이 벽돌로 지은 건물과
바퀴 달린 수레가 오가는 넓은 길을 신기한 듯 둘러보는 뒷모습. 변발한 청나라 사람들. 간판 글자 없이.
```

**09c — 상징 클로즈업**
```
나무 책상 위에 펼쳐진 기계 설계 그림(도르래와 나무 틀), 붓, 쌓인 책. 글자는 보이지 않게.
등잔불과 창밖 새벽빛.
```

### 10 수원 화성 (1796)

> **고증 핵심**: 정조가 수원에 쌓은 성. 1794년 공사 시작, 1796년 완공. 정약용이 설계하고 도르래를 여러 개 단 거중기로 무거운 돌을 들어 공사 기간을 줄임. 회색 벽돌과 돌로 쌓은 성벽, 북문 장안문, 둥근 옹성, 연못가 정자 방화수류정.

**10a — 전경**
```
1796년 가을, 언덕 위에서 내려다본 수원 화성. 회색 돌과 벽돌로 쌓은 성벽이 언덕을 따라 이어지고,
2층 누각이 있는 큰 성문(장안문)과 그 앞을 둥글게 감싼 옹성. 단풍, 맑고 높은 가을 하늘.
```

**10b — 인물·행동**
```
1794년 수원 화성 공사 현장. 나무 기둥으로 짠 높은 틀에 도르래가 여러 개 달린 거중기로 큰 돌을 들어 올리고,
흰옷 입은 일꾼들이 줄을 감는다. 쌓아 올리는 성벽, 힘찬 분위기.
```

**10c — 상징 클로즈업**
```
수원 화성의 연못(용연) 옆 바위 위에 선 정자(방화수류정). 날렵한 한옥 지붕과 연못에 비친 그림자,
버드나무, 노을빛.
```

### 11 홍경래의 난 (1811)

> **고증 핵심**: 1811년 12월(한겨울). 정조가 죽은 뒤 세도 정치 아래, 평안도 지역에 대한 차별과 수탈에 맞서 홍경래가 봉기. 정주성을 거점으로 싸우다 1812년 진압됨.

**11a — 전경**
```
1811년 12월 한겨울 밤, 평안도의 산골 마을. 횃불을 든 수많은 사람들이 눈 덮인 마을 어귀에 모여든다.
초가지붕 위의 눈, 차가운 밤하늘, 결연한 분위기.
```

**11b — 인물·행동**
```
1812년 겨울, 정주성 돌 성벽 위에 선 농민군의 뒷모습. 성 밖 눈 덮인 들판에 관군의 진영과 깃발(글자 없음)이 멀리 보인다.
흐린 겨울 하늘, 긴장감.
```

**11c — 상징 클로즈업**
```
눈 위에 꽂힌 채 타오르는 횃불 하나의 클로즈업. 불꽃과 흩날리는 눈송이,
뒤로 흐릿한 성벽과 어두운 하늘.
```

### 12 동학 창시 (1860)

> **고증 핵심**: 1860년 경주의 최제우가 서학(천주교)에 맞서 동학을 만듦. 경주 구미산 계곡의 정자 용담정에서 깨달음을 얻었다고 전함. 모든 사람이 평등하다고 가르침.

**12a — 전경**
```
1860년 봄, 경주 구미산 깊은 계곡의 작은 한옥 정자(용담정). 맑은 계곡물과 바위, 진달래가 핀 숲.
새벽 안개 사이로 비치는 빛줄기.
```

**12b — 인물·행동**
```
1860년대 시골 마당. 흰 한복 차림의 농민, 아이, 여인들이 함께 둘러앉아 한 사람의 이야기를 듣는 뒷모습.
신분에 상관없이 나란히 앉은 모습. 노을빛, 따뜻한 분위기.
```

**12c — 상징 클로즈업**
```
등잔불 아래 펼쳐진 얇은 책과 붓 클로즈업. 책 글자는 흐릿해서 읽을 수 없게.
창호지 문 너머 밤의 푸른빛.
```

### 13 임술 농민 봉기 (1862)

> **고증 핵심**: 1862년 2월(늦겨울). 삼정(전정·군정·환곡)의 문란에 맞서 진주에서 시작해 전국으로 퍼짐. 진주성의 누각 촉석루와 남강. 농민들은 머리에 흰 수건을 두름.

**13a — 전경**
```
1862년 2월 늦겨울, 경상도 진주. 남강 위 절벽에 선 누각(촉석루)과 진주성,
강가 모래밭에 흰옷 입은 농민들이 모여든다. 흐린 하늘, 차가운 바람.
```

**13b — 인물·행동**
```
1862년 진주 거리. 머리에 흰 수건을 두르고 죽창과 농기구를 든 농민들이 관아를 향해 행진하는 뒷모습.
깃발은 글자 없이. 먹구름 사이로 비치는 빛.
```

**13c — 상징 클로즈업**
```
관아 창고 안에 쌓인 쌀가마니와 장부 더미 클로즈업. 장부 글자는 보이지 않게.
어둑한 창고에 문틈으로 들어오는 한 줄기 빛. 부패와 불공평을 상징하는 분위기.
```

### 14 흥선대원군 집권 (1863)

> **고증 핵심**: 1863년 12월 철종이 죽고 12살의 고종이 왕위에 오르자, 아버지 흥선대원군이 실권을 잡음. 흥선대원군의 집은 운현궁. 1865년부터 경복궁을 다시 지음.

**14a — 전경**

맑고 차가운 겨울 하늘, 고요한 아침.

**14b — 인물·행동**

1863년 겨울, 궁궐 정전 앞. 붉은 곤룡포를 입은 어린 소년 왕의 작은 뒷모습과,
그 뒤에 갓과 도포 차림으로 서 있는 아버지의 뒷모습. 늘어선 관리들, 엄숙한 분위기.
```

**14c — 상징 클로즈업**

1865년 경복궁 중건 공사 현장. 새로 세운 큰 나무 기둥과 비계 위의 목수들, 쌓인 기와.
뒤로 북악산과 맑은 하늘. 근현대사로 이어지는 시작.
