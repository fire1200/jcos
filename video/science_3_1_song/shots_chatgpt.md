## 2. 장면별 프롬프트

각 프롬프트를 **같은 대화에서 한 장씩** 보내고, 받은 그림을 **파일 이름(예: `01a.png`)으로 바꿔** 압축해 올려 주세요. 압축 파일 이름에 **과학3-1**을 꼭 넣어 주세요.

### 01 물체와 물질

> **과학 핵심**: 모양이 있고 공간을 차지하는 것이 물체, 물체를 만드는 재료가 물질. 같은 물체도 여러 물질로 만들 수 있고(컵), 한 물질로 여러 물체를 만들 수 있음(나무).

**01a — 같은 물체, 다른 물질**
```
밝은 교실 실험 책상 위에 모양과 크기가 똑같은 컵 4개가 나란히 있다.
왼쪽부터 은색 금속 컵, 빨간 플라스틱 컵, 나뭇결이 보이는 나무 컵, 주황색 고무 컵.
과학이와 차차가 책상 옆에서 컵들을 신기하게 들여다본다. 컵 4개가 화면 가운데에 크게.
```

**01b — 같은 물질, 다른 물체**
```
나무 책상 위에 모두 나무로 만든 물체들이 모여 있다: 나무 의자(작은 모형), 연필, 나무 숟가락, 나무 쌓기 블록, 나무 자.
모두 같은 나뭇결과 나무색이 잘 보이게. 차차가 연필과 숟가락을 들고 비교한다.
```

**01c — 여러 물질로 만든 물체**
```
교실 앞 풀밭에 세워 둔 어린이 자전거 한 대를 크게.
은색 금속 몸체, 검은 고무 타이어, 플라스틱 손잡이와 안장, 가죽 같은 안장 덮개가 분명하게 보이게.
옆에 열린 필통(플라스틱 몸체, 금속 지퍼, 천 주머니)도 작게. 과학이가 바퀴의 고무 타이어를 손가락으로 가리킨다.
```

### 02 물질마다 다른 성질

> **과학 핵심**: 금속은 단단하고 광택이 있음, 고무는 잘 휘어지고 늘어남, 나무는 물에 뜸(금속은 가라앉음), 플라스틱은 가볍고 여러 가지 색.

**02a — 금속은 단단해요**
```
실험 책상 위에서 과학이가 반짝이는 금속 막대로 나무 막대를 긁어 보는 장면 (교과서의 "서로 긁어 보기" 실험).
나무 막대에는 하얗게 긁힌 자국이 선명하게 생겼고, 금속 막대는 흠집 없이 그대로 반짝인다.
두 막대가 화면 가운데에 크게, 금속의 광택이 잘 보이게.
```

**02b — 고무는 잘 휘어져요**
```
차차가 두 손으로 주황색 고무 막대를 둥글게 휘고 있다. 옆 책상에는 휘지 않는 금속 막대와 나무 막대가 놓여 있다.
고무 막대가 크게 휘어진 모양이 화면 가운데에 크게. 차차의 놀란 표정.
```

**02c — 나무는 물에 떠요**
```
투명한 큰 수조에 물이 담겨 있고, 같은 크기의 나무 토막, 플라스틱 블록, 금속 덩어리, 고무 지우개를 넣었다.
나무 토막과 플라스틱 블록은 물 위에 떠 있고, 금속 덩어리는 바닥에 가라앉아 있다.
수조를 옆에서 본 단면 구도라 떠 있는 것과 가라앉은 것이 한눈에 보이게. 과학이와 차차가 양옆에서 들여다본다.
```

### 03 배추흰나비의 한살이 ①

> **과학 핵심**: 배추흰나비는 알 → 애벌레 → 번데기 → 어른벌레. 알은 노랗고 길쭉하며 배추·케일 잎 뒷면에 하나씩 낳음. 애벌레는 잎을 먹고 허물을 4번 벗으며 자람.

**03a — 알**
```
초록 배추잎 뒷면을 아주 가까이 확대한 장면. 잎맥이 보이는 잎 위에 노랗고 길쭉한 옥수수 알 모양의 알 하나가 세워져 붙어 있다.
화면 구석에 돋보기를 든 과학이가 작게 들여다본다. 알이 화면 가운데에 크게, 아주 선명하게.
```

**03b — 애벌레와 허물 벗기**
```
배추잎 위에 초록색 배추흰나비 애벌레가 잎을 갉아 먹어 구멍이 나 있다.
애벌레 바로 뒤에 벗어 놓은 얇고 투명한 허물이 쭈글쭈글 놓여 있다.
애벌레는 귀엽고 깨끗하게, 몸의 마디와 짧은 털이 사실적으로. 차차가 관찰 상자 너머로 본다.
```

**03c — 번데기**
```
배추 줄기에 연두색의 각진 배추흰나비 번데기가 실 한 가닥으로 허리를 감아 매달려 붙어 있다. 고치가 아니라 번데기.
번데기가 화면 가운데에 크게. 뒤에 흐릿한 배추밭과 아침 햇살.
```

### 04 배추흰나비의 한살이 ②

> **과학 핵심**: 번데기에서 어른벌레가 나옴. 번데기 단계가 있으면 완전 탈바꿈(배추흰나비), 번데기 없이 애벌레가 바로 어른벌레가 되면 불완전 탈바꿈(잠자리, 메뚜기). 닭은 알을 낳고 개는 새끼를 낳음.

**04a — 어른벌레와 한살이 순서**
```
화면 가로로 네 단계가 왼쪽에서 오른쪽으로 놓여 있다: 노랗고 길쭉한 알 → 초록 애벌레 → 연두색 번데기 → 흰 날개를 편 배추흰나비 어른벌레.
단계 사이에 굵은 초록 화살표. 네 단계 크기를 비슷하게 맞춰 또렷하게. 배경은 연한 배추밭. 글자 없이.
```

**04b — 완전 탈바꿈과 불완전 탈바꿈 비교**
```
화면을 위아래 두 줄로 나눈 비교 그림.
위 줄: 배추흰나비 알 → 애벌레 → 번데기 → 어른벌레 (네 단계, 번데기 칸을 노란 동그라미로 강조).
아래 줄: 잠자리 알 → 물속 잠자리 애벌레 → 잠자리 어른벌레 (세 단계, 번데기 자리는 비어 있음).
화살표만 쓰고 글자는 없이. 깨끗한 흰 배경.
```

**04c — 알을 낳는 동물, 새끼를 낳는 동물**
```
화면을 반으로 나눈 비교 그림.
왼쪽: 농장 짚 둥지에 암탉과 알, 막 깨어난 노란 병아리. 
오른쪽: 거실 바구니에 어미 개가 갓 태어난 강아지들에게 젖을 먹이는 모습.
과학이와 차차가 가운데에서 양쪽을 번갈아 본다.
```

### 05 자석이 끌어당기는 물체

> **과학 핵심**: 자석은 철로 된 물체(클립, 못, 철 숟가락)를 끌어당기고, 나무·플라스틱·유리·고무·종이는 끌어당기지 않음. 자석에서 철로 된 물체가 많이 붙는 곳이 극이며, 막대자석은 양 끝(두 극)이 가장 셈.

**05a — 철로 된 물체만 붙어요**
```
실험 책상 위에 클립, 쇠못, 철 숟가락, 나무 블록, 플라스틱 자, 유리구슬, 고무 지우개가 흩어져 있다.
과학이가 빨강·파랑 막대자석을 위에 대자 클립·쇠못·철 숟가락만 자석에 붙어 올라오고, 나무·플라스틱·유리·고무는 책상에 그대로 남아 있다.
붙은 것과 남은 것이 한눈에 구분되게.
```

**05b — 극: 양 끝이 가장 세요**
```
반은 빨강, 반은 파랑인 막대자석 하나를 클립 더미에 굴렸다가 들어 올린 장면.
막대자석의 양 끝에 클립이 수북하게 붙어 있고, 가운데에는 클립이 거의 없다.
막대자석이 화면 가운데에 가로로 크게. 차차가 신기해하며 본다.
```

**05c — N극과 S극**
```
여러 모양의 자석이 깨끗한 흰 책상 위에 나란히 있다: 막대자석, 말굽자석, 둥근 고리 자석, 동전 모양 자석.
모든 자석이 한쪽은 빨간색, 다른 쪽은 파란색으로 칠해져 있다. 글자 없이 색으로만.
과학이가 말굽자석을 들어 보인다.
```

### 06 자석의 극과 나침반

> **과학 핵심**: 같은 극끼리는 밀어 내고, 다른 극끼리는 끌어당김. 물에 띄운 자석과 나침반 바늘의 N극은 북쪽을 가리킴.

**06a — 같은 극은 밀어 내요**
```
책상 위 두 막대자석의 빨간 끝끼리 마주 보고 있다. 둘 사이가 떨어져 있고, 사이에 서로 밀어 내는 투명한 물결 표시.
위쪽 반에는 파란 끝끼리 마주 보고 떨어져 있는 두 자석도 똑같이.
과학이가 자석 하나를 밀어 보지만 다른 자석이 미끄러져 도망간다.
```

**06b — 다른 극은 끌어당겨요**
```
책상 위 두 막대자석의 빨간 끝과 파란 끝이 착 붙어 있다. 붙는 순간을 표현하는 작은 반짝임.
차차가 두 자석을 떼어 보려고 힘을 주는 모습. 붙은 부분이 화면 가운데에 크게.
```

**06c — 나침반 바늘은 북쪽**
```
운동장 위 탁자에 나침반 하나를 크게. 나침반 바늘의 빨간 끝이 화면 위쪽 먼 산 쪽을 가리킨다.
옆에는 물을 담은 넓은 그릇에 스티로폼 조각을 띄우고 그 위에 막대자석을 올렸는데, 막대자석의 빨간 끝도 같은 산 쪽을 가리킨다.
나침반 눈금에 글자는 없이. 과학이와 차차가 가리키는 방향을 손으로 같이 가리킨다.
```

### 07 지구의 모습

> **과학 핵심**: 지구는 둥근 공 모양이고 육지와 바다로 되어 있으며 바다가 육지보다 넓음. 바닷물은 짬. 공기가 지구를 둘러싸고 있어 숨을 쉬고 바람이 불며 생물이 살 수 있음.

**07a — 둥근 공 모양, 바다가 더 넓어요**
```
우주에서 본 지구 전체. 파란 바다가 대부분이고 초록·갈색 육지가 사이사이에 있으며 하얀 구름이 감싸고 있다.
바다가 육지보다 훨씬 넓은 것이 잘 보이도록 태평양 쪽이 많이 보이게. 검은 우주와 반짝이는 별.
```

**07b — 바닷물은 짜요**
```
맑은 날 바닷가 모래사장. 차차가 손가락으로 바닷물을 찍어 맛보고 깜짝 놀라 찡그린 표정.
옆에서 과학이가 바닷물을 담은 접시를 햇볕에 두었는데, 물이 마르고 하얀 소금 알갱이가 남아 있다.
파란 바다와 하얀 파도, 갈매기.
```

**07c — 공기가 지구를 둘러싸요**
```
화면 왼쪽 반: 우주에서 본 지구의 가장자리, 지구를 얇게 감싼 파랗게 빛나는 공기층 띠.
화면 오른쪽 반: 바람 부는 언덕에서 과학이와 차차가 연을 날리고, 나뭇잎이 날리고, 풀이 바람에 눕는다.
두 장면을 부드러운 경계로 나란히.
```

### 08 달의 모습

> **과학 핵심**: 달은 둥근 공 모양. 표면에 크고 작은 충돌 구덩이가 많음. 어둡게 보이는 넓고 평평한 곳이 달의 바다(물은 없음). 달에는 공기와 물이 없어 생물이 살 수 없음.

**08a — 충돌 구덩이**
```
달 표면을 낮게 내려다본 장면. 회색 땅에 크고 작은 둥근 충돌 구덩이가 가득하다. 하늘은 새까맣고 별이 보인다.
멀리 검은 하늘에 파란 지구가 떠 있다. 사람은 없이.
```

**08b — 달의 바다**
```
밤하늘에 떠 있는 커다란 보름달. 달의 밝은 부분과 어둡게 보이는 넓고 평평한 부분(달의 바다)이 또렷하게 구분된다.
아래쪽에 지붕 위에서 망원경으로 달을 보는 과학이와 차차의 작은 실루엣.
```

**08c — 공기와 물이 없어요**
```
화면을 반으로 나눈 비교 그림.
왼쪽: 지구의 푸른 하늘, 흐르는 강, 나무와 새, 숨 쉬는 사람들.
오른쪽: 달의 검은 하늘, 메마른 회색 땅과 구덩이, 물·식물·동물이 하나도 없음.
두 세계가 정반대로 보이게.
```
