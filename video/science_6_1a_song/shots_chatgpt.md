### 01 지구의 자전

> **과학 핵심**: 지구는 서쪽에서 동쪽으로 하루에 한 바퀴 자전함. 그래서 해와 달이 동쪽에서 떠서 서쪽으로 지는 것처럼 보이고, 낮과 밤이 생김.

**01a — 자전하는 지구**
```
검은 우주 배경에 크게 그린 지구. 태양 빛을 받는 왼쪽 절반은 밝은 낮, 오른쪽 절반은 어두운 밤. 북극 위에서 볼 때 시계 반대 방향(서쪽에서 동쪽)으로 도는 굵은 노란 회전 화살표. 자전축이 비스듬히.
```

**01b — 하루 동안 태양의 움직임**
```
왼쪽에서 오른쪽으로 같은 들판 세 칸: 아침(동쪽 낮은 곳의 해), 한낮(남쪽 높은 곳의 해), 저녁(서쪽 낮은 곳의 해). 칸 사이 굵은 화살표. 들판에 과학이와 차차가 서서 해를 가리킨다.
```

**01c — 낮과 밤 모형 실험**
```
어두운 교실에서 책상 위 전등(태양) 앞에 지구본이 있다. 과학이가 지구본을 천천히 돌리고, 전등 쪽 면은 밝고 반대쪽은 어둡다. 차차가 밝은 쪽에 붙인 작은 사람 인형을 가리킨다.
```

### 02 지구의 공전과 계절별 별자리

> **과학 핵심**: 지구는 태양 둘레를 일 년에 한 바퀴 공전함. 그래서 계절마다 밤하늘에 보이는 별자리가 달라짐(봄 사자자리, 여름 백조자리, 가을 페가수스자리, 겨울 오리온자리).

**02a — 지구의 공전**
```
우주 한가운데 큰 태양, 둘레에 둥근 궤도. 궤도 위 네 곳에 작은 지구가 있고 궤도를 따라 시계 반대 방향 화살표. 글자 없이.
```

**02b — 계절별 별자리**
```
밤하늘 네 칸(왼쪽 위 봄, 오른쪽 위 여름, 왼쪽 아래 가을, 오른쪽 아래 겨울): 사자자리, 백조자리, 페가수스자리(큰 사각형), 오리온자리(가운데 별 셋)를 별과 연한 선으로. 칸마다 아래에 계절 풍경 실루엣(벚꽃, 수박밭, 단풍, 눈).
```

**02c — 별자리 관찰**
```
맑은 밤 언덕에서 과학이와 차차가 글자 없는 둥근 별자리판을 들고 밤하늘과 비교한다. 빨간 셀로판을 씌운 손전등.
```

### 03 달의 위치 변화

> **과학 핵심**: 여러 날 동안 같은 시각에 달을 보면 달은 날마다 서쪽에서 동쪽으로 위치가 바뀌고 모양도 바뀜.

**03a — 날마다 옮겨 가는 달**
```
해 진 뒤 남쪽 하늘을 넓게 그린 그림. 지평선 위 서쪽 낮은 곳에 가는 초승달, 가운데 높은 곳에 반달(오른쪽이 밝은 상현달), 동쪽에 둥근 보름달이 차례로 놓이고 서쪽에서 동쪽으로 굵은 화살표.
```

**03b — 같은 시각, 같은 곳에서**
```
저녁 창가에서 과학이가 관찰 기록장(글자 없이 달 그림만 여러 칸)을 들고 하늘의 달을 본다. 벽시계는 숫자 없이 같은 바늘 위치.
```

**03c — 지구 둘레를 도는 달**
```
우주에서 본 지구와 그 둘레를 도는 달, 둥근 궤도와 화살표. 한쪽 멀리 태양 빛.
```

### 04 달의 모양 변화

> **과학 핵심**: 달은 초승달 → 상현달 → 보름달 → 하현달 → 그믐달로 모양이 바뀌고, 약 30일마다 같은 모양이 다시 보임.

**04a — 달의 다섯 모양**
```
짙은 남색 밤하늘에 달 다섯 개를 왼쪽에서 오른쪽으로: 오른쪽이 가늘게 밝은 초승달, 오른쪽 반이 밝은 상현달, 둥근 보름달, 왼쪽 반이 밝은 하현달, 왼쪽이 가늘게 밝은 그믐달. 사이에 굵은 화살표.
```

**04b — 보름달 밤**
```
커다란 보름달 아래 한옥 마을, 과학이와 차차가 마당에서 달을 올려다본다.
```

**04c — 달 모양 모형**
```
어두운 교실, 전등 앞에서 차차가 흰 공(달)을 든 팔을 쭉 뻗고 자기 둘레로 돌린다. 공의 밝은 부분이 반달처럼 보인다. 과학이가 옆에서 본다.
```

### 05 산소

> **과학 핵심**: 묽은 과산화 수소수와 이산화 망가니즈로 산소를 만듦. 산소는 색과 냄새가 없고, 다른 물질이 타는 것을 도우며, 금속을 녹슬게 하고, 숨 쉬는 데 필요함.

**05a — 산소 발생 장치**
```
실험대 위 기체 발생 장치: 가지 달린 삼각 플라스크(바닥에 검은 가루), 위의 깔때기, 고무관이 물 담긴 수조 속 거꾸로 세운 집기병으로 이어져 기포가 모인다. 보안경과 장갑을 낀 과학이, 어른 선생님이 함께.
```

**05b — 더 밝게 타는 향불**
```
산소를 모은 투명 집기병 속에 향불을 넣자 불씨가 환하게 밝아진다. 차차가 보안경을 쓰고 놀란 표정.
```

**05c — 생활 속 산소**
```
화면을 반으로 나눈 그림. 왼쪽: 등에 공기통을 멘 잠수부가 바닷속에서 헤엄친다. 오른쪽: 녹슨 쇠못과 반짝이는 새 쇠못이 나란히 놓여 있다.
```

### 06 이산화 탄소

> **과학 핵심**: 진한 식초와 탄산수소 나트륨으로 이산화 탄소를 만듦. 이산화 탄소는 불을 끄고 석회수를 뿌옇게 함. 소화기, 탄산음료, 드라이아이스에 쓰임.

**06a — 이산화 탄소 발생 장치**
```
같은 기체 발생 장치, 이번에는 플라스크 바닥에 흰 가루(탄산수소 나트륨)와 깔때기의 식초. 수조 속 집기병에 기체가 모인다. 보안경 낀 차차와 선생님.
```

**06b — 꺼지는 촛불, 뿌연 석회수**
```
화면을 반으로 나눈 그림. 왼쪽: 이산화 탄소를 모은 집기병 속에 넣은 촛불이 꺼지며 연기가 오른다. 오른쪽: 맑던 석회수가 든 집기병이 흔들자 우윳빛으로 뿌옇게 됨.
```

**06c — 생활 속 이산화 탄소**
```
부엌 앞 탁자에 빨간 소화기(글자 없이), 거품이 올라오는 탄산음료 컵, 하얀 김이 피어오르는 드라이아이스 그릇이 나란히. 과학이가 가리킨다.
```

### 07 압력과 기체의 부피

> **과학 핵심**: 기체에 가하는 압력이 커지면 부피가 작아지고, 압력이 작아지면 부피가 커짐(높은 산의 과자 봉지).

**07a — 주사기 실험**
```
화면을 반으로 나눈 그림. 왼쪽: 입구를 막은 투명 주사기의 피스톤을 살짝 누름, 안의 공기 칸이 조금 줄어듦. 오른쪽: 세게 누름, 공기 칸이 많이 줄어듦. 눈금은 줄만.
```

**07b — 높은 산의 과자 봉지**
```
왼쪽에서 오른쪽으로: 산 아래 마을에서 납작한 과자 봉지 → 산꼭대기에서 같은 봉지가 빵빵하게 부풀어 있다. 사이 굵은 화살표. 등산복 입은 과학이와 차차.
```

**07c — 커지는 공기 방울**
```
바닷속에서 잠수부가 내뿜은 공기 방울이 위로 올라갈수록 점점 커진다. 아래는 작고 위는 큰 방울.
```

### 08 온도와 기체의 부피, 공기

> **과학 핵심**: 온도가 높아지면 기체의 부피가 커지고, 낮아지면 작아짐. 공기는 질소, 산소, 이산화 탄소 등 여러 기체가 섞인 혼합물.

**08a — 펴지는 탁구공**
```
찌그러진 탁구공을 김이 나는 뜨거운 물이 든 비커에 넣자 둥글게 펴진다. 왼쪽에서 오른쪽으로 두 단계, 사이 화살표. 장갑 낀 어른의 손.
```

**08b — 풍선 실험**
```
화면을 반으로 나눈 그림. 왼쪽: 입구에 고무풍선을 씌운 삼각 플라스크를 뜨거운 물에 넣자 풍선이 부풂. 오른쪽: 얼음물에 넣자 풍선이 쪼그라듦.
```

**08c — 공기 속 여러 기체**
```
생활 속 기체 쓰임을 나란히: 공기를 넣어 빵빵한 과자 봉지, 하늘로 떠오르는 헬륨 풍선 다발, 밤거리에 빛나는 알록달록 네온 조명 관(글자 없이). 과학이와 차차가 올려다본다.
```
