### 01 온도와 온도계

> **과학 핵심**: 온도는 물체의 차갑고 따뜻한 정도를 숫자로 나타낸 것, 단위는 섭씨도(℃). 액체는 알코올 온도계, 물체 표면은 적외선 온도계, 몸은 귀 체온계로 잼.

**01a — 여러 가지 온도계**
```
흰 실험 책상 위에 알코올 온도계(가는 유리관 속 빨간 액체 기둥), 손에 쥐는 적외선 온도계, 귀 체온계가 나란히 놓여 있다. 눈금은 줄만, 표시 창은 비어 있다. 과학이가 하나씩 가리킨다.
```

**01b — 물의 온도 재기**
```
비커에 담긴 물에 알코올 온도계를 세워 담그고, 과학이가 몸을 낮춰 빨간 액체 기둥 끝과 눈높이를 맞춰 읽는다. 온도계는 비커 바닥에 닿지 않게.
```

**01c — 표면 온도 재기**
```
햇볕이 드는 운동장에서 차차가 적외선 온도계를 철봉과 모래 쪽으로 겨누어 표면 온도를 잰다. 온도계에서 나가는 빛은 그리지 않고 겨누는 자세만.
```

### 02 열은 높은 데서 낮은 데로

> **과학 핵심**: 온도가 다른 두 물체가 닿으면 온도가 높은 물체에서 낮은 물체로 열이 이동하고, 시간이 지나면 두 물체의 온도가 같아짐.

**02a — 따뜻한 물과 차가운 물**
```
큰 투명 수조에 차가운 물(연파랑)이 있고, 그 안에 따뜻한 물(연주황)이 든 작은 비커가 놓여 있다. 두 물에 온도계가 하나씩 꽂혀 있다. 작은 비커에서 바깥 물 쪽으로 굵은 주황 화살표.
```

**02b — 온도가 같아져요**
```
왼쪽에서 오른쪽으로 세 단계: 수조 속 작은 비커, 두 온도계의 빨간 액체 기둥 높이가 처음엔 크게 다름 → 차이가 줄어듦 → 같아짐. 단계 사이에 굵은 화살표. 눈금 숫자 없이.
```

**02c — 삶은 달걀 식히기**
```

```

### 03 전도와 단열

> **과학 핵심**: 고체에서는 온도가 높은 곳에서 낮은 곳으로 고체를 따라 열이 이동함(전도). 금속은 열이 빠르게, 나무·플라스틱은 느리게 이동. 열의 이동을 막는 것이 단열.

**03a — 구리판에서 열의 이동**
```

```

**03b — 금속 숟가락과 나무 숟가락**
```
뜨거운 물이 담긴 그릇에 금속 숟가락과 나무 숟가락이 나란히 꽂혀 있다. 두 숟가락 손잡이 끝에 버터를 조금씩 붙였는데, 금속 숟가락의 버터만 녹아 흘러내린다.
```

**03c — 생활 속 단열**
```

```

### 04 대류

> **과학 핵심**: 액체나 기체는 데워진 물질이 위로 올라가고 위에 있던 물질이 아래로 내려오며 열이 이동함(대류). 난방기는 낮은 곳, 에어컨은 높은 곳에 두면 좋음.

**04a — 물의 대류**
```
투명한 사각 수조 바닥 한쪽 아래를 어른의 손이 촛불로 데운다. 바닥에 넣은 파란 색소가 데운 쪽에서 위로 올라가 옆으로 퍼진 뒤 반대쪽으로 내려오는 둥근 흐름. 흐름을 따라 굵은 화살표.
```

**04b — 공기의 대류**


**04c — 난방기와 에어컨**


### 05 태양이 주는 빛과 열

> **과학 핵심**: 태양은 빛과 열을 주어 생물이 살아가게 하고, 우리는 태양 에너지를 생활에 이용함.

**05a — 햇빛 아래 생물**
```
맑은 날 들판, 하늘 한쪽에 밝은 태양. 햇빛을 받아 자라는 풀과 꽃, 풀을 뜯는 토끼, 나비. 과학이와 차차가 햇볕을 쬐며 걷는다.
```

**05b — 태양 에너지 이용**
```
주택 지붕 위 태양 전지판이 햇빛을 받고, 마당 빨랫줄에 빨래가 햇볕에 마른다. 차차가 빨래를 걷는다.
```

**05c — 염전**

### 06 태양계의 행성

> **과학 핵심**: 태양과 그 둘레를 도는 행성 등이 있는 공간이 태양계. 행성은 수성, 금성, 지구, 화성, 목성, 토성, 천왕성, 해왕성. 가장 큰 행성은 목성, 가장 작은 행성은 수성. 태양에서 멀수록 행성 사이 거리가 멀어짐.

**06a — 태양계 한눈에**
```
검은 우주 배경 왼쪽에 큰 태양, 오른쪽으로 동심원 궤도 위에 여덟 행성이 순서대로: 수성(회색), 금성(노란 흰빛), 지구(파랑·초록), 화성(붉은색), 목성(줄무늬, 가장 큼), 토성(고리), 천왕성(청록), 해왕성(짙은 파랑).
```

**06b — 행성 크기 비교**
```
흰 배경에 여덟 행성을 크기 비율대로 왼쪽에서 오른쪽으로 나란히: 수성 아주 작게, 금성과 지구 비슷하게 작게, 화성 작게, 목성 가장 크게, 토성 큼(고리), 천왕성과 해왕성 중간. 왼쪽 가장자리에 태양의 일부만 거대한 호로.
```

**06c — 행성 사이 거리**
```
학교 복도 바닥에 길게 펼친 두루마리 종이 띠 위에 과학이와 차차가 행성 구슬을 놓는다. 시작점의 노란 공(태양) 가까이에 네 개의 구슬이 촘촘히 모여 있고, 바깥 행성 구슬들은 점점 더 멀리 떨어져 있다.
```

### 07 별과 행성

> **과학 핵심**: 별은 스스로 빛을 내고, 행성은 태양 빛을 반사해 빛남. 별은 매우 멀어 움직이지 않는 것처럼 보이지만 행성은 여러 날 동안 위치가 조금씩 바뀜. 별의 무리를 이어 이름을 붙인 것이 별자리.

**07a — 스스로 빛나는 별, 반사하는 행성**
```
화면을 반으로 나눈 우주 그림. 왼쪽: 스스로 빛을 사방으로 내뿜는 별. 오른쪽: 왼쪽 바깥에서 오는 햇빛(노란 화살표)을 받아 한쪽 면만 밝게 빛나는 행성.
```

**07b — 여러 날 밤하늘**
```
왼쪽에서 오른쪽으로 같은 밤하늘 세 칸: 별들의 배치는 세 칸 모두 똑같고, 밝은 행성 하나만 칸마다 조금씩 자리를 옮긴다. 칸 사이 굵은 화살표.
```

**07c — 별자리 관찰**
```
맑은 밤 언덕에서 과학이와 차차가 돗자리에 앉아 밤하늘을 올려다본다. 하늘에 별 몇 개가 연한 점선으로 이어져 별자리 모양을 이룬다. 손전등은 빨간 셀로판을 씌웠다.
```

### 08 북쪽 하늘과 북극성

> **과학 핵심**: 북쪽 하늘의 북두칠성(국자 모양)과 카시오페이아자리(W 모양)를 이용해 북극성을 찾으면 방향을 알 수 있음.

**08a — 북두칠성**
```

```

**08b — 카시오페이아자리**
```
밤하늘에 다섯 개의 별이 W 모양으로 놓이고 연한 선으로 이어져 있다. 아래쪽 지평선에 산 실루엣.
```

**08c — 북극성 찾기**
```
넓은 북쪽 밤하늘 왼쪽에 북두칠성, 오른쪽에 카시오페이아자리, 그 사이에 밝은 북극성 하나. 국자 끝 두 별에서 북극성까지 점선이 이어진다. 아래 언덕에서 과학이가 북극성 쪽을 손으로 가리키고 차차가 나침반을 든다.
```
