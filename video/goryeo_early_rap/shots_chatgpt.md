```
1126년 봄 밤, 개경 궁궐. 돌 축대 위 단청 건물 일부에서 불길과 연기가 솟아오르고,
붉게 물든 밤하늘. 멀리 송악산의 검은 윤곽. 혼란스러운 분위기.
```

**09b — 인물·행동**
```
1126년 귀족의 화려한 저택 대청. 비단 옷을 입은 늙은 귀족의 멀리 있는 뒷모습과
그 앞에 머리를 숙인 관리들. 화려한 병풍과 등불, 무겁고 위압적인 분위기.
```

**09c — 상징 클로즈업**
```
불에 그을린 궁궐 기와와 꺼져 가는 불씨 클로즈업. 연기 사이로 새벽빛이 비친다.
```

### 10 묘청의 서경 천도 운동 (1135)

> **고증 핵심**: 묘청 등 서경 세력이 도읍을 서경(평양)으로 옮기고 금을 정벌하자고 주장. 받아들여지지 않자 1135년 서경에서 난을 일으킴. 김부식이 이끄는 관군이 진압(1136).

**10a — 전경**
```
1135년, 대동강 가의 서경(평양) 성곽. 굳게 닫힌 성문과 성벽 위의 군사들,
강 위로 낮게 깔린 안개와 흐린 하늘. 고요한 긴장감.
```

**10b — 인물·행동**
```
1135년 서경의 절 마당. 승려복을 입은 사람이 사람들 앞에서 북쪽 하늘을 가리키는 뒷모습,
모여든 사람들이 함께 그쪽을 바라본다. 석탑과 연등, 바람에 흔들리는 나뭇가지.
```

**10c — 상징 클로즈업**
```
서경 성벽 너머로 서경을 둘러싼 관군의 진영과 깃발이 보이는 장면. 성벽 돌 틈에 핀 풀,
흐린 하늘 아래 무거운 분위기.
```

### 11 삼국사기 (1145)

> **고증 핵심**: 1145년 김부식이 왕명을 받아 고구려·백제·신라의 역사를 정리한 삼국사기를 편찬. 현재 남아 있는 가장 오래된 역사서.

**11a — 전경**
```
1145년 가을, 개경 궁궐 안 고요한 서고 건물. 단청 처마 아래 열린 창으로 따뜻한 햇살이 들고,
마당의 은행나무가 노랗게 물들었다.
```

**11b — 인물·행동**
```
1145년 서고 안. 복두와 단령 차림의 늙은 학자가 낮은 책상 앞에 앉아 붓으로 글을 쓰는 옆모습,
주위에 쌓인 두루마리와 책들. 옆에서 돕는 젊은 학자들. 글자는 흐릿하게.
```

**11c — 상징 클로즈업**
```
가지런히 묶은 옛 책 여러 권이 쌓인 모습 클로즈업. 표지 글자는 보이지 않게.
창으로 들어온 햇살이 책 위에 내려앉는다. 오래 전해질 역사의 분위기.
```
