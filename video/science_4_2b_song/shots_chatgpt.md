## 2. 장면별 프롬프트

### 01 그림자가 생겨요

> **과학 핵심**: 그림자가 생기려면 빛, 물체, 스크린이 필요함. 빛이 물체를 통과하지 못하면 진한 그림자, 투명한 물체는 연한 그림자.

**01a — 빛 · 물체 · 스크린**
```
어두운 교실. 왼쪽에서 과학이가 손전등을 비추고, 가운데 공룡 인형, 오른쪽 흰 스크린에 공룡 그림자가 선명하게 생겼다. 차차가 스크린 옆에서 본다.
```

**01b — 유리컵과 도자기 컵의 그림자**
```
같은 손전등 빛 앞에 투명한 유리컵과 하얀 도자기 컵을 나란히 두었다. 스크린에 유리컵은 연한 그림자, 도자기 컵은 진하고 까만 그림자.
```

**01c — 햇빛과 그림자**
```
맑은 날 운동장에서 과학이와 차차가 서 있고, 땅 위에 두 아이의 긴 그림자가 같은 방향으로 늘어져 있다. 해는 반대쪽 하늘에.
```

### 02 빛은 곧게 나아가요

> **과학 핵심**: 빛은 곧게 나아가므로 그림자는 물체 모양을 닮음. 물체 방향을 바꾸면 그림자 모양이 달라짐. 손전등을 물체에 가까이 하면 그림자가 커짐.

**02a — 곧게 나아가는 빛**
```
어두운 방에 분무기로 물을 뿌린 공간 속으로 손전등 빛이 곧은 빛줄기로 나아가 스크린에 닿는다. 과학이가 손전등을 들고 있다.
```

**02b — 방향을 바꾸면 달라져요**
```
화면을 반으로: 왼쪽은 원기둥 컵을 세워 비추니 스크린에 직사각형 그림자, 오른쪽은 같은 컵을 눕혀 바닥 쪽을 비추니 둥근 그림자.
```

**02c — 가까이 하면 커져요**
```
화면을 반으로: 왼쪽은 손전등이 인형 가까이 있어 스크린 그림자가 크다, 오른쪽은 손전등이 인형에서 멀어 그림자가 작다. 차차가 손전등을 든다.
```

### 03 거울과 빛의 반사

> **과학 핵심**: 거울에 비친 모습은 좌우가 바뀌어 보임. 빛이 거울에 부딪혀 방향이 바뀌는 것이 빛의 반사.

**03a — 좌우가 바뀌어요**
```
차차가 커다란 거울 앞에서 오른손을 들자 거울 속 차차는 반대쪽 손을 든 것처럼 보인다. 머리띠의 리본도 반대쪽에. 과학이가 옆에서 비교.
```

**03b — 빛의 반사**
```
어두운 책상 위에서 손전등 빛줄기가 거울에 비스듬히 부딪혀 꺾여 다른 쪽 벽의 표적을 비춘다. 빛줄기가 선명한 선으로.
```

**03c — 거울 두 개로 빛 보내기**
```
과학이와 차차가 거울을 하나씩 들고 손전등 빛을 두 번 꺾어 책장 뒤에 숨긴 인형을 비춘다. 빛줄기의 꺾인 길이 선명하게.
```

### 04 생활 속 거울

> **과학 핵심**: 자동차 뒷거울, 굽은 길의 도로 반사경, 잠망경, 미용실·무용실 거울 등 생활 속에서 거울을 이용함.

**04a — 자동차 뒷거울**
```
자동차 옆 뒷거울을 가까이: 거울 속에 뒤따라오는 자동차가 비친다. 운전석 쪽에서 본 구도.
```

**04b — 굽은 길 거울**
```
산길 굽은 길모퉁이에 둥근 볼록 거울(도로 반사경)이 서 있고, 거울 속에 모퉁이 너머에서 오는 자전거가 비친다.
```

**04c — 잠망경**
```
담장 뒤에 숨은 과학이가 종이로 만든 잠망경으로 담 너머 차차를 본다. 잠망경 안의 거울 두 개를 따라 꺾이는 빛길을 투명하게 보여 준다.
```

### 05 화산

> **과학 핵심**: 땅속 마그마가 지표 밖으로 나온 것이 화산. 꼭대기에 분화구. 화산 분출물: 화산 가스(기체), 용암(액체), 화산재·화산 암석 조각(고체).

**05a — 화산과 분화구**
```
멀리서 본 원뿔 모양 화산. 꼭대기의 움푹 파인 분화구에서 연기가 오르고, 산비탈로 붉은 용암이 흘러내린다. 무섭지 않게 밝은 낮 풍경.
```

**05b — 화산 분출물 세 가지**
```
화면을 세로로 셋으로 나눈 그림: 왼쪽 분화구에서 뿜어 나오는 화산 가스, 가운데 흘러내리는 붉은 용암, 오른쪽 하늘에서 날리는 회색 화산재와 돌 조각.
```

**05c — 화산 모형 실험**
```
실험 책상 위 알루미늄 포일로 만든 작은 화산 모형이 가열되어 꼭대기에서 붉은 액체가 흘러나오고 하얀 연기가 오른다. 보안경 쓴 과학이와 차차가 관찰.
```

### 06 화성암

> **과학 핵심**: 마그마가 식어서 굳은 암석이 화성암. 현무암: 지표 근처에서 빨리 식어 알갱이가 작고 검은색, 구멍이 있음. 화강암: 땅속 깊이에서 천천히 식어 알갱이가 크고 밝은색.

**06a — 현무암**
```
검은색에 크고 작은 구멍이 송송 뚫린 현무암 덩어리를 가까이. 뒤로 현무암 돌담이 있는 바닷가 마을.
```

**06b — 화강암**
```
밝은 회색 바탕에 반짝이는 알갱이와 검은 점이 큼직하게 박힌 화강암 덩어리를 가까이. 뒤로 화강암 바위산.
```

**06c — 현무암과 화강암 비교**
```
흰 책상 위 현무암과 화강암을 나란히 놓고 차차가 돋보기로 알갱이 크기를 비교한다. 두 암석의 색과 알갱이 차이가 분명하게.
```

### 07 화산이 주는 것

> **과학 핵심**: 화산재는 피해(호흡, 비행기, 농작물)를 주기도 하지만 땅을 기름지게 함. 화산 주변의 온천과 지열 발전.

**07a — 온천과 지열 발전**
```
김이 모락모락 나는 노천 온천과 멀리 하얀 수증기를 내뿜는 지열 발전소. 화산 산이 뒤에 보인다.
```

**07b — 기름진 땅**
```
화산 아래 넓은 밭에 채소와 과일나무가 무성하게 자란다. 검은 흙이 기름지다.
```

**07c — 화산재 피해**
```
화산재가 하얗게 덮인 마을 거리. 사람들이 마스크를 쓰고 우산을 쓰고 걸으며 차 위에도 재가 쌓였다. 무섭지 않게 차분한 분위기.
```

### 08 지진과 안전한 대피

> **과학 핵심**: 지진: 땅이 오랫동안 힘을 받아 휘어지거나 끊어지며 흔들림. 세기는 규모로 나타냄. 흔들릴 때 탁자 아래에서 머리 보호, 멈추면 계단으로 넓은 곳에 대피, 엘리베이터 금지, 가스·전기 차단.

**08a — 땅이 끊어져 흔들려요**
```

```

**08b — 탁자 아래로**
```

**08c — 계단으로 운동장에**
```
