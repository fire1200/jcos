# 연도 랩! 1866~1953 뮤직비디오

`songs/korea_modern_history_rap_20261003.md`로 만든 Suno 음원(Version1, 3분 6초)에 맞춘 영상 생성기입니다.
노을, 뭉게구름, 빛줄기, 전깃줄, 별하늘, 비를 코드로 그려 신카이 마코토 감성의 장면을 만들고,
가사 자막·연도 카드·연표 막대를 얹어 음원과 합칩니다.

| 파일 | 내용 |
|---|---|
| `render.py` | 영상 생성기 |
| `timing.csv` | 가사 한 줄마다 시작·끝 시각, 화면에 띄울 연도와 사건 |
| `shots.csv` | 시대 장면 그림을 넣을 시각, 파일 이름, 효과(비·반짝임), 움직임(확대·좌우 이동). `make_shots.py`로 생성 |
| `make_shots.py` | 사건마다 그림 3장(전경·인물·상징)을 절·훅·구호·퀴즈에 배치하고 박자(`beats.txt`)에 맞춰 자름 |
| `shots_chatgpt.md` | **ChatGPT로 장면 그림 48장(사건 16개 × 3장) 만드는 가이드.** 공통 규칙, 고증 핵심, 장면별 프롬프트 |
| `images/` | 장면 그림 `01a.png`~`16c.png` (저장소에 올리지 않음) |
| `assets/` | 음원과 폰트 (저장소에 올리지 않음) |
| `out/` | 결과물 (저장소에 올리지 않음) |

## 화면 구성

| 요소 | 위치 | 내용 |
|---|---|---|
| 연도 카드 | 위쪽 가운데 | 큰 연도 + 사건 이름. 훅에서는 연도 3~4개를 한 줄로 |
| 자막 | 아래쪽 | 부르는 가사. 노래 진행에 맞춰 왼쪽부터 노란색으로 채워짐 |
| 연표 막대 | 맨 아래 | 연도 13개. 지금 나오는 연도가 빛남 |
| 퀴즈 | 브리지 | 연도 먼저 → 사건 공개, 또는 사건 먼저 → 연도 공개 (`?`로 가렸다가 공개) |

## 장면 배치

시대 분위기에 맞춰 장면을 바꿉니다. 장면 사이는 1초 동안 겹쳐서 넘어갑니다.

| 시간 | 구간 | 장면 |
|---|---|---|
| 0:00~0:20 | 제목, 훅 | 보랏빛 노을, 전깃줄, 풀밭 |
| 0:20~0:43 | 1절 (1866~1876) | 새벽 바다, 수평선의 군함 |
| 0:43~1:15 | 2절 (1884~1897) | 노을 진 한옥 지붕, 창문 불빛 |
| 1:15~1:26 | 훅 | 노을 |
| 1:26~1:32 | 을사늑약, 국권 피탈 | 비 오는 흐린 하늘 |
| 1:32~1:42 | 3·1 운동, 임시 정부 | 구름 사이로 터지는 빛 |
| 1:42~1:48 | 광복, 정부 수립 | 여름 하늘, 뭉게구름 |
| 1:48~1:55 | 6·25 전쟁, 휴전 | 비 오는 밤 |
| 1:55~2:31 | 브리지 퀴즈 | 은하수와 별똥별 |
| 2:31~2:43 | 마지막 훅 | 노을 |
| 2:43~3:06 | 마무리 | 해돋이, 꽃잎 |

## 시대 장면 그림 넣기

`images/`에 `01a.png`~`16c.png`를 넣으면 `shots.csv`의 시각에 맞춰 들어갑니다. 절에서는 사건마다 3장이 박자에 맞춰 바뀌고, 훅·구호·브리지 퀴즈에서는 연도마다 해당 사건 그림이 빠르게 교차합니다.
그림은 천천히 확대되거나 좌우로 이동하고, 그 위에 비·반짝임 효과와 자막이 얹힙니다.
**그림이 없는 장면은 코드로 그린 하늘 장면이 대신 나오므로** 일부만 넣어도 됩니다.
그림 만드는 방법은 `shots_chatgpt.md`에 있습니다.

## 가사 타이밍 고치기

음성 인식으로 들리는 지점을 찾아 맞췄지만 **0.5~1초 정도 어긋날 수 있습니다.**
영상을 보면서 어긋난 줄이 있으면 `timing.csv`의 `start`, `end`만 고치고 다시 렌더링하면 됩니다.

| 열 | 내용 |
|---|---|
| `start`, `end` | 초 단위 시각 |
| `kind` | `intro`, `hook`, `line`, `gang`, `quiz`(연도→사건), `quizr`(사건→연도), `outro` |
| `text` | 자막 |
| `year`, `event` | 연도 카드 |

장면이 바뀌는 시각은 `render.py`의 `TIMELINE`에 있습니다.

## 다시 만들기

```bash
pip install pillow numpy scipy imageio-ffmpeg
# assets/song.mp3, assets/fonts/ 에 BlackHanSans-Regular.ttf, NotoSansKR.ttf, GowunDodum.ttf
python3 render.py --still 25,50,125        # 정지 화면 미리보기 (out/still_*.png)
python3 render.py                          # 전체 영상 (out/modern_history_rap.mp4, 4코어 약 5분)
```

폰트는 모두 Google Fonts의 OFL 라이선스로 상업적 사용이 가능합니다.

## 한계와 다음 단계

- 장면은 **코드로 그린 배경**입니다. 하늘·구름·빛의 분위기는 신카이 감성이지만, 손으로 그린 애니 배경이나 인물은 없습니다.
- 더 애니다운 그림은 위 "시대 장면 그림 넣기"로 넣습니다. 실제 감독·작품 이름 대신 "애니메이션 배경화, 노을 하늘, 뭉게구름, 빛줄기"처럼 요소로 묘사하세요.
- 특정 작품의 장면을 그대로 따라 그리지 않습니다. 화풍은 참고하되 구도와 소재는 직접 정합니다.
