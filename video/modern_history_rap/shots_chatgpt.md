## 2. 장면별 프롬프트

각 프롬프트를 **같은 대화에서 한 장씩** 보내고, 받은 그림을 **파일 이름(예: `01a.png`)으로 바꿔** 이 대화에 올려 주세요.

### 01 병인양요 (1866)

> **고증 핵심**: 1866년 가을(10~11월). 프랑스 로즈 제독의 함대가 강화도를 침략. 양헌수 부대가 정족산성에서 프랑스군을 물리침. 프랑스군이 물러가며 강화도 외규장각의 의궤 등 책을 약탈.

**01a — 전경**
```
1866년 가을, 강화도와 김포 사이 좁은 바다(염하)에 프랑스 함대가 들어온 장면.
돛대 3개와 굴뚝이 함께 있는 목조 증기 군함 여러 척, 해안 언덕 위 조선의 돌 성곽과 포대.
단풍 든 산, 차가운 가을 아침 하늘과 긴장감 있는 구름.
```

**01b — 인물·행동**
```
1866년 가을, 강화도 정족산성(삼랑성)의 돌 성벽 뒤에 매복한 조선 군사들의 뒷모습.
전립(챙 넓은 검은 벙거지)과 동달이 군복, 화승총. 성벽 너머 단풍 든 산길.
숨죽인 긴장감, 낙엽, 늦은 오후 빛.
```

**01c — 상징 클로즈업**
```
1866년 강화도 외규장각 안. 나무 서가에 비단 표지의 왕실 기록책(의궤)이 가지런히 놓여 있다.
문틈으로 들어오는 가을 햇빛과 먼지. 책 표지에 글자는 보이지 않게. 곧 사라질 것 같은 쓸쓸한 분위기.
```

### 02 신미양요 (1871)

> **고증 핵심**: 1871년 6월(초여름). 미국 아시아 함대(기함 콜로라도호)가 강화도를 침략. 광성보에서 어재연 장군의 조선군이 끝까지 싸움. 조선군은 솜을 여러 겹 누빈 갑옷(면갑)을 입었고, 장군기 '수자기'를 빼앗김.

**02a — 전경**
```
1871년 초여름, 강화도 광성보. 바다를 내려다보는 언덕 위 둥근 돌 돈대(손돌목돈대)와 성곽.
바다 위에 돛과 굴뚝이 함께 있는 미국 증기 군함들. 초록 숲, 짙은 구름 사이로 내리는 빛줄기.
```

**02b — 인물·행동**
```
1871년 초여름, 광성보 돈대 안. 솜을 여러 겹 누빈 두꺼운 흰 면갑을 입은 조선 병사들이
화승총과 창을 들고 바다 쪽을 향해 서 있는 뒷모습. 화약 연기가 자욱하고 긴장감이 흐른다. 폭력 묘사 없이.
```

**02c — 상징 클로즈업**
```
1871년 광성보 성벽 위에서 바람에 크게 펄럭이는 누런 삼베 군기. 깃발 가운데에 큰 검은 한자 '帥' 한 글자만.
깃발 뒤로 연기 낀 하늘과 바다. 그 밖의 글자는 없음.
```
> 02c는 수자기(帥字旗)의 '帥' 한 글자만 예외로 허용했습니다. 글자가 틀리게 나오면 "깃발 글자를 지우고 다시"라고 요청하세요.

### 03 척화비 (1871)

> **고증 핵심**: 신미양요 직후 흥선대원군이 서울 종로를 비롯한 전국 곳곳에 척화비를 세움. 화강암 비석. 흥선대원군의 집은 운현궁.

**03a — 전경**
```
1871년 서울 종로 거리. 기와집 상점과 초가가 늘어선 넓은 길 한가운데 화강암 비석 하나가 서 있다.
한복과 갓 차림의 행인들이 비석을 바라본다. 늦은 오후, 노을 진 하늘. 비석 표면은 글자 없이.
```

**03b — 인물·행동**
```
1871년 서울 운현궁. 한옥 사랑채 툇마루에 도포와 갓 차림의 노인이 마당을 등지고 서 있는 뒷모습.
단정한 마당, 소나무, 저녁 빛. 얼굴은 보이지 않게.
```

**03c — 상징 클로즈업**
```
화강암 척화비를 가까이서 올려다본 모습. 키 큰 직사각형 비석, 윗부분이 둥글게 다듬어져 있다.
표면은 글자 없이 매끈하게. 비석 뒤로 구름 낀 하늘과 빛줄기.
```

### 04 강화도 조약 (1876)

> **고증 핵심**: 1875년 일본 군함 운요호가 강화도 초지진 앞바다에 접근해 충돌(운요호 사건). 이를 구실로 1876년 2월(겨울) 강화도 연무당에서 조약 체결. 조선 대표는 갓·관복, 일본 대표는 서양식 제복.

**04a — 전경**
```
1875년 강화도 초지진 앞바다. 돛대 2개와 굴뚝이 있는 작은 일본 증기 군함 한 척이 해안 가까이 다가와 있다.
해안 언덕 위 조선의 돌 성벽과 포대. 흐리고 바람 부는 하늘, 거친 파도.
```

**04b — 인물·행동**
```
1876년 2월 겨울, 강화도 연무당 앞마당. 눈이 조금 남은 마당에 조선 관리들(갓과 관복)과
서양식 검은 제복을 입은 일본 관리 일행이 마주 서 있다. 멀리서 본 옆모습, 무거운 겨울 하늘.
```

**04c — 상징 클로즈업**
```
1876년 겨울, 한옥 대청 안 탁자 위에 펼쳐진 조약 문서 두 벌, 붓, 벼루, 인주.
문서 글자는 흐릿해서 읽을 수 없게. 창호지 문으로 들어오는 차가운 겨울빛.
```

### 05 갑신정변 (1884)

> **고증 핵심**: 1884년 12월(겨울 밤). 김옥균 등 급진개화파가 서울 우정총국 개국 축하연에서 정변을 일으킴. 신호로 근처에 불을 지름. 청나라 군대의 개입으로 3일 만에 실패.

**05a — 전경**
```
1884년 12월 겨울밤, 서울 우정총국. 단층 한옥 기와 건물 마당에 축하연 등불이 줄지어 켜져 있다.
관복 차림의 손님들과 서양식 옷을 입은 외국 외교관들이 멀리 보인다. 별이 뜬 짙은 남색 하늘, 입김.
```

**05b — 인물·행동**
```
1884년 겨울밤, 우정총국 담장 너머 가까운 곳에서 불길과 연기가 치솟는다.
마당의 손님들이 놀라 돌아보는 뒷모습. 등불과 불빛이 섞인 붉은 밤하늘.
```

**05c — 상징 클로즈업**
```
1884년 12월 새벽, 눈 내린 창덕궁 돈화문 앞. 멀리서 청나라 군대 행렬이 다가오고 있다.
깃발은 멀리서 작게, 글자 없이. 차갑고 푸른 새벽빛, 끝나 가는 사흘의 분위기.
```

### 06 동학 농민 운동 (1894)

> **고증 핵심**: 1894년 봄. 전봉준이 이끄는 농민군이 전라도 고부에서 일어나 백산에 모임("서면 백산, 앉으면 죽산": 흰옷 입은 농민이 서면 산이 하얗고 죽창을 들고 앉으면 산이 대나무밭 같다). 이후 전주성 점령. 농민군은 흰옷, 머리에 흰 수건, 죽창.

**06a — 전경**
```
1894년 봄, 전라도 고부 백산. 낮은 산을 흰옷 입은 농민 수천 명이 하얗게 뒤덮고 있다.
산 아래로 넓은 들판과 강, 봄 하늘과 큰 구름. 멀리서 본 장대한 모습.
```

**06b — 인물·행동**
```
1894년 봄 들판. 흰 한복에 머리에 흰 수건을 두른 농민들이 죽창과 글자 없는 깃발을 들고 행진하는 뒷모습.
짚신, 진흙길, 노을 진 하늘. 힘차고 결연한 분위기.
```

**06c — 상징 클로즈업**
```
1894년 전주성 남문(풍남문). 2층 누각이 있는 돌 성문 위에 농민군의 글자 없는 흰 깃발이 꽂혀 바람에 날린다.
성문 앞 흰옷 입은 사람들, 봄 햇살.
```

### 07 갑오개혁 (1894)

> **고증 핵심**: 1894년 여름부터 군국기무처를 중심으로 추진. 신분제 폐지(양반·상민 구별 없앰, 노비제 폐지), 과거제 폐지 등.

**07a — 전경**
```
1894년 여름, 한옥 관청 대청에 관리들이 둘러앉아 회의하는 모습을 마당에서 멀리 본 장면.
갓과 관복, 열린 창호문, 여름 햇살과 매미 우는 나무.
```

**07b — 인물·행동 (상징 장면)**
