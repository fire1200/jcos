> **과학 핵심**: 플라스틱은 가볍고 여러 가지 색으로 만들 수 있음. 나무는 고유한 무늬와 향기. 같은 컵도 물질에 따라 좋은 점이 다름(금속컵 튼튼, 유리컵 투명, 종이컵 가벼움).

**03a — 플라스틱은 가볍고 색이 여러 가지**
```
실험 책상 위에 빨강·노랑·파랑·초록 플라스틱 장난감 블록과 바구니, 빨대가 알록달록 놓여 있다. 차차가 큰 플라스틱 바구니를 손가락 하나로 가볍게 들어 올리며 웃는다.

**03b — 물질에 따라 다른 컵**
```

**03c — 나무의 무늬와 향기**

### 04 물질을 섞으면: 탱탱볼

> **과학 핵심**: 서로 다른 물질을 섞으면 성질이 바뀜. 물과 흰 가루 물질 두 가지를 섞어 말랑말랑하고 잘 튀는 탱탱볼을 만듦.

**04a — 탱탱볼 재료**
```
실험 책상 위에 물이 담긴 투명 비커, 흰 가루가 담긴 작은 유리그릇 두 개, 나무 젓가락, 투명 플라스틱 컵. 과학이와 차차가 보안경을 쓰고 준비한다. 가루에는 이름표나 글자 없이.
```

**04b — 섞어서 뭉치기**
```
차차가 투명 컵 속에서 물과 흰 가루를 나무 젓가락으로 젓고 있다. 컵 안에서 하얗고 말랑한 덩어리가 뭉쳐지기 시작하는 모습이 크게 보인다.
```

**04c — 말랑말랑 탱탱볼**
```
과학이가 손바닥 위의 하얀 반투명 탱탱볼을 바닥에 튀기자 공이 높이 튀어 오른다. 튀어 오른 궤적을 점선으로. 차차가 박수 친다.
```

### 05 암컷과 수컷, 알 낳기

> **과학 핵심**: 동물은 암컷과 수컷의 생김새가 다르기도 함(수컷 원앙은 화려한 깃털, 수사자는 갈기). 배추흰나비는 배추·케일 잎 뒷면에 알을 하나씩 낳음.

**05a — 원앙 암컷과 수컷**
```
연못 위에 원앙 한 쌍이 나란히 떠 있다. 수컷은 주황·초록·보라 깃털이 화려하고, 암컷은 수수한 회갈색. 두 마리의 차이가 한눈에 보이게 크게.
```

**05b — 사자 암컷과 수컷**
```
초원의 바위 위에 수사자와 암사자가 나란히 앉아 있다. 수사자는 머리 둘레에 풍성한 갈기, 암사자는 갈기가 없다. 무섭지 않게 평화로운 모습.
```

**05c — 잎 뒷면에 알을 낳는 배추흰나비**
```
케일 잎 뒷면에 흰 배추흰나비가 배 끝을 대고 노랗고 길쭉한 알을 하나 붙이는 장면을 가까이. 옆에 이미 낳은 알 하나. 잎맥이 보이게.
```

> **과학 핵심**: 번데기에서 어른벌레가 나옴. 곤충의 몸은 머리·가슴·배 세 부분, 다리 세 쌍(6개), 날개 두 쌍(4장), 더듬이 한 쌍. 완전 탈바꿈 곤충: 나비, 사슴벌레, 벌.
