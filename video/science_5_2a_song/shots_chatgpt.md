### 01 생태계

> **과학 핵심**: 생물 요소(식물, 동물, 곰팡이, 세균)와 비생물 요소(햇빛, 물, 흙, 공기, 온도)가 서로 영향을 주고받는 것이 생태계.

**01a — 연못 생태계**
```
햇살 아래 작은 연못과 둘레의 숲: 물풀, 연꽃, 개구리, 소금쟁이, 잠자리, 물가의 새, 둥치에 난 버섯, 맑은 하늘. 과학이와 차차가 물가에서 관찰 기록장을 든다.
```

**01b — 생물 요소와 비생물 요소**
```
화면을 반으로 나눈 그림. 왼쪽: 풀, 나무, 토끼, 새, 버섯이 모여 있음. 오른쪽: 해, 물방울, 흙덩이, 바람 줄기(공기), 온도계가 모여 있음.
```

**01c — 서로 영향을 주고받아요**
```
들판 단면: 햇빛을 받아 자라는 풀, 흙 속을 지나는 지렁이가 흙을 부드럽게 하고, 풀뿌리가 흙 속 물을 빨아들인다. 해에서 풀로, 흙에서 뿌리로 굵은 화살표.
```

### 02 생산자, 소비자, 분해자

> **과학 핵심**: 스스로 양분을 만드는 생물은 생산자(식물), 다른 생물을 먹어 양분을 얻는 생물은 소비자(동물), 죽은 생물이나 배출물을 분해하는 생물은 분해자(곰팡이, 세균).

**02a — 생산자**
```
햇빛이 쏟아지는 들판의 풀과 나무를 크게. 잎으로 햇빛이 들어가는 노란 화살표.
```

**02b — 소비자**
```
풀을 뜯는 토끼, 그 위 하늘에 날개를 편 매. 무섭지 않게 밝은 낮 들판.
```

**02c — 분해자**
```
숲 바닥에 쓰러져 썩어 가는 나무에 버섯과 하얀 곰팡이가 자라고, 둘레의 낙엽이 부서져 흙이 되어 간다. 차차가 돋보기로 본다.
```

### 03 먹이 사슬과 먹이 그물

> **과학 핵심**: 생물의 먹고 먹히는 관계가 사슬처럼 이어진 것이 먹이 사슬, 여러 먹이 사슬이 그물처럼 얽힌 것이 먹이 그물.

**03a — 먹이 사슬**
```
흰 배경에 왼쪽에서 오른쪽으로 한 줄: 벼 → 메뚜기 → 개구리 → 뱀 → 매. 먹히는 생물에서 먹는 생물 쪽으로 굵은 화살표. 생물은 사실적이고 무섭지 않게.
```

**03b — 먹이 그물**
```
흰 배경에 여러 생물(벼, 풀, 메뚜기, 토끼, 들쥐, 개구리, 참새, 뱀, 매)이 흩어져 있고, 먹히는 생물에서 먹는 생물 쪽으로 화살표가 여러 갈래로 그물처럼 얽혀 있다.
```

**03c — 들판에서 찾아요**
```
가을 논과 들판 풍경 속에 메뚜기, 개구리, 참새, 멀리 하늘의 매가 자연스럽게 있다. 과학이와 차차가 논두렁에서 손가락으로 찾아 가리킨다.
```

### 04 생태계 평형과 적응, 보전

> **과학 핵심**: 생물의 종류와 수가 균형을 이루는 상태가 생태계 평형. 생물은 환경에 적응해 살아감(사막여우의 큰 귀, 선인장의 굵은 줄기와 가시). 쓰레기와 매연을 줄여 생태계를 보전함.

**04a — 평형이 깨지면**
```
왼쪽에서 오른쪽으로 세 칸의 같은 숲: 늑대와 사슴, 풀이 알맞게 있음 → 늑대가 사라지자 사슴이 아주 많아지고 풀과 어린나무가 줄어 땅이 드러남 → 늑대가 돌아와 다시 풀과 나무가 자람. 칸 사이 굵은 화살표.
```

**04b — 환경에 적응**
```
화면을 반으로 나눈 그림. 왼쪽: 모래 사막의 사막여우, 아주 큰 귀. 오른쪽: 사막의 선인장, 통통하고 굵은 줄기와 뾰족한 가시.
```

**04c — 생태계 보전**
```
하천 둑에서 과학이와 차차, 친구들이 장갑을 끼고 집게로 쓰레기를 주워 분리 수거 봉투에 담는다. 맑아진 물에 물고기.
```

### 05 습도

> **과학 핵심**: 공기 중에 수증기가 포함된 정도가 습도. 건습구 습도계로 잼. 습도가 높으면 빨래가 잘 마르지 않고 곰팡이가 생기기 쉬우며, 낮으면 피부가 건조해짐.

**05a — 건습구 습도계**
```
벽에 걸린 건습구 습도계를 가까이: 똑같은 알코올 온도계 두 개가 나란히, 오른쪽 온도계 아래 끝은 하얀 헝겊에 싸여 아래 작은 물통에 잠겨 있다. 눈금은 줄만. 과학이가 들여다본다.
```

**05b — 습도가 높을 때와 낮을 때**
```
화면을 반으로 나눈 같은 방. 왼쪽: 축축한 날 빨래가 마르지 않고 벽 모서리에 곰팡이, 제습기가 돌아간다. 오른쪽: 건조한 날 가습기에서 하얀 김이 나오고 차차가 입술에 보습제를 바른다.
```

**05c — 아침 이슬**
```
이른 아침 풀잎 끝에 동그란 이슬방울이 맺혀 반짝이는 모습을 아주 가까이.
```

### 06 이슬, 안개, 구름

> **과학 핵심**: 공기 중 수증기가 응결해 물체 표면에 맺히면 이슬, 지표면 가까이 작은 물방울로 떠 있으면 안개, 높은 하늘에 떠 있으면 구름.

**06a — 이슬 만들기 실험**
```
실험 책상 위에 얼음물이 담긴 투명한 컵, 컵 바깥 표면에 작은 물방울이 송송 맺혀 흘러내린다. 과학이가 손가락으로 물방울을 만져 본다.
```

**06b — 안개**
```
이른 아침 강가와 다리가 낮게 깔린 하얀 안개에 흐릿하게 가려 있다. 과학이와 차차가 우산 없이 둑길을 걸으며 안개를 손으로 휘젓는다.
```

**06c — 구름이 생겨요**
```
산 단면 그림: 산비탈을 따라 공기가 위로 올라가는 굵은 화살표, 높이 올라간 곳에서 하얀 뭉게구름이 생긴다. 산 아래 마을과 아이들.
```

### 07 비와 눈

> **과학 핵심**: 구름 속 작은 물방울이 합쳐져 무거워지면 떨어져 비가 되고, 구름 속 얼음 알갱이가 녹지 않은 채 떨어지면 눈이 됨.

**07a — 물방울이 커져 비로**
```
왼쪽에서 오른쪽으로 세 단계 확대 그림: 구름 속 작은 물방울들 → 서로 합쳐져 큰 물방울 → 무거워져 아래로 떨어지는 빗방울. 단계 사이 굵은 화살표.
```

**07b — 비와 눈**
```
화면을 반으로 나눈 그림. 왼쪽: 구름에서 떨어지는 얼음 알갱이가 내려오며 녹아 빗방울로 바뀜(따뜻한 공기). 오른쪽: 얼음 알갱이가 녹지 않고 그대로 눈송이가 되어 내림(차가운 공기).
```

**07c — 비 오는 날, 눈 오는 날**
```
화면을 반으로 나눈 같은 학교 앞. 왼쪽: 노란 우비와 장화를 신은 과학이와 차차가 빗속을 걷는다. 오른쪽: 하얗게 눈 쌓인 운동장에서 눈사람을 만든다.
```

### 08 기압과 바람

> **과학 핵심**: 공기의 무게 때문에 생기는 힘이 기압. 차가운 공기는 무거워 고기압, 따뜻한 공기는 가벼워 저기압. 고기압에서 저기압으로 공기가 이동하는 것이 바람. 낮에는 해풍, 밤에는 육풍. 우리나라는 겨울에 북서쪽의 차고 건조한 공기, 여름에 남동쪽의 덥고 습한 공기의 영향을 받음.

**08a — 차가운 공기가 더 무거워요**
```
윗접시저울 양쪽에 같은 크기의 투명한 플라스틱 통이 올려져 있다. 왼쪽 통은 얼음 주머니 옆에서 차갑게 한 공기(파란빛), 오른쪽 통은 따뜻한 공기(주황빛). 차가운 공기 쪽 접시가 아래로 내려가 있다.
```

**08b — 해풍과 육풍**
```
화면을 반으로 나눈 같은 바닷가. 왼쪽(낮, 해): 바다에서 육지 쪽으로 부는 굵은 파란 화살표. 오른쪽(밤, 달): 육지에서 바다 쪽으로 부는 굵은 파란 화살표.
```

**08c — 계절과 공기 덩어리**
```
화면을 반으로 나눈 한반도 둘레 지도(글자 없이, 동아시아 바다와 땅만). 왼쪽 겨울: 북서쪽 대륙에서 한반도로 오는 굵은 파란 화살표, 눈 내리는 작은 그림. 오른쪽 여름: 남동쪽 바다에서 오는 굵은 빨간 화살표, 햇볕과 땀 흘리는 작은 그림.
```
