### 01 전기 회로

> **과학 핵심**: 전지, 전선, 전구를 끊기지 않게 연결하면 전구에 불이 켜짐. 전기가 흐르는 길이 전기 회로.

**01a — 불이 켜지는 회로**
```
실험대 위 전지 끼우개의 전지, 집게 전선, 전구 끼우개의 전구, 스위치가 둥글게 이어져 전구가 환하게 켜져 있다. 전선을 따라 노란 화살표.
```

**01b — 켜지는 연결, 안 켜지는 연결**
```
화면을 반으로 나눈 그림. 왼쪽: 전선이 전지의 양쪽 끝과 전구에 끊김 없이 이어져 불이 켜짐. 오른쪽: 전선 한 곳이 떨어져 있어 불이 꺼짐.
```

**01c — 전기 부품**
```
흰 탁자 위에 전지, 전지 끼우개, 집게 전선, 전구, 전구 끼우개, 스위치가 가지런히 놓여 있다. 과학이와 차차가 고른다.
```

### 02 직렬연결과 병렬연결

> **과학 핵심**: 전구 두 개를 한 줄로 연결하면 직렬연결(어두움), 나누어 연결하면 병렬연결(밝음). 병렬연결은 전구 하나를 빼도 다른 전구가 켜짐.

**02a — 직렬연결**
```
전지 하나에 전구 두 개가 한 줄로 이어진 회로, 두 전구가 은은하게(조금 어둡게) 켜져 있다.
```

**02b — 병렬연결**
```
전지 하나에 전구 두 개가 두 갈래로 나뉘어 이어진 회로, 두 전구가 밝게 켜져 있다.
```

**02c — 하나를 빼도 켜져요**
```
병렬연결 회로에서 차차가 전구 하나를 빼냈는데 나머지 전구는 여전히 밝다. 뒤 벽에 집 거실 전등 여러 개 그림(한 개 꺼져도 나머지 켜짐).
```

### 03 전자석

> **과학 핵심**: 전선에 전기가 흐르면 나침반 바늘이 움직임. 전기가 흐를 때만 자석이 되는 전자석은 세기와 극을 바꿀 수 있음.

**03a — 움직이는 나침반 바늘**
```
전지에 이은 전선 바로 아래 나침반이 있고, 스위치를 누르자 나침반 바늘이 돌아간다. 과학이가 스위치를 누른다.
```

**03b — 전자석**
```
화면을 반으로 나눈 그림. 왼쪽: 에나멜선을 감은 쇠못에 전기가 흐르자 클립들이 붙음. 오른쪽: 스위치를 끄자 클립들이 떨어짐.
```

**03c — 세기를 바꿔요**
```
화면을 반으로 나눈 그림. 왼쪽: 전지 한 개, 전자석에 클립 몇 개. 오른쪽: 전지 두 개를 직렬로, 전자석에 클립이 훨씬 많이.
```

### 04 전자석의 이용과 전기 안전

> **과학 핵심**: 전자석 기중기, 자기 부상 열차, 스피커, 선풍기. 젖은 손으로 만지지 않기, 쓰지 않는 플러그 뽑기, 전기 절약.

**04a — 전자석 기중기**
```
고철 처리장에서 크레인 끝 둥근 전자석이 고철 더미를 들어 올린다. 과학이와 차차가 안전선 밖에서 본다.
```

**04b — 자기 부상 열차와 스피커**
```
화면을 반으로 나눈 그림. 왼쪽: 선로 위에 살짝 떠서 달리는 매끈한 자기 부상 열차. 오른쪽: 음악이 나오는 스피커(물결 무늬 소리).
```

**04c — 전기 안전과 절약**
```
집 거실: 차차가 마른 손으로 쓰지 않는 플러그를 뽑고, 과학이는 빈방의 불을 끈다. 젖은 손은 수건으로 닦고 있다.
```

### 05 태양 고도와 그림자

> **과학 핵심**: 태양이 지표면과 이루는 각이 태양 고도. 태양 고도가 높을수록 그림자는 짧아지고 기온은 높아짐.

**05a — 태양 고도 재기**
```
운동장에서 막대를 세운 태양 고도 측정기와 실, 각도기. 과학이가 그림자 끝에 실을 맞추고 차차가 각도를 읽는다(숫자 없이).
```

**05b — 하루 동안 그림자**
```
같은 막대를 세 칸으로: 아침 길게 서쪽으로 늘어진 그림자 → 한낮 짧은 그림자 → 오후 길게 동쪽으로 늘어진 그림자. 칸마다 하늘의 해 높이가 다름. 칸 사이 화살표.
```

**05c — 기온 재기**
```
운동장 백엽상 옆에서 차차가 온도계를 읽고 과학이가 기록장(숫자 없이)에 적는다. 한낮의 밝은 해.
```

### 06 계절별 태양 고도

> **과학 핵심**: 여름에는 남중 고도가 높아 낮이 길고, 겨울에는 낮아 낮이 짧음.

**06a — 여름과 겨울 태양의 길**
```
넓은 들판 위 하늘에 해가 지나가는 두 개의 호: 여름 해는 높고 긴 호, 겨울 해는 낮고 짧은 호. 각 호에 해 그림. 글자 없이 색으로 구분(여름 주황, 겨울 파랑).
```

**06b — 여름 그림자, 겨울 그림자**
```
화면을 반으로 나눈 같은 운동장 한낮. 왼쪽 여름: 높은 해, 과학이 그림자가 짧음. 오른쪽 겨울: 낮은 해, 같은 과학이 그림자가 길게 늘어짐.
```

**06c — 긴 낮, 짧은 낮**
```
화면을 반으로 나눈 같은 놀이터 저녁. 왼쪽 여름: 저녁에도 밝아 아이들이 논다. 오른쪽 겨울: 같은 시간인데 벌써 어둡고 가로등이 켜졌다.
```

### 07 태양 에너지와 계절

> **과학 핵심**: 남중 고도가 높으면 같은 면적에 도달하는 태양 에너지양이 많아져 기온이 높아짐. 그래서 여름은 덥고 겨울은 추움.

**07a — 전등 실험**
```
화면을 반으로 나눈 그림. 왼쪽: 전등이 바로 위에서 수직으로 비춰 바닥에 작고 밝은 원. 오른쪽: 전등을 비스듬히 비춰 넓고 흐린 타원. 같은 크기 모눈종이 위.
```

**07b — 여름과 겨울**
```
화면을 반으로 나눈 같은 바닷가 마을. 왼쪽 여름: 높은 해, 뜨거운 햇살 아래 수영하는 아이들. 오른쪽 겨울: 낮은 해, 눈 덮인 바닷가에 목도리를 한 아이들.
```

**07c — 태양 전지 실험**
```
화면을 반으로 나눈 그림. 왼쪽: 전등을 높은 각도로 비추자 태양 전지에 연결된 프로펠러가 빠르게 돈다. 오른쪽: 낮은 각도로 비추자 천천히 돈다.
```

### 08 기울어진 자전축과 계절

> **과학 핵심**: 지구의 자전축이 기울어진 채 태양 둘레를 공전하기 때문에 계절이 바뀜. 자전축이 기울지 않았다면 계절 변화가 없음.

**08a — 기울어진 채 공전하는 지구**
```
우주 한가운데 태양, 둘레 궤도 위 네 곳의 지구. 네 지구 모두 자전축이 같은 방향으로 비스듬히 기울어져 있다(막대로 표시). 궤도 화살표.
```

**08b — 지구본 실험**
```
어두운 교실, 가운데 전등(태양) 둘레를 따라 과학이와 차차가 기울어진 지구본을 들고 걸어 옮긴다. 지구본의 우리나라 위치에 작은 막대와 그림자.
```

**08c — 사계절**
```
같은 은행나무와 마을을 네 칸으로: 봄 새싹, 여름 짙은 초록, 가을 노란 잎, 겨울 눈 덮인 가지.
```
