### 01 용해와 용액

> **과학 핵심**: 소금처럼 어떤 물질이 다른 물질에 녹아 골고루 섞이는 현상이 용해. 녹는 물질은 용질, 녹이는 물질은 용매, 골고루 섞인 물질이 용액. 용액은 맑고 오래 두어도 가라앉지 않음.

**01a — 소금이 녹아요**
```
왼쪽에서 오른쪽으로 세 단계: 물이 든 비커에 소금 한 숟가락을 넣음 → 유리 막대로 저으며 소금 알갱이가 작아짐 → 알갱이가 보이지 않는 맑고 투명한 소금물. 단계 사이 굵은 화살표.
```

**01b — 용질과 용매가 만나 용액**
```
흰 책상 위 왼쪽에 소금 한 줌이 담긴 접시, 가운데 물이 든 비커, 두 개에서 오른쪽으로 굵은 화살표가 모여 맑은 소금물이 든 비커로 이어진다.
```

**01c — 용액과 용액이 아닌 것**
```
나란히 놓인 비커 세 개: 맑은 소금물, 맑은 설탕물, 그리고 뿌옇고 바닥에 가루가 가라앉은 미숫가루 물. 차차가 뿌연 비커를 가리키며 고개를 갸웃한다.
```

### 02 녹아도 무게는 그대로

> **과학 핵심**: 각설탕이 물에 녹으면 보이지 않지만 없어지지 않음. 녹기 전 물과 각설탕의 무게 합과 녹은 뒤 설탕물의 무게는 같음.

**02a — 녹이기 전**
```
윗접시저울 한쪽 접시에 물이 든 비커와 각설탕 세 개를 올린 작은 접시가 함께 놓여 있다. 과학이가 저울을 들여다본다.
```

**02b — 각설탕이 녹아요**
```
물이 든 비커 속 각설탕을 아주 가까이: 왼쪽에서 오른쪽으로 네모난 각설탕 → 모서리가 부서지며 작아짐 → 사라지고 맑은 물. 단계 사이 굵은 화살표.
```

**02c — 녹인 뒤에도 같아요**
```
윗접시저울의 왼쪽 접시에는 물 비커와 각설탕 접시, 오른쪽 접시에는 같은 비커에 각설탕을 녹인 설탕물과 빈 접시. 저울이 정확히 수평이다. 차차가 엄지를 든다.
```

### 03 녹는 양이 달라요

> **과학 핵심**: 같은 양의 물에 녹는 양은 용질마다 다름(소금, 설탕, 베이킹 소다). 물의 온도가 높을수록 백반이 많이 녹고, 따뜻한 백반 용액을 식히면 백반 알갱이가 다시 생김.

**03a — 소금, 설탕, 베이킹 소다**
```
같은 크기 비커 세 개에 같은 양의 물. 각각 소금, 설탕, 베이킹 소다를 여러 숟가락 넣고 저은 뒤: 소금 비커 바닥에 조금 남음, 설탕 비커는 모두 녹아 맑음, 베이킹 소다 비커 바닥에 많이 남음. 앞에 각 가루가 담긴 작은 접시.
```

**03b — 따뜻한 물과 차가운 물**
```
화면을 반으로 나눈 비교. 왼쪽: 얼음이 든 차가운 물 비커에 백반을 넣고 저었더니 바닥에 백반 가루가 많이 남음. 오른쪽: 김이 살짝 나는 따뜻한 물 비커에 같은 양을 넣었더니 모두 녹아 맑음.
```

**03c — 다시 생기는 백반**
```
다 녹은 따뜻한 백반 용액 비커를 얼음물이 담긴 큰 그릇에 담가 식힌다. 비커 바닥에 투명하고 각진 백반 알갱이가 생겨 반짝인다. 과학이가 보안경을 쓰고 돋보기로 본다.
```

### 04 용액의 진하기

> **과학 핵심**: 같은 양의 용매에 용질이 많이 녹을수록 진한 용액. 진할수록 색이 진하고 맛이 더 닮. 진한 용액일수록 물체가 높이 떠오름.

**04a — 연한 용액과 진한 용액**
```
같은 양의 물이 든 비커 두 개: 왼쪽은 황설탕을 조금 녹여 연한 갈색, 오른쪽은 많이 녹여 진한 갈색. 앞에 황설탕 한 숟가락과 다섯 숟가락.
```

**04b — 메추리알 띄우기**
```
투명한 컵 세 개를 왼쪽에서 오른쪽으로: 맹물에서는 메추리알이 바닥에 가라앉음, 조금 진한 설탕물에서는 중간쯤 뜸, 아주 진한 설탕물에서는 수면 가까이 높이 뜸.
```

**04c — 진하기 비교 도구**
```
과학이와 차차가 빨대 끝에 고무찰흙을 붙여 만든 간이 도구를 두 컵에 띄운다. 연한 설탕물 컵에서는 낮게, 진한 설탕물 컵에서는 높이 떠 있다.
```

### 05 균류: 버섯과 곰팡이

> **과학 핵심**: 버섯과 곰팡이는 균류. 가는 실 모양의 균사로 이루어져 있고 포자로 번식함. 스스로 양분을 만들지 못하고 죽은 생물이나 다른 생물에서 양분을 얻음.

**05a — 숲 속 버섯**
```
축축한 숲 속 쓰러진 나무 둥치와 그루터기에 갈색 버섯이 여러 송이 자란다. 과학이가 쪼그려 앉아 돋보기로 본다(만지지 않음).
```

**05b — 빵에 핀 곰팡이**
```
투명한 지퍼 비닐 봉지에 담긴 식빵에 푸르고 하얀 곰팡이가 동그랗게 피었다. 차차가 비닐 밖에서 돋보기로 관찰한다.
```

**05c — 곰팡이의 균사와 포자**
```
실체 현미경 접안렌즈로 들여다본 둥근 시야: 가느다란 실 같은 하얀 균사가 얽혀 있고, 그 끝에 작고 둥근 포자 덩어리(검푸른 점)가 달려 있다.
```

### 06 원생생물과 세균

> **과학 핵심**: 짚신벌레와 해캄은 원생생물로 논·연못처럼 물이 고인 곳에 삶. 세균은 매우 작아 맨눈으로 볼 수 없고 공 모양, 막대 모양, 나선 모양 등이 있음.

**06a — 연못 물 채집**
```
햇살 비치는 작은 연못가에서 과학이와 차차가 장화를 신고 스포이트와 채집 병으로 초록빛 물을 뜬다. 물 위에 초록 실 같은 해캄이 떠 있다.
```

**06b — 짚신벌레와 해캄**
```
광학 현미경으로 본 둥근 시야 두 개가 나란히: 왼쪽에 짚신 모양의 투명한 짚신벌레(가장자리에 가는 털), 오른쪽에 초록 실 모양 해캄(속에 나선 모양 초록 띠).

**06c — 세균의 여러 모양**
```
아주 크게 확대한 둥근 시야 세 개가 나란히: 왼쪽 동글동글한 공 모양 세균들, 가운데 길쭉한 막대 모양 세균들, 오른쪽 꼬불꼬불한 나선 모양 세균들. 징그럽지 않게 깔끔하게.

### 07 고마운 세균과 균류

> **과학 핵심**: 세균은 흙, 물, 공기, 우리 몸 등 어디에나 삶. 된장·김치·요구르트 같은 발효 식품을 만들고, 죽은 생물을 분해해 환경을 깨끗하게 함.

**07a — 어디에나 있어요**
```

```

**07b — 발효 식품**
```
한국 가정 식탁 위에 김치 그릇, 된장 항아리, 요구르트 병, 치즈 조각이 놓여 있다. 차차가 숟가락을 들고 웃는다.
```

**07c — 분해하는 생물**
```
숲 바닥 단면: 위에 떨어진 낙엽과 쓰러진 나무, 그 위에 버섯, 아래로 갈수록 낙엽이 부서져 검은 흙이 되는 모습. 위에서 아래로 굵은 화살표.
```

### 08 해로운 점과 첨단 생명 과학

> **과학 핵심**: 세균과 곰팡이는 음식을 상하게 하고 병을 일으키기도 함. 첨단 생명 과학: 푸른곰팡이로 세균을 없애는 약, 해캄 같은 생물로 만든 생물 연료.

**08a — 상한 음식**
```
화면을 반으로 나눈 비교. 왼쪽: 싱싱한 귤과 식빵. 오른쪽: 같은 귤과 식빵에 푸른 곰팡이가 핀 모습. 과학이가 코를 막고 고개를 젓는다.
```

**08b — 푸른곰팡이로 만든 약**
```
깨끗한 실험실 책상 위 둥근 배양 접시: 가운데 푸른곰팡이 덩어리 둘레에 맑은 빈 띠가 있고, 그 바깥에 세균 점들이 퍼져 있다. 옆에 흰 약병과 알약(글자 없이). 흰 가운을 입은 어른 과학자.
```

**08c — 생물 연료**
```
왼쪽에서 오른쪽으로: 초록 해캄이 자라는 투명한 관들 → 기름방울이 담긴 병 → 그 연료로 달리는 버스. 단계 사이 굵은 화살표.
```
