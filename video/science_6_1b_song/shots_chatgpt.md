### 01 세포

> **과학 핵심**: 생물을 이루는 가장 작은 단위는 세포. 식물 세포에는 세포벽, 세포막, 핵이 있고 동물 세포에는 세포벽이 없음.

**01a — 현미경 관찰**
```
과학 교실에서 과학이가 광학 현미경 접안렌즈를 들여다보고, 차차가 슬라이드 유리를 들고 있다.
```

**01b — 양파 표피 세포**
```
현미경으로 본 둥근 시야: 벽돌처럼 직사각형으로 줄지어 붙은 양파 세포들, 세포마다 테두리(세포벽)와 작은 둥근 점(핵). 연보라로 물든 모습.
```

**01c — 식물 세포와 동물 세포**
```
현미경 시야 두 개가 나란히: 왼쪽 직사각형 양파 세포(두꺼운 테두리), 오른쪽 둥글고 불규칙한 입안 세포(얇은 테두리, 핵).
```

### 02 뿌리

> **과학 핵심**: 뿌리는 물을 흡수하고 식물을 지지함. 뿌리털이 있어 물을 잘 흡수함. 곧은뿌리와 수염뿌리.

**02a — 곧은뿌리와 수염뿌리**
```
화면을 반으로 나눈 그림. 왼쪽: 굵은 원뿌리에 곁뿌리가 난 곧은뿌리 식물(명아주)을 뽑아 든 과학이. 오른쪽: 가는 뿌리가 수염처럼 많은 수염뿌리 식물(파)을 든 차차.
```

**02b — 뿌리털**
```
뿌리 끝을 크게 확대: 하얀 솜털 같은 뿌리털이 빽빽하고 흙 사이 물방울이 뿌리털로 들어가는 작은 화살표.
```

**02c — 뿌리가 지지해요**
```
강한 바람에 나뭇가지가 흔들리지만 땅속 단면에 넓게 뻗은 뿌리가 나무를 붙잡고 있다.
```

### 03 줄기

> **과학 핵심**: 줄기는 물이 이동하는 통로이고 식물을 지지하며 양분을 저장하기도 함(감자).

**03a — 붉은 물이 올라가요**
```
붉은 색소를 탄 물에 백합 줄기를 꽂아 두었더니 꽃잎 끝까지 붉게 물들었다. 옆에 줄기를 가로로 자른 단면, 붉은 점들이 보인다.
```

**03b — 양분을 저장하는 줄기**
```
흙을 판 밭에서 감자 줄기에 감자가 주렁주렁 달려 나온다. 과학이가 감자를 들어 올린다.
```

**03c — 여러 가지 줄기**
```
나란히 세 가지: 곧게 선 나무줄기, 막대를 감고 올라가는 나팔꽃 줄기, 땅 위로 기어가는 딸기 줄기.
```

### 04 잎과 광합성, 증산 작용

> **과학 핵심**: 잎은 빛, 이산화 탄소, 물로 양분(녹말)을 만듦(광합성). 아이오딘 용액을 떨어뜨리면 청람색. 잎의 기공으로 물이 빠져나가는 것이 증산 작용.

**04a — 광합성**
```
큰 잎사귀 한 장을 가운데 크게. 위에서 햇빛 노란 화살표, 공기에서 잎으로 들어가는 회색 화살표, 줄기를 타고 올라오는 파란 물 화살표, 잎에서 나가는 작은 공기 방울 화살표. 글자 없이.
```

**04b — 녹말 확인**
```
흰 접시 두 개: 왼쪽 햇빛을 받은 잎에 아이오딘 용액을 떨어뜨려 청람색으로 변함, 오른쪽 알루미늄 포일로 가렸던 잎은 색이 그대로. 스포이트를 든 차차, 보안경.
```

**04c — 증산 작용**
```
화면을 반으로 나눈 그림. 왼쪽: 잎이 달린 가지에 비닐봉지를 씌웠더니 봉지 안에 물방울이 많이 맺힘. 오른쪽: 잎을 모두 딴 가지의 봉지는 거의 맑음.
```

### 05 꽃과 열매

> **과학 핵심**: 꽃은 꽃가루받이를 거쳐 씨를 만듦(곤충, 새, 바람, 물). 열매는 씨를 보호하고 여러 방법으로 퍼뜨림.

**05a — 꽃의 구조**
```
커다란 꽃 한 송이를 확대: 가운데 암술, 둘레 수술, 꽃잎, 아래 초록 꽃받침이 분명하게. 글자 없이.
```

**05b — 꽃가루받이**
```
세 칸 나란히: 꽃에 앉은 벌(다리에 꽃가루), 동백꽃 꿀을 먹는 작은 동박새, 바람에 꽃가루가 날리는 벼 이삭.
```

**05c — 씨를 퍼뜨려요**
```
가을 들판: 빙글빙글 도는 단풍나무 열매, 바람에 날아가는 민들레 씨, 과학이 바지에 붙은 도꼬마리 열매.
```

### 06 프리즘과 햇빛

> **과학 핵심**: 햇빛이 프리즘을 지나면 여러 가지 색의 빛으로 나타남. 햇빛은 여러 가지 색의 빛이 섞여 있음(무지개).

**06a — 프리즘**
```
창가 햇빛이 유리 프리즘을 지나 흰 종이 위에 빨강·주황·노랑·초록·파랑·남색·보라 띠로 펼쳐진다. 차차가 종이를 받치고 있다.
```

**06b — 비 온 뒤 무지개**

### 07 빛의 굴절

> **과학 핵심**: 빛이 공기에서 물로 비스듬히 들어가면 경계에서 꺾여 나아감(굴절). 그래서 물속 빨대가 꺾여 보임. 가운데가 두꺼운 렌즈가 볼록 렌즈.

**07a — 꺾이는 빛**
```
어두운 실험실, 물이 든 투명 수조에 손전등 빛줄기를 비스듬히 비춘다. 빛줄기가 물 표면에서 꺾여 나아가는 모습이 또렷하다(물에 우유 몇 방울, 수조 위 연기). 보안경 쓴 과학이.
```

**07b — 꺾여 보이는 빨대**
```
물이 든 투명 컵에 꽂은 빨대가 물 표면에서 꺾인 것처럼 보인다. 차차가 컵 옆에서 눈높이를 맞춰 본다.
```

**07c — 볼록 렌즈 모양**
```
흰 탁자 위에 볼록 렌즈 여러 개를 옆에서 본 모습: 가운데가 두껍고 가장자리가 얇다. 옆에 평평한 유리판을 놓아 비교.
```

### 08 볼록 렌즈의 이용

> **과학 핵심**: 볼록 렌즈는 빛을 모아 온도를 높이고, 물체를 크게 또는 거꾸로 보이게 함. 간이 사진기, 돋보기, 현미경, 망원경, 사진기.

**08a — 햇빛 모으기**
```
운동장에서 어른 선생님이 볼록 렌즈로 햇빛을 모아 검은 종이 위에 작고 밝은 점을 만든다. 점에서 연기가 조금 피어오른다. 보안경 쓴 과학이와 차차는 한 걸음 떨어져 본다.
```

**08b — 간이 사진기**
```
종이 상자로 만든 간이 사진기를 든 차차. 앞에는 볼록 렌즈, 뒤쪽 기름종이 화면에 창밖 나무가 거꾸로(위아래와 좌우가 바뀌어) 맺혀 있다.
```

**08c — 생활 속 볼록 렌즈**
```
흰 탁자 위에 돋보기, 현미경, 망원경, 카메라, 안경이 나란히 놓여 있다. 과학이가 돋보기로 개미를 크게 본다.
```
