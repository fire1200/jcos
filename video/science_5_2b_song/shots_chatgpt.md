### 01 물체의 운동

> **과학 핵심**: 시간이 지남에 따라 물체의 위치가 바뀌면 물체가 운동한다고 함. 물체의 운동은 걸린 시간과 이동 거리로 나타냄.

**01a — 위치가 바뀌어요**
```
화면을 반으로 나눈 같은 공원 길. 두 칸 모두 같은 자리에 큰 나무와 벤치. 왼쪽: 자전거 탄 과학이가 나무 옆에. 오른쪽: 같은 과학이가 나무에서 멀리 앞으로 가 있다. 칸 사이 굵은 화살표.
```

**01b — 운동하는 것과 하지 않는 것**
```
놀이터 풍경: 그네를 타는 차차, 미끄럼틀을 내려오는 아이, 굴러가는 공은 움직임 선과 함께, 가만히 서 있는 나무와 벤치는 움직임 선 없이.
```

**01c — 시간과 거리 재기**
```
강당 바닥에 줄자를 길게 펼치고, 과학이가 태엽 장난감 자동차를 출발시키고 차차가 초시계를 누른다. 초시계 화면은 비어 있다.
```

### 02 빠르기가 변하는 운동, 일정한 운동

> **과학 핵심**: 롤러코스터와 비행기는 빠르기가 변하는 운동, 에스컬레이터와 자동길은 빠르기가 일정한 운동.

**02a — 롤러코스터**
```
놀이공원 롤러코스터가 높은 곳에서 아래로 내려오며 빨라지는 모습. 탄 사람들이 두 손을 든다. 내려오는 구간에 움직임 선이 길게.
```

**02b — 이륙하는 비행기**
```
왼쪽에서 오른쪽으로 같은 활주로 위 비행기 세 모습: 천천히 출발 → 점점 빨라짐(움직임 선 길어짐) → 하늘로 떠오름.
```

**02c — 에스컬레이터와 자동길**
```
화면을 반으로 나눈 그림. 왼쪽: 지하철역 에스컬레이터에 손잡이를 잡고 서 있는 사람들. 오른쪽: 공항 자동길 위에 여행 가방을 든 사람들이 서서 일정하게 이동.
```

### 03 빠르기 비교와 속력

> **과학 핵심**: 같은 거리를 이동한 물체는 걸린 시간이 짧을수록 빠르고, 같은 시간 동안 이동한 물체는 이동 거리가 길수록 빠름. 속력은 이동 거리를 걸린 시간으로 나눈 값(단위 m/s, km/h).

**03a — 같은 거리 달리기**
```
운동장 달리기 결승선. 차차가 가장 먼저 결승선 테이프를 끊고 다른 친구들이 뒤따른다. 결승선 옆 선생님이 초시계를 누른다.
```

**03b — 같은 시간 동안 이동**
```
같은 출발선에서 동시에 출발한 장난감 자동차 세 대가 같은 시간이 지난 뒤 서로 다른 거리에 멈춰 있다. 가장 멀리 간 빨간 자동차를 과학이가 가리킨다.
```

**03c — 빠른 기차와 자전거**
```
같은 시간 동안의 이동을 비교하는 그림: 위쪽 철로에서 고속 열차는 아주 멀리 이동, 아래쪽 길에서 자전거는 조금 이동. 출발점에서 각자 도착점까지 굵은 화살표, 열차 화살표가 훨씬 길다.
```

### 04 교통안전

> **과학 핵심**: 속력이 큰 자동차는 위험하므로 안전띠, 에어백, 과속 방지 턱, 어린이 보호 구역 같은 안전장치와 규칙이 있음.

**04a — 안전띠**
```
자동차 뒷좌석에서 과학이와 차차가 안전띠를 바르게 매고 엄지를 든다. 운전석 핸들 가운데에 에어백 덮개.
```

**04b — 어린이 보호 구역**
```
학교 앞 도로에 붉은 바닥 포장과 노란 과속 방지 턱, 천천히 지나가는 자동차. 표지판과 바닥에 글자 없이 색과 무늬만.
```

**04c — 횡단보도 건너기**
```
초록 신호등 아래 횡단보도에서 과학이와 차차가 손을 들고 좌우를 살피며 건넌다. 멈춰 선 자동차.
```

### 05 여러 가지 용액 분류

> **과학 핵심**: 식초, 레몬즙, 석회수, 빨랫비누 물, 유리 세정제, 탄산수 등 여러 가지 용액을 색, 냄새, 투명한 정도 같은 특징으로 분류할 수 있음.

**05a — 여러 가지 용액**
```
실험 책상 위에 투명한 유리병 여섯 개가 나란히(라벨 없이): 식초(맑음), 레몬즙(연노랑), 탄산수(기포), 석회수(맑음), 빨랫비누 물(뿌연 흰색), 유리 세정제(연파랑). 앞에 레몬 반쪽과 비누.
```

**05b — 특징으로 나누기**
```
과학이와 차차가 보안경과 장갑을 끼고 병들을 두 무리로 나눠 놓는다. 차차는 손으로 부채질해 냄새를 맡는다(코를 직접 대지 않음).
```

**05c — 안전하게 실험해요**
```
실험실에서 보안경, 실험복, 장갑을 갖춘 과학이와 차차가 스포이트로 용액을 조금씩 옮긴다. 선생님이 옆에서 지켜본다.
```

### 06 지시약

> **과학 핵심**: 산성 용액은 푸른색 리트머스 종이를 붉게, 염기성 용액은 붉은색 리트머스 종이를 푸르게 바꿈. 페놀프탈레인 용액은 염기성에서만 붉게 변함. 붉은 양배추 지시약은 산성에서 붉은 계열, 염기성에서 푸른·초록·노란 계열.

**06a — 리트머스 종이**
```
화면을 반으로 나눈 그림. 왼쪽: 푸른 리트머스 종이 끝을 식초에 담그자 붉게 변함. 오른쪽: 붉은 리트머스 종이 끝을 빨랫비누 물에 담그자 푸르게 변함.
```

**06b — 페놀프탈레인 용액**
```
시험관대에 투명한 용액이 든 시험관 네 개, 스포이트로 페놀프탈레인 용액을 떨어뜨리자 왼쪽 두 개(식초, 레몬즙)는 그대로 투명하고, 오른쪽 두 개(석회수, 빨랫비누 물)는 진한 붉은색으로 변함.
```

**06c — 붉은 양배추 지시약**
```
보라색 붉은 양배추 즙을 넣은 시험관이 왼쪽에서 오른쪽으로 색이 변해 늘어서 있다: 붉은색, 분홍색, 보라색, 푸른색, 초록색, 노란색. 앞에 반으로 자른 붉은 양배추.
```

### 07 산성 용액과 염기성 용액의 성질

> **과학 핵심**: 산성 용액은 달걀 껍데기와 대리석을 녹임(기포 발생). 염기성 용액은 두부와 삶은 달걀흰자를 녹임.

**07a — 달걀 껍데기와 산성 용액**
```
투명 비커 속 산성 용액에 달걀 껍데기 조각을 넣자 표면에서 작은 기포가 보글보글 올라오고 껍데기가 얇아진다. 보안경 쓴 과학이가 본다.
```

**07b — 대리석과 산성 용액**
```
투명 비커 속 산성 용액에 하얀 대리석 조각을 넣자 기포가 많이 생기며 조각이 녹아 작아진다. 옆에 넣기 전의 대리석 조각.
```

**07c — 두부와 염기성 용액**
```
화면을 반으로 나눈 비교. 왼쪽: 염기성 용액 속 두부가 뿌옇게 풀어지며 흐물흐물해짐. 오른쪽: 염기성 용액 속 삶은 달걀흰자가 녹아 작아짐. 차차가 장갑을 끼고 핀셋을 든다.
```

### 08 섞으면 약해져요, 우리 생활

> **과학 핵심**: 산성 용액에 염기성 용액을 넣을수록 산성이 약해지고, 염기성 용액에 산성 용액을 넣을수록 염기성이 약해짐. 생선 비린내에 레몬즙(산성), 속 쓰림에 제산제(염기성).

**08a — 색이 변해요**
```
붉은 양배추 지시약을 넣은 산성 용액(붉은색) 시험관이 왼쪽에서 오른쪽으로 다섯 개: 염기성 용액을 조금씩 더 넣을수록 붉은색 → 분홍 → 보라 → 푸른색 → 초록으로 변함. 위에 스포이트.
```

**08b — 생선 요리에 레몬즙**
```
부엌 식탁 위 구운 생선에 어른이 레몬을 짜서 뿌린다. 과학이가 냄새를 맡으며 웃는다.
```

**08c — 제산제**
```
화면을 반으로 나눈 그림. 왼쪽: 배를 감싸 쥐고 속이 쓰린 표정의 어른. 오른쪽: 물과 함께 하얀 알약(글자 없이)을 먹고 편안해진 같은 어른.
```
