```
세종 때 겨울, 두만강가의 성(진). 눈 덮인 성벽 위에서 투구와 두정갑 차림의 조선 군사들이
얼어붙은 강 너머를 지키는 뒷모습. 차가운 푸른 하늘, 입김.
```

**08c — 상징 클로즈업**

```
나무 책상 위에 펼쳐진 붓으로 그린 옛 지도. 산과 두 개의 큰 강줄기가 그려져 있고 글자는 없다.
지도 위에 작은 깃발 모양 표시들, 등잔불 빛.
```

### 09 경국대전 (1485)

> **고증 핵심**: 세조 때 편찬을 시작해 성종 때 완성한 조선의 기본 법전. 이전·호전·예전·병전·형전·공전의 6권 체제.

**09a — 전경**
```
15세기 조선의 관청 대청. 단령 관복과 사모 차림의 관리들이 긴 책상에 둘러앉아 문서를 정리한다.
쌓인 책과 두루마리, 열린 창호문으로 들어오는 햇빛. 글자는 보이지 않게.
```

**09b — 인물·행동**

```
1485년 궁궐 편전. 붉은 곤룡포를 입은 왕의 뒷모습 앞에 관리가 무릎 꿇고 책을 바친다.
```

**09c — 상징 클로즈업**

```
부드러운 빛, 엄숙하고 단정한 분위기.
```

### 10 사화 (1498~1545)

> **고증 핵심**: 훈구 세력과 사림이 대립해 사림이 화를 입은 사건. 무오사화(1498)부터 을사사화(1545)까지 네 차례. 화를 입은 선비들은 귀양을 갔고, 이후 사림은 지방의 서원에서 학문을 이어감.

**10a — 전경**
```
15세기 말 먹구름이 낀 궁궐. 근엄한 관리들이 늘어선 마당 한쪽에 갓과 도포 차림의 선비들이 고개를 숙이고 서 있다.
무겁고 어두운 분위기, 바람에 흔들리는 나무. 폭력 장면 없이.
```

**10b — 인물·행동**
```
비 오는 산길을 따라 귀양을 떠나는 선비의 뒷모습. 도포와 갓, 작은 봇짐, 뒤따르는 하인 한 명.
안개 낀 산, 쓸쓸한 분위기.
```

**10c — 상징 클로즈업**
```
16세기 산속의 서원. 소나무 숲 사이 기와 강당에서 선비들이 책을 읽는 모습을 마당에서 본 장면.
맑은 계곡물, 새벽빛. 고난 속에서도 이어지는 배움의 희망.
```

### 11 임진왜란 (1592)

> **고증 핵심**: 1592년 4월 일본이 침략. 이순신의 수군이 판옥선과 거북선으로 한산도 앞바다에서 학 날개 모양(학익진)으로 적을 물리침(1592년 7월). 각지에서 의병이 일어남(붉은 옷을 입은 곽재우는 '홍의장군'). 거북선: 판옥선 몸체 위에 쇠못을 박은 덮개, 앞에 용머리, 양옆에 노.

**11a — 전경**
```
1592년 여름, 남해 한산도 앞바다. 조선 수군의 판옥선 수십 척이 학의 날개처럼 반원 모양으로 넓게 펼쳐져 있고,
그 가운데 거북선이 앞장선다. 푸른 바다와 섬들, 극적인 여름 하늘. 전투 직전의 긴장감.
```

**11b — 인물·행동**
```
1592년 산속, 붉은 옷을 입고 말을 탄 장수의 뒷모습과 그를 따르는 흰옷의 농민 의병들.
낫, 활, 창을 든 사람들이 산길을 오른다. 초여름 숲, 결연한 분위기.
```

**11c — 상징 클로즈업**
```
거북선 앞부분 클로즈업. 입을 벌린 용머리, 쇠못이 촘촘히 박힌 거북 등 모양의 덮개, 양옆으로 나온 노.
물보라와 햇빛, 웅장한 분위기.
```
