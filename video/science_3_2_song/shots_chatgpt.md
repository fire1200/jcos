### 01 땅·물·하늘의 동물

> **과학 핵심**: 사는 곳에 따라 생김새와 움직임이 다름. 땅: 다리 없이 기어 다니는 뱀·지렁이, 다리로 걷는 개미·너구리. 물: 지느러미로 헤엄치고 아가미로 숨 쉬는 붕어. 하늘: 날개와 깃털로 나는 새.

**01a — 땅에 사는 동물**
```
숲속 땅을 화면 반으로 나눈 비교 그림.
왼쪽: 다리 없이 몸을 구불구불 움직여 기어가는 초록 뱀과 흙 위의 지렁이 (몸이 지나간 자국).
오른쪽: 다리로 걸어가는 개미 줄과 숲길을 걷는 너구리.
과학이와 차차가 돋보기를 들고 가운데에서 관찰한다.
```

**01b — 물에 사는 동물**
```
맑은 연못 물속을 옆에서 본 장면. 붕어 한 마리가 화면 가운데에 크게,
펼친 지느러미(등·가슴·꼬리 지느러미)와 머리 옆 아가미 뚜껑이 또렷하게 보인다. 입에서 작은 물방울.
물풀과 자갈, 물 위로 수면 너머 과학이와 차차가 들여다보는 모습.
```

**01c — 하늘을 나는 동물**
```
파란 하늘을 나는 참새 한 마리를 가까이. 날개를 활짝 펴서 깃털 한 장 한 장이 보이게.
아래쪽에는 과학이가 바닥에서 주운 깃털을 들어 보이고 있다. 흰 구름과 햇살.
```

### 02 사막·극지방 동물과 동물 흉내

> **과학 핵심**: 사막의 낙타는 물을 오래 마시지 않아도 견디고, 사막여우는 큰 귀로 몸의 열을 내보냄. 극지방의 북극곰은 두꺼운 털과 지방으로 추위를 견딤. 동물의 특징을 흉내 내어 생활 도구를 만듦(도꼬마리 열매 → 찍찍이, 문어 빨판 → 흡착판).

**02a — 사막의 동물**
```
뜨거운 햇볕이 내리쬐는 모래 사막. 왼쪽에 등에 혹이 있는 낙타가 모래 언덕을 걷고,
오른쪽 모래 위에는 얼굴보다 큰 귀를 쫑긋 세운 작은 사막여우가 앉아 있다.
멀리 아지랑이, 선인장은 없이 모래 언덕만.
```

**02b — 극지방의 동물**
```
하얀 얼음과 눈으로 덮인 북극. 두꺼운 하얀 털의 북극곰이 눈보라 속에서도 편안하게 걷고 있다.
털이 두툼하고 복슬복슬한 것이 잘 보이게 가까이. 파란 얼음 바다와 하얀 하늘.
```

**02c — 동물을 흉내 낸 도구**
```
화면을 위아래 두 줄로 나눈 비교 그림, 각 줄은 왼쪽 → 오른쪽 화살표.
위 줄: 갈고리 가시가 달린 도꼬마리 열매가 강아지 털에 붙은 모습 → 신발에 붙은 찍찍이(벨크로) 클로즈업.
아래 줄: 문어 다리의 둥근 빨판 → 욕실 타일에 붙은 둥근 흡착판 걸이.
글자 없이 화살표만. 깨끗한 흰 배경.
```

### 03 흙이 만들어져요

> **과학 핵심**: 바위나 돌이 물, 나무뿌리, 얼음 등에 의해 오랫동안 부서져 흙이 됨. 화단 흙은 운동장 흙보다 부식물(식물 뿌리·잎, 죽은 곤충이 썩은 것)이 많아 식물이 잘 자람. 바닷가에는 갯바위·모래사장·갯벌이 있음.

**03a — 바위가 부서져 흙이 돼요**
```
왼쪽에서 오른쪽으로 네 단계: 나무뿌리가 틈을 벌린 큰 바위 → 갈라진 돌덩이들 → 작은 자갈과 모래 → 고운 흙 더미.
단계 사이에 굵은 갈색 화살표. 첫 그림에는 바위 틈으로 스며드는 빗물과 뿌리가 보이게. 글자 없이.
```

**03b — 운동장 흙과 화단 흙**
```
투명한 물컵 두 개에 각각 흙을 넣고 저은 실험을 화면 반으로 나눠 비교.
왼쪽(운동장 흙): 밝은 갈색 모래 같은 흙, 물 위에 뜬 것이 거의 없음, 옆 화분의 식물은 작고 시들함.
오른쪽(화단 흙): 짙은 검은 갈색 흙, 물 위에 마른 잎 조각과 나뭇가지 같은 부식물이 많이 떠 있음, 옆 화분의 식물은 크고 싱싱함.
차차가 두 컵을 비교한다.
```

**03c — 바닷가의 모습**
```
넓은 바닷가 풍경을 한 장에. 왼쪽에 파도가 부딪히는 울퉁불퉁한 갯바위와 작은 바닷가 동굴,
가운데에 넓은 하얀 모래사장, 오른쪽에 물이 빠진 갯벌(진흙에 작은 게와 구멍들).
과학이와 차차가 모래사장에서 바다를 바라본다.
```

### 04 흐르는 물이 하는 일

> **과학 핵심**: 흐르는 물은 지표를 깎고(침식), 깎은 흙을 옮기고(운반), 옮긴 흙을 쌓음(퇴적). 강 상류는 경사가 급하고 폭이 좁으며 큰 바위가 많음(침식이 활발). 강 하류는 경사가 완만하고 폭이 넓으며 모래와 고운 흙이 많음(퇴적이 활발).

**04a — 흙 언덕 실험: 침식 · 운반 · 퇴적**
```
실험 책상 위 비스듬한 흙 언덕 모형. 과학이가 위쪽에서 물뿌리개로 물을 붓고 있다.
언덕 위쪽은 물길을 따라 흙이 깊게 깎여 있고, 가운데로 흙탕물이 흙을 실어 흘러내리고, 아래쪽 끝에는 흙이 부채꼴로 쌓여 있다.
위(깎임) → 가운데(옮김) → 아래(쌓임)가 한눈에 보이게 옆에서 본 구도.
```

**04b — 강 상류**
```
좁고 가파른 산골짜기 계곡. 빠르게 흐르는 하얀 물살 사이에 크고 모난 바위들이 많다.
물이 바위와 땅을 깎아 내는 힘찬 느낌. 양쪽은 가파른 산비탈과 숲.
```

**04c — 강 하류**
```
넓고 완만하게 흐르는 큰 강의 하류. 강가에 넓은 모래톱과 고운 흙이 쌓인 들판, 작고 둥근 자갈.
물은 천천히 흐르고 멀리 바다가 보인다. 과학이와 차차가 강가에서 모래를 손에 쥐어 본다.
```

### 05 고체와 액체

> **과학 핵심**: 고체는 담는 그릇이 바뀌어도 모양과 부피가 변하지 않음(나무 막대, 돌). 액체는 담는 그릇에 따라 모양이 바뀌지만 부피는 변하지 않음. 물질은 고체·액체·기체 세 가지 상태로 있음.

**05a — 고체: 모양과 부피가 그대로**
```
실험 책상 위에 모양이 다른 투명한 그릇 세 개(둥근 그릇, 네모난 그릇, 길쭉한 컵).
같은 나무 막대 하나와 돌멩이 하나를 그릇마다 옮겨 담았는데, 막대와 돌의 모양과 크기가 어느 그릇에서나 똑같다.
왼쪽에서 오른쪽으로 옮기는 화살표. 차차가 집게로 옮긴다.
```

**05b — 액체: 모양은 바뀌고 부피는 그대로**
```
왼쪽에서 오른쪽으로 네 단계: 눈금 실린더에 담긴 파란 주스 → 넓적한 그릇에 부은 모습(넓게 퍼짐) → 길쭉한 병에 부은 모습(높게 섬) → 다시 눈금 실린더에 부었더니 처음과 똑같은 높이.
첫 번째와 마지막 실린더의 물 높이가 정확히 같게, 높이를 나타내는 가로 점선(글자 없이).
과학이가 붓고 있다.
```

**05c — 고체 · 액체 · 기체**
```
깨끗한 흰 책상 위에 세 가지를 나란히: 왼쪽 회색 돌멩이(고체), 가운데 물이 담긴 투명한 컵(액체), 오른쪽 공기를 가득 넣어 부푼 투명 비닐봉지(기체, 안은 비어 보이지만 빵빵함).
세 개가 똑같은 크기로 또렷하게. 과학이와 차차가 양옆에서 가리킨다.
```

### 06 기체

> **과학 핵심**: 기체는 담는 그릇을 가득 채우고 모양과 부피가 그릇에 따라 변함. 공기는 눈에 보이지 않지만 공간을 차지함(물에 컵을 거꾸로 넣으면 물이 들어오지 못함). 공기도 무게가 있음(공기를 넣은 공이 더 무거움).

**06a — 기체는 그릇을 가득 채워요**
```
투명한 풍선 세 개(둥근 풍선, 길쭉한 풍선, 하트 모양 풍선)가 공기로 빵빵하게 부풀어 있다. 모양은 달라도 안쪽이 빈틈없이 가득 찬 느낌.
옆에서 차차가 투명한 주사기를 누르자 안의 공기가 연결된 작은 풍선을 부풀린다.
```

**06b — 공기는 공간을 차지해요**
```
물이 담긴 투명 수조를 옆에서 본 단면 그림. 과학이가 투명한 플라스틱 컵을 거꾸로 해서 물속에 똑바로 눌러 넣고 있다.
컵 안에는 물이 거의 들어가지 못해 공기가 차 있고, 컵 안쪽 바닥에 붙여 둔 마른 휴지가 젖지 않았다. 수조의 물 높이가 조금 올라가 있다.
```

**06c — 공기도 무게가 있어요**
```
실험 책상 위 커다란 양팔 저울. 왼쪽 접시에는 바람이 빠져 납작한 축구공, 오른쪽 접시에는 공기를 가득 넣어 빵빵한 같은 축구공.
저울이 빵빵한 공 쪽(오른쪽)으로 아래로 기울어 있다.
차차가 공기 주입기를 들고 있다.
```

### 07 소리가 나요

> **과학 핵심**: 소리가 나는 물체는 떨림이 있음. 소리의 세기: 크게 치면 큰 소리(떨림이 큼), 약하게 치면 작은 소리. 소리의 높낮이: 실로폰의 짧은 음판은 높은 소리, 긴 음판은 낮은 소리.

**07a — 물체가 떨려요**
```
실험 책상 위 작은 북 위에 하얀 좁쌀(쌀알)을 올려놓고 과학이가 북채로 친다.
쌀알이 위로 통통 튀어 오르고, 북 가죽 둘레에 떨림을 나타내는 작은 진동 선.
옆에서 차차가 소리굽쇠를 물그릇에 대자 물이 튀어 오른다.
```

**07b — 세기: 큰 소리, 작은 소리**
```
화면을 반으로 나눈 비교 그림. 같은 북과 같은 쌀알.
왼쪽: 과학이가 북을 세게 치자 쌀알이 높이 튀고, 둘레에 크고 진한 물결선이 여러 겹 퍼진다. 귀를 막는 차차.
오른쪽: 과학이가 북을 살살 치자 쌀알이 조금만 튀고, 작고 옅은 물결선 한두 겹.
```

**07c — 높낮이: 높은 소리, 낮은 소리**
```
알록달록한 실로폰을 위에서 비스듬히 크게. 음판이 왼쪽 긴 것에서 오른쪽 짧은 것으로 차례로 짧아진다.
차차가 오른쪽 짧은 음판을 치자 위로 촘촘하고 작은 물결선, 과학이가 왼쪽 긴 음판을 치자 넓고 느린 큰 물결선.
음표는 그리지 말고 물결선으로만.
```

### 08 소리가 전해지고 반사돼요

> **과학 핵심**: 소리는 고체·액체·기체를 통해 전달됨(실 전화기는 실이라는 고체로 전달). 소리는 물체에 부딪히면 되돌아오는데 이것이 소리의 반사(메아리). 딱딱한 물체는 소리를 잘 반사하고 부드러운 물체는 잘 반사하지 않음. 방음벽 등으로 소음을 줄임.

**08a — 실 전화기**
```
교실 양 끝에서 과학이와 차차가 종이컵 실 전화기를 팽팽하게 당기고 있다.
과학이가 컵에 대고 말하고, 팽팽한 실을 따라 떨림을 나타내는 작은 진동 선이 차차 쪽으로 이어진다. 차차가 귀에 컵을 대고 놀란 표정.
```

**08b — 메아리: 소리의 반사**
```
산꼭대기에서 과학이와 차차가 맞은편의 커다란 바위 절벽을 향해 손나팔을 하고 외치고 있다.
아이들 입에서 나간 물결선이 계곡을 건너 절벽에 부딪힌 뒤 다시 아이들 쪽으로 되돌아오는 화살표 모양 물결선.
말풍선과 글자 없이. 맑은 하늘과 초록 산.
```

**08c — 방음벽으로 소음 줄이기**
```
아파트 옆 큰 도로. 차들이 달리며 나는 소음이 물결선으로 퍼지다가, 도로와 아파트 사이의 높고 투명한 방음벽에 막혀 되돌아간다.
방음벽 뒤 아파트 쪽은 조용하고, 창가에서 과학이와 차차가 편안하게 책을 읽고 있다.
```
