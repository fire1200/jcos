## 2. 장면별 프롬프트

받은 그림은 **파일 이름(예: `01a.png`)으로 바꿔** 압축해 올려 주세요. 압축 파일 이름에 **과학4-1상**를 꼭 넣어 주세요.

### 01 지층의 모습

> **과학 핵심**: 지층은 자갈·모래·진흙이 층층이 쌓여 줄무늬로 보임. 수평인 지층, 휘어진 지층, 끊어진 지층이 있음.

**01a — 바닷가 절벽의 지층**
```
바닷가 절벽에 색깔이 다른 층이 수평 줄무늬로 층층이 쌓여 있다. 절벽 아래 모래밭에서 과학이와 차차가 올려다보며 손가락으로 줄무늬를 가리킨다.
```

**01b — 수평 · 휘어진 · 끊어진 지층**
```
화면을 세로로 셋으로 나눈 그림. 왼쪽: 반듯한 수평 지층 절벽. 가운데: 둥글게 휘어진 지층 절벽. 오른쪽: 비스듬히 끊어져 어긋난 지층 절벽.
```

**01c — 층마다 다른 알갱이**
```
지층 절벽을 아주 가까이 확대: 위에서부터 고운 진흙 층(회색), 모래 층(노란빛), 자갈 층(동글동글한 돌)이 분명하게 다르다. 차차가 돋보기로 본다.
```

### 02 지층이 만들어져요

> **과학 핵심**: 물에 운반된 자갈·모래·진흙이 쌓이고, 오랜 시간 위에서 눌려 단단해지면 지층이 됨. 아래층이 먼저 쌓여 더 오래됨.

**02a — 물이 옮겨 쌓아요**
```
강이 바다로 흘러드는 곳의 단면 그림. 강물이 자갈·모래·진흙을 실어 오고, 물 아래 바닥에 알갱이들이 차곡차곡 가라앉아 쌓인다. 화살표는 글자 없이.
```

**02b — 쌓이고 눌려 굳어요**
```
왼쪽에서 오른쪽으로 세 단계 단면: 느슨하게 쌓인 층 → 위에 층이 더 쌓여 아래를 누르는 모습(아래 방향 굵은 화살표) → 단단하게 굳은 줄무늬 지층. 단계 사이에 굵은 화살표.
```

**02c — 지층 모형 실험**
```
실험 책상 위 투명한 원통에 과학이가 자갈·모래·진흙을 차례로 물과 함께 부어 층이 생긴 모습. 아래가 먼저 부은 층. 차차가 옆에서 층을 가리킨다.
```

### 03 퇴적암

> **과학 핵심**: 진흙이 굳은 이암(알갱이 작고 부드러움), 모래가 굳은 사암, 자갈이 섞여 굳은 역암.

**03a — 이암 · 사암 · 역암**
```
흰 책상 위에 암석 세 덩어리가 나란히: 왼쪽 매끈한 회색 이암, 가운데 모래알이 보이는 노란빛 사암, 오른쪽 동글동글한 자갈이 박힌 역암. 각 암석 앞에 진흙·모래·자갈이 조금씩 놓여 있다.
```

**03b — 돋보기로 관찰**
```
과학이가 돋보기로 사암 표면을 들여다본다. 돋보기 속에 모래 알갱이가 크게 확대되어 보인다.
```

**03c — 손으로 만져 보기**
```
차차가 한 손으로 매끈한 이암을 쓰다듬고 다른 손으로 울퉁불퉁한 역암을 만지며 비교한다. 두 암석 표면의 차이가 분명하게.
```

### 04 화석

> **과학 핵심**: 생물의 몸체나 흔적이 암석에 남은 것이 화석. 생물이 죽어 빨리 묻히고 오랜 시간이 지나 만들어짐. 산호 화석이 나오면 옛날에 따뜻하고 얕은 바다였음.

**04a — 여러 가지 화석**
```
자연사 박물관 진열장 안에 삼엽충, 암모나이트, 고사리 잎, 물고기 화석, 공룡 발자국 화석이 나란히 전시되어 있다. 이름표 없이. 과학이와 차차가 유리 너머로 본다.
```

**04b — 화석이 만들어지는 과정**
```
왼쪽에서 오른쪽으로 네 단계 단면: 물고기가 죽어 바닥에 가라앉음 → 진흙에 빨리 묻힘 → 위에 지층이 여러 겹 쌓이고 뼈가 돌처럼 굳음 → 땅이 깎여 화석이 드러나 아이들이 발견. 단계 사이 굵은 화살표.
```

**04c — 산호 화석과 옛날 바다**
```
화면을 반으로 나눈 그림. 왼쪽: 산 위 바위에서 산호 화석을 발견한 과학이. 오른쪽: 같은 곳의 아주 먼 옛날 모습, 따뜻하고 얕은 바다에 알록달록 산호와 물고기.
```

### 05 씨와 싹 트는 조건

> **과학 핵심**: 씨는 크기와 모양이 다양함(강낭콩, 사과, 호두, 봉숭아). 씨가 싹 트려면 물과 알맞은 온도가 필요함. 싹 틀 때 뿌리가 먼저 나옴.

**05a — 여러 가지 씨**
```
흰 책상 위에 여러 씨가 크기 순서로 나란히: 호두, 강낭콩, 옥수수 알, 사과씨, 해바라기씨, 봉숭아씨(아주 작음). 차차가 돋보기로 작은 씨를 본다.
```

**05b — 물을 준 씨와 안 준 씨**
```
화면을 반으로 나눈 비교. 왼쪽 접시: 젖은 솜 위 강낭콩들이 부풀고 뿌리가 나옴. 오른쪽 접시: 마른 솜 위 강낭콩들이 그대로. 과학이가 분무기를 들고 있다.
```

**05c — 뿌리가 먼저**
```
강낭콩 한 알을 아주 가까이 확대: 껍질이 벌어지며 하얀 뿌리가 먼저 아래로 뻗어 나온다. 촉촉한 흙과 물방울.
```

### 06 떡잎과 본잎

> **과학 핵심**: 흙 위로 떡잎 두 장이 나오고, 떡잎 사이로 본잎이 나옴. 물을 주면 잎이 많아지고 줄기가 길어짐.

**06a — 떡잎 두 장**
```
화분 흙 위로 강낭콩 싹이 올라와 통통한 떡잎 두 장을 펼친 모습을 가까이. 과학이가 물뿌리개로 물을 준다.
```

**06b — 떡잎 사이로 본잎**
```
강낭콩 싹의 떡잎 두 장 사이로 하트 모양의 초록 본잎이 펼쳐진다. 떡잎은 조금 쪼그라들었다.
```

**06c — 쑥쑥 자라요**
```
창가에 화분 세 개가 왼쪽에서 오른쪽으로: 작은 싹 → 잎 몇 장 → 잎이 많고 키가 큰 강낭콩. 화분 사이 화살표. 차차가 키를 재 본다.
```

### 07 꽃과 열매

> **과학 핵심**: 강낭콩은 꽃이 피고 진 자리에 꼬투리(열매)가 생기고, 꼬투리 속에 새 씨가 들어 있음.

**07a — 강낭콩 꽃**
```
강낭콩 줄기에 핀 작은 흰색·연보라색 꽃들을 가까이. 벌 한 마리가 날아온다.
```

**07b — 꼬투리가 열려요**
```
꽃이 진 자리에 길쭉한 초록 꼬투리가 여러 개 매달려 있다. 차차가 꼬투리를 손가락으로 가리킨다.
```

**07c — 꼬투리 속 새 씨**
```
과학이가 잘 익은 꼬투리를 열어 손바닥 위에 강낭콩 씨 여러 알을 보여 준다. 꼬투리 속에 줄지어 있던 씨가 보인다.
```

### 08 식물의 한살이와 한해살이 · 여러해살이

> **과학 핵심**: 씨 → 싹 → 잎과 줄기 → 꽃 → 열매 → 씨. 한 해만 살고 씨를 남기면 한해살이(강낭콩, 벼), 여러 해 살며 열매를 맺으면 여러해살이(사과나무, 감나무).

**08a — 한살이 순환**
```
흰 배경에 강낭콩의 한살이를 둥근 고리로: 씨 → 싹 → 잎과 줄기 → 꽃 → 꼬투리 → 다시 씨. 단계 사이 굵은 초록 화살표, 글자 없이.
```

**08b — 한해살이: 벼**
```
가을 황금빛 논에 고개 숙인 벼 이삭. 옆 작은 그림 동그라미 속에 같은 논의 봄 모내기 모습. 과학이와 차차가 논두렁에 서 있다.
```

**08c — 여러해살이: 사과나무**
```
화면을 반으로 나눈 같은 사과나무: 왼쪽 봄에 하얀 사과꽃이 핀 모습, 오른쪽 가을에 빨간 사과가 주렁주렁 열린 모습. 나무는 크고 굵은 줄기 그대로.
```
