### 01 잎 분류와 풀 · 나무

> **과학 핵심**: 잎의 모양·가장자리로 기준을 세워 분류함. 풀은 줄기가 가늘고, 나무는 줄기가 굵고 단단함.

**01a — 잎 분류하기**
```
흰 책상 위 두 무리로 나눈 잎들. 왼쪽 무리: 가장자리가 톱니 모양인 잎(단풍잎, 벚나무잎, 느티나무잎). 오른쪽 무리: 가장자리가 매끈한 잎(감나무잎, 목련잎, 은행잎). 차차가 잎을 옮긴다.
```

**01b — 들의 풀**
```
들판에 민들레, 강아지풀, 토끼풀이 자란다. 과학이가 쪼그려 앉아 가느다란 풀줄기를 살펴본다.
```

**01c — 산의 나무**
```
산속 숲에 굵고 단단한 줄기의 소나무와 참나무. 차차가 두 팔로 굵은 나무줄기를 안아 본다.
```

### 02 물에 사는 식물

> **과학 핵심**: 부레옥잠은 잎자루의 공기주머니로 물에 떠서 삶. 수련은 잎이 물에 뜨고, 검정말은 물속에 잠겨 삶. 부들과 갈대는 물가에 뿌리를 내림.

**02a — 부레옥잠과 공기주머니**
```
연못 위에 떠 있는 부레옥잠. 통통하게 부푼 잎자루를 잘라 본 단면이 오른쪽 둥근 확대 그림 속에 스펀지처럼 공기 구멍이 많게 보인다.
```

**02b — 수련**
```
연못 수면에 둥근 수련 잎이 떠 있고 분홍 수련꽃이 피어 있다. 물 위에는 작은 개구리밥도 떠 있다.
```

**02c — 물속과 물가의 식물**
```
연못 단면 그림: 물속에 검정말과 나사말이 잠겨 흔들리고, 물가에는 키 큰 부들과 갈대가 뿌리를 내리고 서 있다. 과학이와 차차가 물가에서 관찰.
```

### 03 사막과 추운 곳의 식물

> **과학 핵심**: 선인장은 굵은 줄기에 물을 저장하고 잎이 가시로 되어 물이 덜 빠져나감. 추운 곳의 식물은 키가 작아 바람을 피함.

**03a — 사막의 선인장**
```
햇볕이 쨍쨍한 사막에 굵고 통통한 선인장이 서 있다. 줄기의 뾰족한 가시가 잘 보이게 가까이.
```

**03b — 선인장 줄기 속**
```
실험 책상 위에서 과학이가 장갑을 끼고 자른 선인장 줄기 단면을 보여 준다. 속이 촉촉하고 물기가 많다.
```

**03c — 추운 곳의 식물**
```
차갑고 바람 부는 북쪽 땅에 키 작은 꽃과 이끼가 땅에 바짝 붙어 자란다. 멀리 눈 덮인 산.
```

### 04 식물을 흉내 낸 생활용품

> **과학 핵심**: 연잎(물이 스며들지 않음) → 물이 스며들지 않는 옷. 단풍나무 열매(빙글빙글) → 헬리콥터 날개. 도꼬마리 가시 → 찍찍이.

**04a — 연잎과 물이 스며들지 않는 옷**
```
화면을 반으로 나눈 그림. 왼쪽: 연잎 위에서 물방울이 동그랗게 굴러 떨어짐. 오른쪽: 비 오는 날 우비를 입은 차차, 우비 위 빗방울이 또르르 굴러떨어진다. 사이에 화살표.
```

**04b — 단풍나무 열매와 헬리콥터**
```
왼쪽: 날개 달린 단풍나무 열매가 빙글빙글 돌며 떨어지는 모습(회전 화살표). 오른쪽: 하늘의 헬리콥터 날개. 사이에 화살표.
```

**04c — 도꼬마리와 찍찍이**
```
왼쪽: 갈고리 가시가 있는 도꼬마리 열매가 과학이 바지에 붙은 모습. 오른쪽: 운동화의 찍찍이 클로즈업. 사이에 화살표.
```

### 05 물의 세 가지 상태

> **과학 핵심**: 얼음(고체), 물(액체), 수증기(기체). 수증기는 눈에 보이지 않음.

**05a — 얼음 · 물 · 수증기**
```
실험 책상 위 세 가지: 왼쪽 접시의 얼음덩어리, 가운데 물이 담긴 컵, 오른쪽 끓고 있는 투명 주전자(주둥이 바로 앞은 투명하게 비어 있고 조금 떨어진 곳에 하얀 김). 과학이와 차차가 비교.
```

**05b — 얼면 부피가 늘어요**
```
왼쪽에서 오른쪽으로: 시험관에 물을 넣고 높이를 고무줄로 표시 → 냉동실 → 얼음이 된 시험관, 얼음 높이가 고무줄보다 위로 올라감. 단계 사이 화살표.
```

**05c — 얼어도 무게는 그대로**
```
양팔저울 양쪽에 같은 시험관: 한쪽은 물, 다른 쪽은 그 물이 언 얼음. 저울이 수평. 차차가 신기해한다.
```

### 06 얼고 녹을 때 부피

> **과학 핵심**: 물이 얼면 부피가 늘어나 수도관이 터지거나 페트병이 볼록해짐. 얼음이 녹으면 부피가 줄어듦. 무게는 변하지 않음.

**06a — 겨울 수도관**
```
눈 쌓인 겨울날 집 밖 수도관이 갈라져 얼음이 삐져나와 있다. 과학이가 장갑 낀 손으로 가리킨다.
```

**06b — 녹으면 부피가 줄어요**
```
왼쪽에서 오른쪽으로: 얼음이 가득한 시험관(높이 표시) → 녹아서 물이 되자 높이가 표시보다 낮아짐. 화살표.
```

**06c — 꽁꽁 언 페트병**
```
냉동실에서 꺼낸 물이 꽁꽁 언 페트병이 볼록하게 부풀어 있다. 옆에 얼리기 전 반듯한 페트병을 나란히.
```

### 07 증발과 끓음

> **과학 핵심**: 증발: 물 표면에서 물이 천천히 수증기로 변함(빨래, 오징어 말리기). 끓음: 물 표면과 물속에서 수증기로 빠르게 변함(기포).

**07a — 빨래와 오징어 말리기**
```
햇볕 좋은 마당에 빨래가 바람에 마르고, 옆 바닷가 마을에는 오징어가 줄줄이 널려 마르고 있다.
```

**07b — 물이 줄어들어요**
```
창가에 같은 비커 세 개가 왼쪽에서 오른쪽으로: 물이 가득 → 조금 줄어듦 → 많이 줄어듦. 처음 높이에 점선. 해가 비친다.
```

**07c — 보글보글 끓음**
```
투명한 냄비에서 물이 끓어 물속 바닥에서부터 커다란 기포가 보글보글 올라온다. 보안경 쓴 과학이가 관찰.
```

### 08 응결과 물의 여행

> **과학 핵심**: 응결: 수증기가 차가운 물체 표면에서 물로 변함(차가운 컵 물방울, 이슬). 물의 여행: 바다·강의 물이 증발 → 구름 → 비·눈 → 강·바다.

**08a — 차가운 컵의 물방울**
```
얼음물이 담긴 유리컵 바깥 표면에 물방울이 송골송골 맺혀 흘러내린다. 차차가 손가락으로 물방울을 만져 본다.
```

**08b — 이슬과 안경 김**
```
화면을 반으로: 왼쪽 맑은 아침 거미줄과 풀잎에 맺힌 이슬방울, 오른쪽 겨울에 따뜻한 교실로 들어온 과학이의 안경에 하얗게 서린 김.
```

**08c — 물의 여행**
```
한 장의 큰 풍경 그림: 바다에서 물이 증발해 올라가는 화살표 → 하늘의 구름 → 산에 내리는 비와 눈 → 강을 따라 흘러 → 다시 바다로. 둥근 흐름 화살표, 글자 없이.
```
