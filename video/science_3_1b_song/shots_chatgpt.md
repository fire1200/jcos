## 2. 장면별 프롬프트

새로 그릴 장면만 프롬프트가 있습니다. 받은 그림은 **파일 이름(예: `03a.png`)으로 바꿔** 압축해 올려 주세요. 압축 파일 이름에 **과학3-1하**를 꼭 넣어 주세요.

### 01 자석이 끌어당기는 물체와 극

> **과학 핵심**: 자석은 철로 된 물체를 끌어당김. 클립이 많이 붙는 양 끝이 극. N극(빨강)·S극(파랑).

> **기존 그림 사용**: 이미 받은 그림을 그대로 씁니다 (새로 그리지 않음).

### 02 사이에 물체가 있어도

> **과학 핵심**: 자석과 철 사이에 종이·유리·물 같은 물체가 있어도 자석은 철을 끌어당김.

**02a — 종이 너머로**
```
얇은 종이를 두 손으로 팽팽히 든 차차. 종이 위에 클립 하나가 있고, 과학이가 종이 아래에서 빨강·파랑 막대자석을 움직이자 클립이 종이 위에서 따라 움직인다. 종이 아래 자석이 살짝 비쳐 보이게.
```

**02b — 유리 너머로**
```
투명한 유리판을 사이에 두고, 한쪽에 클립들이 유리에 붙어 매달려 있고 반대쪽에서 과학이가 막대자석을 대고 있다. 유리 너머로 클립이 끌려온 모습이 분명하게.
```

**02c — 물속의 클립**
```
물이 담긴 투명한 컵 바닥에 클립이 있고, 차차가 컵 바깥 옆면에 자석을 대고 위로 올리자 물속 클립이 컵 벽을 따라 위로 끌려 올라온다.
```

### 03 같은 극·다른 극과 나침반

> **과학 핵심**: 같은 극은 밀어 내고 다른 극은 끌어당김. 물에 띄운 자석과 나침반 바늘의 N극은 북쪽.

> **기존 그림 사용**: 이미 받은 그림을 그대로 씁니다 (새로 그리지 않음).

### 04 생활 속 자석

> **과학 핵심**: 자석은 생활 곳곳에 쓰임: 냉장고 문, 메모 자석, 자석 필통, 가방 자석 단추, 클립 통, 자석 드라이버.

**04a — 냉장고 문과 메모 자석**
```
부엌의 하얀 냉장고. 문 가장자리 고무 패킹이 착 붙어 닫혀 있고, 문에는 알록달록한 메모 자석이 그림 종이를 붙잡고 있다. 차차가 메모 자석을 하나 붙이고 있다.
```

**04b — 자석 필통과 가방 단추**
```
교실 책상 위에 뚜껑이 자석으로 탁 닫히는 필통, 옆에 자석 단추로 닫히는 책가방. 과학이가 필통 뚜껑을 닫는 순간.
```

**04c — 클립 통과 자석 드라이버**
```
책상 위 자석 클립 통 입구에 클립들이 붙어 있고, 옆에서 과학이가 자석 드라이버 끝에 나사를 붙여 들어 보인다.
```

### 05 지구의 모습

> **과학 핵심**: 지구는 둥근 공 모양, 바다가 육지보다 넓음, 바닷물은 짬, 공기가 지구를 둘러쌈.

> **기존 그림 사용**: 이미 받은 그림을 그대로 씁니다 (새로 그리지 않음).

### 06 지구 표면의 여러 모습

> **과학 핵심**: 지구 표면에는 산, 들, 강, 호수, 바다, 사막, 화산, 폭포 등 여러 모습이 있음. 강물과 호숫물은 짜지 않음.

**06a — 산과 들, 강과 호수**
```
높은 곳에서 내려다본 넓은 풍경: 푸른 산맥, 그 아래 초록 들판, 구불구불 흐르는 강, 잔잔한 호수. 언덕 위에서 과학이와 차차가 바라본다.
```

**06b — 사막, 화산, 폭포**
```

```

**06c — 강물과 바닷물 비교**
```
화면을 반으로 나눈 비교. 왼쪽: 맑은 강가에서 과학이가 물을 손으로 떠서 맛보고 괜찮다는 표정. 오른쪽: 바닷가에서 차차가 바닷물을 맛보고 짜서 찡그린 표정.
```

> **과학 핵심**: 지구에는 물과 공기가 있고 온도가 알맞아 생물이 살 수 있음. 달에는 공기가 없어 우주복과 산소통이 필요함.
