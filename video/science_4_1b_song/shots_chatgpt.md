### 01 무게란

> **과학 핵심**: 무게는 지구가 물체를 끌어당기는 힘의 크기. 용수철에 물체를 매달면 늘어남.

```
사과나무에서 사과가 떨어지는 장면, 사과 아래로 땅을 향한 굵은 화살표. 나무 아래 과학이와 차차가 올려다본다.
```

**01b — 무거운 것과 가벼운 것**
```
과학이가 두 손으로 무거운 책가방을 힘겹게 들고, 차차는 손가락 끝에 깃털을 가볍게 들고 웃는다.
```

**01c — 용수철에 매달아요**
```
실험대 스탠드에 매단 용수철에 추 하나를 걸자 용수철이 아래로 늘어난다. 늘어난 길이를 옆에 점선으로 표시(숫자 없이).
```

### 02 용수철저울

> **과학 핵심**: 무게가 일정하게 늘어나면 용수철이 늘어난 길이도 일정하게 늘어남. 용수철저울은 영점을 맞추고 눈높이에서 눈금을 읽음. 단위 g중, N.

**02a — 추가 늘면 길이도 늘어요**
```
스탠드에 같은 용수철 세 개가 나란히: 왼쪽 추 없음, 가운데 추 1개, 오른쪽 추 2개. 늘어난 길이가 같은 간격으로 늘어난 것이 보이게 가로 점선.
```

**02b — 영점 맞추기**
```
차차가 용수철저울 위쪽의 영점 조절 나사를 돌려 표시 바늘을 맨 위 눈금에 맞추는 모습을 가까이. 눈금에는 숫자 없이 줄만.
```

**02c — 눈높이로 읽기**
```
과학이가 용수철저울에 필통을 매달고 몸을 낮춰 표시 바늘과 눈높이를 맞춰 읽는다. 눈과 바늘을 잇는 점선.
```

### 03 수평잡기

> **과학 핵심**: 받침점에서 같은 거리에 같은 무게를 놓으면 수평. 무거운 물체는 받침점에 가깝게, 가벼운 물체는 멀게 놓아야 수평.

**03a — 같은 무게, 같은 거리**
```
삼각형 받침점 위에 긴 나무판. 양쪽 끝에서 같은 거리에 같은 나무토막을 하나씩 올려 나무판이 수평. 받침점에서 같은 거리를 점선으로.
```

**03b — 무거운 쪽은 가까이**
```
같은 받침점과 나무판. 왼쪽에는 나무토막 두 개를 받침점 가까이, 오른쪽에는 한 개를 멀리 올려 수평. 차차가 손을 떼고 놀란 표정.
```

**03c — 시소 수평잡기**
```
놀이터 시소. 몸집 큰 아빠는 받침점 가까이 앉고, 차차는 반대쪽 끝에 앉아 시소가 수평이다. 과학이가 옆에서 엄지를 든다.
```

### 04 양팔저울과 생활 속 저울

> **과학 핵심**: 양팔저울에 물체와 클립을 올려 무게를 비교함. 생활 속에는 체중계, 가정용 저울, 전자저울이 있음.

**04a — 양팔저울로 비교**
```
실험 책상 위 양팔저울. 왼쪽 접시에 지우개, 오른쪽 접시에 클립 여러 개를 올려 수평. 과학이가 클립을 하나씩 올린다.
```

**04b — 체중계와 가정용 저울**
```
화면을 반으로 나눈 그림. 왼쪽: 욕실 체중계 위에 선 과학이. 오른쪽: 부엌 가정용 저울 위 밀가루 그릇과 저울을 보는 차차. 저울 화면과 눈금에 숫자 없이.
```

**04c — 전자저울**
```
우체국 창구의 전자저울 위에 편지 봉투가 올려져 있다. 저울 화면은 빈 칸. 차차가 편지를 올려놓는다.
```

### 05 혼합물

> **과학 핵심**: 여러 물질이 섞여 있는 것이 혼합물. 섞여도 각 물질의 성질은 변하지 않음(팥빙수 속 팥은 팥 맛). 필요한 물질을 얻으려고 분리함(사금).

**05a — 팥빙수**
```
그릇에 담긴 팥빙수를 가까이: 하얀 얼음, 단팥, 떡, 과일 조각이 각각 그대로 보인다. 과학이가 숟가락으로 팥만 떠서 맛본다.
```

**05b — 콩 · 팥 · 좁쌀 혼합물**
```
큰 그릇에 콩, 팥, 좁쌀이 섞여 있는 모습을 위에서 가까이. 세 가지 알갱이의 크기 차이가 분명하게.
```

**05c — 사금 채취**
```
맑은 냇가에서 차차가 넓은 접시로 모래를 물에 흔들어 거르자 접시 바닥에 반짝이는 작은 금 알갱이가 남는다.
```

### 06 체와 자석으로 분리

> **과학 핵심**: 알갱이 크기가 다르면 체로 분리. 철로 된 물질은 자석으로 분리. 재활용품도 자석으로 철 캔을 분리함.

**06a — 체로 분리하기**
```
과학이가 구멍 크기가 다른 체를 두 개 겹쳐 흔든다: 위 체에 콩, 아래 체에 팥, 맨 아래 그릇에 좁쌀이 모인다.
```

**06b — 자석으로 분리하기**
```
철 구슬과 플라스틱 구슬이 섞인 그릇 위에 차차가 빨강·파랑 막대자석을 대자 은색 철 구슬만 자석에 붙어 올라온다. 알록달록 플라스틱 구슬은 그릇에 남는다.
```

**06c — 재활용 센터의 자석**
```
재활용 센터 컨베이어 벨트 위 캔들. 위에 매달린 커다란 자석이 철 캔만 끌어 올리고 알루미늄 캔은 그대로 지나간다.
```

### 07 거름

> **과학 핵심**: 소금과 모래 혼합물을 물에 넣으면 소금만 녹음. 거름종이와 깔때기로 거르면 모래는 거름종이에 남고 소금물은 아래로 빠짐.

**07a — 소금을 녹여요**
```
투명 비커 속 소금과 모래 혼합물에 차차가 물을 붓고 유리 막대로 젓는다. 하얀 소금이 녹아 사라지고 모래는 바닥에 남는다.
```

**07b — 깔때기로 거르기**
```
스탠드에 깔때기를 걸고 거름종이를 접어 넣었다. 과학이가 유리 막대를 따라 혼합물을 붓자 맑은 소금물이 아래 비커로 떨어진다.
```

**07c — 거름종이에 남은 모래**
```

```
