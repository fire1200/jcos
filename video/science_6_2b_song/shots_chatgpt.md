### 01 연소

> **과학 핵심**: 물질이 산소와 빠르게 반응해 빛과 열을 내는 것이 연소. 연소의 조건은 탈 물질, 산소, 발화점 이상의 온도.

**01a — 초와 알코올이 탈 때**
```
실험대 위에 타는 초와 알코올램프. 불꽃 둘레로 빛(노란 선)과 열(아지랑이)이 퍼진다. 보안경 쓴 과학이와 차차, 어른 선생님이 함께.
```

**01b — 촛불 관찰**
```
촛불 하나를 가까이: 위로 길쭉한 불꽃, 심지, 불꽃 아래 녹아 고인 촛농, 흘러내린 촛농.
```

**01c — 연소의 세 가지 조건**
```
세 칸 나란히: 장작(탈 물질), 바람 줄기와 공기(산소), 온도계가 높이 올라간 뜨거운 철판(온도). 세 칸에서 가운데 모닥불로 굵은 화살표가 모인다. 글자 없이.
```

### 02 발화점과 산소

> **과학 핵심**: 물질이 불에 직접 닿지 않아도 발화점 이상으로 온도가 높아지면 불이 붙음. 산소가 충분해야 오래 탐.

**02a — 발화점 실험**
```
얇은 철판 위 한쪽에 성냥 머리, 다른 쪽에 나무 조각. 철판 가운데 아래를 알코올램프로 가열하자 성냥 머리에만 먼저 불이 붙는다. 장갑 낀 어른의 손, 보안경 쓴 아이들.
```

**02b — 크기가 다른 병**
```
같은 촛불 두 개에 크기가 다른 투명 집기병을 덮었다. 작은 병 속 촛불은 꺼져 가고 큰 병 속 촛불은 아직 탄다.
```

**02c — 성냥 긋기**
```
어른이 성냥갑 옆면에 성냥을 그어 불을 붙이는 손을 가까이. 아이들은 한 걸음 떨어져 본다.
```

### 03 연소 후에 생기는 물질

> **과학 핵심**: 초가 연소하면 물과 이산화 탄소가 생김(푸른색 염화 코발트 종이가 붉게, 석회수가 뿌옇게).

**03a — 물이 생겨요**
```
촛불을 덮은 집기병 안쪽 벽에 작은 물방울이 맺혀 있다. 옆에서 푸른색 종이가 물방울에 닿아 분홍빛으로 변한다.
```

**03b — 이산화 탄소가 생겨요**
```
촛불이 꺼진 집기병에 맑은 석회수를 붓고 흔들자 우윳빛으로 뿌옇게 변한다. 장갑 낀 차차.
```

**03c — 생활 속 연소**
```
가스레인지의 파란 불꽃 위 냄비와, 캠핑장에서 어른과 함께 피운 모닥불을 화면 반으로 나눠.
```

### 04 소화와 화재 안전

> **과학 핵심**: 연소의 조건을 하나 이상 없애 불을 끄는 것이 소화(탈 물질 없애기, 산소 막기, 온도 낮추기). 불이 나면 알리고, 젖은 수건으로 코와 입을 막고 낮은 자세로 계단으로 대피, 119 신고.

**04a — 촛불을 끄는 세 방법**
```
세 칸 나란히: 집기병으로 덮기(산소 막기), 분무기로 물 뿌리기(온도 낮추기), 가위로 심지 자르기(탈 물질 없애기).
```

**04b — 소화기 사용**
```
소방관이 빨간 소화기(글자 없이)의 안전핀을 뽑고 호스를 불 쪽으로 향해 분말을 뿌리는 모습. 아이들은 뒤에서 배운다.
```

**04c — 화재 대피**
```
연기가 위쪽에 낀 복도에서 과학이와 차차, 친구들이 젖은 수건으로 코와 입을 막고 몸을 낮춰 계단 쪽으로 대피한다. 엘리베이터 문에는 빨간 엑스 표시(글자 없이), 초록 비상구 사람 그림.
```

### 05 뼈와 근육

> **과학 핵심**: 뼈는 몸의 형태를 만들고 몸을 지탱하며 내부 기관을 보호함. 근육이 줄어들거나 늘어나면서 뼈를 움직임.

**05a — 뼈 모형**
```
과학실에 세워 둔 사람 뼈 모형(귀엽고 깔끔한 교구)을 과학이와 차차가 살펴본다. 무섭지 않게 밝은 교실.
```

**05b — 팔 근육 모형**
```
막대 두 개(뼈)와 고무풍선(근육)으로 만든 팔 모형. 화면을 반으로 나눠 왼쪽 풍선에 바람을 넣자 팔 모형이 굽혀지고, 오른쪽 바람을 빼자 펴진다.
```

**05c — 공을 차는 다리**
```
축구공을 차는 과학이, 다리 부분만 엑스레이처럼 투명하게 뼈와 근육이 단순한 선으로 보인다. 귀엽고 깔끔하게.
```

### 06 소화와 호흡

> **과학 핵심**: 음식물은 입 → 식도 → 위 → 작은창자 → 큰창자 → 항문을 지나며 소화됨. 코 → 기관 → 기관지 → 폐로 숨을 쉬며 산소를 받아들이고 이산화 탄소를 내보냄.

**06a — 소화 기관**
```
사과를 먹는 어린이 몸 실루엣 안에 소화 기관을 단순하고 귀엽게: 입, 식도, 위, 꼬불꼬불한 작은창자, 둘레의 큰창자. 음식물이 지나가는 순서대로 노란 화살표. 글자 없이.
```

**06b — 호흡 기관**
```
숨을 크게 들이쉬는 어린이 몸 실루엣 안에 코, 기관, 나뭇가지처럼 갈라진 기관지, 양쪽 폐. 들어가는 파란 화살표, 나오는 회색 화살표.
```

**06c — 폐 모형**


### 07 순환과 배설

> **과학 핵심**: 심장이 펌프 작용을 해 혈액이 혈관을 따라 온몸을 돎(순환). 콩팥이 혈액 속 노폐물을 걸러 오줌으로 내보냄(배설).

**07a — 심장과 혈관**

**07b — 순환 모형 실험**

**07c — 콩팥과 방광**

### 08 감각 기관과 자극, 반응

> **과학 핵심**: 눈, 귀, 코, 혀, 피부가 자극을 받아들이고, 신경계가 자극을 전달해 뇌가 명령을 내림. 운동하면 체온이 오르고 맥박과 호흡이 빨라짐.

**08a — 다섯 감각 기관**
```
다섯 칸: 꽃을 보는 눈, 새소리를 듣는 귀, 갓 구운 빵 냄새를 맡는 코, 사과를 맛보는 혀, 시냇물을 만지는 손(피부). 칸마다 과학이나 차차.
```

**08b — 공을 받아요**
```
날아오는 공 → 공을 보는 차차의 눈 → 머릿속 뇌(빛나는 단순한 그림) → 팔로 이어진 빛나는 신경 선 → 공을 잡는 손. 경로를 따라 화살표.
```

**08c — 운동 뒤 우리 몸**
```
줄넘기를 마친 과학이가 땀을 닦으며 손목에 손가락을 대고 맥박을 잰다. 볼이 빨갛고 숨이 차다. 옆에 운동장.
```
